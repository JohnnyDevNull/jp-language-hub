Swedish nouns form the indefinite plural in several ways. Gender and word
ending provide useful clues, but they do not predict every noun. For reliable
use, learn a noun with its gender and plural.

## Main plural patterns

Traditional descriptions group Swedish nouns by their plural endings:

| Pattern | Typical example | Indefinite plural | Definite plural |
| --- | --- | --- | --- |
| <span lang="sv">-or</span> | <span lang="sv">en flicka</span> | <span lang="sv">flickor</span> | <span lang="sv">flickorna</span> |
| <span lang="sv">-ar</span> | <span lang="sv">en bil</span> | <span lang="sv">bilar</span> | <span lang="sv">bilarna</span> |
| <span lang="sv">-er</span> | <span lang="sv">en telefon</span> | <span lang="sv">telefoner</span> | <span lang="sv">telefonerna</span> |
| <span lang="sv">-n</span> | <span lang="sv">ett äpple</span> | <span lang="sv">äpplen</span> | <span lang="sv">äpplena</span> |
| no ending | <span lang="sv">ett hus</span> | <span lang="sv">hus</span> | <span lang="sv">husen</span> |

These are learning patterns, not rules that remove the need to learn individual
noun forms.

## Useful clues

- Many en-words ending in unstressed <span lang="sv">-a</span> use
  <span lang="sv">-or</span>: <span lang="sv">en vecka → veckor</span>.
- Many common en-words use <span lang="sv">-ar</span>:
  <span lang="sv">en stol → stolar</span>.
- Many international words use <span lang="sv">-er</span>:
  <span lang="sv">en station → stationer</span>.
- Many ett-words ending in a vowel use <span lang="sv">-n</span>:
  <span lang="sv">ett äpple → äpplen</span>.
- Many ett-words ending in a consonant have no indefinite plural ending:
  <span lang="sv">ett barn → barn</span>.

## Stem changes and irregular forms

Some frequent nouns change internally or use an irregular plural:

- <span lang="sv">en bok → böcker → böckerna</span>
- <span lang="sv">en man → män → männen</span>
- <span lang="sv">en hand → händer → händerna</span>
- <span lang="sv">ett öga → ögon → ögonen</span>

These forms should be learned as complete noun paradigms rather than forced into
a regular ending pattern.

## Number after numerals

Use the indefinite plural form after numbers greater than one:

- <span lang="sv">en bil</span>
- <span lang="sv">två bilar</span>
- <span lang="sv">tre hus</span>

The absence of a visible ending in <span lang="sv">tre hus</span> does not make
the noun singular; number and context show that it is plural.

## Direct comparison

| Language | Singular | Plural |
| --- | --- | --- |
| <span lang="de">🇩🇪 Deutsch</span> | <span lang="de">ein Haus</span> | <span lang="de">Häuser</span> |
| <span lang="en">🇬🇧 English</span> | <span lang="en">a house</span> | <span lang="en">houses</span> |
| <span lang="sv">🇸🇪 Svenska</span> | <span lang="sv">ett hus</span> | <span lang="sv">hus</span> |

Like German, Swedish has several plural patterns and stem changes. English
<span lang="en">-s</span> is therefore not a safe model for Swedish.

<MistakeBox>
Do not infer that all en-words take one ending and all ett-words another:

<span lang="sv">en bil → bilar</span>, but
<span lang="sv">en telefon → telefoner</span>;  
<span lang="sv">ett äpple → äpplen</span>, but
<span lang="sv">ett hus → hus</span>.
</MistakeBox>

<MemoryTip>
Learn the four forms, not a guessed group number:
<span lang="sv"><strong>ett äpple — äpplet — äpplen — äpplena</strong></span>.
The pattern will become familiar through repeated examples.
</MemoryTip>
