Swedish relative clauses are easier than German ones: the relative pronoun does
not change with gender, number, or case. In almost every everyday sentence the
word is <span lang="sv">som</span>.

## som is the default

<span lang="sv">Som</span> is invariable. It works for people and things, and
as both subject and object of the relative clause:

- <span lang="sv">Mannen som bor här heter Erik.</span> — *The man who lives
  here is called Erik.*
- <span lang="sv">Boken som jag läste var bra.</span> — *The book that I read
  was good.*
- <span lang="sv">Barnen som vi träffade var trevliga.</span> — *The children
  we met were nice.*

Compare the German equivalents, which change form:
<span lang="de">der Mann, **der** hier wohnt</span> against
<span lang="de">das Buch, **das** ich gelesen habe</span>. Swedish keeps
<span lang="sv">som</span> in both.

## The preposition goes to the end

This is the rule that German speakers need most. <span lang="sv">Som</span>
can never follow a preposition. The preposition stays behind in the relative
clause, at the end:

| Swedish | German |
| --- | --- |
| <span lang="sv">huset som jag bor i</span> | <span lang="de">das Haus, in dem ich wohne</span> |
| <span lang="sv">bussen som vi väntar på</span> | <span lang="de">der Bus, auf den wir warten</span> |
| <span lang="sv">personen som jag talade med</span> | <span lang="de">die Person, mit der ich gesprochen habe</span> |

<RuleBox title="Rule">
	Never write a preposition directly before <span lang="sv">som</span>. Put it
	at the end of the relative clause instead:
	<span lang="sv">❌ huset i som jag bor</span>,
	<span lang="sv">✅ huset som jag bor i</span>.
</RuleBox>

## som can be dropped as an object

When <span lang="sv">som</span> is the **object** of the relative clause, it
may be left out, just as English can drop *that*:

- <span lang="sv">Boken (som) jag läste var bra.</span>

When it is the **subject**, it must stay:

- <span lang="sv">Mannen som bor här</span> — not
  <span lang="sv">❌ Mannen bor här</span>, which is a different sentence
  entirely.

## vilket refers to a whole clause

<span lang="sv">Vilken / vilket / vilka</span> is the inflected relative
pronoun. In modern everyday Swedish you mainly need one of its uses:
<span lang="sv">vilket</span> referring back to an entire preceding clause,
where English uses *which*:

- <span lang="sv">Han kom för sent, vilket irriterade alla.</span> — *He
  arrived late, which annoyed everyone.*
- <span lang="sv">Det regnade hela veckan, vilket vi inte hade väntat oss.</span>

Note that German normally uses <span lang="de">was</span> here, not a form of
<span lang="de">welcher</span>.

After a preposition, <span lang="sv">vilken</span> is the form that is
grammatically possible, but the result is formal and written:
<span lang="sv">ett problem för vilket det inte finns någon lösning</span>. In
speech, restructure the sentence instead.

## vars for "whose"

<span lang="sv">Vars</span> is the genitive relative pronoun. It is
invariable, takes no article after it, and belongs to a somewhat formal
register:

- <span lang="sv">en författare vars böcker jag älskar</span> — *an author
  whose books I love*

With a plural antecedent, formal Swedish uses <span lang="sv">vilkas</span>.
In everyday speech, people usually avoid both and rebuild the sentence with
<span lang="sv">som</span> and a possessive.

## där and dit for places

For a place, <span lang="sv">där</span> often replaces
<span lang="sv">som … i</span>, and <span lang="sv">dit</span> covers
direction:

- <span lang="sv">staden där jag bor</span> = <span lang="sv">staden som jag
  bor i</span>
- <span lang="sv">staden dit jag flyttade</span> — *the city I moved to*

## Word order inside the relative clause

A relative clause is a subordinate clause, so it follows the subordinate-clause
pattern: <span lang="sv">inte</span> and similar adverbs come **before** the
verb.

- <span lang="sv">Mannen som inte bor här</span>
- <span lang="sv">Boken som jag aldrig läste</span>

See [BIFF and subordinate clauses](../../../sentence-structure/swedish/biff/).

<MemoryTip>
Two sentences carry most of what you need:
<span lang="sv"><strong>Bussen som vi väntar på är sen.</strong></span> —
preposition at the end. <span lang="sv"><strong>Han kom sent, vilket
irriterade alla.</strong></span> — <span lang="sv">vilket</span> for a whole
clause.
</MemoryTip>

## Common mistakes

<MistakeBox title="Common mistakes">
	- ❌ <span lang="sv">huset i som jag bor</span>
	  ✅ <span lang="sv">huset som jag bor i</span>
	- ❌ <span lang="sv">Mannen vilken bor här</span>
	  ✅ <span lang="sv">Mannen som bor här</span>
	- ❌ <span lang="sv">Han kom sent, som irriterade alla.</span>
	  ✅ <span lang="sv">Han kom sent, vilket irriterade alla.</span>
	- ❌ <span lang="sv">Mannen som bor inte här</span>
	  ✅ <span lang="sv">Mannen som inte bor här</span>
	- Do not inflect <span lang="sv">som</span> for gender or case the way German
	  inflects <span lang="de">der / die / das</span>.
</MistakeBox>
