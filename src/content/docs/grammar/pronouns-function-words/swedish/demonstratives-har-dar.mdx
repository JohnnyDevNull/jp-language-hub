Swedish often uses <span lang="sv">här</span> and <span lang="sv">där</span>
with demonstratives to distinguish “this here” from “that there”. The form
before the noun follows the noun's gender.

## Core forms

| Distance | en-word | ett-word |
| --- | --- | --- |
| near the speaker | <span lang="sv">den här jackan</span> | <span lang="sv">det här paraplyet</span> |
| farther away | <span lang="sv">den där cykeln</span> | <span lang="sv">det där biblioteket</span> |

Use <span lang="sv">den</span> with en-words and <span lang="sv">det</span>
with ett-words:

- <span lang="sv">den här nyckeln</span> — this key here
- <span lang="sv">det här mejlet</span> — this email here
- <span lang="sv">den där cykeln</span> — that bike there
- <span lang="sv">det där biblioteket</span> — that library there

## The noun is definite

After <span lang="sv">den här</span>, <span lang="sv">det här</span>,
<span lang="sv">den där</span>, and <span lang="sv">det där</span>, the noun
normally uses the definite form:

| Indefinite | Demonstrative phrase |
| --- | --- |
| <span lang="sv">en nyckel</span> | <span lang="sv">den här nyckeln</span> |
| <span lang="sv">ett paraply</span> | <span lang="sv">det här paraplyet</span> |
| <span lang="sv">en cykel</span> | <span lang="sv">den där cykeln</span> |
| <span lang="sv">ett bibliotek</span> | <span lang="sv">det där biblioteket</span> |

This is one reason the four noun forms are useful to learn early.

## Standing alone

When the noun is not spoken directly after the demonstrative, Swedish normally
uses <span lang="sv">det här</span> or <span lang="sv">det där</span> as a
general “this” or “that”:

| Svenska | Deutsch | English |
| --- | --- | --- |
| <span lang="sv">Det här är min plats.</span> | <span lang="de">Das hier ist mein Platz.</span> | <span lang="en">This is my seat.</span> |
| <span lang="sv">Det där är vår buss.</span> | <span lang="de">Das dort ist unser Bus.</span> | <span lang="en">That is our bus.</span> |

In <span lang="sv">Det här är min plats</span>, the demonstrative is not
attached to the noun phrase <span lang="sv">min plats</span>. It points to the
situation as “this”.

## With adjectives

If an adjective appears inside the demonstrative noun phrase, Swedish uses the
definite adjective form and the noun still remains definite:

| Phrase | Pattern |
| --- | --- |
| <span lang="sv">den här varma jackan</span> | <span lang="sv">den här</span> + definite adjective + definite noun |
| <span lang="sv">det där nya biblioteket</span> | <span lang="sv">det där</span> + definite adjective + definite noun |

This is closely related to [double definiteness](../../../adjectives-adverbs/swedish/agreement/#definite-noun-phrases-and-double-definiteness).

<MistakeBox title="Common mistakes">
	- ❌ <span lang="sv">den här nyckel</span>
	  ✅ <span lang="sv">den här nyckeln</span>
	- ❌ <span lang="sv">det här jackan</span>
	  ✅ <span lang="sv">den här jackan</span>
	- ❌ <span lang="sv">den här varm jackan</span>
	  ✅ <span lang="sv">den här varma jackan</span>
</MistakeBox>

<MemoryTip>
First choose <span lang="sv">den</span> or <span lang="sv">det</span> from the
noun's gender. Then use the noun's definite form:
<span lang="sv"><strong>en nyckel → den här nyckeln</strong></span>.
</MemoryTip>
