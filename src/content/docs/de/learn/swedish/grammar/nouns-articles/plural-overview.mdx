<KeyTakeaway>
- Der unbestimmte Plural folgt einem von fünf Mustern: <span lang="sv">-or</span>, <span lang="sv">-ar</span>, <span lang="sv">-er</span>, <span lang="sv">-n</span> oder keiner Endung.
- Genus und Wortende grenzen die Vermutung nur ein; den Plural musst du mit dem Substantiv lernen.
- Keine Endung bedeutet nicht Singular: <span lang="sv">tre hus</span> ist Plural.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Schwedische Substantive bilden den unbestimmten Plural auf verschiedene Arten. Genus und Wortende geben hilfreiche Hinweise, sagen aber nicht jedes Wort voraus. Lerne ein Substantiv für sicheren Gebrauch mit Genus und Plural.

## Die wichtigsten Pluralmuster

Traditionelle Beschreibungen ordnen schwedische Substantive nach ihren Pluralendungen:

| Muster | Typisches Beispiel | Unbestimmter Plural | Bestimmter Plural |
| --- | --- | --- | --- |
| <span lang="sv">-or</span> | <span lang="sv">en flicka</span> | <span lang="sv">flickor</span> | <span lang="sv">flickorna</span> |
| <span lang="sv">-ar</span> | <span lang="sv">en bil</span> | <span lang="sv">bilar</span> | <span lang="sv">bilarna</span> |
| <span lang="sv">-er</span> | <span lang="sv">en telefon</span> | <span lang="sv">telefoner</span> | <span lang="sv">telefonerna</span> |
| <span lang="sv">-n</span> | <span lang="sv">ett äpple</span> | <span lang="sv">äpplen</span> | <span lang="sv">äpplena</span> |
| keine Endung | <span lang="sv">ett hus</span> | <span lang="sv">hus</span> | <span lang="sv">husen</span> |

Das sind Lernmuster, keine Regeln, die das Lernen einzelner Substantivformen überflüssig machen.

## Nützliche Hinweise

- Viele en-Wörter auf unbetontes <span lang="sv">-a</span> erhalten <span lang="sv">-or</span>: <span lang="sv">en vecka → veckor</span>.
- Viele häufige en-Wörter erhalten <span lang="sv">-ar</span>: <span lang="sv">en stol → stolar</span>.
- Viele internationale Wörter erhalten <span lang="sv">-er</span>: <span lang="sv">en station → stationer</span>.
- Viele ett-Wörter auf Vokal erhalten <span lang="sv">-n</span>: <span lang="sv">ett äpple → äpplen</span>.
- Viele ett-Wörter auf Konsonant haben im unbestimmten Plural keine Endung: <span lang="sv">ett barn → barn</span>.

## Stammwechsel und unregelmäßige Formen

Einige häufige Substantive verändern sich im Inneren oder haben einen unregelmäßigen Plural:

- <span lang="sv">en bok → böcker → böckerna</span>
- <span lang="sv">en man → män → männen</span>
- <span lang="sv">en hand → händer → händerna</span>
- <span lang="sv">ett öga → ögon → ögonen</span>

Lerne diese Formen als vollständige Substantivparadigmen, statt sie in ein regelmäßiges Endungsmuster zu zwängen.

## Lateinische und griechische Lehnwörter

Eine Gruppe von ett-Wörtern auf <span lang="sv">-um</span> ersetzt diese Endung im Plural. Einige davon sind Alltagswörter, daher lohnt es sich, das Muster zu erkennen:

| Singular | Plural | Bestimmter Plural |
| --- | --- | --- |
| <span lang="sv">ett museum</span> | <span lang="sv">museer</span> | <span lang="sv">museerna</span> |
| <span lang="sv">ett gymnasium</span> | <span lang="sv">gymnasier</span> | <span lang="sv">gymnasierna</span> |
| <span lang="sv">ett laboratorium</span> | <span lang="sv">laboratorier</span> | <span lang="sv">laboratorierna</span> |
| <span lang="sv">ett akvarium</span> | <span lang="sv">akvarier</span> | <span lang="sv">akvarierna</span> |

Zwei häufige Wörter verhalten sich anders:

- <span lang="sv">ett faktum → fakta</span> — der Plural lautet <span lang="sv">fakta</span> und wird auch oft als Massensubstantiv behandelt.
- <span lang="sv">ett datum → datum</span> — im Plural unverändert.

Übertrage das nicht auf jedes Wort auf <span lang="sv">-um</span>: Das alltägliche <span lang="sv">ett centrum</span> heißt im Plural meist <span lang="sv">centrum</span>; das lateinische <span lang="sv">centra</span> ist auf formelle Texte beschränkt.

## Zahl nach Numeralen

Nach Zahlen größer als eins steht der unbestimmte Plural:

- <span lang="sv">en bil</span>
- <span lang="sv">två bilar</span>
- <span lang="sv">tre hus</span>

Die fehlende sichtbare Endung in <span lang="sv">tre hus</span> macht das Substantiv nicht zum Singular; Zahl und Kontext zeigen den Plural.

Wie Deutsch hat Schwedisch mehrere Pluralmuster und Stammwechsel. Englisches <span lang="en">-s</span> ist daher kein sicheres Modell für Schwedisch.

<MistakeBox>
Folgere nicht, dass alle en-Wörter dieselbe Endung und alle ett-Wörter eine andere erhalten:

<span lang="sv">en bil → bilar</span>, aber <span lang="sv">en telefon → telefoner</span>;  
<span lang="sv">ett äpple → äpplen</span>, aber <span lang="sv">ett hus → hus</span>.
</MistakeBox>

<MemoryTip>
Lerne die vier Formen, nicht eine erratene Gruppennummer: <span lang="sv"><strong>ett äpple — äpplet — äpplen — äpplena</strong></span>. Das Muster wird durch wiederholte Beispiele vertraut.
</MemoryTip>
