<KeyTakeaway>
- Jedes Substantiv hat ein Genus; lerne deshalb <span lang="sv">en bil</span> oder <span lang="sv">ett hus</span>, nie das nackte Substantiv.
- <span lang="sv">en</span> ist die bessere Vermutung: en-Wörter sind klar in der Mehrheit, und mehrere Wortbildungsendungen machen die Vermutung sicherer.
- Produktive Zusammensetzungen übernehmen normalerweise das Genus ihres **letzten** Elements.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Die meisten schwedischen Substantive gehören zu einem von zwei grammatischen Genera. Ein **en-Wort** verwendet <span lang="sv">en</span>, ein **ett-Wort** <span lang="sv">ett</span>. Das Genus beeinflusst Artikel, bestimmte Formen und Adjektivendungen.

## Jetzt anwenden

Wenn du ein neues Substantiv verwenden musst, wähle diesen sicheren Weg:

| Situation | Was du tust | Beispiel |
| --- | --- | --- |
| Du lernst ein neues Substantiv | Speichere es mit Artikel, nicht allein. | <span lang="sv">en bil</span>, <span lang="sv">ett hus</span> |
| Du weißt es nicht | Rate <span lang="sv">en</span> und prüfe später nach. | <span lang="sv">en dag</span>, <span lang="sv">en fråga</span> |
| Das Substantiv hat eine deutliche Endung | Lass die Endung leiten, lerne aber trotzdem die ganze Nominalgruppe. | <span lang="sv">en tidning</span>, <span lang="sv">ett bibliotek</span> |
| Das Wort sieht wie eine gewöhnliche produktive Zusammensetzung aus | Beginne mit dem Genus des letzten Elements und prüfe unbekannte Wörter nach. | <span lang="sv">ett sommarhus</span> aus <span lang="sv">ett hus</span> |
| Du fügst ein Adjektiv hinzu | Passe das Adjektiv an Genus und Zahl an. | <span lang="sv">en stor bil</span>, <span lang="sv">ett stort hus</span> |

Für die Alltagssprache ist die nützlichste Gewohnheit einfach: Sprich ein neues Substantiv immer mit seinem Artikel aus. Diese eine Gewohnheit gibt dir den Artikel, die bestimmte Form und das spätere Adjektivmuster.

## Grundregel

| Genus | Unbestimmter Singular | Bedeutung |
| --- | --- | --- |
| en-Wort | <span lang="sv">en bil</span> | ein Auto |
| ett-Wort | <span lang="sv">ett hus</span> | ein Haus |

Keine Regel sagt das Genus jedes schwedischen Substantivs vollständig zuverlässig voraus. Lerne den Artikel mit dem Substantiv: nicht nur <span lang="sv">bil</span>, sondern <span lang="sv">en bil</span>. Einige Endungen engen die Vermutung regelmäßig genug ein; produktive Zusammensetzungen folgen normalerweise dem letzten Element.

<RuleBox>
	Lerne ein schwedisches Substantiv zusammen mit seinem Artikel. Der Artikel gehört zu seiner grammatischen Information: Er zeigt das Genus und hilft bei passenden Formen in der Nominalgruppe.
</RuleBox>

## Endungen, die auf ein Genus hinweisen

en-Wörter sind im Schwedischen klar in der Mehrheit, deshalb ist <span lang="sv">en</span> die bessere Vermutung ohne weitere Hinweise. Viele Wortbildungsendungen engen sie weiter ein.

Diese Endungen sind normalerweise en-Wörter:

| Endung | Beispiele |
| --- | --- |
| <span lang="sv">-a</span> | <span lang="sv">en flicka</span>, <span lang="sv">en gata</span>, <span lang="sv">en vecka</span> |
| <span lang="sv">-are</span> | <span lang="sv">en lärare</span>, <span lang="sv">en bagare</span> |
| <span lang="sv">-else</span> | <span lang="sv">en händelse</span>, <span lang="sv">en rörelse</span> |
| <span lang="sv">-het</span> | <span lang="sv">en möjlighet</span>, <span lang="sv">en nyhet</span> |
| <span lang="sv">-ning</span>, <span lang="sv">-ing</span> | <span lang="sv">en tidning</span>, <span lang="sv">en övning</span> |
| <span lang="sv">-dom</span> | <span lang="sv">en sjukdom</span>, <span lang="sv">en visdom</span> |
| <span lang="sv">-lek</span> | <span lang="sv">en kärlek</span>, <span lang="sv">en storlek</span> |
| <span lang="sv">-nad</span> | <span lang="sv">en byggnad</span>, <span lang="sv">en skillnad</span> |
| <span lang="sv">-tion</span>, <span lang="sv">-sion</span> | <span lang="sv">en station</span>, <span lang="sv">en diskussion</span> |
| <span lang="sv">-ist</span>, <span lang="sv">-ent</span>, <span lang="sv">-ör</span> | <span lang="sv">en turist</span>, <span lang="sv">en student</span>, <span lang="sv">en frisör</span> |

Diese Endungen sind normalerweise ett-Wörter:

| Endung | Beispiele |
| --- | --- |
| <span lang="sv">-ande</span>, <span lang="sv">-ende</span> | <span lang="sv">ett meddelande</span>, <span lang="sv">ett leende</span> |
| <span lang="sv">-eri</span> | <span lang="sv">ett bageri</span>, <span lang="sv">ett tryckeri</span> |
| <span lang="sv">-um</span> | <span lang="sv">ett museum</span>, <span lang="sv">ett centrum</span>, <span lang="sv">ett faktum</span> |
| <span lang="sv">-ment</span> | <span lang="sv">ett dokument</span>, <span lang="sv">ett argument</span> |
| <span lang="sv">-tek</span> | <span lang="sv">ett bibliotek</span>, <span lang="sv">ett apotek</span> |
| <span lang="sv">-gram</span> | <span lang="sv">ett program</span>, <span lang="sv">ett diagram</span> |

Drei Fälle brauchen Aufmerksamkeit:

- <span lang="sv">-a</span> hat eine kleine Gruppe von ett-Wörtern: <span lang="sv">ett öga</span>, <span lang="sv">ett öra</span>, <span lang="sv">ett hjärta</span>.
- <span lang="sv">-ande</span> und <span lang="sv">-ende</span> sind ett-Wörter, wenn sie eine Handlung bezeichnen, aber en-Wörter, wenn sie eine Person bezeichnen: <span lang="sv">ett meddelande</span> gegenüber <span lang="sv">en studerande</span>.
- <span lang="sv">-skap</span> ist wirklich geteilt. Konkrete und kollektive Substantive sind meist ett-Wörter (<span lang="sv">ett landskap</span>, <span lang="sv">ett sällskap</span>), Beziehungen und Eigenschaften meist en-Wörter (<span lang="sv">en vänskap</span>, <span lang="sv">en kunskap</span>). Prüfe diese Endung nach, statt zu raten.

Eine Endung wie <span lang="sv">-e</span> liefert gar keinen hilfreichen Hinweis: Vergleiche <span lang="sv">en pojke</span> mit <span lang="sv">ett äpple</span>.

Substantive für Menschen und Tiere sind meistens en-Wörter — <span lang="sv">en man</span>, <span lang="sv">en kvinna</span>, <span lang="sv">en hund</span> — aber nicht immer: <span lang="sv">ett barn</span>, <span lang="sv">ett djur</span>, <span lang="sv">ett lejon</span>.

## Produktive Zusammensetzungen folgen normalerweise ihrem letzten Element

Dies ist die nützlichste Genusregel, weil Schwedisch fortlaufend Zusammensetzungen bildet. In produktiven Zusammensetzungen ist das letzte Element der Kopf und liefert normalerweise das Genus; die früheren Elemente spielen keine Rolle:

| Teile | Zusammensetzung |
| --- | --- |
| <span lang="sv">en cykel</span> + <span lang="sv">ett hjul</span> | <span lang="sv">ett cykelhjul</span> |
| <span lang="sv">ett tåg</span> + <span lang="sv">en station</span> | <span lang="sv">en tågstation</span> |
| <span lang="sv">en sommar</span> + <span lang="sv">ett hus</span> | <span lang="sv">ett sommarhus</span> |
| <span lang="sv">en post</span> + <span lang="sv">ett kontor</span> | <span lang="sv">ett postkontor</span> |

Bei gewöhnlichen produktiven Zusammensetzungen folgen bestimmte und Pluralformen ebenfalls meist dem letzten Element: <span lang="sv">ett cykelhjul → cykelhjulet</span>, <span lang="sv">en tågstation → tågstationen</span>.

<RuleBox title="Zuverlässige Abkürzung">
	Beginne bei einer gewöhnlichen produktiven Zusammensetzung mit dem letzten Element. Sein Genus, seine bestimmte Endung und sein Pluralmuster übertragen sich normalerweise auf das ganze Wort.
</RuleBox>

## Unbestimmt und bestimmt

Schwedisch verwendet im unbestimmten Singular normalerweise einen eigenen Artikel, fügt beim einfachen bestimmten Form aber eine Endung an das Substantiv an:

| Genus | Unbestimmt | Bestimmt |
| --- | --- | --- |
| en-Wort | <span lang="sv">en bil</span> | <span lang="sv">bilen</span> |
| ett-Wort | <span lang="sv">ett hus</span> | <span lang="sv">huset</span> |

## Adjektivkongruenz

Genus und Zahl der Nominalgruppe bestimmen die Grundform des Adjektivs. Der Artikel macht diese grammatische Information sichtbar:

- <span lang="sv">en <strong>stor</strong> bil</span> — ein großes Auto
- <span lang="sv">ett <strong>stort</strong> hus</span> — ein großes Haus
- <span lang="sv"><strong>stora</strong> bilar</span> — große Autos
- <span lang="sv"><strong>stora</strong> hus</span> — große Häuser

Das Grundmuster ist die **Grundform** beim en-Wort, oft **-t** beim ett-Wort und oft **-a** im Plural. Adjektive haben auch unregelmäßige und schreibungsabhängige Formen; die kanonische Erklärung steht unter [Adjektivkongruenz](../../adjectives-adverbs/agreement/).

## Bestimmte Adjektivkonstruktionen

Wenn ein Adjektiv ein bestimmtes Substantiv bestimmt, markiert Standardschwedisch die Bestimmtheit normalerweise sowohl mit einem eigenen Artikel als auch mit der bestimmten Endung am Substantiv:

<p lang="sv">den stora bilen</p>

Das heißt **doppelte Bestimmtheit**. Unter [Adjektivkongruenz](../../adjectives-adverbs/agreement/#bestimmte-nominalphrasen-und-doppelte-bestimmtheit) findest du das vollständige Muster, die Formen für Genus und Zahl sowie die Besitz-Ausnahme.

## Plural

Die Pluralendung lässt sich nicht allein aus en oder ett ableiten:

- <span lang="sv">en bil → bilar</span>
- <span lang="sv">ett hus → hus</span>
- <span lang="sv">ett äpple → äpplen</span>

Lerne die wichtigen Pluralformen mit dem Substantiv. Siehe [Pluralübersicht](../plural-overview/).

<MistakeBox title="Typische Fehler">
Gehe nicht davon aus, dass natürliche Eigenschaften eines Gegenstands über en oder ett entscheiden, und nutze <span lang="sv">en</span> nicht als Universalartikel. Bestimme das Genus einer Zusammensetzung auch nicht nach ihrem ersten Element: <span lang="sv">❌ en cykelhjul</span>, <span lang="sv">✅ ett cykelhjul</span>.

<span lang="sv">❌ en hus</span>  
<span lang="sv">✅ ett hus</span>

Halte auch das Adjektiv passend:

<span lang="sv">❌ ett stor hus</span>  
<span lang="sv">✅ ett stort hus</span>
</MistakeBox>

<MemoryTip>
	Behandle den Artikel als Teil des Wortes: Lerne <span lang="sv"><strong>en bil</strong></span> und <span lang="sv"><strong>ett hus</strong></span>. Ergänze, wenn möglich, die vier Formen: <span lang="sv">en bil, bilen, bilar, bilarna</span>.
</MemoryTip>
