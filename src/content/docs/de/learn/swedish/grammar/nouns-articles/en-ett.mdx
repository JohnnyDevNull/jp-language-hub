<KeyTakeaway>
- Jedes Substantiv ist ein en-Wort oder ein ett-Wort. Lerne es deshalb als
  <span lang="sv">en bil</span> oder <span lang="sv">ett hus</span>, nie allein.
- Wenn du raten musst, rate <span lang="sv">en</span>: Die meisten Substantive
  sind en-Wörter, und viele Endungen verraten das Genus.
- Ein zusammengesetztes Wort hat das Genus seines **letzten** Teils (des
  Grundworts): <span lang="sv">ett sommarhus</span>, weil
  <span lang="sv">ett hus</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Jedes schwedische Substantiv gehört zu einer von zwei Gruppen. Das nennt man das
Genus ([<span lang="sv">genus</span>](../../../glossary/#genus)). Ein
**en-Wort** bekommt den Artikel <span lang="sv">en</span>
(<span lang="sv">en bil</span>, ein Auto), ein **ett-Wort** bekommt
<span lang="sv">ett</span> (<span lang="sv">ett hus</span>, ein Haus). Das
Deutsche hat drei solche Gruppen: der, die, das. Das Englische hat keine. Du
musst das Genus bei jedem Substantiv kennen, denn der Artikel, die bestimmte Form
(„das Auto“) und das Adjektiv hängen davon ab.

## Das hilft dir sofort

Wenn du ein neues Substantiv triffst, gehst du diese Liste von oben nach unten
durch:

| Situation | Was du tun kannst | Beispiel |
| --- | --- | --- |
| Du lernst ein neues Substantiv. | Lerne es mit seinem Artikel, nicht allein. | <span lang="sv">en bil</span>, <span lang="sv">ett hus</span> |
| Du hast keine Ahnung. | Rate <span lang="sv">en</span> und prüfe später nach. | <span lang="sv">en dag</span>, <span lang="sv">en fråga</span> |
| Das Substantiv hat eine typische Endung. | Lass dich von der Endung leiten, lerne das Substantiv aber trotzdem mit seinem Artikel. | <span lang="sv">en tidning</span>, <span lang="sv">ett bibliotek</span> |
| Das Substantiv ist ein zusammengesetztes Wort. | Nimm das Genus des letzten Teils und prüfe Wörter, die du nicht kennst. | <span lang="sv">ett sommarhus</span> von <span lang="sv">ett hus</span> |
| Du setzt ein Adjektiv dazu. | Pass das Adjektiv an Genus und Singular oder Plural des Substantivs an. | <span lang="sv">en stor bil</span>, <span lang="sv">ett stort hus</span> |

Die nützlichste Gewohnheit ist einfach: Sprich jedes neue Substantiv laut mit
seinem Artikel. Diese eine Gewohnheit bringt dir den Artikel, die bestimmte
Form und später die richtige Adjektivendung gleich mit.

## Die Kernregel

| Genus | Mit unbestimmtem Artikel | Bedeutung |
| --- | --- | --- |
| en-Wort | <span lang="sv">en bil</span> | ein Auto |
| ett-Wort | <span lang="sv">ett hus</span> | ein Haus |

Keine Regel sagt dir das Genus aller schwedischen Substantive. Lerne den
Artikel zusammen mit dem Substantiv: nicht nur <span lang="sv">bil</span>,
sondern <span lang="sv">en bil</span>. Manche Wortendungen sind verlässlich
genug, um beim Raten zu helfen, und zusammengesetzte Wörter richten sich nach
ihrem letzten Teil.

<RuleBox>
	Lerne ein schwedisches Substantiv zusammen mit seinem Artikel. Der Artikel
	zeigt das Genus, und das Genus entscheidet über die anderen Formen: die
	bestimmte Form und das Adjektiv.
</RuleBox>

## Endungen, die auf ein Genus hinweisen

Die meisten schwedischen Substantive sind en-Wörter. Wenn du sonst nichts
weißt, rate deshalb <span lang="sv">en</span>. Viele Endungen machen den Tipp
sicherer.

Diese Endungen gehören normalerweise zu en-Wörtern:

| Endung | Beispiele |
| --- | --- |
| <span lang="sv">-a</span> | <span lang="sv">en flicka</span>, <span lang="sv">en gata</span>, <span lang="sv">en vecka</span> |
| <span lang="sv">-are</span> | <span lang="sv">en lärare</span>, <span lang="sv">en bagare</span> |
| <span lang="sv">-else</span> | <span lang="sv">en händelse</span>, <span lang="sv">en rörelse</span> |
| <span lang="sv">-het</span> | <span lang="sv">en möjlighet</span>, <span lang="sv">en nyhet</span> |
| <span lang="sv">-ning</span>, <span lang="sv">-ing</span> | <span lang="sv">en tidning</span>, <span lang="sv">en övning</span> |
| <span lang="sv">-dom</span> | <span lang="sv">en sjukdom</span>, <span lang="sv">en visdom</span> |
| <span lang="sv">-lek</span> | <span lang="sv">en kärlek</span>, <span lang="sv">en storlek</span> |
| <span lang="sv">-nad</span> | <span lang="sv">en byggnad</span>, <span lang="sv">en skillnad</span> |
| <span lang="sv">-tion</span>, <span lang="sv">-sion</span> | <span lang="sv">en station</span>, <span lang="sv">en diskussion</span> |
| <span lang="sv">-ist</span>, <span lang="sv">-ent</span>, <span lang="sv">-ör</span> | <span lang="sv">en turist</span>, <span lang="sv">en student</span>, <span lang="sv">en frisör</span> |

Diese Endungen gehören normalerweise zu ett-Wörtern:

| Endung | Beispiele |
| --- | --- |
| <span lang="sv">-ande</span>, <span lang="sv">-ende</span> | <span lang="sv">ett meddelande</span>, <span lang="sv">ett leende</span> |
| <span lang="sv">-eri</span> | <span lang="sv">ett bageri</span>, <span lang="sv">ett tryckeri</span> |
| <span lang="sv">-um</span> | <span lang="sv">ett museum</span>, <span lang="sv">ett centrum</span>, <span lang="sv">ett faktum</span> |
| <span lang="sv">-ment</span> | <span lang="sv">ett dokument</span>, <span lang="sv">ett argument</span> |
| <span lang="sv">-tek</span> | <span lang="sv">ett bibliotek</span>, <span lang="sv">ett apotek</span> |
| <span lang="sv">-gram</span> | <span lang="sv">ett program</span>, <span lang="sv">ett diagram</span> |

Bei drei Endungen musst du aufpassen:

- <span lang="sv">-a</span> hat eine kleine Gruppe von ett-Wörtern:
  <span lang="sv">ett öga</span>, <span lang="sv">ett öra</span>,
  <span lang="sv">ett hjärta</span>.
- <span lang="sv">-ande</span> und <span lang="sv">-ende</span> gehören zu
  ett-Wörtern, wenn sie eine Handlung nennen, aber zu en-Wörtern, wenn sie eine
  Person nennen: <span lang="sv">ett meddelande</span> im Gegensatz zu
  <span lang="sv">en studerande</span>.
- <span lang="sv">-skap</span> ist gemischt. Wörter für Dinge oder Gruppen sind
  meist ett-Wörter (<span lang="sv">ett landskap</span>,
  <span lang="sv">ett sällskap</span>), Wörter für Beziehungen und Eigenschaften
  meist en-Wörter (<span lang="sv">en vänskap</span>,
  <span lang="sv">en kunskap</span>). Prüfe diese Endung lieber nach, statt zu
  raten.

Eine Endung wie <span lang="sv">-e</span> hilft dir gar nicht weiter: Vergleiche
<span lang="sv">en pojke</span> mit <span lang="sv">ett äpple</span>.

Substantive für Menschen und Tiere sind meist en-Wörter –
<span lang="sv">en man</span>, <span lang="sv">en kvinna</span>,
<span lang="sv">en hund</span> –, aber nicht immer:
<span lang="sv">ett barn</span>, <span lang="sv">ett djur</span>,
<span lang="sv">ett lejon</span>.

## Zusammengesetzte Wörter richten sich nach ihrem letzten Teil

Im Schwedischen werden ständig Wörter zusammengesetzt:
<span lang="sv">sommar</span> + <span lang="sv">hus</span> ergibt
<span lang="sv">sommarhus</span>. Deshalb ist das die nützlichste Genusregel:
Der letzte Teil, das Grundwort
([<span lang="sv">efterled</span>](../../../glossary/#efterled)), bestimmt das
Genus. Die Teile davor spielen keine Rolle:

| Teile | Zusammengesetztes Wort |
| --- | --- |
| <span lang="sv">en cykel</span> + <span lang="sv">ett hjul</span> | <span lang="sv">ett cykelhjul</span> |
| <span lang="sv">ett tåg</span> + <span lang="sv">en station</span> | <span lang="sv">en tågstation</span> |
| <span lang="sv">en sommar</span> + <span lang="sv">ett hus</span> | <span lang="sv">ett sommarhus</span> |
| <span lang="sv">en post</span> + <span lang="sv">ett kontor</span> | <span lang="sv">ett postkontor</span> |

Die bestimmte Form und der Plural richten sich meist ebenfalls nach dem
letzten Teil:
<span lang="sv">ett cykelhjul → cykelhjulet</span>,
<span lang="sv">en tågstation → tågstationen</span>.

<RuleBox title="Faustregel">
	Schau bei einem zusammengesetzten Wort auf den letzten Teil. Sein Genus, seine
	bestimmte Form und sein Plural gelten meist für das ganze Wort.
</RuleBox>

## „Ein Auto“ und „das Auto“

Für „ein“ setzt das Schwedische den Artikel davor:
<span lang="sv">en bil</span>. Für den bestimmten Artikel („das Auto“) hängt es
stattdessen eine Endung an das Substantiv:

| Genus | Unbestimmt | Bestimmt |
| --- | --- | --- |
| en-Wort | <span lang="sv">en bil</span> | <span lang="sv">bilen</span> |
| ett-Wort | <span lang="sv">ett hus</span> | <span lang="sv">huset</span> |

## Das Adjektiv passt sich an

Das Adjektiv ändert seine Endung passend zum Substantiv: en-Wort oder ett-Wort,
Singular oder Plural. Der Artikel zeigt dir, was du vor dir hast:

- <span lang="sv">en <strong>stor</strong> bil</span> – ein großes Auto
- <span lang="sv">ett <strong>stort</strong> hus</span> – ein großes Haus
- <span lang="sv"><strong>stora</strong> bilar</span> – große Autos
- <span lang="sv"><strong>stora</strong> hus</span> – große Häuser

Das Grundmuster: die **Grundform** bei einem en-Wort, meist **-t** bei einem
ett-Wort, meist **-a** im Plural. Manche Adjektive haben unregelmäßige Formen;
die ganze Erklärung steht auf der Seite
[Adjektivendungen](../../adjectives-adverbs/agreement/).

## „Das große Auto“: der bestimmte Artikel doppelt

Steht ein Adjektiv vor einem Substantiv mit bestimmtem Artikel, zeigt das
Schwedische das gleich zweimal an: mit einem eigenen Wort davor
(<span lang="sv">den</span>) und mit der Endung am Substantiv
(<span lang="sv">-en</span>):

<p lang="sv">den stora bilen</p>

Das nennt man doppelte Bestimmtheit
([<span lang="sv">dubbel bestämdhet</span>](../../../glossary/#dubbel-bestämdhet)).
Das ganze Muster und die Ausnahme nach Wörtern wie
<span lang="sv">min</span> (mein) stehen auf der Seite
[Adjektivendungen](../../adjectives-adverbs/agreement/#bestimmte-nominalphrasen-und-doppelte-bestimmtheit).

## Der Plural

Die Pluralendung kannst du weder an <span lang="sv">en</span> noch an
<span lang="sv">ett</span> allein erkennen:

- <span lang="sv">en bil → bilar</span>
- <span lang="sv">ett hus → hus</span>
- <span lang="sv">ett äpple → äpplen</span>

Lerne die wichtigen Pluralformen zusammen mit dem Substantiv. Mehr dazu steht in
der [Pluralübersicht](../plural-overview/).

<MistakeBox title="Häufige Fehler">
Die Bedeutung eines Wortes entscheidet nicht darüber, ob es
<span lang="sv">en</span> oder <span lang="sv">ett</span> hat, und
<span lang="sv">en</span> passt nicht zu jedem Wort. Bei zusammengesetzten
Wörtern darfst du das Genus auch nicht vom ersten Teil nehmen:
<span lang="sv">❌ en cykelhjul</span>, <span lang="sv">✅ ett cykelhjul</span>.

<span lang="sv">❌ en hus</span>  
<span lang="sv">✅ ett hus</span>

Achte außerdem darauf, dass das Adjektiv passt:

<span lang="sv">❌ ett stor hus</span>  
<span lang="sv">✅ ett stort hus</span>
</MistakeBox>

<MemoryTip>
	Behandle den Artikel als Teil des Wortes: Lerne
	<span lang="sv"><strong>en bil</strong></span> und
	<span lang="sv"><strong>ett hus</strong></span>. Ergänze die vier
	Substantivformen, sobald du sie kennst:
	<span lang="sv">en bil, bilen, bilar, bilarna</span>.
</MemoryTip>
