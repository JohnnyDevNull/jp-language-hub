<KeyTakeaway>
- Hänge <span lang="sv">-s</span> an ein Substantiv oder einen Namen, damit es zum Besitzer wird: <span lang="sv">Annas bok</span>, <span lang="sv">hundens namn</span>.
- Nach einem Besitzer steht das Besessene normalerweise ohne Artikel und bestimmte Endung: <span lang="sv">Annas nya bil</span>, nicht <span lang="sv">den Annas bilen</span>.
- Nutze ein Possessivpronomen, wenn der Besitzer mit *mein, dein, sein, ihr, unser* oder *ihr* ausgedrückt wird.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Im schwedischen nominalen Besitz steht der Besitzer zuerst und trägt <span lang="sv">-s</span>. Diese Seite behandelt Besitz mit Substantiven und Namen; für Besitzerpronomen gibt es eine eigene Übersicht.

## Jetzt anwenden

| Was bezeichnet den Besitzer? | Nutze | Beispiel |
| --- | --- | --- |
| ein Name | Name + <span lang="sv">-s</span> | <span lang="sv">Annas bok</span> |
| eine Nominalgruppe | Nominalgruppe + <span lang="sv">-s</span> | <span lang="sv">min väns bil</span> |
| *mein, dein, sein, ihr, unser, ihr* | ein Possessivpronomen | <span lang="sv">min bok</span> |
| die eigene Sache des Subjekts in der dritten Person | <span lang="sv">sin / sitt / sina</span> | <span lang="sv">Anna tar sin bok.</span> |

## Grundregel

Der Besitzer steht vor dem besessenen Substantiv:

| Besitzer | Besitzgruppe |
| --- | --- |
| <span lang="sv">Anna</span> | <span lang="sv">Annas cykel</span> |
| <span lang="sv">hunden</span> | <span lang="sv">hundens namn</span> |
| <span lang="sv">mina vänner</span> | <span lang="sv">mina vänners hus</span> |

Das <span lang="sv">-s</span> gehört zur ganzen Besitzergruppe. Im Schwedischen schreibt man es ohne Apostroph: <span lang="sv">Eriks rum</span>, nicht <span lang="sv">Erik's rum</span>.

Namen, die bereits auf <span lang="sv">-s</span>, <span lang="sv">-x</span> oder <span lang="sv">-z</span> enden, bekommen normalerweise kein weiteres geschriebenes <span lang="sv">s</span>: <span lang="sv">Lars bok</span>, <span lang="sv">Max cykel</span>.

## Das besessene Substantiv bleibt formal unbestimmt

Nach einem Besitzer steht das Substantiv normalerweise ohne Artikel und ohne einfache bestimmte Endung:

- <span lang="sv">Annas bil</span> — Annas Auto
- <span lang="sv">Annas nya bil</span> — Annas neues Auto
- <span lang="sv">hundens namn</span> — der Name des Hundes

Ein Adjektiv erhält seine bestimmt wirkende Form auf <span lang="sv">-a</span>, aber Schwedisch ergänzt trotzdem weder <span lang="sv">den</span> noch eine bestimmte Form beim besessenen Substantiv: <span lang="sv">Annas nya bil</span>.

## Andere natürliche Aussagen über Besitz

Der s-Genitiv bildet eine Nominalgruppe. Wenn es darum geht, auszudrücken, wem etwas gehört, ist ein ganzer Satz oft klarer:

- <span lang="sv">Boken tillhör Anna.</span> — Das Buch gehört Anna.
- <span lang="sv">Det är Annas bok.</span> — Es ist Annas Buch.
- <span lang="sv">Anna har en bok.</span> — Anna hat ein Buch.

## Direkter Vergleich

<LanguageComparison title="Annas neues Auto">
	<p slot="de">Annas neues Auto</p>
	<p slot="en">Anna's new car</p>
	<p slot="sv">Annas nya bil</p>
</LanguageComparison>

Englisch verwendet hier einen Apostroph; Schwedisch und Deutsch nicht. Schwedisch lässt das besessene Substantiv außerdem ohne eigenen Artikel.

<MistakeBox title="Typische Fehler">
- <span lang="sv">❌ Anna's bok</span> → <span lang="sv">✅ Annas bok</span>
- <span lang="sv">❌ Annas bilen</span> → <span lang="sv">✅ Annas bil</span>
- <span lang="sv">❌ Annas ny bil</span> → <span lang="sv">✅ Annas nya bil</span>
</MistakeBox>

<MemoryTip>
Stelle den Besitzer voran, füge <span lang="sv">-s</span> an und lasse das Besessene ohne Artikel: <span lang="sv"><strong>Anna + s + bok → Annas bok</strong></span>.
</MemoryTip>
