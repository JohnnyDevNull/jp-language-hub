<KeyTakeaway>
- Das indefinite Muster ist Grundform, <span lang="sv">-t</span>, <span lang="sv">-a</span>:
  <span lang="sv">en stor bil</span>, <span lang="sv">ett stort hus</span>, <span lang="sv">stora bilar</span>.
- Die Pluralform ist bei en-Wörtern und ett-Wörtern identisch.
- Eine bestimmte Nominalphrase markiert Bestimmtheit zweimal: Artikel plus
  bestimmtes Adjektiv plus bestimmtes Substantiv — <span lang="sv">den stora bilen</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Schwedische Adjektive richten sich nach Genus und Numerus des Substantivs, das
sie beschreiben. Attributive Adjektive innerhalb von Nominalphrasen spiegeln
außerdem wider, ob die Phrase indefinit oder definit ist. Das zentrale Muster
für Anfänger ist **Grundform**, **-t** und **-a**.

## Jetzt anwenden

Um schnell die richtige Adjektivform zu wählen, frage dich, welche Art von
Phrase du bildest:

| Frage | Verwende | Beispiel |
| --- | --- | --- |
| Ist es ein indefinites en-Wort? | Grundform | <span lang="sv">en stor bil</span> |
| Ist es ein indefinites ett-Wort? | meist <span lang="sv">-t</span> ergänzen | <span lang="sv">ett stort hus</span> |
| Ist es Plural? | meist <span lang="sv">-a</span> ergänzen | <span lang="sv">stora bilar</span>, <span lang="sv">stora hus</span> |
| Ist es eine bestimmte Nominalphrase? | Artikel + <span lang="sv">-a</span>-Adjektiv + bestimmtes Substantiv | <span lang="sv">den stora bilen</span>, <span lang="sv">det stora huset</span> |

Prüfe danach eine der häufigen Ausnahmen:

- Manche Adjektive ändern die Schreibweise vor einer Endung:
  <span lang="sv">röd → rött → röda</span>, <span lang="sv">öppen → öppet → öppna</span>.
- Manche häufigen Adjektive sind unregelmäßig oder unveränderlich:
  <span lang="sv">liten → litet → små</span>, aber <span lang="sv">bra → bra → bra</span>.
- Nach Verben wie <span lang="sv">vara</span> und <span lang="sv">bli</span> richte dich nach Genus oder
  Numerus des Subjekts, verwende aber keine doppelte Bestimmtheit:
  <span lang="sv">Huset är stort.</span>

Wenn du unsicher bist, bilde zuerst die ganze Nominalphrase:
<span lang="sv">en stor bil</span>, <span lang="sv">ett stort hus</span>,
<span lang="sv">stora bilar</span>, <span lang="sv">den stora bilen</span>.

## Kernmuster

| Nominalphrase | Adjektivform | Beispiel |
| --- | --- | --- |
| indefinit en-Singular | Grundform | <span lang="sv">en <strong>{stor.morphology.en}</strong> bil</span> |
| indefinit ett-Singular | meist <span lang="sv">-t</span> | <span lang="sv">ett <strong>{stor.morphology.ett}</strong> hus</span> |
| indefiniter Plural | meist <span lang="sv">-a</span> | <span lang="sv"><strong>{stor.morphology.plural}</strong> bilar</span> |
| definit | meist <span lang="sv">-a</span> | <span lang="sv">den <strong>{stor.morphology.definite}</strong> bilen</span> |

Die gleiche Pluralform des Adjektivs wird bei en-Wörtern und ett-Wörtern
verwendet:

- <span lang="sv">stora bilar</span>
- <span lang="sv">stora hus</span>

## Indefinitformen

Gehe von der Wörterbuch- oder en-Form aus:

<p lang="sv">stor</p>

Ergänze <span lang="sv">-t</span> für die reguläre ett-Form und
<span lang="sv">-a</span> für den regulären Plural:

<p lang="sv">stor → stort → stora</p>

Ein weiteres reguläres Beispiel:

<p lang="sv">{gul.morphology.en} → {gul.morphology.ett} → {gul.morphology.plural}</p>

Beim Anfügen von Endungen kann sich die Schreibweise ändern, und manche
Adjektive sind unregelmäßig. Zum Beispiel:

- <span lang="sv">{glad.morphology.en} → {glad.morphology.ett} → {glad.morphology.plural}</span>
- <span lang="sv">liten → litet → små</span>
- <span lang="sv">bra → bra → bra</span>

Lerne häufige Ausnahmen anhand vollständiger Phrasen.

## Schreibmuster

Die Endungen <span lang="sv">-t</span> und <span lang="sv">-a</span> sind
regulär, aber der Stamm ändert sich beim Anfügen oft. Diese Muster
decken die meisten Adjektive ab:

| Stammmuster | en-Form | ett-Form | Plural / definit |
| --- | --- | --- | --- |
| betonter Vokal | <span lang="sv">ny</span>, <span lang="sv">blå</span> | <span lang="sv">nytt</span>, <span lang="sv">blått</span> | <span lang="sv">nya</span>, <span lang="sv">blåa</span> |
| Vokal + <span lang="sv">-d</span> | <span lang="sv">röd</span>, <span lang="sv">god</span> | <span lang="sv">rött</span>, <span lang="sv">gott</span> | <span lang="sv">röda</span>, <span lang="sv">goda</span> |
| Konsonant + <span lang="sv">-d</span> | <span lang="sv">hård</span> | <span lang="sv">hårt</span> | <span lang="sv">hårda</span> |
| Vokal + <span lang="sv">-t</span> | <span lang="sv">vit</span>, <span lang="sv">söt</span> | <span lang="sv">vitt</span>, <span lang="sv">sött</span> | <span lang="sv">vita</span>, <span lang="sv">söta</span> |
| Konsonant + <span lang="sv">-t</span> | <span lang="sv">kort</span>, <span lang="sv">svart</span> | <span lang="sv">kort</span>, <span lang="sv">svart</span> | <span lang="sv">korta</span>, <span lang="sv">svarta</span> |
| <span lang="sv">-nn</span> | <span lang="sv">sann</span>, <span lang="sv">tunn</span> | <span lang="sv">sant</span>, <span lang="sv">tunt</span> | <span lang="sv">sanna</span>, <span lang="sv">tunna</span> |
| <span lang="sv">-en</span> | <span lang="sv">öppen</span>, <span lang="sv">mogen</span> | <span lang="sv">öppet</span>, <span lang="sv">moget</span> | <span lang="sv">öppna</span>, <span lang="sv">mogna</span> |
| <span lang="sv">-er</span>, <span lang="sv">-el</span> | <span lang="sv">vacker</span>, <span lang="sv">enkel</span> | <span lang="sv">vackert</span>, <span lang="sv">enkelt</span> | <span lang="sv">vackra</span>, <span lang="sv">enkla</span> |

Zwei häufige Adjektive sind über diese Muster hinaus unregelmäßig:

- <span lang="sv">gammal → gammalt → gamla</span>
- <span lang="sv">liten → litet → små</span>, mit
  <span lang="sv">lilla</span> im bestimmten Singular:
  <span lang="sv">den lilla bilen</span>

Das Muster, das du dir zuerst einprägen solltest, ist die
<span lang="sv">-en</span>-Gruppe, weil das unbetonte
<span lang="sv">e</span> im Plural verschwindet:
<span lang="sv">ett öppet fönster</span>, aber
<span lang="sv">öppna fönster</span>.

## Adjektive, die sich nie ändern

Eine kleine Gruppe nimmt überhaupt keine Endungen an. Sie zu verwenden ist
einfach, sobald du weißt, welche das sind:

<span lang="sv">bra</span>, <span lang="sv">kul</span>,
<span lang="sv">äkta</span>, <span lang="sv">sakta</span>,
<span lang="sv">främmande</span> sowie Farbwörter wie
<span lang="sv">rosa</span>, <span lang="sv">lila</span>,
<span lang="sv">beige</span>.

- <span lang="sv">ett bra hus</span>, <span lang="sv">bra bilar</span>
- <span lang="sv">ett rosa hus</span>, <span lang="sv">rosa bilar</span>

## Partizipien als Adjektive

Partizip-Perfekt-Formen werden wie gewöhnliche Adjektive gebeugt:

| Nominalphrase | Beispiel |
| --- | --- |
| indefinit en | <span lang="sv">en stängd dörr</span> |
| indefinit ett | <span lang="sv">ett stängt fönster</span> |
| Plural | <span lang="sv">stängda dörrar</span> |

Das Gleiche gilt für Partizipien anderer Verbgruppen:
<span lang="sv">en målad vägg</span>,
<span lang="sv">ett målat hus</span>,
<span lang="sv">målade väggar</span>; sowie
<span lang="sv">en skriven text</span>,
<span lang="sv">ett skrivet brev</span>,
<span lang="sv">skrivna brev</span>.

Partizip-Präsens-Formen auf <span lang="sv">-ande</span> und
<span lang="sv">-ende</span> werden nie gebeugt:

<p lang="sv">ett leende barn · en leende flicka · leende barn</p>

Partizip-Perfekt-Formen sind auch die Grundlage des bli-Passivs. Siehe
[Passiv](../../verb-patterns-voice/passive/).

## Das optionale maskuline -e

Bei Bezug auf eine männliche Person kann die bestimmte Form
<span lang="sv">-e</span> statt <span lang="sv">-a</span> annehmen:

- <span lang="sv">den gamle mannen</span> neben
  <span lang="sv">den gamla mannen</span>
- <span lang="sv">min gode vän</span>

Das ist optional und gehört einem leicht formellen oder traditionellen
Register an; es überlebt auch in festen Namen wie
<span lang="sv">Karl den store</span>. Die
<span lang="sv">-a</span>-Form ist immer akzeptabel — behandle
<span lang="sv">-e</span> also eher als etwas zum Wiedererkennen denn als
anzuwendende Regel.

## Bestimmte Nominalphrasen und doppelte Bestimmtheit

Ein Substantiv ohne attributives Adjektiv markiert Bestimmtheit normalerweise
nur mit seiner Endung:

<p lang="sv">bilen · huset · bilarna</p>

Wird ein attributives Adjektiv hinzugefügt, markiert das Standardschwedische
Bestimmtheit normalerweise zweimal: mit einem eigenen bestimmten Artikel vor
dem Adjektiv und mit der bestimmten Endung am Substantiv. Diese Konstruktion
heißt **doppelte Bestimmtheit**.

| Numerus und Genus | Bestimmter Artikel | Adjektiv | Bestimmtes Substantiv | Vollständige Phrase |
| --- | --- | --- | --- | --- |
| en-Singular | <span lang="sv">den</span> | <span lang="sv">{stor.morphology.definite}</span> | <span lang="sv">bilen</span> | <span lang="sv">den {stor.morphology.definite} bilen</span> |
| ett-Singular | <span lang="sv">det</span> | <span lang="sv">{stor.morphology.definite}</span> | <span lang="sv">huset</span> | <span lang="sv">det {stor.morphology.definite} huset</span> |
| Plural | <span lang="sv">de</span> | <span lang="sv">{stor.morphology.definite}</span> | <span lang="sv">bilarna</span> | <span lang="sv">de {stor.morphology.definite} bilarna</span> |

Das dreiteilige Muster lautet also:

<p lang="sv"><strong>den / det / de + bestimmtes Adjektiv + bestimmtes Substantiv</strong></p>

Der Artikel markiert Genus oder Numerus, das Adjektiv verwendet meist seine
<span lang="sv">-a</span>-Form, und das Substantiv behält seine bestimmte Endung. Das
Englische markiert dieselbe Phrase meist nur einmal in <span lang="en">the big car</span>;
das Schwedische verwendet sowohl <span lang="sv">den</span> als auch <span lang="sv">-en</span> in
<span lang="sv">den stora bilen</span>.

Possessiva sind eine wichtige Ausnahme vom Standardmuster. Das Adjektiv
verwendet die bestimmte Form, aber es gibt keinen eigenen bestimmten Artikel,
und das Substantiv nimmt keine bestimmte Endung an:

<p lang="sv">min stora bil</p>

Demonstrativa wie <span lang="sv">den här</span> und
<span lang="sv">det där</span> folgen dem Rhythmus der bestimmten Nominalphrase:
<span lang="sv">den här stora bilen</span>,
<span lang="sv">det där stora huset</span>.

Siehe [Substantivformen](../../nouns-articles/noun-forms/) für die
Substantivendungen selbst.

## Nach Verben wie *vara* und *bli*

Prädikative Adjektive richten sich nach dem Subjekt, verwenden aber keine
doppelte Bestimmtheit:

- <span lang="sv">Bilen är stor.</span>
- <span lang="sv">Huset är stort.</span>
- <span lang="sv">Bilarna är stora.</span>

	<p slot="sv">den stora bilen</p>
</LanguageComparison>

Englische Adjektive richten sich nicht nach dem Substantiv. Deutsche
Adjektive stimmen zwar auch überein, aber die deutschen Endungen hängen
zusätzlich von Kasus und Artikeltyp ab, nicht nur von Genus und Numerus.
Übertrage das deutsche Endungssystem nicht direkt auf das Schwedische.

<MistakeBox title="Häufige Fehler">
Achte darauf, dass Artikel, Adjektiv und Substantiv zusammenpassen:

<span lang="sv">❌ ett stor hus</span>
<span lang="sv">✅ ett stort hus</span>

Lasse in einer normalen bestimmten Phrase keinen Teil der doppelten
Bestimmtheit weg:

<span lang="sv">❌ det stora hus</span>
<span lang="sv">✅ det stora huset</span>
</MistakeBox>

<MemoryTip>
Merke dir den dreiteiligen Rhythmus:
<span lang="sv"><strong>en stor — ett stort — flera stora</strong></span>.
Für eine bestimmte Phrase verwende die vertraute <span lang="sv">-a</span>-Form:
<span lang="sv">den stora bilen</span>.
</MemoryTip>
