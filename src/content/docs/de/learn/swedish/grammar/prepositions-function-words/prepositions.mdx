<KeyTakeaway>
- Lerne eine Präposition im ganzen Ausdruck, nicht als Übersetzung einer deutschen oder englischen.
- Ein Verb mit fester Präposition ist eine Einheit: <span lang="sv">vänta på</span>, <span lang="sv">gifta sig med</span>.
- <span lang="sv">Om en vecka</span> zählt von jetzt vorwärts, <span lang="sv">för en vecka sedan</span> rückwärts.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Lerne schwedische Präpositionen in vollständigen Ausdrücken. Deutsche oder
englische Präpositionen sind keine zuverlässige Eins-zu-eins-Übersetzung.

## Jetzt anwenden

Wähle zuerst nach der Aufgabe des Ausdrucks. Übersetze erst danach aus dem
Deutschen oder Englischen.

| Bedarf | Beginne mit | Beispiel |
| --- | --- | --- |
| in einem Land, einer Stadt, Gegend oder einem Raum | <span lang="sv">i</span> | <span lang="sv">Jag bor i Malmö.</span> |
| an einem Aktivitätsort, in einer Straße, in Verkehrsmitteln | <span lang="sv">på</span> | <span lang="sv">Jag bor på Sveavägen.</span> |
| neben oder bei etwas | <span lang="sv">vid</span> | <span lang="sv">Vi ses vid stationen.</span> |
| Bewegung zu einem Ziel | <span lang="sv">till</span> | <span lang="sv">Jag går till biblioteket.</span> |
| Richtung, Strecke oder Schild | <span lang="sv">mot</span> | <span lang="sv">Tåget mot Göteborg.</span> |
| ein zukünftiger Zeitraum ab jetzt | <span lang="sv">om</span> | <span lang="sv">Vi ses om en vecka.</span> |
| ein vergangener Zeitraum rückwärts ab jetzt | <span lang="sv">för ... sedan</span> | <span lang="sv">Jag kom hit för en timme sedan.</span> |
| eine bekannte Verbgruppe | ganzen Ausdruck speichern | <span lang="sv">vänta på bussen</span>, <span lang="sv">leta efter nycklarna</span> |

Frage: Geht es um Ort, Richtung, Zeit oder eine feste Verbgruppe? Bei Ort:
<span lang="sv">i</span> oder <span lang="sv">på</span>? Beim Verb: Präposition mitgelernt?

## Ort: wo etwas ist

| Präposition | Typische Idee | Beispiel |
| --- | --- | --- |
| <span lang="sv">i</span> | in einem Land, einer Stadt, Gegend oder einem geschlossenen Ort | <span lang="sv">Malmö ligger i Skåne.</span> |
| <span lang="sv">på</span> | auf, an oder in vielen Ortsausdrücken | <span lang="sv">Vi träffas på caféet.</span> |
| <span lang="sv">vid</span> | bei, an, neben | <span lang="sv">Bänken står vid dörren.</span> |
| <span lang="sv">under</span> | unter | <span lang="sv">Väskan ligger under stolen.</span> |
| <span lang="sv">över</span> | über, oberhalb, über ... hinweg | <span lang="sv">Bron går över älven.</span> |
| <span lang="sv">mellan</span> | zwischen | <span lang="sv">Caféet ligger mellan biblioteket och torget.</span> |
| <span lang="sv">mittemot</span> | gegenüber | <span lang="sv">Apoteket ligger mittemot hotellet.</span> |

## Richtung: wohin etwas geht

| Präposition | Typische Idee | Beispiel |
| --- | --- | --- |
| <span lang="sv">från</span> | von | <span lang="sv">Bussen kommer från Lund.</span> |
| <span lang="sv">till</span> | zu, nach | <span lang="sv">Vi går till biblioteket.</span> |
| <span lang="sv">mot</span> | in Richtung von | <span lang="sv">Spårvagnen mot centrum stannar här.</span> |

Die Präposition <span lang="sv">till</span> steht, wenn das Ziel der Bewegung gemeint ist,
<span lang="sv">mot</span> für Richtung, Linie, Schild oder Strecke.

## Häufige feste Wahlen

Manche häufigen Wahlen müssen als Ausdruck gespeichert werden:

<LanguageComparison title="Wohnen in einer Straße">
	<p slot="de">Ich wohne in der Sveavägen.</p>
	<p slot="en">I live on Sveavägen.</p>
	<p slot="sv">Jag bor på Sveavägen.</p>
</LanguageComparison>

<LanguageComparison title="Im Zug">
	<p slot="de">Wir sitzen im Zug nach Kalmar.</p>
	<p slot="en">We are sitting on the train to Kalmar.</p>
	<p slot="sv">Vi sitter på tåget till Kalmar.</p>
</LanguageComparison>

<LanguageComparison title="Willkommen zu etwas">
	<p slot="de">Willkommen im Kurs!</p>
	<p slot="en">Welcome to the course!</p>
	<p slot="sv">Välkommen till kursen!</p>
</LanguageComparison>

Deutsch <span lang="de">in</span> und Englisch <span lang="en">in</span> werden
nicht immer zu schwedisch <span lang="sv">i</span>.

## Verben mit fester Präposition

Viele schwedische Verben verlangen eine bestimmte Präposition, die sich nicht
aus Deutsch oder Englisch vorhersagen lässt. Lerne Verb und Präposition zusammen.

| Schwedisch | Englisch | Deutsch |
| --- | --- | --- |
| <span lang="sv">vänta på</span> | to wait for | <span lang="de">warten auf</span> |
| <span lang="sv">titta på</span> | to look at | <span lang="de">ansehen, schauen auf</span> |
| <span lang="sv">lyssna på</span> | to listen to | <span lang="de">hören, zuhören</span> |
| <span lang="sv">tänka på</span> | to think about | <span lang="de">denken an</span> |
| <span lang="sv">tro på</span> | to believe in | <span lang="de">glauben an</span> |
| <span lang="sv">svara på</span> | to answer | <span lang="de">antworten auf</span> |
| <span lang="sv">bero på</span> | to depend on | <span lang="de">abhängen von</span> |
| <span lang="sv">leta efter</span> | to look for | <span lang="de">suchen nach</span> |
| <span lang="sv">längta efter</span> | to long for | <span lang="de">sich sehnen nach</span> |
| <span lang="sv">be om</span> | to ask for | <span lang="de">bitten um</span> |
| <span lang="sv">skratta åt</span> | to laugh at | <span lang="de">lachen über</span> |
| <span lang="sv">vara intresserad av</span> | to be interested in | <span lang="de">interessiert an</span> |
| <span lang="sv">bli kär i</span> | to fall in love with | <span lang="de">sich verlieben in</span> |
| <span lang="sv">gifta sig med</span> | to marry | <span lang="de">heiraten</span> |

In solchen Gruppen ist <span lang="sv">på</span> sehr häufig. Manche schwedischen Verben
brauchen eine Präposition, wo Deutsch keine hat:
<span lang="sv">gifta sig med någon</span> gegenüber <span lang="de">jemanden heiraten</span>.

### Wo die Präposition steht

In vielen Relativsätzen und Fragen wandert die Präposition nicht mit ihrem
Nomen nach vorn, sondern bleibt am Ende:

- <span lang="sv">Bussen som vi väntar på är sen.</span> — *Der Bus, auf den wir warten, kommt zu spät.*
- <span lang="sv">Var kommer du ifrån?</span> — *Woher kommst du?*

Deutsch macht das Gegenteil. Siehe [Relativpronomen](../../pronouns-roles/relative-pronouns/).

### Präposition oder Partikel?

<span lang="sv">Titta på</span> und <span lang="sv">tycka om</span> sehen ähnlich aus, verhalten sich aber
anders. Bei <span lang="sv">titta på</span> ist die Präposition unbetont und leitet das Objekt
ein. Bei <span lang="sv">tycka om</span> gehört die betonte Partikel zum Verb und verändert die Bedeutung:

- <span lang="sv">Jag tittar inte på henne.</span> — Präposition
- <span lang="sv">Jag tycker inte om henne.</span> — Partikel

Den Betonungstest und die Folgen für die Wortstellung erklärt
[Partikelverben](../../verb-patterns-voice/particle-verbs/).

## Zeit: wann etwas passiert

| Präposition | Typische Idee | Beispiel |
| --- | --- | --- |
| <span lang="sv">på</span> | kommender Wochentag oder Tageszeit | <span lang="sv">Vi ses på måndag.</span> |
| <span lang="sv">i</span> | feste Ausdrücke für heute und gestern | <span lang="sv">Jag kommer i kväll.</span> |
| <span lang="sv">om</span> | nach einem Zeitraum ab jetzt | <span lang="sv">Vi ses om en vecka.</span> |
| <span lang="sv">för … sedan</span> | Zeitraum rückwärts ab jetzt | <span lang="sv">Jag flyttade hit för ett år sedan.</span> |
| <span lang="sv">i</span> | Dauer | <span lang="sv">Jag bodde i Lund i tre år.</span> |
| <span lang="sv">under</span> | während | <span lang="sv">Vi reser under sommaren.</span> |
| <span lang="sv">mellan</span> | zwischen zwei Zeitpunkten | <span lang="sv">Mötet är mellan två och tre.</span> |

Besonders wichtig sind <span lang="sv">om</span> und <span lang="sv">för … sedan</span>: Schwedisch ändert
die ganze Konstruktion.
<span lang="sv">På måndag</span> weist auf den kommenden, <span lang="sv">i måndags</span> auf den vorigen
Montag. <span lang="sv">På måndagar</span> im Plural beschreibt eine Gewohnheit.

Für Uhrzeiten siehe [Uhrzeit](../../../vocabulary/telling-time/).

<MistakeBox title="Typische Fehler">
	- Übersetze deutsche oder englische Präpositionen nicht mechanisch.
	- Nimm nicht <span lang="sv">i</span> als Standard für jedes deutsche <span lang="de">in</span>.
	- ❌ <span lang="sv">Jag gifte mig henne.</span> ✅ <span lang="sv">Jag gifte mig med henne.</span>
	- ❌ <span lang="sv">Jag flyttade hit för ett år.</span> ✅ <span lang="sv">Jag flyttade hit för ett år sedan.</span>
	- Verwende für einen zukünftigen Zeitraum nicht <span lang="sv">i</span>: <span lang="sv">Om en vecka</span> heißt *in einer Woche ab jetzt*.
</MistakeBox>

<MemoryTip>
Speichere den ganzen Ausdruck: <span lang="sv"><strong>bo på en gata</strong></span>,
<span lang="sv"><strong>träffas på caféet</strong></span>, <span lang="sv"><strong>gå till biblioteket</strong></span>,
<span lang="sv"><strong>vänta på bussen</strong></span>. Verb und Präposition gehören zusammen.
</MemoryTip>
