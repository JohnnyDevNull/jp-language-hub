<KeyTakeaway>
- <span lang="sv">där</span>, <span lang="sv">här</span> und <span lang="sv">var</span> bilden mit einer Präposition ein
  Wort, genau wie deutsch <span lang="de">darum</span> oder <span lang="de">hiermit</span>.
- <span lang="sv">Därför</span> bedeutet *deshalb* und hat das Verb an zweiter Stelle;
  <span lang="sv">därför att</span> bedeutet *weil* und eröffnet einen Nebensatz.
- Für Ort stehen <span lang="sv">här</span> und <span lang="sv">där</span>, für Richtung <span lang="sv">hit</span> und <span lang="sv">dit</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Schwedisch verbindet <span lang="sv">där</span>, <span lang="sv">här</span> und <span lang="sv">var</span> mit einer
Präposition zu einem Wort. Deutschsprachige kennen das Prinzip aus
<span lang="de">darum</span>, <span lang="de">damit</span> und
<span lang="de">hiermit</span>; schwedische Wörter entstehen genauso.

## Das Muster

| Basis | + Präposition | Bedeutung |
| --- | --- | --- |
| <span lang="sv">där</span> | <span lang="sv">därför</span> | deshalb, darum |
| | <span lang="sv">därmed</span> | dadurch, damit |
| | <span lang="sv">därefter</span> | danach |
| | <span lang="sv">därav</span> | daher, daraus |
| | <span lang="sv">därifrån</span> | von dort |
| <span lang="sv">här</span> | <span lang="sv">härmed</span> | hiermit |
| | <span lang="sv">härefter</span> | von nun an |
| | <span lang="sv">härav</span> | hiervon, daraus |
| <span lang="sv">var</span> | <span lang="sv">varför</span> | warum |
| | <span lang="sv">varav</span> | wovon |
| | <span lang="sv">varifrån</span> | woher |

Die <span lang="sv">där-</span>-Wörter verweisen zurück auf etwas Erwähntes, die
<span lang="sv">här-</span>-Wörter auf etwas Gegenwärtiges oder Unmittelbares und die
<span lang="sv">var-</span>-Wörter fragen oder beziehen sich auf etwas.

Auch das Register zählt. <span lang="sv">Därför</span>, <span lang="sv">därefter</span>, <span lang="sv">därifrån</span>
und <span lang="sv">varför</span> sind alltagssprachlich. <span lang="sv">Härmed</span>, <span lang="sv">härav</span>,
<span lang="sv">därav</span> und <span lang="sv">varav</span> gehören zur formellen Schriftsprache: Erkenne
sie, aber beim Sprechen ist Präposition + <span lang="sv">det</span> normal:
<span lang="sv">Jag är intresserad av det</span> statt <span lang="sv">Jag är intresserad därav</span>.

## därför und därför att sind nicht dasselbe

Hier passieren die entscheidenden Fehler. <span lang="sv">Därför</span> allein bedeutet
*deshalb* und leitet einen Hauptsatz ein. <span lang="sv">Därför att</span> bedeutet *weil*
und leitet einen Nebensatz ein.

- <span lang="sv">Jag var sjuk. Därför stannade jag hemma.</span> — *Ich war krank. Deshalb blieb ich zu Hause.*
- <span lang="sv">Jag stannade hemma därför att jag var sjuk.</span> — *Ich blieb zu Hause, weil ich krank war.*

<RuleBox title="Regel">
	<span lang="sv">Därför</span> = *deshalb*; weil es am Anfang seines Satzes steht, löst es
	das V2-Muster aus: <span lang="sv">Därför **stannade** jag hemma.</span>
	<span lang="sv">Därför att</span> = *weil*; der folgende Satz hat Nebensatzstellung.
</RuleBox>

Für *weil* gibt es auch <span lang="sv">eftersom</span>:

- <span lang="sv">Eftersom jag var sjuk stannade jag hemma.</span>
- <span lang="sv">Jag stannade hemma eftersom jag var sjuk.</span>

Siehe [V2](../../sentence-structure/v2/) und [Nebensätze](../../sentence-structure/subordinate-clauses/).

## här oder hit, där oder dit

Die einfachen Adverbien unterscheiden Ort und Richtung; jedes Paar hat seine
eigene Form:

| Ort | Richtung | Von dort |
| --- | --- | --- |
| <span lang="sv">här</span> — hier | <span lang="sv">hit</span> — hierher | <span lang="sv">härifrån</span> |
| <span lang="sv">där</span> — dort | <span lang="sv">dit</span> — dorthin | <span lang="sv">därifrån</span> |

- <span lang="sv">Jag bor här.</span> — *Ich wohne hier.*
- <span lang="sv">Kom hit!</span> — *Komm her!* 
- <span lang="sv">Hon arbetar där.</span> — *Sie arbeitet dort.*
- <span lang="sv">Vi åker dit i morgon.</span> — *Wir fahren morgen dorthin.*

Die Fragewörter folgen derselben Trennung: <span lang="sv">var</span> fragt nach dem Ort,
<span lang="sv">vart</span> nach der Richtung. Siehe [Fragewörter](../../questions-negation/question-words/).

## varför fragt, därför antwortet

- <span lang="sv">Varför stannade du hemma?</span> — *Warum bist du zu Hause geblieben?*
- <span lang="sv">Därför att jag var sjuk.</span> — *Weil ich krank war.*

Als kurze Antwort auf <span lang="sv">varför</span> sind sowohl
<span lang="sv">därför att jag var sjuk</span> als auch bloßes <span lang="sv">därför!</span> — *weil!* —
üblich. Siehe [Fragewörter](../../questions-negation/question-words/).

## Direkter Vergleich

	<p slot="de">Ich war krank. Darum blieb ich zu Hause.</p>
	<p slot="en">I was ill. That is why I stayed home.</p>
	<p slot="sv">Jag var sjuk. Därför stannade jag hemma.</p>

<LanguageComparison title="Weil, ein Nebensatz">
	<p slot="de">Ich blieb zu Hause, weil ich krank war.</p>

	<p slot="sv">Jag stannade hemma därför att jag var sjuk.</p>
</LanguageComparison>

<MistakeBox title="Typische Fehler">
	- ❌ <span lang="sv">Jag stannade hemma därför jag var sjuk.</span>
	  ✅ <span lang="sv">Jag stannade hemma därför att jag var sjuk.</span>
	- ❌ <span lang="sv">Därför jag stannade hemma.</span>
	  ✅ <span lang="sv">Därför stannade jag hemma.</span> — Verb an zweiter Stelle
	- Baue formelles <span lang="sv">därav</span> oder <span lang="sv">härmed</span> nicht in Alltagssprache ein.
	  Verwende Präposition + <span lang="sv">det</span>.
</MistakeBox>

<MemoryTip>
Merke dir ein Paar: <span lang="sv"><strong>Därför stannade jag hemma</strong></span> —
deshalb, Verb an zweiter Stelle. <span lang="sv"><strong>… därför att jag var sjuk</strong></span>
— weil, Nebensatz. Das zusätzliche <span lang="sv">att</span> verändert den Konnektor.
</MemoryTip>
