<KeyTakeaway>
- Beginnt ein Hauptsatz nicht mit dem Subjekt, rückt das Subjekt hinter das finite Verb.
- Nur das finite Verb verschiebt sich; Infinitiv und Supinum stehen später.
- Deutsch nutzt in vergleichbaren Hauptsätzen ebenfalls das Verb-Subjekt-Muster, Englisch meist nicht.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Inversion entsteht, wenn ein schwedischer Aussagesatz mit etwas anderem als dem Subjekt beginnt. Das finite Verb bleibt an zweiter Stelle, das Subjekt folgt ihm.

## Kernregel

> **vorangestelltes Satzglied + finites Verb + Subjekt + Satzrest**

<SentenceSchema caption="Vorangestellte Satzglieder gegenüber neutraler Wortstellung" rowHeader="Erste Position" columns={['1 Vorfeld', '2 Finites Verb', '3 Subjekt', 'Satzadverbial', 'Nicht-finites Verb', 'Rest']} rows={[{ label: 'Subjekt (neutral)', cells: ['Jag', 'jobbar', '', '', '', 'hemma idag.'] }, { label: 'Zeit', cells: ['Idag', 'jobbar', 'jag', '', '', 'hemma.'] }, { label: 'Ort', cells: ['Hemma', 'jobbar', 'jag', '', '', 'idag.'] }, { label: 'Objekt', cells: ['Den boken', 'har', 'jag', 'redan', 'läst', ''] }, { label: 'Nebensatz', cells: ['När mötet är slut', 'går', 'vi', '', '', 'hem.'] }, { label: 'Deutsch (gleiche Verschiebung)', lang: 'de', cells: ['Heute', 'arbeite', 'ich', '', '', 'zu Hause.'] }]} />

Das ist die sichtbare Folge der [V2-Regel](../v2/). Auch mehrere Wörter können ein einziges erstes Satzglied bilden. Nur das finite Verb steht vor dem Subjekt: <Sv>Imorgon ska vi träffa Anna.</Sv>

## Inversion und Fragen

Auch Ja-/Nein-Fragen haben ein finites Verb vor dem Subjekt: <Sv>Kommer du imorgon?</Sv> In einer Aussage steht das Verb aber nach einem vorangestellten Satzglied an zweiter Stelle; die Ja-/Nein-Frage beginnt meist mit dem Verb. Siehe [Fragen](../../questions-negation/questions/).

<MistakeBox incorrect="Efter jobbet jag ska handla." correct="Efter jobbet ska jag handla." lang="sv">Ein vorangestellter Ausdruck schafft keinen zusätzlichen Platz; er verändert die Hauptsatzwortstellung.</MistakeBox>

<MemoryTip>Steht das Subjekt nicht zuerst, höre direkt nach dem Anfangsblock auf **Verb + Subjekt**: <Sv>Idag <strong>kommer jag</strong> …</Sv></MemoryTip>
