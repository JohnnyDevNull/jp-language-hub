<KeyTakeaway>
- Beginne mit dem neutralen Hauptsatzrahmen; nutze dann V2 und Inversion, wenn
  ein anderes Satzglied vorn steht.
- Behandle Nebensätze als eigenen Satztyp; BIFF erklärt darin die engere
  Stellung von Satzadverbialen.
- Schlage die Position von *inte* separat nach, wenn Satztyp, Fragen oder
  mehrteilige Verbgruppen unsicher machen, wohin es gehört.
</KeyTakeaway>

Dieser Bereich hilft dir zu entscheiden, wo <span lang="sv">finit verb</span>, <span lang="sv">subjekt</span>,
<span lang="sv">satsadverbial</span> und <span lang="sv">infinit verb</span> stehen. Fragen haben einen eigenen Einstieg
unter [Fragen & Verneinung](../questions-negation/).

## Wähle nach Bedarf

| Wenn du … | Beginne mit … |
| --- | --- |
| eine neutrale Aussage baust | [Grundwortstellung](./basic-word-order/) |
| verstehen willst, warum das <span lang="sv">finit verb</span> an zweiter Stelle bleibt | [V2-Regel](./v2/) |
| das <span lang="sv">subjekt</span> nach das Verb setzt, weil etwas anderes vorn steht | [Inversion](./inversion/) |
| einen Nebensatz erkennst und baust | [Nebensätze](./subordinate-clauses/) |
| ein <span lang="sv">satsadverbial</span> im Nebensatz platzierst | [BIFF](./biff/) |
| *inte* in verschiedenen Satz- und Verbmustern platzierst | [Stellung von *inte*](./inte-placement/) |

## Lerne in dieser Reihenfolge

1. [Grundwortstellung](./basic-word-order/) gibt dir den neutralen
   Hauptsatzrahmen.
2. [V2-Regel](./v2/) erklärt die feste zweite Position des <span lang="sv">finit verb</span>.
3. [Inversion](./inversion/) zeigt, was mit dem <span lang="sv">subjekt</span> passiert, wenn ein
   anderes Satzglied zuerst steht.
4. [Nebensätze](./subordinate-clauses/) führen den Rahmen für abhängige Sätze ein.
5. [BIFF](./biff/) konzentriert sich auf <span lang="sv">satsadverbial</span> in diesem Rahmen.
6. [Stellung von *inte*](./inte-placement/) verbindet die Hauptmuster und
   ergänzt Fragen, Infinitive und Imperative.

## Achte auf

- **V2 und Inversion:** V2 ist die Regel „<span lang="sv">finit verb</span> an zweiter Stelle“;
  Inversion ist das sichtbare Ergebnis „<span lang="sv">subjekt</span> nach dem Verb“, wenn das
  <span lang="sv">subjekt</span> nicht zuerst steht.
- **Nebensätze und BIFF:** Die erste Seite baut den ganzen Satz; BIFF
  beantwortet nur die Stellung des <span lang="sv">satsadverbial</span>.
- **Verneinung und Position:** [Negation](../questions-negation/negation/)
  wählt einen negativen Ausdruck; Position von *inte* setzt einen bestimmten
  Ausdruck an die richtige Stelle.
