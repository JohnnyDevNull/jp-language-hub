Schwedische Wortstellung trägt grammatische Bedeutung. Der nützlichste
Startpunkt ist der neutrale subjektinitiale Hauptsatz; eigene Seiten behandeln
Voranstellung, Fragen und Nebensätze.

## Kernregel

In einem neutralen aussagenden Hauptsatz folgt Schwedisch meist dieser Ordnung:

> **<span lang="sv">subjekt + finit verb + satsadverbial + infinit verb + objekt / predikativ + adverbial</span>**

Lies den Satz als Reihe von Feldern. Das ist das neutrale Schema hinter der
[V2-Regel](../v2/):

In einem neutralen Satz füllt das <span lang="sv">subjekt</span> selbst Position eins, deshalb
bleibt Position drei leer. Die deutsche Zeile füllt dieselben Anfangsfelder;
darum fühlt sich das neutrale Muster vertraut an. Deutsch unterscheidet sich
später im Satz, wo es nicht-finite Verbformen ganz ans Ende schickt.

- <span lang="sv">Jag</span> - <span lang="sv">subjekt</span>
- <span lang="sv">köper</span> - <span lang="sv">finit verb</span>
- <span lang="sv">inte</span> - <span lang="sv">satsadverbial</span>
- <span lang="sv">bilen</span> - <span lang="sv">objekt</span>
- <span lang="sv">idag</span> - Zeitadverbial

Das <span lang="sv">finit verb</span> markiert das Tempus und verankert die Satzstruktur. Schwedische
Verben ändern sich nicht nach Person:

- <span lang="sv">Jag arbetar.</span> - Ich arbeite.
- <span lang="sv">Vi arbetar.</span> - Wir arbeiten.

## Eine Konstituente kann mehrere Wörter enthalten

Eine Satzposition wird von einer **Konstituente** besetzt, nicht unbedingt von
einem einzelnen Wort.

<p lang="sv">Min nya kollega börjar idag.</p>

Die ganze Nominalphrase <span lang="sv">min nya kollega</span> ist das <span lang="sv">subjekt</span> und
besetzt die erste Position. Das <span lang="sv">finit verb</span> <span lang="sv">börjar</span> steht deshalb an zweiter Stelle.

## Wähle das nächste Muster

- Wenn etwas anderes als das Subjekt zuerst steht, nutze
  [Inversion](../inversion/).
- Wenn der Satz nach Bestätigung oder fehlender Information fragt, nutze
  [Fragen](../../questions-negation/questions/).
- Wenn der Satz von einem anderen Satz abhängt, nutze
  [Nebensätze](../subordinate-clauses/).
- Wenn du speziell <span lang="sv">inte</span> platzieren musst, nutze
  [Stellung von *inte*](../inte-placement/).

## Direkter Vergleich

<LanguageComparison title="Neutrale Aussage">
	<p slot="de">Ich kaufe heute ein Auto.</p>
	<p slot="en">I am buying a car today.</p>
	<p slot="sv">Jag köper en bil idag.</p>
</LanguageComparison>

Die drei Sprachen können in einem neutralen Satz ähnlich aussehen. Schwedisch
behält dieselbe finite Form bei allen Personen, während Englisch ein Hilfsverb
verwenden kann und Deutsch spätere Verbteile anders platziert.

<MistakeBox
	incorrect="Jag inte köper bilen idag."
	correct="Jag köper inte bilen idag."
	lang="sv"
>
Stelle im neutralen Hauptsatz das <span lang="sv">finit verb</span> vor das <span lang="sv">satsadverbial</span>.
</MistakeBox>

<MemoryTip>
Beginne mit **wer + <span lang="sv">finit verb</span>** und ergänze dann <span lang="sv">satsadverbial</span>, weitere
Verbteile, <span lang="sv">objekt</span> und andere Informationen.
</MemoryTip>
