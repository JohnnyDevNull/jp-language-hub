<KeyTakeaway>
- Ein Nebensatz ist Teil eines größeren Satzes und beginnt oft mit einer
  Subjunktion wie <span lang="sv">att</span>, <span lang="sv">eftersom</span>, <span lang="sv">om</span> oder <span lang="sv">när</span>.
- Sein praktisches Grundmuster lautet **<span lang="sv">bisatsinledare + subjekt + satsadverbial +
  finit verb + adverbial</span>**.
- Steht der ganze Nebensatz zuerst, verwendet der folgende Hauptsatz Inversion.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Ein Nebensatz ergänzt Inhalt wie das, was jemand sagt, warum etwas passiert,
eine Bedingung oder eine Zeitangabe. Er kann normalerweise nicht allein mit
dieser Funktion stehen: <span lang="sv">eftersom jag är trött</span> braucht einen Hauptsatz
drumherum.

## Jetzt anwenden

| Bedeutung | Beginne den Nebensatz mit … | Beispiel |
| --- | --- | --- |
| dass / berichteter Inhalt | <span lang="sv">att</span> | <span lang="sv">Jag vet att hon kommer.</span> |
| weil | <span lang="sv">eftersom</span> | <span lang="sv">Jag stannar eftersom jag är trött.</span> |
| ob / falls | <span lang="sv">om</span> | <span lang="sv">Vi går ut om det inte regnar.</span> |
| wenn / als | <span lang="sv">när</span> | <span lang="sv">Ring mig när du är klar.</span> |
| bevor | <span lang="sv">innan</span> | <span lang="sv">Ät innan du går.</span> |

## Kernregel

Verwende dieses zuverlässige Muster, wenn der Nebensatz ein
<span lang="sv">satsadverbial</span> wie <span lang="sv">inte</span> enthält:

<SentenceSchema
	caption="Das schwedische Nebensatzmuster"
	rowHeader="Bedeutung"
	columns={['bisatsinledare', 'subjekt', 'satsadverbial', 'finit verb', 'infinit verb', 'objekt / predikativ', 'adverbial']}
	rows={[
		{ label: 'Grund', cells: ['eftersom', 'jag', 'inte', 'kan', 'komma', '', 'idag'] },
		{ label: 'Inhalt', cells: ['att', 'hon', 'redan', 'har', 'köpt', 'biljetten', ''] },
		{ label: 'Bedingung', cells: ['om', 'det', 'inte', 'regnar', '', '', ''] },
	]}
/>

Ohne <span lang="sv">satsadverbial</span> folgt das <span lang="sv">finit verb</span> direkt auf
das <span lang="sv">subjekt</span>:

- <span lang="sv">Jag vet **att hon kommer**.</span>
- <span lang="sv">Ring mig **när du är klar**.</span>

Die [BIFF-Regel](../biff/) behandelt die engere Frage, warum <span lang="sv">inte</span> und
andere <span lang="sv">satsadverbial</span> hier vor dem <span lang="sv">finit verb</span> stehen.

## Wenn der Nebensatz zuerst kommt

Der ganze Nebensatz kann das erste Feld eines folgenden Hauptsatzes besetzen.
Der Hauptsatz stellt sein <span lang="sv">finit verb</span> dann vor sein
<span lang="sv">subjekt</span>:

<SentenceSchema
	caption="Ein Nebensatz vor einem Hauptsatz"
	rowHeader="Satz"
	columns={['fundament', 'finit verb', 'subjekt', 'adverbial']}
	rows={[
		{
			label: 'Nebensatz + Hauptsatz',
			cells: ['När mötet är slut', 'går', 'vi', 'hem.'],
		},
	]}
/>

Diese Verschiebung im Hauptsatz gehört zur [Inversion](../inversion/), nicht
zur inneren Wortstellung des Nebensatzes selbst.

## Indirekte Fragen

Auch eine indirekte Frage verhält sich wie ein Nebensatz:

- <span lang="sv">Jag vet inte **var hon bor**.</span>
- <span lang="sv">Han frågade **om tåget var sent**.</span>

[Fragewörter](../../questions-negation/question-words/) behandelt die
Wortwahl und das Muster direkter gegenüber indirekter Fragen.

## Direkter Vergleich

<LanguageComparison title="Eftersom-Satz">
	<p slot="de">… weil ich heute nicht kommen kann.</p>
	<p slot="en">… because I cannot come today.</p>
	<p slot="sv">… eftersom jag inte kan komma idag.</p>
</LanguageComparison>

Auch das Deutsche markiert Nebensätze mit besonderer Wortstellung, schickt das
finite Verb dabei aber ans Ende. Das Schwedische hält das <span lang="sv">finit verb</span>
nach dem <span lang="sv">satsadverbial</span> und vor einem eventuellen nicht-finiten Verb.

<MistakeBox
	incorrect="Jag stannar hemma eftersom jag kan inte komma."
	correct="Jag stannar hemma eftersom jag inte kan komma."
	lang="sv"
>
Übernimm nicht die <span lang="sv">satsadverbial</span>-Stellung des Hauptsatzes in einen
Nebensatz.
</MistakeBox>

<MemoryTip>
Baue den abhängigen Block von links nach rechts: **<span lang="sv">bisatsinledare → subjekt →
satsadverbial → finit verb → adverbial</span>**.
</MemoryTip>
