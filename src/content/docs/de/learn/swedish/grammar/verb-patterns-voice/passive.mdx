<KeyTakeaway>
- Das s-Passiv verwendet eine <span lang="sv">-s</span>-Form über die gängigen Muster
  Infinitiv, Präsens, Präteritum und Perfekt hinweg; die genaue Form richtet
  sich nach der Morphologie des Verbs.
- <span lang="sv">Bli</span> + Partizip stellt ein Ereignis oder einen Wechsel dar, während
  <span lang="sv">vara</span> + Partizip einen Zustand darstellt; das Partizip kongruiert
  mit dem Subjekt.
- Eine <span lang="sv">-s</span>-Form ist nicht immer ein Passiv: <span lang="sv">hoppas</span> und
  <span lang="sv">Vi ses!</span> sind es nicht.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Das Schwedische hat ein in die Verbform eingebautes **s-Passiv** sowie
periphrastische Passivkonstruktionen mit <span lang="sv">bli</span> oder <span lang="sv">vara</span>.
Deutschsprachige erkennen oft die vertraute Form von <span lang="sv">bli</span> + Partizip
wieder, aber die Konstruktionen entsprechen sich nicht eins zu eins zwischen
den Sprachen.

Diese Seite behandelt Bildung und Erkennung. Für Informationsfokus, das
Weglassen des Agens und die Wahl zwischen aktiver und passiver Formulierung
siehe [Aktiv vs. Passiv](../active-vs-passive/).

## Das s-Passiv

Das <span lang="sv">-s</span>-Muster erscheint im Infinitiv, Präsens, Präteritum und
Supinum. Die genaue Präsensform hängt vom Verbmuster ab: Gruppe 1 hat meist
<span lang="sv">-as</span>, viele andere Verben verwenden den Stamm plus <span lang="sv">-s</span>, und
Stämme, die bereits auf einen s-Laut enden, verwenden mitunter <span lang="sv">-es</span>,
wie in <span lang="sv">läsa → läses</span>. Präteritum und Supinum fügen der entsprechenden
aktiven Form meist <span lang="sv">-s</span> hinzu. Nutze die Formenkette statt einer
ausnahmslosen Schreibregel:

| Form | Aktiv | Passiv |
| --- | --- | --- |
| Infinitiv | <span lang="sv">öppna</span> | <span lang="sv">öppnas</span> |
| Präsens | <span lang="sv">öppnar</span> | <span lang="sv">öppnas</span> |
| Präteritum | <span lang="sv">öppnade</span> | <span lang="sv">öppnades</span> |
| Supinum | <span lang="sv">öppnat</span> | <span lang="sv">öppnats</span> |

Andere Verbgruppen bilden Formen wie diese:

| Verb | Präsens | Präteritum | Supinum |
| --- | --- | --- | --- |
| <span lang="sv">köpa</span> | <span lang="sv">köps</span> | <span lang="sv">köptes</span> | <span lang="sv">köpts</span> |
| <span lang="sv">skriva</span> | <span lang="sv">skrivs</span> | <span lang="sv">skrevs</span> | <span lang="sv">skrivits</span> |

Beispiele im Gebrauch:

- <span lang="sv">Rummet städas varje dag.</span> — *Das Zimmer wird jeden Tag geputzt.*
- <span lang="sv">Cykeln stals i går.</span> — *Das Fahrrad wurde gestern gestohlen.*
- <span lang="sv">Boken skrevs av Astrid Lindgren.</span> — *Das Buch wurde von Astrid
  Lindgren geschrieben.*

Der Agens wird, falls überhaupt genannt, mit
<span lang="sv">av</span> eingeführt.

<RuleBox title="Das s-Passiv erkennen">
	Bestimme das zugrunde liegende Verb und prüfe, ob das Subjekt die betroffene
	Person oder Sache ist: <span lang="sv">Dörrarna stängs automatiskt.</span> Eine
	<span lang="sv">-s</span>-Endung allein ist kein Beweis für passivische Bedeutung.
</RuleBox>

## Partizipiale Passivkonstruktionen mit <span lang="sv">bli</span> und <span lang="sv">vara</span>

<span lang="sv">Bli</span> plus Partizip Perfekt stellt meist ein Ereignis oder einen
Zustandswechsel dar:

- <span lang="sv">Dörren blev öppnad.</span> — *Die Tür wurde geöffnet.*
- <span lang="sv">Han blev vald till ordförande.</span> — *Er wurde zum Vorsitzenden
  gewählt.*

Das Partizip verhält sich wie ein Adjektiv und kongruiert mit dem Subjekt:

| Subjekt | Beispiel |
| --- | --- |
| en-Wort | <span lang="sv">Bilen blev såld.</span> |
| ett-Wort | <span lang="sv">Huset blev sålt.</span> |
| Plural | <span lang="sv">Böckerna blev sålda.</span> |

Siehe [Adjektivkongruenz](../../adjectives-adverbs/agreement/)
für die Endungen.

Mit <span lang="sv">vara</span> statt <span lang="sv">bli</span> beschreibt dasselbe
Partizip einen resultierenden Zustand statt des Ereignisses:
<span lang="sv">Huset är sålt.</span>

## Bildungsübersicht

| Konstruktion | Form | Beispiel |
| --- | --- | --- |
| s-Passiv, Präsens | Präsensstamm/-form + <span lang="sv">-s</span> | <span lang="sv">Biljetter köps i appen.</span> |
| s-Passiv, Präteritum | Präteritum + <span lang="sv">-s</span> | <span lang="sv">Boken skrevs 1950.</span> |
| Ereignis-/Wechselpassiv | finites <span lang="sv">bli</span> + kongruierendes Partizip | <span lang="sv">Han blev bjuden.</span> |
| resultierender Zustand | finites <span lang="sv">vara</span> + kongruierendes Partizip | <span lang="sv">Dörren är stängd.</span> |

## Direkter Vergleich

<LanguageComparison title="Routine, kein Agens">
	<p slot="de">Das Zimmer wird jeden Tag geputzt.</p>
	<p slot="en">The room is cleaned every day.</p>
	<p slot="sv">Rummet städas varje dag.</p>
</LanguageComparison>

<LanguageComparison title="Ereignis als Wechsel dargestellt">
	<p slot="de">Die Tür wurde geöffnet.</p>
	<p slot="en">The door was opened.</p>
	<p slot="sv">Dörren blev öppnad.</p>
</LanguageComparison>

Das s-Passiv kann auch ein konkretes Ereignis beschreiben, wie in <span lang="sv">Cykeln
stals i går</span>. <span lang="sv">Bli</span> hebt das Ereignis oder den Übergang expliziter
hervor; es beansprucht nicht jedes Einzelereignis-Passiv für sich. Siehe
[Aktiv vs. Passiv](../active-vs-passive/) für die kommunikative Wahl und die
aktive Alternative mit <span lang="sv">man</span>.

## S-Verben, die kein Passiv sind

Manche Verben enden einfach auf <span lang="sv">-s</span> und haben keine aktive Form.
Sie sind keine Passive, und sie als solche zu übersetzen führt nicht weiter:

| Verb | Bedeutung |
| --- | --- |
| <span lang="sv">finns</span> | es gibt, existieren |
| <span lang="sv">hoppas</span> | hoffen |
| <span lang="sv">trivs</span> | sich wohlfühlen |
| <span lang="sv">minns</span> | sich erinnern |
| <span lang="sv">lyckas</span> | gelingen, erfolgreich sein |
| <span lang="sv">andas</span> | atmen |

- <span lang="sv">Jag hoppas att du mår bra.</span>
- <span lang="sv">Jag trivs i Malmö.</span>

## Das reziproke -s

Eine <span lang="sv">-s</span>-Form kann auch bedeuten, dass zwei oder mehr Personen etwas
*miteinander* tun:

- <span lang="sv">Vi ses!</span> — *Wir sehen uns!*
- <span lang="sv">De träffas varje vecka.</span> — *Sie treffen sich jede Woche.*
- <span lang="sv">De kramades.</span> — *Sie umarmten sich.*

## Typische Fehler

<MistakeBox title="Typische Fehler">
	- <span lang="sv">Rummet städas varje dag</span> ist das kompakte Routinemuster; schließe
	  daraus nicht, dass <span lang="sv">bli</span> jedem Einzelereignis vorbehalten ist.
	- ❌ <span lang="sv">Huset blev sålld</span>
	  ✅ <span lang="sv">Huset blev sålt.</span> — das Partizip kongruiert mit dem
	  Subjekt
	- ❌ <span lang="sv">Jag hoppar att du mår bra</span>
	  ✅ <span lang="sv">Jag hoppas att du mår bra.</span> —
	  <span lang="sv">hoppas</span> hat keine aktive Form
	- ❌ <span lang="sv">Boken skrevs från Astrid Lindgren</span>
	  ✅ <span lang="sv">Boken skrevs av Astrid Lindgren.</span>
	- Greife nicht zu <span lang="sv">bli</span>, nur weil das Deutsche
	  <span lang="de">werden</span> verwendet.
	</MistakeBox>

<MemoryTip>
Drei kurze Sätze trennen die zentralen Muster:
<span lang="sv"><strong>Rummet städas varje dag</strong></span> — Routine.
<span lang="sv"><strong>Dörren blev öppnad</strong></span> — Ereignis oder Wechsel.
<span lang="sv"><strong>Vi ses!</strong></span> — miteinander, überhaupt kein Passiv.
</MemoryTip>
