<KeyTakeaway>
- Der Imperativ ist eine Verbform ohne ausgedrücktes Subjekt:
  <span lang="sv">Kom!</span>, <span lang="sv">Vänta!</span>, <span lang="sv">Läs!</span>
- Verwende das verneinte Muster <span lang="sv">imperativ + inte</span>:
  <span lang="sv">Glöm inte biljetten!</span>
- Dieselbe Form kann ein direkter Befehl, eine Anweisung, eine Einladung oder
  ein freundlicher Vorschlag sein; Kontext und Abschwächungen bestimmen den
  Ton.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Verwende den Imperativ, wenn du willst, dass jemand direkt etwas tut. Das
Schwedische nutzt dieselbe Form, ob man eine Person oder mehrere anspricht.

## Jetzt anwenden

| Zweck | Beispiel |
| --- | --- |
| direkte Anweisung | <span lang="sv">Tryck här.</span> |
| Einladung | <span lang="sv">Kom in!</span> |
| freundlicher Vorschlag | <span lang="sv">Ta en bulle!</span> |
| verneinte Anweisung | <span lang="sv">Rör inte skärmen.</span> |

## Kernregel

Der Imperativ gehört zur Formenkette des Verbs. Bei vielen Verben ist er der
Stamm, der vor weiteren Endungen steht:

| Infinitiv | Imperativ |
| --- | --- |
| <span lang="sv">att tala</span> | <span lang="sv">tala!</span> |
| <span lang="sv">att köpa</span> | <span lang="sv">köp!</span> |
| <span lang="sv">att ringa</span> | <span lang="sv">ring!</span> |
| <span lang="sv">att gå</span> | <span lang="sv">gå!</span> |

Häufige unregelmäßige Formen sollten zusammen mit dem Verb gelernt werden, zum
Beispiel <span lang="sv">vara → var!</span> und <span lang="sv">göra → gör!</span>

Das Subjekt wird normalerweise weggelassen. Im verneinten Imperativ steht
<span lang="sv">inte</span> nach dem Imperativ: <span lang="sv">Gå inte dit!</span> Siehe
[Stellung von inte](../../sentence-structure/inte-placement/) für das
größere Stellungssystem.

## Ton und Alternativen

Ein bloßer Imperativ kann in Rezepten, auf Schildern und bei klaren
Anweisungen neutral sein. Im Gespräch füge <span lang="sv">gärna</span>, <span lang="sv">snälla</span>
oder eine Frageform hinzu, wenn die Beziehung oder die Bitte mehr Sanftheit
braucht:

- <span lang="sv">Sitt gärna här.</span>
- <span lang="sv">Kan du öppna fönstret?</span>

[Höfliche Bitten](../../../sentence-patterns/polite-requests/) bündelt diese
einsatzbereiten Kommunikationsmuster.

<MistakeBox title="Typische Fehler">
	- ❌ <span lang="sv">Inte glöm biljetten!</span>
	  ✅ <span lang="sv">Glöm inte biljetten!</span>
	- Füge kein obligatorisches Subjekt nach Analogie zu einer gewöhnlichen
	  Aussage hinzu.
	- Behandle nicht jeden Imperativ als unhöflich; Situation und Wortwahl
	  bestimmen den Ton.
</MistakeBox>
