<KeyTakeaway>
- Die Kernmodalverben <span lang="sv">kan</span>, <span lang="sv">vill</span>, <span lang="sv">måste</span>,
  <span lang="sv">får</span>, <span lang="sv">bör</span> und <span lang="sv">ska</span> stehen normalerweise mit einem

- Bei gewöhnlichen Verben ist das unterschiedlich: manche verlangen

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Modalverben drücken Fähigkeit, Wunsch, Notwendigkeit, Erlaubnis, Rat, Absicht
oder Erwartung aus. Sie sind finit; das folgende lexikalische Verb bleibt im
Infinitiv.

## Jetzt anwenden

| Bedeutung | Modalverb | Beispiel |
| --- | --- | --- |
| Fähigkeit oder Möglichkeit | <span lang="sv">kan</span> | <span lang="sv">Jag kan simma.</span> |
| Wunsch | <span lang="sv">vill</span> | <span lang="sv">Hon vill stanna.</span> |
| Notwendigkeit | <span lang="sv">måste</span> | <span lang="sv">Vi måste gå.</span> |
| Erlaubnis | <span lang="sv">får</span> | <span lang="sv">Ni får komma in.</span> |
| Rat | <span lang="sv">bör</span> | <span lang="sv">Du bör vila.</span> |
| Plan, Erwartung oder Verpflichtung | <span lang="sv">ska</span> | <span lang="sv">Jag ska ringa.</span> |

## Kernregel: bloßer Infinitiv nach einem Modalverb

Das Grundmuster ist **finites Modalverb + bloßer Infinitiv**:

- <span lang="sv">Jag kan tala svenska.</span>
- <span lang="sv">Vi vill beställa.</span>
- <span lang="sv">Du måste vänta.</span>

Füge kein <span lang="sv">att</span> ein: <span lang="sv">kan tala</span>, nicht <span lang="sv">kan att tala</span>.
Das finite Modalverb besetzt die Verbposition, die von den schwedischen
Wortstellungsregeln vorgegeben wird; der Infinitiv folgt als zweites Verb.
Siehe [V2](../../sentence-structure/v2/) für das Positionsmuster im
Hauptsatz.

## Gewöhnliche Zwei-Verb-Muster

Außerhalb der Kernmodalverben lernst du die Konstruktion mit dem ersten Verb:

- normalerweise erforderliches <span lang="sv">att</span>: <span lang="sv">planera att resa</span>,
  <span lang="sv">lova att komma</span>
- etablierte Muster mit bloßem Infinitiv: <span lang="sv">brukar arbeta</span>,
  <span lang="sv">orkar vänta</span>
- freie Variation in vielen Kontexten: <span lang="sv">börja arbeta</span> oder
  <span lang="sv">börja att arbeta</span>; <span lang="sv">försöka förstå</span> oder
  <span lang="sv">försöka att förstå</span>

Die Verwendung hängt von Verb und Register ab, sodass eine einzige
allgemeine Regel „zwei Verben brauchen <span lang="sv">att</span>“ scheitert. Speichere das
Anschlussmuster zusammen mit dem Verb.

## <span lang="sv">Ska</span>: Syntax hier, Zukunftswahl dort

Diese Seite behandelt das Muster <span lang="sv">ska</span> + bloßer Infinitiv und seinen
modalen Bedeutungsbereich. Nutze [Futurformen](../../verbs-time-forms/future-forms/),
um zu entscheiden, ob <span lang="sv">ska</span>, ein kontextuelles Präsens, <span lang="sv">tänker</span>
oder <span lang="sv">kommer att</span> die Zukunft am besten ausdrückt.

<MistakeBox title="Häufige Fehler">
	- ❌ <span lang="sv">Jag kan att simma.</span>
	  ✅ <span lang="sv">Jag kan simma.</span>
	- <span lang="sv">Får</span> betrifft meist Erlaubnis; <span lang="sv">kan</span> meist Fähigkeit oder
	  praktische Möglichkeit.
	- Verwende <span lang="sv">ska</span> nicht automatisch als Entsprechung für jedes
	  englische <em>will</em> oder deutsche <span lang="de">werden</span>.
</MistakeBox>

<MemoryTip>
Lerne eine kurze Einheit: <span lang="sv">kan simma</span>, <span lang="sv">vill stanna</span>,
<span lang="sv">försöker att förstå</span>. Das erste Verb entscheidet über das Muster.
</MemoryTip>
