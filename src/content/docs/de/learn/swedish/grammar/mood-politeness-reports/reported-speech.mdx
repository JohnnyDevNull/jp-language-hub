<KeyTakeaway>
- Gib eine Aussage mit <span lang="sv">att</span> wieder, eine Ja/Nein-Frage mit <span lang="sv">om</span>
  und eine W-Frage mit ihrem Fragewort.
- Indirekte Fragen verwenden die Wortstellung des Nebensatzes, nicht die
  Inversion der direkten Frage.
- Ändere Pronomen sowie Zeit- oder Ortsangaben, wenn sich die Perspektive der
  Wiedergabe ändert; das schwedische Tempus verlangt keine automatische
  Rückverschiebung nach englischem Muster.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Die indirekte Rede gibt den Inhalt der Worte einer Person wieder, ohne den
ursprünglichen Satz als Zitat zu wiederholen.

## Jetzt anwenden

| Ursprüngliche Aussage | Verknüpfung | Wiedergabe |
| --- | --- | --- |
| Aussage | <span lang="sv">att</span> | <span lang="sv">Hon säger att hon kommer.</span> |
| Ja/Nein-Frage | <span lang="sv">om</span> | <span lang="sv">Han frågar om jag kommer.</span> |
| W-Frage | dasselbe Fragewort | <span lang="sv">Hon frågar när tåget går.</span> |

## Aussagen mit <span lang="sv">att</span>

Verwende ein Redeverb wie <span lang="sv">säga</span>, <span lang="sv">berätta</span> oder
<span lang="sv">förklara</span>, gefolgt von einem <span lang="sv">att</span>-Satz:

<span lang="sv">Lisa säger: “Jag är trött.”</span> →
<span lang="sv">Lisa säger att hon är trött.</span>

## Indirekte Fragen

Eine Ja/Nein-Frage wird zu einem <span lang="sv">om</span>-Satz. Eine W-Frage behält ihr
Fragewort. Beide verwenden die Wortstellung des Nebensatzes:

<SentenceSchema
	caption="Wortstellung in indirekten Fragen"
	columns={['bisatsinledare', 'subjekt', 'satsadverbial', 'finit verb', 'infinit verb', 'adverbial']}
	rows={[
		{ label: 'Ja/Nein', lang: 'sv', cells: ['om', 'du', 'inte', 'kan', 'komma', ''] },
		{ label: 'Fragewort', lang: 'sv', cells: ['varför', 'hon', '', 'gick', '', 'hem'] },
	]}
/>

- <span lang="sv">Han frågar om du inte kan komma.</span>
- <span lang="sv">Jag undrar varför hon gick hem.</span>

Behalte die Inversion der direkten Frage nicht bei: <span lang="sv">varför hon gick</span>,
nicht <span lang="sv">varför gick hon</span> innerhalb der Wiedergabe.

## Perspektivwechsel

Passe Formen nur an, wenn die Wiedergabesituation es erfordert:

- Person: <span lang="sv">jag</span> kann zu <span lang="sv">hon</span> oder <span lang="sv">han</span> werden
- Besitz: <span lang="sv">min</span> kann zu <span lang="sv">hennes</span>, <span lang="sv">hans</span> oder einem
  reflexiven Possessivpronomen im betreffenden Satz werden
- Zeit: <span lang="sv">i dag</span> kann zu <span lang="sv">den dagen</span> werden
- Ort: <span lang="sv">här</span> kann zu <span lang="sv">där</span> werden

Wird die ursprüngliche Perspektive weiterhin geteilt, ist eine Änderung
möglicherweise unnötig.

## Tempusverhalten

Das Schwedische behält oft ein Tempus bei, das weiterhin wahr oder relevant
ist: <span lang="sv">Hon sa att hon bor i Malmö.</span> kann eine aktuell gültige Tatsache
wiedergeben. Eine Vergangenheitsform ist ebenso natürlich, wenn die Wiedergabe
in einen vergangenen Rahmen gehört oder die Situation nicht mehr zutrifft:
<span lang="sv">Hon sa att hon bodde i Malmö.</span>

Wende keine mechanische Rückverschiebungsregel nach englischem Vorbild an.
Wähle das Tempus anhand der aktuellen Zeitperspektive des Sprechers und der
beabsichtigten Bedeutung.

## Direkter Vergleich

<MistakeBox title="Typische Fehler">
	- ❌ <span lang="sv">Han frågar att jag kommer.</span>
	  ✅ <span lang="sv">Han frågar om jag kommer.</span>
	- ❌ <span lang="sv">Hon frågar var bor du.</span>
	  ✅ <span lang="sv">Hon frågar var du bor.</span>
	- Ändere nicht jedes Präsens in ein Präteritum, nur weil das Redeverb im
	  Präteritum steht.
</MistakeBox>

<MemoryTip>
Wähle zuerst die Verknüpfung: Aussage <span lang="sv">att</span>, Ja/Nein-Frage <span lang="sv">om</span>,
W-Frage das ursprüngliche Fragewort. Wechsle dann zur Wortstellung des
Nebensatzes.
</MemoryTip>
