<KeyTakeaway>
- Nutze die Subjektform für die Person oder Sache, die im Satz handelt oder etwas erlebt: <span lang="sv">hon kommer</span>.
- Nutze die Objektform nach Verb oder Präposition: <span lang="sv">jag ser henne</span>, <span lang="sv">med henne</span>.
- Geschriebenes <span lang="sv">de</span> und <span lang="sv">dem</span> werden normalerweise beide <span lang="sv">dom</span> ausgesprochen.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Schwedische Personalpronomen verändern sich vor allem nach Subjekt- oder Objektrolle. Das ist ein kompaktes Nachschlagen von Form und Rolle, keine schwedische Ausgabe des produktiven deutschen Nominativ-Akkusativ-Dativ-Systems für Nomen.

## Jetzt anwenden

| Rolle | Frage | Beispiel |
| --- | --- | --- |
| Subjekt | Wer handelt oder erlebt etwas? | <span lang="sv">Hon väntar.</span> |
| Objekt | Wen oder was betrifft die Handlung? | <span lang="sv">Jag ser henne.</span> |
| nach Präposition | Welche Form folgt auf Wörter wie <span lang="sv">med</span> oder <span lang="sv">till</span>? | <span lang="sv">med henne</span> |

## Grundformen

| Bedeutung | Subjekt | Objekt / nach Präposition |
| --- | --- | --- |
| ich / mich | <span lang="sv">jag</span> | <span lang="sv">mig</span> |
| du / dich | <span lang="sv">du</span> | <span lang="sv">dig</span> |
| er / ihn | <span lang="sv">han</span> | <span lang="sv">honom</span> |
| sie / sie | <span lang="sv">hon</span> | <span lang="sv">henne</span> |
| geschlechtsneutrale Person im Singular | <span lang="sv">hen</span> | <span lang="sv">hen</span> |
| es, en-Wort | <span lang="sv">den</span> | <span lang="sv">den</span> |
| es, ett-Wort | <span lang="sv">det</span> | <span lang="sv">det</span> |
| Menschen allgemein | <span lang="sv">man</span> | <span lang="sv">en</span> |
| wir / uns | <span lang="sv">vi</span> | <span lang="sv">oss</span> |
| ihr / euch | <span lang="sv">ni</span> | <span lang="sv">er</span> |
| sie / sie | <span lang="sv">de</span> | <span lang="sv">dem</span> |

<span lang="sv">Ni</span> ist hauptsächlich Plural. In manchen Dienstleistungssituationen oder bewusst formellen Kontexten kann es eine Person ansprechen, ist aber kein allgemeines schwedisches Gegenstück zu höflichem <span lang="de">Sie</span>. <span lang="sv">Du</span> ist im modernen Schwedisch die normale Form im Singular.

## Subjekt oder Objekt

- <span lang="sv">Hon ringer mig.</span> — Sie ruft mich an.
- <span lang="sv">Jag hjälper honom.</span> — Ich helfe ihm.
- <span lang="sv">De väntar på oss.</span> — Sie warten auf uns.
- <span lang="sv">Vi åker med dem.</span> — Wir fahren mit ihnen.

Präpositionen verlangen die Objektform: <span lang="sv">med mig</span>, <span lang="sv">till dig</span>, <span lang="sv">från henne</span>.

## Auf Dinge verweisen

Nutze <span lang="sv">den</span> für ein en-Wort und <span lang="sv">det</span> für ein ett-Wort, wenn ein Personalpronomen auf eine bestimmte Sache verweist:

- <span lang="sv">Var är bilen? Den står ute.</span>
- <span lang="sv">Var är brevet? Det ligger här.</span>

Diese Verweisfunktion ist etwas anderes als demonstrative Gruppen wie <span lang="sv">den här bilen</span>.

## Gesprochenes *dom* und geschriebenes *de/dem*

In der Standardschrift steht <span lang="sv">de</span> als Subjekt und <span lang="sv">dem</span> als Objekt: <span lang="sv">De såg oss</span>; <span lang="sv">vi såg dem</span>. In der gesprochenen Sprache heißen beide normalerweise <span lang="sv">dom</span>; auch in informeller Schrift kommt <span lang="sv">dom</span> vor.

## Direkter Vergleich

<LanguageComparison title="Nach einer Präposition">
  <p slot="de">mit ihr</p>
  <p slot="en">with her</p>
  <p slot="sv">med henne</p>
</LanguageComparison>

Deutsch hat ein breiteres produktives Kasussystem bei Artikeln, Adjektiven und Nomen. Schwedisch bewahrt den Kontrast zwischen Subjekt und Objekt hauptsächlich bei Personalpronomen.

<MistakeBox title="Typische Fehler">
- <span lang="sv">❌ med jag</span> → <span lang="sv">✅ med mig</span>
- <span lang="sv">❌ henne kommer</span> → <span lang="sv">✅ hon kommer</span>
- Verwende in der Standardschrift <span lang="sv">de</span> als Subjekt und <span lang="sv">dem</span> als Objekt.
</MistakeBox>

<MemoryTip>
Lerne jedes Paar als kleinen Rhythmus: <span lang="sv"><strong>jag–mig, du–dig, hon–henne, vi–oss, de–dem</strong></span>.
</MemoryTip>
