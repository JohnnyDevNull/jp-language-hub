<KeyTakeaway>
- Vor einem Nomen folgt die Form dem Nomen: <span lang="sv">någon</span> bei <span lang="sv">en</span>,
  <span lang="sv">något</span> bei <span lang="sv">ett</span>, <span lang="sv">några</span> im Plural.
- Alleinstehend bezeichnet <span lang="sv">någon</span> eine Person, <span lang="sv">något</span> eine Sache
  und <span lang="sv">några</span> eine Gruppe im Plural.
- <span lang="sv">ingen</span>, <span lang="sv">inget</span> und <span lang="sv">inga</span> sind die negativen Formen
  derselben Dreiteilung.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Schwedisch verwendet <span lang="sv">någon</span>, <span lang="sv">något</span> und <span lang="sv">några</span> für
unbestimmte Bedeutung: „ein/einige“, „irgend-“ oder „jemand/etwas“. Die
negativen Formen sind <span lang="sv">ingen</span>, <span lang="sv">inget</span> und <span lang="sv">inga</span>:
„kein“, „niemand“ oder „nichts“.

## Grundformen

Steht eines dieser Wörter vor einem Nomen, wählst du nach dem Nomen:

| Bedeutung | <span lang="sv">en</span>-Nomen | <span lang="sv">ett</span>-Nomen | Pluralnomen |
| --- | --- | --- | --- |
| ein / irgendein | <span lang="sv">någon</span> | <span lang="sv">något</span> | <span lang="sv">några</span> |
| kein | <span lang="sv">ingen</span> | <span lang="sv">inget</span> | <span lang="sv">inga</span> |

## Vor einem Nomen

Vor einem <span lang="sv">en</span>-Nomen im Singular steht <span lang="sv">någon</span>:

<span lang="sv">Finns det någon mataffär?</span>

<span lang="de">Gibt es einen Supermarkt?</span>

Vor einem <span lang="sv">ett</span>-Nomen im Singular steht <span lang="sv">något</span>:

<span lang="sv">Har du något smultronställe?</span>

<span lang="de">Hast du einen Lieblingsplatz?</span>

Vor einem Pluralnomen steht <span lang="sv">några</span>:

<span lang="sv">Har ni några lediga rum?</span>

<span lang="de">Habt ihr irgendwelche freien Zimmer?</span>

## Negative Formen

Für die Verneinung verwendest du <span lang="sv">ingen</span>, <span lang="sv">inget</span> oder
<span lang="sv">inga</span> nach demselben Nomenschema:

| Frage | Verneinte Antwort |
| --- | --- |
| <span lang="sv">Finns det någon kyrka?</span> | <span lang="sv">Nej, det finns ingen kyrka.</span> |
| <span lang="sv">Finns det något hav här?</span> | <span lang="sv">Nej, det finns inget hav här.</span> |
| <span lang="sv">Har ni några lediga rum?</span> | <span lang="sv">Nej, vi har inga lediga rum.</span> |

Deutsch heißt das oft „kein“, „keine“ oder „nicht irgendein“:

<span lang="de">Gibt es hier ein Meer? Nein, es gibt hier kein Meer.</span>

## Alleinstehend

<span lang="sv">Någon</span> und <span lang="sv">något</span> können auch allein stehen. Dann entscheidest
du zwischen Person und Sache:

| Schwedisch | Bedeutung | Beispiel |
| --- | --- | --- |
| <span lang="sv">någon</span> | jemand / irgendjemand | <span lang="sv">Ska någon gå till spaavdelningen?</span> |
| <span lang="sv">något</span> | etwas / irgendetwas | <span lang="sv">Finns det något att äta?</span> |
| <span lang="sv">ingen</span> | niemand | <span lang="sv">Ingen behöver köpa ägg.</span> |
| <span lang="sv">inget</span> | nichts | <span lang="sv">Jag förstår inget.</span> |
| <span lang="sv">några</span> | einige Personen oder Dinge | <span lang="sv">Några kom tidigt.</span> |
| <span lang="sv">inga</span> | keine | <span lang="sv">Inga kom för sent.</span> |

Die Pluralformen können auch ein verstandenes Pluralnomen ersetzen:
<span lang="sv">Jag köpte några</span> („Ich kaufte welche“) und <span lang="sv">Jag hittade inga</span>
(„Ich fand keine“).

## Fragen und Aussagen

In Fragen bedeuten <span lang="sv">någon</span>, <span lang="sv">något</span> und <span lang="sv">några</span> oft
„irgendein“ oder „etwas“:

- <span lang="sv">Finns det någon kyrka?</span>
- <span lang="sv">Finns det något hav här?</span>
- <span lang="sv">Har du några planer för semestern?</span>

In Aussagen kann <span lang="sv">några</span> auch „ein paar“ bedeuten:

<span lang="sv">Jag tar några tomater också.</span>

<span lang="de">Ich nehme auch ein paar Tomaten.</span>

## Gesprochene Formen

Im Alltag wird <span lang="sv">någon</span> oft als <span lang="sv">nån</span> gesprochen und informell auch
so geschrieben. Ebenso wird <span lang="sv">något</span> oft zu <span lang="sv">nåt</span>.

| Standardsprache | Informell | Bedeutung |
| --- | --- | --- |
| <span lang="sv">någon</span> | <span lang="sv">nån</span> | jemand / irgendein <span lang="sv">en</span>-Nomen |
| <span lang="sv">något</span> | <span lang="sv">nåt</span> | etwas / irgendein <span lang="sv">ett</span>-Nomen |

Verwende in sorgfältigen Texten die Standardformen, außer der Ton soll bewusst
informell sein.

## Schnelle Entscheidungstabelle

| Kontext | Entscheide nach | Verwende |
| --- | --- | --- |
| Ein Nomen folgt | <span lang="sv">en</span>, <span lang="sv">ett</span> oder Plural | <span lang="sv">någon</span> / <span lang="sv">något</span> / <span lang="sv">några</span> |
| Eine negative Nomengruppe folgt | <span lang="sv">en</span>, <span lang="sv">ett</span> oder Plural | <span lang="sv">ingen</span> / <span lang="sv">inget</span> / <span lang="sv">inga</span> |
| Kein Nomen folgt | Person, Sache oder Pluralgruppe | <span lang="sv">någon</span> = jemand, <span lang="sv">något</span> = etwas, <span lang="sv">några</span> = einige |
| Negativ, ohne Nomen | Person, Sache oder Pluralgruppe | <span lang="sv">ingen</span> = niemand, <span lang="sv">inget</span> = nichts, <span lang="sv">inga</span> = keine |

Diese Seite behandelt Formen und Übereinstimmung in der Nominalgruppe. Für die
größere Wahl zwischen Satzverneinung, negativer Nominalgruppe und negativem
Adverb siehe [Negation](../../questions-negation/negation/).

## Typische Fehler

<MistakeBox title="Typische Fehler">
	- ❌ <span lang="sv">något kyrka</span> ✅ <span lang="sv">någon kyrka</span>
	- ❌ <span lang="sv">någon hav</span> ✅ <span lang="sv">något hav</span>
	- ❌ <span lang="sv">ingen lediga rum</span> ✅ <span lang="sv">inga lediga rum</span>
	- ❌ <span lang="sv">någon</span> und <span lang="sv">något</span> bei folgendem Nomen nach Person oder
	  Sache wählen. Wähle dann nach <span lang="sv">en</span>, <span lang="sv">ett</span> oder Plural.
</MistakeBox>
