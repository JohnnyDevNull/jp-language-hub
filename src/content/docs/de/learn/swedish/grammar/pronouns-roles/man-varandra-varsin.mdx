Diese Seite sammelt Pronomen, mit denen Schwedisch über Menschen allgemein und
über ihr Verhältnis zueinander spricht.

## man für allgemeine Aussagen

<span lang="sv">Man</span> funktioniert wie deutsches <span lang="de">man</span>, wenn beide
Pronomen sind: Es macht eine Aussage über Menschen allgemein, ohne jemanden zu
nennen.

- <span lang="sv">Man får inte parkera här.</span> — Hier darf man nicht parken.
- <span lang="sv">Så säger man i Sverige.</span> — So sagt man in Schweden.

Englisch hat kein einzelnes Gegenstück und weicht deshalb oft auf das Passiv
aus. Im Schwedischen ist <span lang="sv">man</span> häufig die natürlichere Wahl.

<span lang="sv">Man</span> hat eine Objektform, eine Genitivform und ein eigenes
reflexives Possessivpronomen:

| Funktion | Form | Beispiel |
| --- | --- | --- |
| Subjekt | <span lang="sv">man</span> | <span lang="sv">Man vet aldrig.</span> |
| Objekt | <span lang="sv">en</span> | <span lang="sv">Det gör en glad.</span> |
| Genitiv / gewöhnliches Possessiv | <span lang="sv">ens</span> | <span lang="sv">Det påverkar ens hälsa.</span> |
| Reflexives Possessivpronomen | <span lang="sv">sin / sitt / sina</span> | <span lang="sv">Man måste ta sitt ansvar.</span> |

Verwende <span lang="sv">ens</span> für allgemeines „sein/ihr“, wenn der Besitzer nicht das
Subjekt ist, das innerhalb desselben Satzes etwas besitzt. Ist <span lang="sv">man</span>
Subjekt und verweist der Besitz darauf zurück, steht <span lang="sv">sin / sitt / sina</span>:
<span lang="sv">Man måste ta sitt ansvar</span>. Die Satzgrenze erklärt
[*sin, sitt, sina*](../sin-sitt-sina/).

<RuleBox title="Verwechsle man nicht mit einem Nomen">
	<span lang="sv">Man</span> als Pronomen ist unbetont und hat nie einen Artikel.
	<span lang="sv">En man</span> mit Artikel ist das Nomen „ein Mann“. Nur Artikel und Betonung
	trennen sie.
</RuleBox>

## varandra für „einander"

<span lang="sv">Varandra</span> ist unveränderlich und nie Subjekt. Es kann Objekt eines
Verbs oder Ergänzung nach einer Präposition sein. Der Genitiv lautet
<span lang="sv">varandras</span>:

- <span lang="sv">De hjälper varandra.</span> — Sie helfen einander.
- <span lang="sv">De talar med varandra.</span> — Sie sprechen miteinander.
- <span lang="sv">Vi läser varandras texter.</span> — Wir lesen die Texte voneinander.

Viele Verben drücken dieselbe Idee stattdessen mit einer <span lang="sv">-s</span>-Form aus:

- <span lang="sv">De träffas varje vecka.</span> = <span lang="sv">De träffar varandra varje vecka.</span>
- <span lang="sv">Vi ses!</span>

Siehe [Passiv](../../verb-patterns-voice/passive/) für dieses <span lang="sv">-s</span>.

Weil <span lang="sv">varandra</span> ein <span lang="sv">objekt</span> ist, kann es unter der V2-Regel dennoch
vorangestellt werden: <span lang="sv">Varandra hjälper de</span> ist markiert, aber
grammatisch. Die Voranstellung macht es nicht zum <span lang="sv">subjekt</span>.

## var sin: je eins

<span lang="sv">Var sin</span> und <span lang="sv">var sitt</span> — auch <span lang="sv">varsin</span> und
<span lang="sv">varsitt</span> — bedeuten, dass jede Person etwas Eigenes hat. Die Form folgt
dem Genus der besessenen Sache:

- <span lang="sv">De fick var sin bok.</span> — Sie bekamen je ein Buch.
- <span lang="sv">Barnen har var sitt rum.</span> — Die Kinder haben je ein eigenes Zimmer.

## varje, var och en und alla

| Schwedisch | Bedeutung | Hinweis |
| --- | --- | --- |
| <span lang="sv">varje</span> | jeder, jede, jedes | mit unbestimmtem Singular: <span lang="sv">varje dag</span> |
| <span lang="sv">var och en</span> | jede und jeder | alleinstehend: <span lang="sv">Var och en fick ett äpple.</span> |
| <span lang="sv">alla</span> | alle | <span lang="sv">alla barn</span>, <span lang="sv">Alla kom.</span> |
| <span lang="sv">allt</span> | alles | <span lang="sv">Allt är klart.</span> |

Für <span lang="sv">någon</span> und <span lang="sv">ingen</span> siehe
[någon, något, ingen und inget](../nagon-nagot-ingen-inget/).

## Ausdrücke mit som helst

Nach einem Fragewort ergibt <span lang="sv">som helst</span> die Bedeutung „irgend- / ganz
beliebig“:

| Schwedisch | Deutsch |
| --- | --- |
| <span lang="sv">vem som helst</span> | irgendjemand |
| <span lang="sv">vad som helst</span> | irgendetwas |
| <span lang="sv">när som helst</span> | jederzeit |
| <span lang="sv">var som helst</span> | irgendwo |
| <span lang="sv">hur som helst</span> | irgendwie, jedenfalls |

<span lang="sv">Hur som helst</span> ist außerdem ein sehr häufiger Diskursmarker mit der
Bedeutung „jedenfalls“.

## Direkter Vergleich

	<p slot="de">Man darf hier nicht parken.</p>
	<p slot="en">You may not park here.</p>
	<p slot="sv">Man får inte parkera här.</p>
</LanguageComparison>

<LanguageComparison title="Einander">
	<p slot="de">Sie helfen einander.</p>
	<p slot="en">They help each other.</p>
	<p slot="sv">De hjälper varandra.</p>
</LanguageComparison>

Deutsch hat ebenfalls <span lang="de">man</span>; Englisch muss zwischen
*you*, *people* und einem Passiv wählen.

## Typische Fehler

<MistakeBox title="Typische Fehler">
	- ❌ <span lang="sv">Man måste ta hans ansvar.</span>
	  ✅ <span lang="sv">Man måste ta sitt ansvar.</span>
	- ❌ <span lang="sv">Varandra hjälper.</span>, wenn „Sie helfen einander“ gemeint ist
	  ✅ <span lang="sv">De hjälper varandra.</span> — <span lang="sv">varandra</span> kann nicht das Subjekt liefern
	- ❌ <span lang="sv">varje dagen</span>
	  ✅ <span lang="sv">varje dag</span>
	- ❌ <span lang="sv">Man är trevlig</span> für „ein Mann ist nett“
	  ✅ <span lang="sv">En man är trevlig.</span>
</MistakeBox>

<span lang="sv"><strong>Man</strong></span> für Menschen allgemein,
<span lang="sv"><strong>varandra</strong></span> für Menschen zueinander und
<span lang="sv"><strong>var sin</strong></span> für je eins. Die Ausdrücke mit <span lang="sv">som helst</span>
bauen auf Fragewörtern auf.
</MemoryTip>
