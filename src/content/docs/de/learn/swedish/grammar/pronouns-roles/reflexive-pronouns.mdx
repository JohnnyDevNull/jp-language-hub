<KeyTakeaway>
- Verwende <span lang="sv">mig, dig, sig, oss,</span> oder <span lang="sv">er</span>, wenn das Objekt auf
  das Subjekt desselben Satzes zurückverweist.
- Subjekte der dritten Person verwenden <span lang="sv">sig</span>: <span lang="sv">hon tvättar sig</span>,
  <span lang="sv">de skyndar sig</span>.
- Reflexiver Besitz gehört zu <span lang="sv">sin, sitt, sina</span>; wechselseitige Bedeutung
  zu <span lang="sv">varandra</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Ein Reflexivpronomen zeigt, dass Subjekt und Objekt dieselbe Person oder Gruppe
meinen. Schwedisch verwendet Reflexivformen auch als Teil mehrerer häufiger Verben.

## Jetzt anwenden

| Subjekt | Reflexivobjekt | Beispiel |
| --- | --- | --- |
| <span lang="sv">jag</span> | <span lang="sv">mig</span> | <span lang="sv">Jag tvättar mig.</span> |
| <span lang="sv">du</span> | <span lang="sv">dig</span> | <span lang="sv">Du skyndar dig.</span> |
| <span lang="sv">han, hon, den, det, man</span> | <span lang="sv">sig</span> | <span lang="sv">Hon sätter sig.</span> |
| <span lang="sv">vi</span> | <span lang="sv">oss</span> | <span lang="sv">Vi lär oss svenska.</span> |
| <span lang="sv">ni</span> | <span lang="sv">er</span> | <span lang="sv">Ni måste skynda er.</span> |
| <span lang="sv">de</span> | <span lang="sv">sig</span> | <span lang="sv">De känner sig trötta.</span> |

## Grundregel

Wähle die Reflexivform nach dem Subjekt des Satzes. Vergleiche:

- <span lang="sv">Hon tvättar sig.</span> — Sie wäscht sich.
- <span lang="sv">Hon tvättar henne.</span> — Sie wäscht eine andere Frau.
- <span lang="sv">De ser sig i spegeln.</span> — Sie sehen sich im Spiegel.
- <span lang="sv">De ser dem.</span> — Sie sehen eine andere Gruppe.

Die Form verweist innerhalb desselben Satzes zurück. In
<span lang="sv">Anna säger att Erik skyndar sig</span> verweist <span lang="sv">sig</span> auf Erik, das
Subjekt des Nebensatzes.

## Häufige reflexive Verben

Lerne diese als vollständige Ausdrücke:

| Ausdruck | Bedeutung |
| --- | --- |
| <span lang="sv">skynda sig</span> | sich beeilen |
| <span lang="sv">sätta sig</span> | sich setzen |
| <span lang="sv">känna sig</span> | sich fühlen |
| <span lang="sv">lära sig</span> | lernen |
| <span lang="sv">gifta sig</span> | heiraten |

Das Reflexivpronomen ändert sich trotzdem mit dem Subjekt:
<span lang="sv">jag skyndar mig</span>, <span lang="sv">vi skyndar oss</span>, <span lang="sv">de skyndar sig</span>.

## Halte drei Systeme getrennt

- <span lang="sv">Hon tvättar sig.</span> — reflexives Objekt: Die Handlung kehrt zu ihr zurück.
- <span lang="sv">Hon tar sin jacka.</span> — reflexiver Besitz: Die Jacke gehört ihr.
- <span lang="sv">De hjälper varandra.</span> — reziprok: Jede Person hilft einer anderen.

## Direkter Vergleich

Im Englischen fehlt manchmal eine Reflexivform, die Schwedisch und Deutsch als
Teil des Verbsausdrucks verwenden.

<MistakeBox title="Typische Fehler">
- <span lang="sv">❌ Hon skyndar henne.</span> → <span lang="sv">✅ Hon skyndar sig.</span>
- <span lang="sv">❌ Vi känner sig trötta.</span> → <span lang="sv">✅ Vi känner oss trötta.</span>
- Verwende <span lang="sv">sig</span> nicht für Besitz; wähle <span lang="sv">sin, sitt,</span> oder
  <span lang="sv">sina</span> nach dem besessenen Nomen.
</MistakeBox>

<MemoryTip>
Ordne das Objekt dem Subjekt zu:
<span lang="sv"><strong>jag–mig, du–dig, hon–sig, vi–oss, ni–er, de–sig</strong></span>.
</MemoryTip>
