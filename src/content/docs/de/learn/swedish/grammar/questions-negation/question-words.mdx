<KeyTakeaway>
- In einer direkten Frage steht das Fragewort an erster und das
  <span lang="sv">finit verb</span> an zweiter Stelle: <span lang="sv">Var bor du?</span>
- Eine indirekte Frage ist ein Nebensatz, daher steht das <span lang="sv">subjekt</span>
  wieder vor dem Verb: <span lang="sv">Jag vet inte var hon bor.</span>
- In einer indirekten Frage erhalten <span lang="sv">vem</span> und <span lang="sv">vad</span> ein
  <span lang="sv">som</span>, wenn sie <span lang="sv">subjekt</span> ihres eigenen Nebensatzes sind.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Schwedische Fragewörter beginnen fast alle mit <span lang="sv">v-</span>, was
sie leicht erkennbar macht. Schwieriger ist die Wortstellung, die sich
zwischen direkten und indirekten Fragen unterscheidet.

## Jetzt anwenden

| Schwedisch | Frage nach … |
| --- | --- |
| <span lang="sv">vem</span> | einer Person |
| <span lang="sv">vems</span> | einem Besitzer |
| <span lang="sv">vad</span> | einer Sache, einem Ereignis oder einer Identität |
| <span lang="sv">vilken / vilket / vilka</span> | einer Auswahl aus einer Menge |
| <span lang="sv">var</span> | einem Ort |
| <span lang="sv">vart</span> | einer Richtung |
| <span lang="sv">när</span> | einer Zeit |
| <span lang="sv">hur</span> | Art und Weise oder Zustand |
| <span lang="sv">varför</span> | einem Grund |
| <span lang="sv">hur mycket / hur många</span> | Menge oder Anzahl |

<span lang="sv">Vem</span> ist unveränderlich — es gibt keine eigene Objektform,
sodass sich <span lang="sv">Vem såg du?</span> und <span lang="sv">Vem såg dig?</span>
nur in der Wortstellung unterscheiden, nicht im Pronomen.

## Kernregel: direkte Fragen

Steht das Fragewort nicht als <span lang="sv">subjekt</span>, besetzt es das erste
Satzglied, und das <span lang="sv">finit verb</span> folgt direkt darauf. Vergleiche diesen
Rahmen mit einer Ja/Nein-Frage:

<SentenceSchema
	caption="Muster direkter Fragen"
	rowHeader="Frage"
	columns={['1 fundament', '2 finit verb', '3 subjekt', 'adverbial']}
	rows={[
		{ label: 'Fragewort', cells: ['Var', 'bor', 'du', ''] },
		{ label: 'Fragephrase', cells: ['Vilken bok', 'läser', 'du', ''] },
		{ label: 'Ja/Nein', cells: ['', 'Bor', 'du', 'här?'] },
	]}
/>

Ist das Fragewort selbst das <span lang="sv">subjekt</span>, übernimmt es die
<span lang="sv">subjekt</span>rolle, und es folgt kein separates <span lang="sv">subjekt</span>:
<span lang="sv">Vem ringde?</span> und <span lang="sv">Vad hände?</span>

<RuleBox title="Kein do-support">
	Das Schwedische kennt nichts wie das englische *do*. <span lang="sv">Bor du här?</span>
	heißt *Do you live here?*, und <span lang="sv">Vad sa han?</span> heißt *What did he
	say?* Das Verb selbst rückt vor; es wird kein Hilfsverb eingefügt.
</RuleBox>

Siehe [Fragen](../questions/) für den gemeinsamen Ja/Nein-Rahmen und
[V2](../../sentence-structure/v2/) für Aussagesätze im Hauptsatz.

## Var oder vart

Das Standardschwedische trennt Ort von Richtung, wie im Deutschen:

- <span lang="sv">Var bor du?</span> — *Wo wohnst du?*
- <span lang="sv">Vart går du?</span> — *Wohin gehst du?*

Für „woher" steht die Präposition am Ende:
<span lang="sv">Var kommer du ifrån?</span>

## Vilken richtet sich nach dem Substantiv

Die <span lang="sv">vilken</span>-Reihe richtet sich nach Genus und Numerus des Substantivs:

- <span lang="sv">Vilken bok läser du?</span> — ein en-Wort
- <span lang="sv">Vilket hus är ditt?</span> — ein ett-Wort
- <span lang="sv">Vilka böcker har du läst?</span> — Plural

Für „was für ein/eine" verwendet das Schwedische <span lang="sv">vad för</span> oder
<span lang="sv">vad för sorts</span>:
<span lang="sv">Vad för sorts musik lyssnar du på?</span>

Siehe [en / ett](../../nouns-articles/en-ett/) für das Genus hinter dieser
Wahl.

## Indirekte Fragen: keine Inversion

Eine indirekte Frage ist ein Nebensatz. Das <span lang="sv">subjekt</span> steht daher vor
dem <span lang="sv">finit verb</span>, und ein <span lang="sv">satsadverbial</span> wie <span lang="sv">inte</span> steht
ebenfalls vor diesem Verb:

	caption="Wortstellung in der direkten Frage"
	rowHeader="Frage"

	rows={[
		{ label: 'Direkt', cells: ['Var', 'bor', 'hon', '', ''] },
	]}
/>

<SentenceSchema
	caption="Wortstellung in der indirekten Frage"
	rowHeader="Frage"
	columns={['bisatsinledare', 'subjekt', 'satsadverbial', 'finit verb', 'adverbial']}
	rows={[
		{ label: 'Neutral', cells: ['var', 'hon', '', 'bor', ''] },
		{ label: 'Verneint', cells: ['varför', 'hon', 'inte', 'kommer', ''] },

/>

- <span lang="sv">Var bor hon?</span> → <span lang="sv">Jag vet inte var hon bor.</span>
- <span lang="sv">Varför kommer hon?</span> → <span lang="sv">Jag förstår inte varför hon kommer.</span>

Siehe [Nebensätze](../../sentence-structure/subordinate-clauses/) für den
allgemeinen Rahmen von Nebensätzen. [Fragen](../questions/#indirect-yesno-questions-with-om)
behandelt indirekte Ja/Nein-Fragen mit <span lang="sv">om</span>.

## som einfügen, wenn das Fragewort <span lang="sv">subjekt</span> ist

In einer indirekten Frage erhalten <span lang="sv">vem</span> und <span lang="sv">vad</span> ein
<span lang="sv">som</span>, wenn sie das <span lang="sv">subjekt</span> ihres eigenen Nebensatzes sind:

- <span lang="sv">Jag vet inte vem som ringde.</span> — *Ich weiß nicht, wer angerufen
  hat.*
- <span lang="sv">Berätta vad som hände!</span> — *Erzähl, was passiert ist!*

Sind sie das <span lang="sv">objekt</span>, erscheint kein <span lang="sv">som</span>:

- <span lang="sv">Jag vet inte vem hon ringde.</span> — *…wen sie angerufen hat.*
- <span lang="sv">Berätta vad du gjorde!</span> — *…was du getan hast.*

Direkte Fragen brauchen es nicht: <span lang="sv">Vem ringde?</span>,
<span lang="sv">Vad hände?</span>

## Häufige Fehler

<MistakeBox title="Häufige Fehler">
	- ❌ <span lang="sv">Jag vet inte var bor hon.</span>
	  ✅ <span lang="sv">Jag vet inte var hon bor.</span>
	- ❌ <span lang="sv">Jag vet inte vem ringde.</span>
	  ✅ <span lang="sv">Jag vet inte vem som ringde.</span>
	- ❌ <span lang="sv">Vart bor du?</span>
	  ✅ <span lang="sv">Var bor du?</span>
	- ❌ <span lang="sv">Vilken hus är ditt?</span>
	  ✅ <span lang="sv">Vilket hus är ditt?</span>
</MistakeBox>

<MemoryTip>
Kontrastiere ein Paar, bis es automatisch sitzt:
<span lang="sv"><strong>Vem som ringde</strong></span> — der Anrufer ist das
<span lang="sv">subjekt</span>. <span lang="sv"><strong>Vem hon ringde</strong></span> — der Anrufer ist
jemand anderes. Das zusätzliche <span lang="sv">som</span> markiert das <span lang="sv">subjekt</span>.
</MemoryTip>
