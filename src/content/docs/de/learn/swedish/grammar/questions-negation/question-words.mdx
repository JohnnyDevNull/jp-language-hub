<KeyTakeaway>
- In einer direkten Frage steht das Fragewort an erster und das finite Verb an
  zweiter Stelle: <Sv>Var bor du?</Sv>
- Eine indirekte Frage ist ein Nebensatz, daher steht das Subjekt wieder vor
  dem Verb: <Sv>Jag vet inte var hon bor.</Sv>
- In einer indirekten Frage erhalten <Sv>vem</Sv> und <Sv>vad</Sv> ein
  <Sv>som</Sv>, wenn sie Subjekt ihres eigenen Nebensatzes sind.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Schwedische Fragewörter beginnen fast alle mit <Sv>v-</Sv>, was
sie leicht erkennbar macht. Schwieriger ist die Wortstellung, die sich
zwischen direkten und indirekten Fragen unterscheidet.

## Jetzt anwenden

| Schwedisch | Frage nach … |
| --- | --- |
| <Sv>vem</Sv> | einer Person |
| <Sv>vems</Sv> | einem Besitzer |
| <Sv>vad</Sv> | einer Sache, einem Ereignis oder einer Identität |
| <Sv>vilken / vilket / vilka</Sv> | einer Auswahl aus einer Menge |
| <Sv>var</Sv> | einem Ort |
| <Sv>vart</Sv> | einer Richtung |
| <Sv>när</Sv> | einer Zeit |
| <Sv>hur</Sv> | Art und Weise oder Zustand |
| <Sv>varför</Sv> | einem Grund |
| <Sv>hur mycket / hur många</Sv> | Menge oder Anzahl |

<Sv>Vem</Sv> ist unveränderlich — es gibt keine eigene Objektform,
sodass sich <Sv>Vem såg du?</Sv> und <Sv>Vem såg dig?</Sv>
nur in der Wortstellung unterscheiden, nicht im Pronomen.

## Kernregel: direkte Fragen

Steht das Fragewort nicht als Subjekt, besetzt es das erste Satzglied, und
das finite Verb folgt direkt darauf. Vergleiche diesen Rahmen mit einer
Ja/Nein-Frage:

<SentenceSchema
	caption="Muster direkter Fragen"
	rowHeader="Frage"
	columns={['Fragephrase', 'Finites Verb', 'Subjekt', 'Rest']}
	rows={[
		{ label: 'Fragewort', cells: ['Var', 'bor', 'du', ''] },
		{ label: 'Fragephrase', cells: ['Vilken bok', 'läser', 'du', ''] },
		{ label: 'Ja/Nein', cells: ['', 'Bor', 'du', 'här?'] },
	]}
/>

Ist das Fragewort selbst das Subjekt, übernimmt es die Subjektrolle, und es
folgt kein separates Subjekt: <Sv>Vem ringde?</Sv> und <Sv>Vad hände?</Sv>

<RuleBox title="Kein do-support">
	Das Schwedische kennt nichts wie das englische *do*. <Sv>Bor du här?</Sv>
	heißt *Do you live here?*, und <Sv>Vad sa han?</Sv> heißt *What did he
	say?* Das Verb selbst rückt vor; es wird kein Hilfsverb eingefügt.
</RuleBox>

Siehe [Fragen](../questions/) für den gemeinsamen Ja/Nein-Rahmen und
[V2](../../sentence-structure/v2/) für Aussagesätze im Hauptsatz.

## Var oder vart

Das Standardschwedische trennt Ort von Richtung, wie im Deutschen:

- <Sv>Var bor du?</Sv> — *Wo wohnst du?*
- <Sv>Vart går du?</Sv> — *Wohin gehst du?*

Für „woher" steht die Präposition am Ende:
<Sv>Var kommer du ifrån?</Sv>

## Vilken richtet sich nach dem Substantiv

Die <Sv>vilken</Sv>-Reihe richtet sich nach Genus und Numerus des Substantivs:

- <Sv>Vilken bok läser du?</Sv> — ein en-Wort
- <Sv>Vilket hus är ditt?</Sv> — ein ett-Wort
- <Sv>Vilka böcker har du läst?</Sv> — Plural

Für „was für ein/eine" verwendet das Schwedische <Sv>vad för</Sv> oder
<Sv>vad för sorts</Sv>:
<Sv>Vad för sorts musik lyssnar du på?</Sv>

Siehe [en / ett](../../nouns-articles/en-ett/) für das Genus hinter dieser
Wahl.

## Indirekte Fragen: keine Inversion

Eine indirekte Frage ist ein Nebensatz. Das Subjekt steht daher vor dem
finiten Verb, und ein Satzadverbial wie <Sv>inte</Sv> steht ebenfalls vor
diesem Verb:

<SentenceSchema
	caption="Wortstellung bei direkten und indirekten Fragen"
	rowHeader="Frage"
	columns={['Fragewort', 'Finites Verb (direkt)', 'Subjekt', 'Satzadverbial', 'Verb (indirekt)', 'Rest']}
	rows={[
		{ label: 'Direkt', cells: ['Var', 'bor', 'hon', '', '', ''] },
		{ label: 'Indirekt', cells: ['var', '', 'hon', '', 'bor', ''] },
		{ label: 'Indirekt, verneint', cells: ['varför', '', 'hon', 'inte', 'kommer', ''] },
	]}
/>

- <Sv>Var bor hon?</Sv> → <Sv>Jag vet inte var hon bor.</Sv>
- <Sv>Varför kommer hon?</Sv> → <Sv>Jag förstår inte varför hon kommer.</Sv>

Siehe [Nebensätze](../../sentence-structure/subordinate-clauses/) für den
allgemeinen Rahmen von Nebensätzen. [Fragen](../questions/#indirect-yesno-questions-with-om)
behandelt indirekte Ja/Nein-Fragen mit <Sv>om</Sv>.

## som einfügen, wenn das Fragewort Subjekt ist

In einer indirekten Frage erhalten <Sv>vem</Sv> und <Sv>vad</Sv> ein
<Sv>som</Sv>, wenn sie das Subjekt ihres eigenen Nebensatzes sind:

- <Sv>Jag vet inte vem som ringde.</Sv> — *Ich weiß nicht, wer angerufen
  hat.*
- <Sv>Berätta vad som hände!</Sv> — *Erzähl, was passiert ist!*

Sind sie das Objekt, erscheint kein <Sv>som</Sv>:

- <Sv>Jag vet inte vem hon ringde.</Sv> — *…wen sie angerufen hat.*
- <Sv>Berätta vad du gjorde!</Sv> — *…was du getan hast.*

Direkte Fragen brauchen es nicht: <Sv>Vem ringde?</Sv>,
<Sv>Vad hände?</Sv>

## Häufige Fehler

<MistakeBox title="Häufige Fehler">
	- ❌ <Sv>Jag vet inte var bor hon.</Sv>
	  ✅ <Sv>Jag vet inte var hon bor.</Sv>
	- ❌ <Sv>Jag vet inte vem ringde.</Sv>
	  ✅ <Sv>Jag vet inte vem som ringde.</Sv>
	- ❌ <Sv>Vart bor du?</Sv>
	  ✅ <Sv>Var bor du?</Sv>
	- ❌ <Sv>Vilken hus är ditt?</Sv>
	  ✅ <Sv>Vilket hus är ditt?</Sv>
</MistakeBox>

<MemoryTip>
Kontrastiere ein Paar, bis es automatisch sitzt:
<Sv><strong>Vem som ringde</strong></Sv> — der Anrufer ist das Subjekt.
<Sv><strong>Vem hon ringde</strong></Sv> — der Anrufer ist jemand anderes.
Das zusätzliche <Sv>som</Sv> markiert das Subjekt.
</MemoryTip>
