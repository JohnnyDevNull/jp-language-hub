<KeyTakeaway>
- Eine Ja-/Nein-Frage beginnt meist mit dem finiten Verb, dann folgt das Subjekt: <Sv>Kommer du?</Sv>
- Schwedisch verschiebt das vorhandene finite Verb; es gibt kein Gegenstück zu englischem *do*.
- Beginnt eine direkte Frage mit einem Nicht-Subjekt-Fragewort, folgt dasselbe Verb-Subjekt-Muster.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Bei einer Ja-/Nein-Frage kann die Antwort zustimmen oder verneinen. Stelle das finite Verb vor das Subjekt: <Sv>Du bor här.</Sv> → <Sv>Bor du här?</Sv>; <Sv>Hon har köpt biljetten.</Sv> → <Sv>Har hon köpt biljetten?</Sv>

## Kernregel

<SentenceSchema caption="Aussage und Ja-/Nein-Frage" rowHeader="Satz" columns={['Erstes Feld', 'Finites Verb', 'Subjekt', 'Satzadverbial', 'Nicht-finites Verb', 'Rest']} rows={[{ label: 'Aussage', cells: ['Du', 'kommer', '', '', '', 'imorgon.'] }, { label: 'Ja/Nein-Frage', cells: ['', 'Kommer', 'du', '', '', 'imorgon?'] }, { label: 'Verneinte Frage', cells: ['', 'Kommer', 'du', 'inte', '', 'imorgon?'] }, { label: 'Zwei Verben', cells: ['', 'Har', 'hon', '', 'köpt', 'biljetten?'] }]} />

Nur das finite Verb verschiebt sich. [Die Stellung von *inte*](../../sentence-structure/inte-placement/) behandelt <Sv>inte</Sv>.

## Das gemeinsame Muster direkter Fragen

<SentenceSchema caption="Zwei direkte Frageanfänge" rowHeader="Fragetyp" columns={['Fragephrase', 'Finites Verb', 'Subjekt', 'Rest']} rows={[{ label: 'Ja/Nein', cells: ['', 'Bor', 'du', 'här?'] }, { label: 'Fragewort', cells: ['Var', 'bor', 'du', ''] }]} />

[Fragewörter](../question-words/) behandelt Wortwahl, Kongruenz, Subjektfragen und indirekte Fragen. Eine indirekte Ja-/Nein-Frage nutzt <Sv>om</Sv> und Nebensatzwortstellung:

<SentenceSchema caption="Direkte und indirekte Ja-/Nein-Fragen" rowHeader="Frage" columns={['Einleitung', 'Finites Verb (direkt)', 'Subjekt', 'Satzadverbial', 'Verb (indirekt)', 'Rest']} rows={[{ label: 'Direkt', cells: ['', 'Kommer', 'du', '', '', 'imorgon?'] }, { label: 'Indirekt', cells: ['om', '', 'du', '', 'kommer', 'imorgon'] }, { label: 'Indirekt, verneint', cells: ['om', '', 'du', 'inte', 'kommer', 'imorgon'] }]} />

<Sv>Kommer du imorgon?</Sv> → <Sv>Jag undrar om du kommer imorgon.</Sv> Kurze Antworten sind oft <Sv>Ja, det gör jag.</Sv> oder <Sv>Nej, det har hon inte.</Sv>

## Direkter Vergleich

<MistakeBox incorrect="Gör du bor här?" correct="Bor du här?" lang="sv">Übernimm nicht englisches *do*-support. Verschiebe das finite Verb, das schon in der Aussage steht.</MistakeBox>

<MemoryTip>Lass das finite Verb zuerst fragen: **finites Verb → Subjekt → Rest**.</MemoryTip>
