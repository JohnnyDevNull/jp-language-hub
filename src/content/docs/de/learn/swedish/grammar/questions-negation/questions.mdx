<KeyTakeaway>
- Eine Ja-/Nein-Frage beginnt meist mit dem <span lang="sv">finit verb</span>, gefolgt vom <span lang="sv">subjekt</span>: <span lang="sv">Kommer du?</span>
- Das Schwedische verschiebt das vorhandene <span lang="sv">finit verb</span>; es gibt keine
  Entsprechung zu englischem *do*.
- Beginnt eine direkte Frage mit einem Fragewort, das nicht <span lang="sv">subjekt</span> ist, steht
  dieser Ausdruck zuerst, und danach folgt dasselbe Verb-<span lang="sv">subjekt</span>-Muster.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Verwende eine Ja-/Nein-Frage, wenn die Antwort Bestätigung oder Verneinung
sein kann. Das finite Verb rückt vor das Subjekt; die Intonation unterstützt
die Frage, aber die Wortstellung markiert sie bereits.

## Jetzt anwenden

Mache aus einer neutralen Aussage eine Ja-/Nein-Frage, indem du das <span lang="sv">finit verb</span>
an den Satzanfang stellst:

- <span lang="sv">Du **bor** här.</span> → <span lang="sv">**Bor** du här?</span>
- <span lang="sv">Hon **har** köpt biljetten.</span> → <span lang="sv">**Har** hon köpt biljetten?</span>
- <span lang="sv">Ni **kan** komma imorgon.</span> → <span lang="sv">**Kan** ni komma imorgon?</span>

Nur das <span lang="sv">finit verb</span> verschiebt sich. Ein Supinum oder Infinitiv bleibt weiter
hinten im Satz stehen. Zur Stellung und zum pragmatischen Ton von <span lang="sv">inte</span>
siehe [Stellung von *inte*](../../sentence-structure/inte-placement/).

Eine direkte Frage kann auf zwei Arten beginnen:

## Indirekte Ja-/Nein-Fragen mit *om*

Wird eine Ja-/Nein-Frage Teil eines größeren Satzes, leite sie mit <span lang="sv">om</span>
("ob") ein und verwende die Nebensatz-Wortstellung:

- <span lang="sv">Jag vet inte om du kommer imorgon.</span>

[Nebensätze](../../sentence-structure/subordinate-clauses/).

## Kurze Antworten

Im Schwedischen antwortet man oft mit <span lang="sv">ja</span> oder <span lang="sv">nej</span> plus einem
knappen Nebensatz:

- <span lang="sv">Kommer du imorgon? — Ja, det gör jag.</span>
- <span lang="sv">Har hon ringt? — Nej, det har hon inte.</span>

Im Alltagsgespräch ist auch ein blankes <span lang="sv">ja</span> oder <span lang="sv">nej</span> möglich,
wenn die Antwort eindeutig ist.

## Direkter Vergleich

<LanguageComparison title="Ja-/Nein-Frage im Präsens">
	<p slot="de">Wohnst du hier?</p>
	<p slot="en">Do you live here?</p>
	<p slot="sv">Bor du här?</p>
</LanguageComparison>

Deutsch und Schwedisch verschieben das lexikalische finite Verb. Englisch
fügt im einfachen Präsens und Präteritum meist *do* hinzu, sofern nicht schon
ein Hilfsverb oder *be* vorhanden ist.

<MistakeBox
	incorrect="Gör du bor här?"
	correct="Bor du här?"
	lang="sv"
>
Übernimm nicht das englische *do*-Support ins Schwedische. Verschiebe das
<span lang="sv">finit verb</span>, das die Aussage bereits enthält.
</MistakeBox>

<MemoryTip>
Lass bei einer Ja-/Nein-Frage das <span lang="sv">finit verb</span> zuerst fragen: **<span lang="sv">finit verb</span> →
<span lang="sv">subjekt</span> → Rest**.
</MemoryTip>
