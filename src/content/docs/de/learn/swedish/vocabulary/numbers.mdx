<KeyTakeaway>
- Gewöhnliche zweiteilige Zahlen setzen den Zehner vor den Einer und
  schreiben die Teile normalerweise als ein Wort ohne <span lang="sv">och</span>:
  <span lang="sv">tjugoett</span>.
- Alleinstehendes <span lang="sv">en</span>/<span lang="sv">ett</span> richtet sich nach dem Substantiv.
  Nach Zehnern ist die End-1 normalerweise <span lang="sv">-en</span>; <span lang="sv">-ett</span>
  bleibt in festen Kontexten wie <span lang="sv">år</span>, <span lang="sv">nummer</span>,
  <span lang="sv">öre</span>, und bei Uhrzeitangaben erhalten.
- In einer zusammengesetzten Ordnungszahl wird nur das letzte Element zur
  Ordnungszahl: <span lang="sv">tjugoförsta</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Schwedische Zahlen sind praktisches Vokabular für Preise, Daten, Uhrzeiten,
Adressen und Mengen. Sitzen die ersten zwanzig sicher, folgen die meisten
alltäglichen Formen einem vorhersehbaren Muster.

## Jetzt anwenden

| Wenn du ... möchtest | Verwende |
| --- | --- |
| von 0 bis 20 zählen | die Grundliste auswendig lernen |
| 21, 42 oder 156 bilden | Zehner vor Einer, kein <span lang="sv">och</span>: <span lang="sv">tjugoett</span>, <span lang="sv">fyrtiotvå</span>, <span lang="sv">hundrafemtiosex</span> |
| ein einzelnes Substantiv zählen | <span lang="sv">en</span> oder <span lang="sv">ett</span> je nach Genus wählen |
| 21, 31, 41 vor einem Substantiv bilden | normalerweise die End-<span lang="sv">-en</span> verwenden: <span lang="sv">trettioen fartyg</span> |
| feste Zahlkontexte mit der t-Form verwenden | <span lang="sv">-ett</span> verwenden: <span lang="sv">tjugoett år</span>, <span lang="sv">nummer tjugoett</span>, <span lang="sv">tjugoett öre</span> |
| Daten schreiben | die Ordnungszahl nach <span lang="sv">den</span> verwenden: <span lang="sv">den tredje maj</span> |
| Dezimalzahlen schreiben | ein Komma verwenden: <span lang="sv">3,5</span> |

## Grundzahlen

| Zahl | Schwedisch | Zahl | Schwedisch |
| --- | --- | --- | --- |
| 0 | <span lang="sv">noll</span> | 11 | <span lang="sv">elva</span> |
| 1 | <span lang="sv">en / ett</span> | 12 | <span lang="sv">tolv</span> |
| 2 | <span lang="sv">två</span> | 13 | <span lang="sv">tretton</span> |
| 3 | <span lang="sv">tre</span> | 14 | <span lang="sv">fjorton</span> |
| 4 | <span lang="sv">fyra</span> | 15 | <span lang="sv">femton</span> |
| 5 | <span lang="sv">fem</span> | 16 | <span lang="sv">sexton</span> |
| 6 | <span lang="sv">sex</span> | 17 | <span lang="sv">sjutton</span> |
| 7 | <span lang="sv">sju</span> | 18 | <span lang="sv">arton</span> |
| 8 | <span lang="sv">åtta</span> | 19 | <span lang="sv">nitton</span> |
| 9 | <span lang="sv">nio</span> | 20 | <span lang="sv">tjugo</span> |
| 10 | <span lang="sv">tio</span> | | |

Die Zehner werden mit <span lang="sv">-tio</span> gebildet:

| Zahl | Schwedisch | Zahl | Schwedisch |
| --- | --- | --- | --- |
| 30 | <span lang="sv">trettio</span> | 70 | <span lang="sv">sjuttio</span> |
| 40 | <span lang="sv">fyrtio</span> | 80 | <span lang="sv">åttio</span> |
| 50 | <span lang="sv">femtio</span> | 90 | <span lang="sv">nittio</span> |
| 60 | <span lang="sv">sextio</span> | 100 | <span lang="sv">hundra</span> |

Beachte die Schreibweise <span lang="sv">fyrtio</span> für 40, die nicht
<span lang="sv">fyra</span> folgt. Mehrere Zahlwörter enthalten außerdem die sj- und
tj-Laute: <span lang="sv">sju</span>, <span lang="sv">sjutton</span>,
<span lang="sv">sjuttio</span>, <span lang="sv">tjugo</span>. Siehe
[Aussprache-Grundlagen](../../pronunciation-basics/).

## Größere Zahlen bilden

Alltägliche zusammengesetzte Zahlen werden von der größten Stelle abwärts
gebildet. Zwei- und dreiteilige Zusammensetzungen werden normalerweise als
ein Wort geschrieben:

- 21 — <span lang="sv">tjugoett</span>
- 42 — <span lang="sv">fyrtiotvå</span>
- 156 — <span lang="sv">hundrafemtiosex</span>
- 3 000 — <span lang="sv">tretusen</span>

<RuleBox title="Schwedisch dreht die Ziffern nicht um">
	Deutsch sagt <span lang="de">einundzwanzig</span>, mit der Einheit
	zuerst. Schwedisch sagt, wie das Englische, zuerst den Zehner:
	<span lang="sv">tjugoett</span> — *einundzwanzig*. Zwischen den Teilen steht kein
	<span lang="sv">och</span>.
</RuleBox>

<span lang="sv">Hundra</span> und <span lang="sv">tusen</span> können allein stehen
oder zur Betonung oder Klarheit <span lang="sv">ett</span> voranstellen:
<span lang="sv">hundra kronor</span> oder
<span lang="sv">etthundra kronor</span>.

## en oder ett für „eins“

Für sich genommen richtet sich die Zahl 1 nach dem Genus des gezählten
Substantivs, genau wie der unbestimmte Artikel:

- <span lang="sv">en bil</span> — ein Auto
- <span lang="sv">ett hus</span> — ein Haus

Nach einem Zehner ist die End-1 jedoch normalerweise <span lang="sv">-en</span>, sogar
vor vielen ett-Wörtern:

- <span lang="sv">tjugoen kronor</span> — 21 Kronen
- <span lang="sv">trettioen fartyg</span> — 31 Schiffe, obwohl <span lang="sv">ett fartyg</span> ein
  ett-Wort ist

Verwende <span lang="sv">-ett</span> in festen Zahlkontexten mit der t-Form, besonders
<span lang="sv">år</span>, <span lang="sv">nummer</span>, <span lang="sv">öre</span>, und bei Uhrzeitangaben:

- <span lang="sv">tjugoett år</span>
- <span lang="sv">nummer tjugoett</span>
- <span lang="sv">tjugoett öre</span>
- <span lang="sv">klockan tjugoett</span>

Jede andere Zahl bleibt unverändert. Siehe
[en / ett](../../grammar/nouns-articles/en-ett/) für das Substantivgenus.

## Ordnungszahlen

| Zahl | Schwedisch | Zahl | Schwedisch |
| --- | --- | --- | --- |
| 1. | <span lang="sv">första</span> | 11. | <span lang="sv">elfte</span> |
| 2. | <span lang="sv">andra</span> | 12. | <span lang="sv">tolfte</span> |
| 3. | <span lang="sv">tredje</span> | 13. | <span lang="sv">trettonde</span> |
| 4. | <span lang="sv">fjärde</span> | 14. | <span lang="sv">fjortonde</span> |
| 5. | <span lang="sv">femte</span> | 15. | <span lang="sv">femtonde</span> |
| 6. | <span lang="sv">sjätte</span> | 16. | <span lang="sv">sextonde</span> |
| 7. | <span lang="sv">sjunde</span> | 17. | <span lang="sv">sjuttonde</span> |
| 8. | <span lang="sv">åttonde</span> | 18. | <span lang="sv">artonde</span> |
| 9. | <span lang="sv">nionde</span> | 19. | <span lang="sv">nittonde</span> |
| 10. | <span lang="sv">tionde</span> | 20. | <span lang="sv">tjugonde</span> |

Die ersten zwölf lohnt es sich auswendig zu lernen. Von 13 bis 19 hängt
das Schwedische normalerweise <span lang="sv">-de</span> an die Grundzahl an:
<span lang="sv">trettonde</span>, <span lang="sv">fjortonde</span>,
<span lang="sv">nittonde</span>. Volle Zehner haben eigene Formen, wie
<span lang="sv">tjugo → tjugonde</span> und
<span lang="sv">trettio → trettionde</span>.

Bei einer zusammengesetzten Ordnungszahl wird **nur das letzte Element**
zur Ordnungszahl. Ist das letzte Element 1 oder 2, verwende
<span lang="sv">första</span> oder <span lang="sv">andra</span>:

- 21. — <span lang="sv">tjugoförsta</span>
- 42. — <span lang="sv">fyrtioandra</span>
- 100. — <span lang="sv">hundrade</span>

## Ordnungszahlen in Daten und im Schriftbild

Ordnungszahlen folgen normalerweise auf <span lang="sv">den</span>:

- <span lang="sv">Vi ses den första maj.</span> — *Wir sehen uns am 1. Mai.*
- <span lang="sv">Det är hennes tredje bok.</span> — *Es ist ihr drittes Buch.*

Als Ziffern geschrieben markiert das Schwedische die Ordnungszahl mit
einem Doppelpunkt plus Endung: <span lang="sv">1:a</span> und
<span lang="sv">2:a</span> für die Formen auf <span lang="sv">-a</span>, und
<span lang="sv">3:e</span>, <span lang="sv">4:e</span>, <span lang="sv">24:e</span> für
die übrigen.

## Millionen, Milliarden und Dezimalzahlen

<span lang="sv">Miljon</span> und <span lang="sv">miljard</span> sind Substantive:
sie nehmen einen Artikel und einen Plural.

| Wert | Schwedisch | Plural |
| --- | --- | --- |
| 10⁶ | <span lang="sv">en miljon</span> | <span lang="sv">två miljoner</span> |
| 10⁹ | <span lang="sv">en miljard</span> | <span lang="sv">två miljarder</span> |
| 10¹² | <span lang="sv">en biljon</span> | <span lang="sv">två biljoner</span> |

<MistakeBox title="Ein gefährlicher falscher Freund">
Schwedisch <span lang="sv">en biljon</span> ist 10¹², keine Milliarde. Das englische
*billion* entspricht <span lang="sv">en miljard</span>. Schwedisch zählt wie das
Deutsche: <span lang="de">Milliarde</span> → <span lang="sv">miljard</span>,
<span lang="de">Billion</span> → <span lang="sv">biljon</span>.
</MistakeBox>

Wie im Deutschen verwendet Schwedisch ein **Komma** als
Dezimaltrennzeichen und ein Leerzeichen zur Tausendergruppierung:
<span lang="sv">3,5</span> liest man
<span lang="sv">tre komma fem</span>, und 10 000 wird mit Leerzeichen geschrieben.

<MistakeBox title="Häufige Fehler">
	- ❌ <span lang="sv">ettochtjugo</span> — deutsche Ziffernreihenfolge
	  ✅ <span lang="sv">tjugoett</span>
	- ❌ <span lang="sv">tjugo och ett</span>
	  ✅ <span lang="sv">tjugoett</span>
	- ❌ <span lang="sv">tjugoett kronor</span>
	  ✅ <span lang="sv">tjugoen kronor</span>
	- ❌ <span lang="sv">trettioett fartyg</span>
	  ✅ <span lang="sv">trettioen fartyg</span>
	- ❌ <span lang="sv">den 3:a maj</span>
	  ✅ <span lang="sv">den 3:e maj</span>
	- Mache nicht beide Teile einer zusammengesetzten Ordnungszahl zur
	  Ordnungszahl:
	  <span lang="sv">❌ fyrtiondeandra</span>,
	  <span lang="sv">✅ fyrtioandra</span>.
</MistakeBox>

<MemoryTip>
Übe zuerst die Zahlen, die du wirklich brauchst: Preise, Hausnummern,
Jahreszahlen und deine eigene Telefonnummer. Sprich sie laut im
schwedischen Rhythmus —
<span lang="sv">tjugoett, tjugotvå, tjugotre</span> — damit die Reihenfolge
Zehner-vor-Einer automatisch wird statt übersetzt.
</MemoryTip>
