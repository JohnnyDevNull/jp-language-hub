<KeyTakeaway>
- Hausvokabular eignet sich gut, um <span lang="sv">en</span>, <span lang="sv">ett</span> und Pluralformen
  zu üben.
- Benutze <span lang="sv">i</span> für Zimmer und geschlossene Orte: <span lang="sv">i köket</span>.
- Benutze <span lang="sv">på</span> für viele Oberflächen und Tätigkeiten zu Hause:
  <span lang="sv">på bordet</span>, <span lang="sv">på jobbet</span>.
</KeyTakeaway>

Nutze diese Seite, um Zimmer und alltägliche Gegenstände zu benennen und sie
dann in kurze Sätze darüber einzubauen, wo sich etwas befindet.

## Zimmer

| Schwedisch | Deutsch |
| --- | --- |
| <span lang="sv">ett rum, rum</span> | Zimmer |
| <span lang="sv">ett kök, kök</span> | Küche |
| <span lang="sv">ett badrum, badrum</span> | Badezimmer |
| <span lang="sv">ett sovrum, sovrum</span> | Schlafzimmer |
| <span lang="sv">ett vardagsrum, vardagsrum</span> | Wohnzimmer |
| <span lang="sv">en hall, hallar</span> | Flur |

## Alltagsgegenstände

| Schwedisch | Deutsch |
| --- | --- |
| <span lang="sv">ett bord, bord</span> | Tisch |
| <span lang="sv">en stol, stolar</span> | Stuhl |
| <span lang="sv">en säng, sängar</span> | Bett |
| <span lang="sv">en dörr, dörrar</span> | Tür |
| <span lang="sv">ett fönster, fönster</span> | Fenster |
| <span lang="sv">en lampa, lampor</span> | Lampe |
| <span lang="sv">en nyckel, nycklar</span> | Schlüssel |
| <span lang="sv">en väska, väskor</span> | Tasche |

## Ortsangaben

| Bedarf | Schwedisches Muster |
| --- | --- |
| sagen, wo sich etwas befindet | <span lang="sv">Väskan ligger i hallen.</span> |
| sagen, dass etwas auf einer Fläche liegt | <span lang="sv">Nyckeln ligger på bordet.</span> |
| fragen, wo sich etwas befindet | <span lang="sv">Var är nyckeln?</span> |
| sagen, dass es in einem Zimmer etwas gibt | <span lang="sv">Det finns ett bord i köket.</span> |
| sagen, dass du zu Hause bist | <span lang="sv">Jag är hemma.</span> |

Die bestimmte Form taucht oft ganz natürlich auf, wenn der Gegenstand bekannt
ist: <span lang="sv">nyckeln</span>, <span lang="sv">väskan</span>, <span lang="sv">bordet</span>.
