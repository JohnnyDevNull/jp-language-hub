<KeyTakeaway>
- Hausvokabular eignet sich gut, um <Sv>en</Sv>, <Sv>ett</Sv> und Pluralformen
  zu üben.
- Benutze <Sv>i</Sv> für Zimmer und geschlossene Orte: <Sv>i köket</Sv>.
- Benutze <Sv>på</Sv> für viele Oberflächen und Tätigkeiten zu Hause:
  <Sv>på bordet</Sv>, <Sv>på jobbet</Sv>.
</KeyTakeaway>

Nutze diese Seite, um Zimmer und alltägliche Gegenstände zu benennen und sie
dann in kurze Sätze darüber einzubauen, wo sich etwas befindet.

## Zimmer

| Schwedisch | Deutsch |
| --- | --- |
| <Sv>ett rum, rum</Sv> | Zimmer |
| <Sv>ett kök, kök</Sv> | Küche |
| <Sv>ett badrum, badrum</Sv> | Badezimmer |
| <Sv>ett sovrum, sovrum</Sv> | Schlafzimmer |
| <Sv>ett vardagsrum, vardagsrum</Sv> | Wohnzimmer |
| <Sv>en hall, hallar</Sv> | Flur |

## Alltagsgegenstände

| Schwedisch | Deutsch |
| --- | --- |
| <Sv>ett bord, bord</Sv> | Tisch |
| <Sv>en stol, stolar</Sv> | Stuhl |
| <Sv>en säng, sängar</Sv> | Bett |
| <Sv>en dörr, dörrar</Sv> | Tür |
| <Sv>ett fönster, fönster</Sv> | Fenster |
| <Sv>en lampa, lampor</Sv> | Lampe |
| <Sv>en nyckel, nycklar</Sv> | Schlüssel |
| <Sv>en väska, väskor</Sv> | Tasche |

## Ortsangaben

| Bedarf | Schwedisches Muster |
| --- | --- |
| sagen, wo sich etwas befindet | <Sv>Väskan ligger i hallen.</Sv> |
| sagen, dass etwas auf einer Fläche liegt | <Sv>Nyckeln ligger på bordet.</Sv> |
| fragen, wo sich etwas befindet | <Sv>Var är nyckeln?</Sv> |
| sagen, dass es in einem Zimmer etwas gibt | <Sv>Det finns ett bord i köket.</Sv> |
| sagen, dass du zu Hause bist | <Sv>Jag är hemma.</Sv> |

Die bestimmte Form taucht oft ganz natürlich auf, wenn der Gegenstand bekannt
ist: <Sv>nyckeln</Sv>, <Sv>väskan</Sv>, <Sv>bordet</Sv>.
