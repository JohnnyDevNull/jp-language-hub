<KeyTakeaway>
- Benutze <Sv>till</Sv> für das Ziel und <Sv>mot</Sv> für die Strecke oder das
  Schild.
- Öffentliche Verkehrsmittel nutzen oft <Sv>på</Sv>: <Sv>på bussen</Sv>,
  <Sv>på tåget</Sv>.
- Speichere Fahrkartenwörter zusammen mit der Reiseart: <Sv>en enkelbiljett</Sv>,
  <Sv>en tur och retur</Sv>.
</KeyTakeaway>

Diese Seite gibt dir die Wörter, um eine Strecke zu finden, eine Fahrkarte zu
kaufen oder zu erwähnen, und zu fragen, wann etwas abfährt.

## Verkehrswörter

| Bereich | Schwedisch | Deutsch |
| --- | --- | --- |
| Fahrzeug | <Sv>en buss, bussar</Sv> | Bus |
| Fahrzeug | <Sv>ett tåg, tåg</Sv> | Zug |
| System | <Sv>tunnelbanan</Sv> | die U-Bahn |
| Fahrzeug | <Sv>en spårvagn, spårvagnar</Sv> | Straßenbahn |
| Ort | <Sv>en hållplats, hållplatser</Sv> | Haltestelle |
| Ort | <Sv>en station, stationer</Sv> | Bahnhof |
| Fahrkarte | <Sv>en biljett, biljetter</Sv> | Fahrkarte |
| Zeit | <Sv>en avgång, avgångar</Sv> | Abfahrt |

## Reisemuster

| Bedarf | Schwedisches Muster |
| --- | --- |
| fragen, wohin ein Bus fährt | <Sv>Går den här bussen till centrum?</Sv> |
| fragen, wann er abfährt | <Sv>När går tåget?</Sv> |
| dein Ziel nennen | <Sv>Jag ska till Malmö.</Sv> |
| nach der Haltestelle fragen | <Sv>Var är hållplatsen?</Sv> |
| das Schild lesen | <Sv>bussen mot centrum</Sv> |
| eine Fahrkarte kaufen | <Sv>En biljett till Lund, tack.</Sv> |

## Richtungswörter

| Schwedisch | Deutsch |
| --- | --- |
| <Sv>till</Sv> | zu, Richtung |
| <Sv>från</Sv> | von, aus |
| <Sv>mot</Sv> | in Richtung, Streckenschild |
| <Sv>nästa</Sv> | nächste |
| <Sv>sista</Sv> | letzte |
| <Sv>här</Sv> | hier |
| <Sv>där</Sv> | dort |
