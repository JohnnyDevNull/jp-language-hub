<KeyTakeaway>
- Benutze <span lang="sv">till</span> für das Ziel und <span lang="sv">mot</span> für die Strecke oder das
  Schild.
- Öffentliche Verkehrsmittel nutzen oft <span lang="sv">på</span>: <span lang="sv">på bussen</span>,
  <span lang="sv">på tåget</span>.
- Speichere Fahrkartenwörter zusammen mit der Reiseart: <span lang="sv">en enkelbiljett</span>,
  <span lang="sv">en tur och retur</span>.
</KeyTakeaway>

Diese Seite gibt dir die Wörter, um eine Strecke zu finden, eine Fahrkarte zu
kaufen oder zu erwähnen, und zu fragen, wann etwas abfährt.

## Verkehrswörter

| Bereich | Schwedisch | Deutsch |
| --- | --- | --- |
| Fahrzeug | <span lang="sv">en buss, bussar</span> | Bus |
| Fahrzeug | <span lang="sv">ett tåg, tåg</span> | Zug |
| System | <span lang="sv">tunnelbanan</span> | die U-Bahn |
| Fahrzeug | <span lang="sv">en spårvagn, spårvagnar</span> | Straßenbahn |
| Ort | <span lang="sv">en hållplats, hållplatser</span> | Haltestelle |
| Ort | <span lang="sv">en station, stationer</span> | Bahnhof |
| Fahrkarte | <span lang="sv">en biljett, biljetter</span> | Fahrkarte |
| Zeit | <span lang="sv">en avgång, avgångar</span> | Abfahrt |

## Reisemuster

| Bedarf | Schwedisches Muster |
| --- | --- |
| fragen, wohin ein Bus fährt | <span lang="sv">Går den här bussen till centrum?</span> |
| fragen, wann er abfährt | <span lang="sv">När går tåget?</span> |
| dein Ziel nennen | <span lang="sv">Jag ska till Malmö.</span> |
| nach der Haltestelle fragen | <span lang="sv">Var är hållplatsen?</span> |
| das Schild lesen | <span lang="sv">bussen mot centrum</span> |
| eine Fahrkarte kaufen | <span lang="sv">En biljett till Lund, tack.</span> |

## Richtungswörter

| Schwedisch | Deutsch |
| --- | --- |
| <span lang="sv">till</span> | zu, Richtung |
| <span lang="sv">från</span> | von, aus |
| <span lang="sv">mot</span> | in Richtung, Streckenschild |
| <span lang="sv">nästa</span> | nächste |
| <span lang="sv">sista</span> | letzte |
| <span lang="sv">här</span> | hier |
| <span lang="sv">där</span> | dort |

## Kurze Route

<p lang="sv">A: Ursäkta, går den här bussen till stationen?</p>

<p lang="sv">A: Tack! Var är hållplatsen?</p>
<p lang="sv">B: Där borta, vid apoteket.</p>
