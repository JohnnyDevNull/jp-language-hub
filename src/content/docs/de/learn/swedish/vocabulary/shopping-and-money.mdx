<KeyTakeaway>
- Preise werden mit <span lang="sv">kostar</span> ausgedrückt: <span lang="sv">Vad kostar den?</span>
- Zeige mit <span lang="sv">den här</span> oder <span lang="sv">det här</span>, wenn du das Wort nicht
  kennst.
- Zahlungsausdrücke sind kurz: <span lang="sv">med kort</span>, <span lang="sv">med Swish</span>,
  <span lang="sv">kontant</span>.
</KeyTakeaway>

Nutze diese Seite, wenn du eine einzelne Sache kaufen, nach dem Preis fragen
oder die grundlegenden Kassenwörter verstehen möchtest.

## Grundwörter

| Bereich | Schwedisch | Deutsch |
| --- | --- | --- |
| Ort | <span lang="sv">en affär, affärer</span> | Geschäft |
| Ort | <span lang="sv">en butik, butiker</span> | Laden |
| Gegenstand | <span lang="sv">en vara, varor</span> | Ware, Artikel |
| Gegenstand | <span lang="sv">ett kvitto, kvitton</span> | Quittung |
| Geld | <span lang="sv">ett pris, priser</span> | Preis |
| Geld | <span lang="sv">en krona, kronor</span> | Krone |
| Zahlung | <span lang="sv">ett kort, kort</span> | Karte |
| Zahlung | <span lang="sv">kontanter</span> | Bargeld |

## Einkaufsmuster

| Bedarf | Schwedisches Muster |
| --- | --- |
| nach dem Preis fragen | <span lang="sv">Vad kostar den?</span> |
| nach einem Ding im Neutrum fragen | <span lang="sv">Vad kostar det här?</span> |
| sagen, dass du dieses hier nimmst | <span lang="sv">Jag tar den här.</span> |
| um Hilfe bitten | <span lang="sv">Kan du hjälpa mig?</span> |
| mit Karte bezahlen | <span lang="sv">Jag betalar med kort.</span> |
| nach einer Quittung fragen | <span lang="sv">Kan jag få kvitto?</span> |

## Preiswörter

| Schwedisch | Deutsch |
| --- | --- |
| <span lang="sv">billig</span> | günstig |
| <span lang="sv">dyr</span> | teuer |
| <span lang="sv">rea</span> | Ausverkauf |
| <span lang="sv">rabatt</span> | Rabatt |
| <span lang="sv">öppet</span> | geöffnet |
| <span lang="sv">stängt</span> | geschlossen |

Bei Preisen sagt man auf Schwedisch normalerweise die Zahl plus <span lang="sv">kronor</span>:
<span lang="sv">Det kostar femtio kronor.</span>
