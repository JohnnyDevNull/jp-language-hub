<KeyTakeaway>
- Preise werden mit <Sv>kostar</Sv> ausgedrückt: <Sv>Vad kostar den?</Sv>
- Zeige mit <Sv>den här</Sv> oder <Sv>det här</Sv>, wenn du das Wort nicht
  kennst.
- Zahlungsausdrücke sind kurz: <Sv>med kort</Sv>, <Sv>med Swish</Sv>,
  <Sv>kontant</Sv>.
</KeyTakeaway>

oder die grundlegenden Kassenwörter verstehen möchtest.

## Grundwörter

| Bereich | Schwedisch | Deutsch |
| --- | --- | --- |
| Ort | <Sv>en affär, affärer</Sv> | Geschäft |
| Ort | <Sv>en butik, butiker</Sv> | Laden |
| Gegenstand | <Sv>en vara, varor</Sv> | Ware, Artikel |
| Gegenstand | <Sv>ett kvitto, kvitton</Sv> | Quittung |
| Geld | <Sv>ett pris, priser</Sv> | Preis |
| Geld | <Sv>en krona, kronor</Sv> | Krone |
| Zahlung | <Sv>ett kort, kort</Sv> | Karte |
| Zahlung | <Sv>kontanter</Sv> | Bargeld |

## Einkaufsmuster

| Bedarf | Schwedisches Muster |
| --- | --- |
| nach dem Preis fragen | <Sv>Vad kostar den?</Sv> |
| nach einem Ding im Neutrum fragen | <Sv>Vad kostar det här?</Sv> |
| sagen, dass du dieses hier nimmst | <Sv>Jag tar den här.</Sv> |
| um Hilfe bitten | <Sv>Kan du hjälpa mig?</Sv> |
| mit Karte bezahlen | <Sv>Jag betalar med kort.</Sv> |
| nach einer Quittung fragen | <Sv>Kan jag få kvitto?</Sv> |

## Preiswörter

| Schwedisch | Deutsch |
| --- | --- |
| <Sv>billig</Sv> | günstig |
| <Sv>dyr</Sv> | teuer |
| <Sv>rea</Sv> | Ausverkauf |
| <Sv>rabatt</Sv> | Rabatt |
| <Sv>öppet</Sv> | geöffnet |
| <Sv>stängt</Sv> | geschlossen |

Bei Preisen sagt man auf Schwedisch normalerweise die Zahl plus <Sv>kronor</Sv>:
<Sv>Det kostar femtio kronor.</Sv>
