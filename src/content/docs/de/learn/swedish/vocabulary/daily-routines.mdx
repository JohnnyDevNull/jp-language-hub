<KeyTakeaway>
- Das Präsens ändert sich nicht nach Person: <span lang="sv">jag jobbar</span>,
  <span lang="sv">vi jobbar</span>.
- Zeitgeführte Routinesätze nutzen das V2-Muster:
  <span lang="sv">På morgonen dricker jag kaffe.</span>
- Speichere Routinen als ganze Wendungen: <span lang="sv">gå upp</span>,
  <span lang="sv">gå och lägga sig</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Nutze diese Seite, um über das zu sprechen, was normalerweise an einem Tag
passiert. Die Wörter sind einfach, aber sie üben das Präsens und gängige
Zeitausdrücke. Zur Wortstellung hinter zeitgeführten Sätzen siehe die
[V2-Regel](../../grammar/sentence-structure/v2/).

## Routineverben

| Schwedisch | Deutsch |
| --- | --- |
| <span lang="sv">gå upp</span> | aufstehen |
| <span lang="sv">äta frukost</span> | frühstücken |
| <span lang="sv">dricka kaffe</span> | Kaffee trinken |
| <span lang="sv">gå till jobbet</span> | zur Arbeit gehen |
| <span lang="sv">jobba</span> | arbeiten |
| <span lang="sv">plugga</span> | lernen |
| <span lang="sv">laga mat</span> | kochen |
| <span lang="sv">titta på tv</span> | fernsehen |
| <span lang="sv">läsa</span> | lesen |
| <span lang="sv">gå och lägga sig</span> | ins Bett gehen |

## Zeitausdrücke

| Schwedisch | Deutsch |
| --- | --- |
| <span lang="sv">på morgonen</span> | am Morgen |
| <span lang="sv">på förmiddagen</span> | am Vormittag |
| <span lang="sv">på eftermiddagen</span> | am Nachmittag |
| <span lang="sv">på kvällen</span> | am Abend |
| <span lang="sv">på natten</span> | in der Nacht |
| <span lang="sv">varje dag</span> | jeden Tag |
| <span lang="sv">ofta</span> | oft |
| <span lang="sv">ibland</span> | manchmal |

## Alltagsmuster

| Bedarf | Schwedisches Muster |
| --- | --- |
| sagen, was du tust | <span lang="sv">Jag dricker kaffe på morgonen.</span> |
| die Zeit voranstellen | <span lang="sv">På morgonen dricker jag kaffe.</span> |
| sagen, wann du beginnst | <span lang="sv">Jag börjar klockan åtta.</span> |
| sagen, wie oft | <span lang="sv">Jag tränar ofta.</span> |
| nach einer Gewohnheit fragen | <span lang="sv">Vad gör du på kvällen?</span> |

## Kurze Routine

<p lang="sv">På morgonen går jag upp klockan sju.</p>
<p lang="sv">Jag äter frukost och dricker kaffe.</p>
<p lang="sv">Sedan går jag till jobbet.</p>
<p lang="sv">På kvällen lagar jag mat och läser.</p>
