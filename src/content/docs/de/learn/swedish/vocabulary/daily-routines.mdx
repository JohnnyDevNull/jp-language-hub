<KeyTakeaway>
- Das Präsens ändert sich nicht nach Person: <Sv>jag jobbar</Sv>,
  <Sv>vi jobbar</Sv>.
- Zeitgeführte Routinesätze nutzen das V2-Muster:
  <Sv>På morgonen dricker jag kaffe.</Sv>
- Speichere Routinen als ganze Wendungen: <Sv>gå upp</Sv>,
  <Sv>gå och lägga sig</Sv>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Nutze diese Seite, um über das zu sprechen, was normalerweise an einem Tag
passiert. Die Wörter sind einfach, aber sie üben das Präsens und gängige
Zeitausdrücke. Zur Wortstellung hinter zeitgeführten Sätzen siehe die
[V2-Regel](../../grammar/sentence-structure/v2/).

## Routineverben

| Schwedisch | Deutsch |
| --- | --- |
| <Sv>gå upp</Sv> | aufstehen |
| <Sv>äta frukost</Sv> | frühstücken |
| <Sv>dricka kaffe</Sv> | Kaffee trinken |
| <Sv>gå till jobbet</Sv> | zur Arbeit gehen |
| <Sv>jobba</Sv> | arbeiten |
| <Sv>plugga</Sv> | lernen |
| <Sv>laga mat</Sv> | kochen |
| <Sv>titta på tv</Sv> | fernsehen |
| <Sv>läsa</Sv> | lesen |
| <Sv>gå och lägga sig</Sv> | ins Bett gehen |

## Zeitausdrücke

| Schwedisch | Deutsch |
| --- | --- |
| <Sv>på morgonen</Sv> | am Morgen |
| <Sv>på förmiddagen</Sv> | am Vormittag |
| <Sv>på eftermiddagen</Sv> | am Nachmittag |
| <Sv>på kvällen</Sv> | am Abend |
| <Sv>på natten</Sv> | in der Nacht |
| <Sv>varje dag</Sv> | jeden Tag |
| <Sv>ofta</Sv> | oft |
| <Sv>ibland</Sv> | manchmal |

## Alltagsmuster

| Bedarf | Schwedisches Muster |
| --- | --- |
| sagen, was du tust | <Sv>Jag dricker kaffe på morgonen.</Sv> |
| die Zeit voranstellen | <Sv>På morgonen dricker jag kaffe.</Sv> |
| sagen, wann du beginnst | <Sv>Jag börjar klockan åtta.</Sv> |
| sagen, wie oft | <Sv>Jag tränar ofta.</Sv> |
| nach einer Gewohnheit fragen | <Sv>Vad gör du på kvällen?</Sv> |

## Kurze Routine

<p lang="sv">På morgonen går jag upp klockan sju.</p>

<p lang="sv">Sedan går jag till jobbet.</p>
<p lang="sv">På kvällen lagar jag mat och läser.</p>
