<KeyTakeaway>
- Lerne Essenssubstantive mit Artikel und Plural: <span lang="sv">en bulle, bullar</span>.
- Nutze <span lang="sv">jag skulle vilja ha</span> als höfliche Standardformel beim Bestellen.
- Kleine Zusatzwörter leisten viel: <span lang="sv">med</span>, <span lang="sv">utan</span>,
  <span lang="sv">lite</span>, <span lang="sv">en till</span>.
</KeyTakeaway>

Diese Seite gibt dir genug Wortschatz zum Thema Essen, um etwas Einfaches zu
bestellen, eine einfache Speisekarte zu lesen und deine Bestellung
anzupassen.

## Grundwörter

| Verwendung | Schwedisch | Deutsch |
| --- | --- | --- |
| Getränk | <span lang="sv">en kaffe, kaffe</span> | Kaffee |
| Getränk | <span lang="sv">ett te, teer</span> | Tee |
| Getränk | <span lang="sv">ett vatten, vatten</span> | Wasser |
| Getränk | <span lang="sv">en mjölk</span> | Milch |
| Essen | <span lang="sv">en bulle, bullar</span> | süßes Gebäckstück |
| Essen | <span lang="sv">en smörgås, smörgåsar</span> | belegtes Brot |
| Essen | <span lang="sv">en sallad, sallader</span> | Salat |
| Essen | <span lang="sv">en soppa, soppor</span> | Suppe |
| Süßes | <span lang="sv">en kaka, kakor</span> | Keks oder Kuchen |
| Süßes | <span lang="sv">en glass, glassar</span> | Eis |

Massennomen wie <span lang="sv">kaffe</span>, <span lang="sv">te</span> und <span lang="sv">vatten</span> kommen beim
alltäglichen Bestellen oft ohne Plural aus. Nutze den Artikel, wenn du eine
einzelne Portion meinst: <span lang="sv">en kaffe</span>, <span lang="sv">ett vatten</span>.

## Bestellmuster

| Bedarf | Schwedisches Muster |
| --- | --- |
| höflich bestellen | <span lang="sv">Jag skulle vilja ha en kaffe.</span> |
| direkt fragen | <span lang="sv">Kan jag få en smörgås?</span> |
| etwas hinzufügen | <span lang="sv">med mjölk</span>, <span lang="sv">med ost</span> |
| etwas weglassen | <span lang="sv">utan socker</span>, <span lang="sv">utan lök</span> |
| um ein weiteres Stück bitten | <span lang="sv">en till, tack</span> |
| fragen, was es gibt | <span lang="sv">Finns det något vegetariskt?</span> |
