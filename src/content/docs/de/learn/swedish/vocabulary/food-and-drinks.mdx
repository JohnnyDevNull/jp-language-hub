<KeyTakeaway>
- Lerne Essenssubstantive mit Artikel und Plural: <Sv>en bulle, bullar</Sv>.
- Nutze <Sv>jag skulle vilja ha</Sv> als höfliche Standardformel beim Bestellen.
- Kleine Zusatzwörter leisten viel: <Sv>med</Sv>, <Sv>utan</Sv>,
  <Sv>lite</Sv>, <Sv>en till</Sv>.
</KeyTakeaway>

Diese Seite gibt dir genug Wortschatz zum Thema Essen, um etwas Einfaches zu
bestellen, eine einfache Speisekarte zu lesen und deine Bestellung
anzupassen.

## Grundwörter

| Verwendung | Schwedisch | Deutsch |
| --- | --- | --- |
| Getränk | <Sv>en kaffe, kaffe</Sv> | Kaffee |
| Getränk | <Sv>ett te, teer</Sv> | Tee |
| Getränk | <Sv>ett vatten, vatten</Sv> | Wasser |
| Getränk | <Sv>en mjölk</Sv> | Milch |
| Essen | <Sv>en bulle, bullar</Sv> | süßes Gebäckstück |
| Essen | <Sv>en smörgås, smörgåsar</Sv> | belegtes Brot |
| Essen | <Sv>en sallad, sallader</Sv> | Salat |
| Essen | <Sv>en soppa, soppor</Sv> | Suppe |
| Süßes | <Sv>en kaka, kakor</Sv> | Keks oder Kuchen |
| Süßes | <Sv>en glass, glassar</Sv> | Eis |

Massennomen wie <Sv>kaffe</Sv>, <Sv>te</Sv> und <Sv>vatten</Sv> kommen beim
alltäglichen Bestellen oft ohne Plural aus. Nutze den Artikel, wenn du eine
einzelne Portion meinst: <Sv>en kaffe</Sv>, <Sv>ett vatten</Sv>.

## Bestellmuster

| Bedarf | Schwedisches Muster |
| --- | --- |
| höflich bestellen | <Sv>Jag skulle vilja ha en kaffe.</Sv> |
| direkt fragen | <Sv>Kan jag få en smörgås?</Sv> |
| etwas hinzufügen | <Sv>med mjölk</Sv>, <Sv>med ost</Sv> |
| etwas weglassen | <Sv>utan socker</Sv>, <Sv>utan lök</Sv> |
| um ein weiteres Stück bitten | <Sv>en till, tack</Sv> |
| fragen, was es gibt | <Sv>Finns det något vegetariskt?</Sv> |
