<KeyTakeaway>
- Nutze <span lang="sv">Jag skulle vilja ha ...</span> als sicheren höflichen Bestellrahmen.
- Nutze <span lang="sv">Kan jag få ...?</span>, wenn du nach einer Sache, einer Speisekarte,
  Wasser oder der Rechnung fragst.
- Passe die Bestellung an mit <span lang="sv">med</span>, <span lang="sv">utan</span>, <span lang="sv">extra</span> und
  <span lang="sv">vid sidan av</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Diese Seite gibt dir ein brauchbares Restaurant- oder Café-Skript: fragen, was
es gibt, bestellen, anpassen, auf eine Frage antworten und bezahlen.

## Bestellen

| Muster | Wofür du es nutzt | Beispiel |
| --- | --- | --- |
| <span lang="sv">Jag skulle vilja ha ...</span> | höfliche Standardbestellung | <span lang="sv">Jag skulle vilja ha en kaffe.</span> |
| <span lang="sv">Kan jag få ...?</span> | nach einer Sache fragen | <span lang="sv">Kan jag få menyn?</span> |
| <span lang="sv">Jag tar ...</span> | schnelle Wahl | <span lang="sv">Jag tar dagens lunch.</span> |
| <span lang="sv">Har ni ...?</span> | Verfügbarkeit prüfen | <span lang="sv">Har ni något vegetariskt?</span> |
| <span lang="sv">Vad rekommenderar du?</span> | um Empfehlung bitten | <span lang="sv">Vad rekommenderar du?</span> |
| <span lang="sv">Vad ingår?</span> | was inbegriffen ist | <span lang="sv">Vad ingår i dagens lunch?</span> |

## Die Bestellung anpassen

| Muster | Wofür du es nutzt | Beispiel |
| --- | --- | --- |
| <span lang="sv">med ...</span> | mit etwas | <span lang="sv">med mjölk</span> |
| <span lang="sv">utan ...</span> | ohne etwas | <span lang="sv">utan lök</span> |
| <span lang="sv">extra ...</span> | extra | <span lang="sv">extra sås</span> |
| <span lang="sv">vid sidan av</span> | separat serviert | <span lang="sv">Kan jag få såsen vid sidan av?</span> |
| <span lang="sv">att dricka</span> | zum Hiertrinken | <span lang="sv">En kaffe att dricka här.</span> |
| <span lang="sv">att ta med</span> | zum Mitnehmen | <span lang="sv">En kaffe att ta med, tack.</span> |

## Bezahlen und abschließen

| Muster | Wofür du es nutzt | Beispiel |
| --- | --- | --- |
| <span lang="sv">Kan jag få notan?</span> | nach der Rechnung fragen | <span lang="sv">Kan jag få notan?</span> |
| <span lang="sv">Kan jag betala med kort?</span> | mit Karte zahlen | <span lang="sv">Kan jag betala med kort?</span> |
| <span lang="sv">Det var allt, tack.</span> | das wars | <span lang="sv">Det var allt, tack.</span> |
| <span lang="sv">Tack, det var jättegott.</span> | nach dem Essen danken | <span lang="sv">Tack, det var jättegott.</span> |

## Kurzer Dialog

| Sprecher | Schwedisch |
| --- | --- |
| A | <span lang="sv">Hej! Vad vill du ha?</span> |
| B | <span lang="sv">Jag skulle vilja ha en kaffe och en bulle.</span> |
| A | <span lang="sv">Vill du ha mjölk i kaffet?</span> |
| B | <span lang="sv">Ja tack, lite mjölk. Och kan jag få ett glas vatten?</span> |
| A | <span lang="sv">Självklart.</span> |
| B | <span lang="sv">Tack. Det var allt.</span> |

## Direkter Vergleich

<LanguageComparison title="Höfliche Bestellung">
	<p slot="de">Ich hätte gern einen Kaffee.</p>
	<p slot="en">I would like a coffee.</p>
	<p slot="sv">Jag skulle vilja ha en kaffe.</p>
</LanguageComparison>

Das ist der sicherste vollständige Rahmen, weil er den Konditional
<span lang="sv">skulle</span>, das Wunschverb <span lang="sv">vilja</span> und das Erhalten-Verb
<span lang="sv">ha</span> enthält.

<LanguageComparison title="Zum Mitnehmen">
	<p slot="de">Einen Kaffee zum Mitnehmen, bitte.</p>
	<p slot="en">A coffee to go, please.</p>
	<p slot="sv">En kaffe att ta med, tack.</p>
</LanguageComparison>

Schwedisch nutzt eine Infinitivphrase: wörtlich „ein Kaffee zum Mitnehmen".
Lern <span lang="sv">att ta med</span> als eine feste Café-Einheit.
