<KeyTakeaway>
- <span lang="sv">tycker</span> drückt ein persönliches Urteil aus, <span lang="sv">tror</span> einen
  Glauben über Fakten, <span lang="sv">vet</span> Wissen. Deutsches
  <span lang="de">glauben</span> und <span lang="de">finden</span> lassen
  sich nicht eins zu eins übertragen.
- Die meisten Meinungs-Rahmen nehmen einen <span lang="sv">att</span>-Satz, und <span lang="sv">att</span>
  wird viel seltener weggelassen als das englische *that*.
- Verneine den Rahmen, nicht den Inhalt: <span lang="sv">Jag tror inte att han kommer.</span>
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Diese Rahmen tragen den Satz, während du über den Rest nachdenkst. Lerne sie
als ganze Einheiten, einschließlich des <span lang="sv">att</span>, das darauf folgt.
Für die Grammatik hinter <span lang="sv">borde</span> und anderen Modalentscheidungen, nutze
[Modalverben](../../grammar/verb-patterns-voice/modal-verbs/). Um die Aussage
einer anderen Person wiederzugeben statt deine eigene Sicht zu äußern, nutze
[Indirekte Rede](../../grammar/mood-politeness-reports/reported-speech/).

## Eine Meinung äußern

| Muster | Wofür es steht | Register |
| --- | --- | --- |
| <span lang="sv">Jag tycker att …</span> | persönliches Urteil, Geschmack, Bewertung | neutral |
| <span lang="sv">Jag tror att …</span> | Glaube oder Vermutung über einen Fakt | neutral |
| <span lang="sv">Jag anser att …</span> | wohlüberlegte, vertretene Position | formell |
| <span lang="sv">Enligt min mening …</span> | meiner Meinung nach | formell, schriftlich |
| <span lang="sv">Jag skulle säga att …</span> | abgeschwächte Meinung | neutral |
| <span lang="sv">För mig är det …</span> | rahmt es als persönlich, nicht allgemein | gesprochen |

## Unsicherheit markieren

| Muster | Wofür es steht | Register |
| --- | --- | --- |
| <span lang="sv">Jag är inte säker på om …</span> | ich bin nicht sicher, ob | neutral |
| <span lang="sv">Jag vet inte riktigt.</span> | ich weiß nicht so genau | gesprochen |
| <span lang="sv">Det beror på …</span> | es kommt darauf an | neutral |
| <span lang="sv">Så vitt jag vet …</span> | soweit ich weiß | neutral |
| <span lang="sv">Jag har ingen aning.</span> | ich habe keine Ahnung | gesprochen, unverblümt |

## Eine Annahme treffen

| Muster | Wofür es steht | Register |
| --- | --- | --- |
| <span lang="sv">Jag antar att …</span> | ich nehme an | neutral |
| <span lang="sv">Det verkar som om …</span> | es scheint, als ob | neutral |
| <span lang="sv">Det låter som …</span> | das klingt wie | gesprochen |
| <span lang="sv">Förmodligen …</span> / <span lang="sv">Troligen …</span> | wahrscheinlich | neutral bis formell |
| <span lang="sv">Det borde vara …</span> | Schlussfolgerung aus Anzeichen | neutral |

<span lang="sv">Förmodligen</span>, <span lang="sv">troligen</span> und <span lang="sv">så vitt jag vet</span> sind
Adverbiale. Stelle sie an den Anfang, und das finite Verb folgt trotzdem
sofort — V2 kümmert sich nicht darum, dass die Phrase drei Wörter lang ist.

## Direkter Vergleich

<LanguageComparison title="Urteil: tycker">
	<p slot="de">Ich finde, dass der Film gut ist.</p>
	<p slot="en">I think the film is good.</p>
	<p slot="sv">Jag tycker att filmen är bra.</p>
</LanguageComparison>

<LanguageComparison title="Glaube über einen Fakt: tror">
	<p slot="de">Ich glaube, dass er kommt.</p>
	<p slot="en">I think he is coming.</p>
	<p slot="sv">Jag tror att han kommer.</p>
</LanguageComparison>

Englisches *I think* deckt beide Zeilen ab; das Schwedische erzwingt die
Wahl. Deutsches <span lang="de">finden</span> entspricht <span lang="sv">tycker</span> und
<span lang="de">glauben</span> entspricht <span lang="sv">tror</span>, was Deutsch hier zur
sichereren Brücke macht.

<LanguageComparison title="Abschwächung">
	<p slot="de">Ich bin mir nicht sicher, ob das stimmt.</p>
	<p slot="en">I'm not sure if that's right.</p>
	<p slot="sv">Jag är inte säker på om det stämmer.</p>
</LanguageComparison>

Die Präposition gehört zum Muster: <span lang="sv">säker på</span>, nie <span lang="sv">säker om</span>.
