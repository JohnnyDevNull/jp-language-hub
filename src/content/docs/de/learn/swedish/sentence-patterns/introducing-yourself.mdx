<KeyTakeaway>
- Nutze <span lang="sv">Jag heter ...</span> als normalen ersten Satz; es bedeutet "ich
  heiße", nicht wörtlich "ich nenne".
- Nutze <span lang="sv">kommer från</span> für Herkunft und <span lang="sv">bor i</span> für den Ort, an
  dem du jetzt wohnst.
- Frag mit demselben Rahmen zurück: <span lang="sv">Vad heter du?</span>,
  <span lang="sv">Var kommer du ifrån?</span>, <span lang="sv">Vad gör du?</span>
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Das ist die kleinste nützliche Selbstvorstellung: Name, Herkunft, Ort, ein
Grund, warum du hier bist, und eine Rückfrage.

## Grundmuster zum Vorstellen

| Muster | Wofür du es nutzt | Beispiel |
| --- | --- | --- |
| <span lang="sv">Hej, jag heter ...</span> | mit deinem Namen eröffnen | <span lang="sv">Hej, jag heter Philipp.</span> |
| <span lang="sv">Jag kommer från ...</span> | Land, Stadt, Hintergrund | <span lang="sv">Jag kommer från Tyskland.</span> |
| <span lang="sv">Jag bor i ...</span> | wo du jetzt wohnst | <span lang="sv">Jag bor i Stockholm.</span> |
| <span lang="sv">Jag jobbar som ...</span> | berufliche Rolle | <span lang="sv">Jag jobbar som utvecklare.</span> |
| <span lang="sv">Jag pluggar ...</span> | Studienfach oder Lerninhalt | <span lang="sv">Jag pluggar svenska.</span> |
| <span lang="sv">Jag lär mig svenska.</span> | warum du langsam sprichst | <span lang="sv">Jag lär mig svenska.</span> |
| <span lang="sv">Trevligt att träffas.</span> | schön, dich kennenzulernen | <span lang="sv">Trevligt att träffas!</span> |

## Zurückfragen

| Frage | Wonach sie fragt | Natürliche Antwort |
| --- | --- | --- |
| <span lang="sv">Vad heter du?</span> | Name | <span lang="sv">Jag heter Anna.</span> |
| <span lang="sv">Var kommer du ifrån?</span> | Herkunft | <span lang="sv">Jag kommer från Malmö.</span> |
| <span lang="sv">Var bor du?</span> | aktueller Wohnort | <span lang="sv">Jag bor i Uppsala.</span> |
| <span lang="sv">Vad gör du?</span> | Arbeit oder Studium, im Kontext | <span lang="sv">Jag pluggar.</span> |
| <span lang="sv">Hur länge har du bott här?</span> | wie lange jemand hier wohnt | <span lang="sv">I två år.</span> |

Bei Städten und Ländern ist <span lang="sv">i</span> das sichere frühe Muster:
<span lang="sv">i Sverige</span>, <span lang="sv">i Stockholm</span>, <span lang="sv">i Tyskland</span>. Straßennamen und
manche Institutionen nutzen oft <span lang="sv">på</span>, aber heb dir das für die
Präpositionsseite auf.

## Mini-Sequenz

| Sprecher | Schwedisch |
| --- | --- |
| A | <span lang="sv">Hej, jag heter Anna. Vad heter du?</span> |
| B | <span lang="sv">Jag heter Philipp. Trevligt att träffas.</span> |
| A | <span lang="sv">Trevligt! Var kommer du ifrån?</span> |
| B | <span lang="sv">Jag kommer från Tyskland, men jag bor i Stockholm.</span> |
| A | <span lang="sv">Vad gör du?</span> |
| B | <span lang="sv">Jag jobbar som utvecklare och jag lär mig svenska.</span> |

## Direkter Vergleich

<LanguageComparison title="Name">
	<p slot="de">Ich heiße Philipp.</p>
	<p slot="en">My name is Philipp.</p>
	<p slot="sv">Jag heter Philipp.</p>
</LanguageComparison>

Deutsch ist hier die bessere Brücke: <span lang="de">heißen</span> und
<span lang="sv">heta</span> funktionieren beide wie "genannt werden". Englisch zieht dich zu
einer Nominalphrase, aber der alltägliche schwedische Satz ist der Verb-Rahmen.

<LanguageComparison title="Herkunft und aktueller Wohnort">
	<p slot="de">Ich komme aus Deutschland, aber ich wohne in Stockholm.</p>
	<p slot="en">I am from Germany, but I live in Stockholm.</p>
	<p slot="sv">Jag kommer från Tyskland, men jag bor i Stockholm.</p>
</LanguageComparison>
