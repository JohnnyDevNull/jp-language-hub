<KeyTakeaway>
- <span lang="sv">Kan jag få ...?</span> ist das Standardmuster, wenn du darum bittest, eine
  Sache zu bekommen.
- <span lang="sv">Kan du ...?</span> bittet jemanden, etwas zu tun; <span lang="sv">Skulle du kunna ...?</span>
  macht dieselbe Bitte weicher.
- Stell <span lang="sv">tack</span> ans Ende kleiner Serviceanfragen:
  <span lang="sv">En kaffe, tack.</span>
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Höfliches Schwedisch ist meist direkt, wird aber durch den richtigen Rahmen,
Ton und <span lang="sv">tack</span> abgemildert. Du brauchst keine lange Entschuldigung vor
jeder Bitte.

## Etwas erbitten

| Muster | Wofür du es nutzt | Beispiel |
| --- | --- | --- |
| <span lang="sv">Kan jag få ...?</span> | kann ich haben, kann ich bekommen | <span lang="sv">Kan jag få ett kvitto?</span> |
| <span lang="sv">Jag skulle vilja ha ...</span> | ich möchte gern; höflicher Standard | <span lang="sv">Jag skulle vilja ha en kaffe.</span> |
| <span lang="sv">En ..., tack.</span> | kurze Bestellung am Tresen | <span lang="sv">En bulle, tack.</span> |
| <span lang="sv">Har ni ...?</span> | habt ihr | <span lang="sv">Har ni havremjölk?</span> |
| <span lang="sv">Finns det ...?</span> | gibt es | <span lang="sv">Finns det en toalett här?</span> |

## Jemanden bitten, etwas zu tun

| Muster | Wofür du es nutzt | Beispiel |
| --- | --- | --- |
| <span lang="sv">Kan du ...?</span> | einfache Bitte | <span lang="sv">Kan du hjälpa mig?</span> |
| <span lang="sv">Skulle du kunna ...?</span> | weichere Bitte | <span lang="sv">Skulle du kunna skriva ner det?</span> |
| <span lang="sv">Kan du säga det igen?</span> | etwas wiederholen lassen | <span lang="sv">Kan du säga det igen?</span> |
| <span lang="sv">Kan du prata lite långsammare?</span> | um langsameres Sprechen bitten | <span lang="sv">Kan du prata lite långsammare?</span> |
| <span lang="sv">Ursäkta, var ligger ...?</span> | nach einem Ort fragen | <span lang="sv">Ursäkta, var ligger stationen?</span> |

## Abmildern und abschließen

| Muster | Wofür du es nutzt | Beispiel |
| --- | --- | --- |
| <span lang="sv">Ursäkta ...</span> | Aufmerksamkeit bekommen | <span lang="sv">Ursäkta, kan du hjälpa mig?</span> |
| <span lang="sv">lite</span> | eine Menge oder einen Grad abmildern | <span lang="sv">Kan du prata lite långsammare?</span> |
| <span lang="sv">om det går</span> | wenn es möglich ist | <span lang="sv">Jag skulle vilja byta tid, om det går.</span> |
| <span lang="sv">Tack så mycket.</span> | vielen Dank | <span lang="sv">Tack så mycket!</span> |
| <span lang="sv">Ingen fara.</span> | kein Problem | <span lang="sv">Ingen fara.</span> |

## Mini-Sequenz

| Sprecher | Schwedisch |
| --- | --- |
| A | <span lang="sv">Ursäkta, kan du hjälpa mig?</span> |
| B | <span lang="sv">Ja, absolut.</span> |
| A | <span lang="sv">Kan du säga det igen, lite långsammare?</span> |
| B | <span lang="sv">Självklart.</span> |
| A | <span lang="sv">Tack så mycket.</span> |

## Direkter Vergleich

<LanguageComparison title="Kann ich haben?">
	<p slot="de">Kann ich bitte eine Quittung bekommen?</p>
	<p slot="en">Can I have a receipt, please?</p>
	<p slot="sv">Kan jag få ett kvitto?</p>
</LanguageComparison>

<span lang="sv">få</span> ist hier das nützliche Serviceverb: Du bittest darum, etwas zu
bekommen. Ein abschließendes <span lang="sv">tack</span> kann hinzugefügt werden, aber der
Rahmen ist in einer normalen Servicesituation schon höflich.

<LanguageComparison title="Könntest du?">
	<p slot="de">Könntest du das bitte aufschreiben?</p>
	<p slot="en">Could you write that down, please?</p>
	<p slot="sv">Skulle du kunna skriva ner det?</p>
</LanguageComparison>

Schwedisch nutzt <span lang="sv">skulle</span> + <span lang="sv">kunna</span>, um die Bitte abzumildern,
ganz ähnlich wie im Deutschen und Englischen ein Konditional-Modalverb genutzt
wird.
