<KeyTakeaway>
- Beginne mit <span lang="sv">Ursäkta, var ligger …?</span> für Orte und
  <span lang="sv">Hur kommer jag till …?</span> für Routen.
- Nutze <span lang="sv">till</span> für das Ziel, <span lang="sv">mot</span> für die Richtung und
  <span lang="sv">förbi</span> für "vorbei".
- Antworten auf Richtungsfragen sind oft Imperative:
  <span lang="sv">Gå rakt fram</span>, <span lang="sv">sväng vänster</span>, <span lang="sv">ta höger</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Diese Seite ist für den Moment auf der Straße: Du musst jemanden ansprechen,
einfach fragen und die Wörter erkennen, die dir sagen, wohin es als Nächstes
geht.

Für die Imperativform selbst nutze
[Imperativ](../../grammar/verb-patterns-voice/imperative/). Diese Seite
bleibt beim Routen-Skript.

## Die Frage stellen

| Muster | Verwende es, wenn … | Register |
| --- | --- | --- |
| <span lang="sv">Ursäkta, var ligger …?</span> | nach einem Ort fragen, wo er ist | neutral |
| <span lang="sv">Vet du var … ligger?</span> | weicher: fragen, ob jemand weiß, wo es ist | neutral |
| <span lang="sv">Hur kommer jag till …?</span> | fragen, wie man dorthin kommt | neutral |
| <span lang="sv">Är det långt härifrån?</span> | fragen, ob es von hier weit ist | neutral |
| <span lang="sv">Är det åt rätt håll?</span> | prüfen, ob das die richtige Richtung ist | neutral |
| <span lang="sv">Kan du visa på kartan?</span> | jemanden bitten, es auf der Karte zu zeigen | neutral |

Eine häufige schwedische Ortsfrage ist <span lang="sv">Var ligger stationen?</span> Für das
vollständige Fragewort-Muster siehe
[Fragewörter](../../grammar/questions-negation/question-words/). Für eine
Route nutze <span lang="sv">till</span>: <span lang="sv">Hur kommer jag till stationen?</span>

## Die Antwort verstehen

| Muster | Bedeutung |
| --- | --- |
| <span lang="sv">Gå rakt fram.</span> | geradeaus gehen |
| <span lang="sv">Sväng vänster.</span> / <span lang="sv">Ta vänster.</span> | links abbiegen |
| <span lang="sv">Sväng höger.</span> / <span lang="sv">Ta höger.</span> | rechts abbiegen |
| <span lang="sv">Gå förbi kyrkan.</span> | an der Kirche vorbeigehen |
| <span lang="sv">Det ligger bredvid apoteket.</span> | es liegt neben der Apotheke |
| <span lang="sv">Det ligger mittemot stationen.</span> | es liegt gegenüber dem Bahnhof |
| <span lang="sv">Det är på vänster sida.</span> | es ist auf der linken Seite |

## Mini-Straßengespräch

<p lang="sv">
	A: Ursäkta, var ligger biblioteket?
	<br />
	B: Gå rakt fram och sväng höger vid torget.
	<br />
	A: Är det långt härifrån?
	<br />
	B: Nej, det tar fem minuter.
</p>

## Direkter Vergleich

<LanguageComparison title="Wo befindet sich das?">
	<p slot="de">Wo ist der Bahnhof?</p>
	<p slot="en">Where is the station?</p>
	<p slot="sv">Var ligger stationen?</p>
</LanguageComparison>

Schwedisch nutzt oft <span lang="sv">ligger</span> dafür, wo sich Gebäude und Orte befinden.
Die Frage handelt nicht davon, ob ein Objekt liegt; es ist einfach das
normale Verb für den Standort.

<LanguageComparison title="Wie komme ich dahin?">
	<p slot="de">Wie komme ich zum Bahnhof?</p>
	<p slot="en">How do I get to the station?</p>
	<p slot="sv">Hur kommer jag till stationen?</p>
</LanguageComparison>
