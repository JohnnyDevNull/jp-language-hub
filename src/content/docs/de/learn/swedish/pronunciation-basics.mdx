<KeyTakeaway>
- Ein verdoppelter Konsonant ist für Anfänger der stärkste Hinweis auf einen
  **kurzen Vokal**, während ein einzelner Konsonant oft auf einen langen
  hindeutet; der Unterschied unterscheidet Wörter: <span lang="sv">glas</span> ist ein
  Trinkglas, <span lang="sv">glass</span> ist Eis.
- <span lang="sv">g</span>, <span lang="sv">k</span> und <span lang="sv">sk</span> ändern ihren Laut oft vor den weichen
  Vokalen <span lang="sv">e, i, y, ä, ö</span>, aber häufige Ausnahmen bleiben bestehen.
- Die Schreibweise bringt dich nah heran, aber nicht ganz ans Ziel: die Vokale
  <span lang="sv">u</span> und <span lang="sv">y</span>, die sj- und tj-Laute und die beiden Wortakzente
  müssen durch Hören erfasst werden.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Die schwedische Aussprache lässt sich nicht vollständig aus der Schreibweise
ableiten, aber eine Handvoll Muster deckt das meiste ab, was ein Anfänger laut
liest.

## Grundregel

> Lies zuerst die Konsonanten nach einem betonten Vokal. Ein verdoppelter
> Konsonant markiert meist einen kurzen Vokal; ein einzelner Konsonant oder das
> Wortende deutet oft auf einen langen Vokal hin. Prüfe dann, ob der Vokal, der
> auf ein <span lang="sv">g</span>, <span lang="sv">k</span> oder <span lang="sv">sk</span> *folgt*, hart oder weich ist.

## Das Alphabet

Das Schwedische hat 29 Buchstaben. Die drei zusätzlichen Vokale stehen **am
Ende** des Alphabets, nach <span lang="sv">z</span>: <span lang="sv">… x, y, z, å, ä, ö</span>.

Das ist nicht nur eine Randnotiz: Wörterbücher, Register, Namenslisten und
sortierte Tabellen folgen dieser Reihenfolge, sodass <span lang="sv">Ångström</span> nach
<span lang="sv">Zetterberg</span> einsortiert wird, nicht neben <span lang="sv">Andersson</span>.

## Vokale

Das Schwedische hat die Vokalbuchstaben <span lang="sv">a, e, i, o, u, y, å, ä, ö</span>.
Mehrere wirken für deutsche Sprecher vertraut, aber ihr genauer Laut und ihre
Länge können abweichen.

| Buchstabe | Hinweis für Einsteiger |
| --- | --- |
| <span lang="sv">a</span> | oft offener als deutsches <span lang="de">a</span> |
| <span lang="sv">e</span> | lang in <span lang="sv">resa</span>, kurz in <span lang="sv">hem</span> |
| <span lang="sv">i</span> | oft nah am deutschen <span lang="de">i</span> |
| <span lang="sv">o</span> | lang oft näher am deutschen <span lang="de">u</span> |
| <span lang="sv">u</span> | ein gerundeter schwedischer Laut; nicht einfach deutsches <span lang="de">u</span> |
| <span lang="sv">y</span> | gerundeter Vordervokal; Lippen dabei gerundet halten |
| <span lang="sv">å</span> | oft nah am deutschen <span lang="de">o</span> |
| <span lang="sv">ä</span> | oft nah am deutschen <span lang="de">ä</span> |
| <span lang="sv">ö</span> | oft nah am deutschen <span lang="de">ö</span> |

### Die Vokallänge verändert das Wort

| Langer Vokal | Kurzer Vokal |
| --- | --- |
| <span lang="sv">glas</span> — Trinkglas | <span lang="sv">glass</span> — Eis |
| <span lang="sv">tak</span> — Dach | <span lang="sv">tack</span> — Danke |
| <span lang="sv">vit</span> — weiß | <span lang="sv">vitt</span> — weiß (<span lang="sv">ett</span>-Form) |

Konsonantenverdopplung ist das gängige Schreibsignal für einen kurzen betonten
Vokal, sodass sich <span lang="sv">glas</span> und <span lang="sv">glass</span> vor allem in der
Vokallänge unterscheiden, nicht im s-Laut.

<MistakeBox
	incorrect="„glass“ mit demselben langen a lesen wie „glas“"
	correct="glass hat ein kurzes a; glas hat ein langes"
	lang="sv"
>
	Die deutsche Schreibweise verwendet Konsonantenverdopplung nicht so
	konsequent, daher wird sie leicht übersehen. Im Schwedischen ist sie ein
	starkes Längensignal, und die Länge trägt Bedeutung.
</MistakeBox>

## Harte und weiche Vokale

| Vokaltyp | Buchstaben |
| --- | --- |
| harte Vokale | <span lang="sv">a, o, u, å</span> |
| weiche Vokale | <span lang="sv">e, i, y, ä, ö</span> |

## Häufige Konsonantenmuster

| Schreibweise | Typische Anfängerregel | Beispiele |
| --- | --- | --- |
| <span lang="sv">g</span> vor harten Vokalen | wird hart ausgesprochen | <span lang="sv">gata</span> |
| <span lang="sv">g</span> vor weichen Vokalen | klingt oft wie schwedisches <span lang="sv">j</span> | <span lang="sv">gärna</span> |
| <span lang="sv">k</span> vor harten Vokalen | wie deutsches <span lang="de">k</span> | <span lang="sv">karta</span> |
| <span lang="sv">k</span> vor weichen Vokalen | oft nah am deutschen <span lang="de">ch</span> in <span lang="de">ich</span> | <span lang="sv">kyrka</span> |
| <span lang="sv">sk</span> vor weichen Vokalen | oft der schwedische sj-Laut | <span lang="sv">sked</span> |
| <span lang="sv">tj</span>, <span lang="sv">kj</span> | oft ein vorderer „ch-artiger“ Laut | <span lang="sv">tjugo</span>, <span lang="sv">kjol</span> |
| <span lang="sv">sj</span> | schwedischer sj-Laut | <span lang="sv">sju</span> |
| <span lang="sv">rs</span> | verschmilzt oft zu einem retroflexen „sch-artigen“ Laut | <span lang="sv">första</span> |
| <span lang="sv">gn</span> | das <span lang="sv">g</span> klingt wie <span lang="sv">ng</span> | <span lang="sv">regn</span>, <span lang="sv">lugn</span> |
| <span lang="sv">-tion</span>, <span lang="sv">-sion</span> | enthalten oft einen sj-artigen Laut | <span lang="sv">station</span> |

In Wörtern, die mit <span lang="sv">dj</span>, <span lang="sv">gj</span>, <span lang="sv">hj</span> oder <span lang="sv">lj</span>
beginnen, ist nur das <span lang="sv">j</span> deutlich zu hören.

## Wortakzent

Das Schwedische unterscheidet zwei Wortakzente — einen einfachen Akzent 1 und
einen zweigipfligen Akzent 2. Ein paar Wortpaare unterscheiden sich durch
nichts anderes:

| Wort | Akzent 1 | Akzent 2 |
| --- | --- | --- |
| <span lang="sv">anden</span> | die Ente | der Geist |
| <span lang="sv">tomten</span> | das Grundstück | der Weihnachtsmann |

Lass dich davon anfangs nicht verrückt machen. Muttersprachler verstehen dich
auch ohne ihn, und er lässt sich viel effektiver durch das Nachahmen ganzer
Phrasen lernen als durch das Studieren der Regel. Zu wissen, dass es ihn gibt,
reicht aus, um zu erklären, warum ein Wort, das du „richtig“ ausgesprochen
hast, trotzdem missverstanden wurde.

## Aussprache in der gesprochenen Sprache

- <span lang="sv">de</span> wird umgangssprachlich oft wie <span lang="sv">dom</span> ausgesprochen.
- <span lang="sv">är</span> wird umgangssprachlich oft wie <span lang="sv">e</span> ausgesprochen.
- <span lang="sv">någon</span> und <span lang="sv">något</span> klingen oft wie <span lang="sv">nån</span> und
  <span lang="sv">nåt</span>.
- Das <span lang="sv">g</span> in den Endungen <span lang="sv">-ig</span> und <span lang="sv">-igt</span> wird meist
  nicht ausgesprochen: <span lang="sv">roligt</span> klingt wie <span lang="sv">rolit</span>.
- <span lang="sv">och</span> wird in schneller Sprache oft reduziert, und <span lang="sv">att</span> kann
  vor einem Infinitiv reduziert werden.

<MemoryTip>
Zwei Fragen beantworten viele Vorlese-Probleme: **Gibt es einen verdoppelten
Konsonanten nach dem betonten Vokal** (Länge), und **ist der folgende Vokal
weich** (ändert sich <span lang="sv">g</span>, <span lang="sv">k</span> oder <span lang="sv">sk</span>).
</MemoryTip>
