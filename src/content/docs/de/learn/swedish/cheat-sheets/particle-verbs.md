## Wortstellung

| Regel | Beispiel |
| --- | --- |
| Die Partikel steht vor dem Objekt | <span lang="sv">Han slog på radion.</span> |
| Auch vor einem Pronomenobjekt | <span lang="sv">Han slog på den.</span> |
| <span lang="sv">inte</span> steht zwischen Verb und Partikel | <span lang="sv">Jag tycker inte om henne.</span> |
| Die Partikel folgt dem Supinum | <span lang="sv">Jag har tagit med boken.</span> |

Die Partikel wandert nie ans Satzende, wie es ein deutsches trennbares
Präfix tut: <span lang="de">Ich rufe ihn an</span> →
<span lang="sv">Jag ringer upp honom.</span>

## Partikel oder Präposition?

| Test | Partikel | Präposition |
| --- | --- | --- |
| Betonung | auf der Partikel: <span lang="sv">tycka **om**</span> | auf dem Verb: <span lang="sv">**tit**ta på</span> |
| Mit <span lang="sv">inte</span> | <span lang="sv">tycker inte om</span> | <span lang="sv">tittar inte på</span> |

## Häufige Partikelverben

| Schwedisch | Deutsch |
| --- | --- |
| <span lang="sv">tycka om</span> | mögen |
| <span lang="sv">komma ihåg</span> | sich erinnern |
| <span lang="sv">komma på</span> | einfallen, merken |
| <span lang="sv">se ut</span> | aussehen |
| <span lang="sv">känna igen</span> | wiedererkennen |
| <span lang="sv">ta med</span> | mitnehmen |
| <span lang="sv">ta på sig</span> / <span lang="sv">ta av sig</span> | anziehen / ausziehen |
| <span lang="sv">ta reda på</span> | herausfinden |
| <span lang="sv">slå på</span> / <span lang="sv">stänga av</span> | einschalten / ausschalten |
| <span lang="sv">tala om</span> | erzählen |
| <span lang="sv">hålla på</span> | gerade dabei sein, etwas zu tun |
| <span lang="sv">passa på</span> | die Gelegenheit nutzen |

## Getrennt oder zusammengeschrieben

| Getrennt | Präfigiert |
| --- | --- |
| <span lang="sv">gå av</span> — aussteigen | <span lang="sv">avgå</span> — zurücktreten, abfahren |
| <span lang="sv">gå ut</span> — hinausgehen | <span lang="sv">utgå</span> — entfallen |

Als Adjektiv oder Substantiv wachsen die Teile zusammen:
<span lang="sv">radion är påslagen</span>,
<span lang="sv">tågets avgång</span>.

:::tip[Merktipp]
<span lang="sv">Jag tycker inte om det.</span> — zuerst
<span lang="sv">inte</span>, dann die Partikel, dann das Objekt.
:::

## Diese Fehler vermeiden

- ❌ <span lang="sv">Han slog den på.</span> → ✅ <span lang="sv">Han slog på den.</span>
- ❌ <span lang="sv">Jag tycker om inte henne.</span> → ✅ <span lang="sv">Jag tycker inte om henne.</span>
- Verwende <span lang="sv">passa på</span> nicht für „aufpassen“ oder „sich in
  Acht nehmen“; nutze stattdessen einen passenden Ausdruck wie <span
  lang="sv">var uppmärksam</span> oder <span lang="sv">akta dig</span>.
- Lerne die Konstruktion, die auf <span lang="sv">hålla på</span> folgt, denn
  sie hilft, seine geläufigen Bedeutungen zu unterscheiden.
