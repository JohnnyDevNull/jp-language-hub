## Die Wörter

| Schwedisch | Deutsch | Schwedisch | Deutsch |
| --- | --- | --- | --- |
| <span lang="sv">vem</span> | wer | <span lang="sv">var</span> | wo |
| <span lang="sv">vems</span> | wessen | <span lang="sv">vart</span> | wohin |
| <span lang="sv">vad</span> | was | <span lang="sv">när</span> | wann |
| <span lang="sv">vilken/vilket/vilka</span> | welche(r/s) | <span lang="sv">hur</span> | wie |
| <span lang="sv">hur mycket / många</span> | wie viel / wie viele | <span lang="sv">varför</span> | warum |

<span lang="sv">Vem</span> hat keine eigene Objektform. Unter diesen Kernformen
ist die <span lang="sv">vilken</span>-Reihe diejenige, die sich nach Genus und
Numerus richtet: <span lang="sv">vilken bok</span>,
<span lang="sv">vilket hus</span>, <span lang="sv">vilka böcker</span>.

## var oder vart

Die Tabelle zeigt die Unterscheidung des Standardschwedischen:
<span lang="sv">var</span> für den Ort und <span lang="sv">vart</span> für die
Richtung. In der Umgangssprache wird <span lang="sv">var</span> manchmal auch
für die Richtung verwendet.

| Frage | Bedeutung |
| --- | --- |
| <span lang="sv">Var bor du?</span> | Position — <span lang="de">wo</span> |
| <span lang="sv">Vart går du?</span> | Richtung — <span lang="de">wohin</span> |
| <span lang="sv">Var kommer du ifrån?</span> | Herkunft — Präposition am Ende |

## Wortstellung

| Typ | Muster | Beispiel |
| --- | --- | --- |
| Mit Fragewort | <span lang="sv">fundament + finit verb</span> | <span lang="sv">Var bor du?</span> |
| Ja/Nein-Frage | Verb zuerst, kein <span lang="sv">do</span> | <span lang="sv">Bor du här?</span> |
| Indirekt | keine Inversion | <span lang="sv">Jag vet inte var hon bor.</span> |
| Indirekt Ja/Nein | <span lang="sv">om</span> | <span lang="sv">Jag vet inte om hon kommer.</span> |

## som markiert das Subjekt

Nur in indirekten Fragen:

| Rolle | Beispiel |
| --- | --- |
| Fragewort ist das Subjekt | <span lang="sv">Jag vet inte vem **som** ringde.</span> |
| Fragewort ist das Objekt | <span lang="sv">Jag vet inte vem hon ringde.</span> |

Direkte Fragen brauchen kein <span lang="sv">som</span>:
<span lang="sv">Vem ringde?</span>, <span lang="sv">Vad hände?</span>

:::tip[Merktipp]
<span lang="sv">vem som ringde</span> — der Anrufer.
<span lang="sv">vem hon ringde</span> — die angerufene Person. Das
zusätzliche <span lang="sv">som</span> markiert das Subjekt.
:::

## Diese Fehler vermeiden

- ❌ <span lang="sv">Jag vet inte var bor hon.</span> → ✅ <span lang="sv">…var hon bor.</span>
- ❌ <span lang="sv">Jag vet inte vem ringde.</span> → ✅ <span lang="sv">…vem som ringde.</span>
- ❌ <span lang="sv">Vart bor du?</span> → ✅ <span lang="sv">Var bor du?</span>
- ❌ <span lang="sv">Vilken hus är ditt?</span> → ✅ <span lang="sv">Vilket hus är ditt?</span>
