Lerne ein schwedisches Substantiv als Kette aus vier Formen.

| Bedeutung | Unbestimmter Singular | Bestimmter Singular | Unbestimmter Plural | Bestimmter Plural |
| --- | --- | --- | --- | --- |
| Auto | <span lang="sv">en bil</span> | <span lang="sv">bilen</span> | <span lang="sv">bilar</span> | <span lang="sv">bilarna</span> |
| Haus | <span lang="sv">ett hus</span> | <span lang="sv">huset</span> | <span lang="sv">hus</span> | <span lang="sv">husen</span> |
| Apfel | <span lang="sv">ett äpple</span> | <span lang="sv">äpplet</span> | <span lang="sv">äpplen</span> | <span lang="sv">äpplena</span> |
| Mädchen | <span lang="sv">en flicka</span> | <span lang="sv">flickan</span> | <span lang="sv">flickor</span> | <span lang="sv">flickorna</span> |

## Grundmuster

- Der unbestimmte Singular verwendet <span lang="sv">en</span> oder
  <span lang="sv">ett</span>: <span lang="sv">en bil</span>,
  <span lang="sv">ett hus</span>.
- Der bestimmte Artikel ist normalerweise eine Endung:
  <span lang="sv">bilen</span>, <span lang="sv">huset</span>.
- Die Pluralendungen sind unterschiedlich. Lerne den Plural zusammen mit dem Substantiv.
- Der bestimmte Plural fügt der Pluralform eine bestimmte Endung hinzu:
  <span lang="sv">bilarna</span>, <span lang="sv">husen</span>.

## Mit einem bestimmten Adjektiv

Schwedisch verwendet normalerweise sowohl einen eigenen Artikel als auch die
bestimmte Substantivendung:

- <span lang="sv">den stora bilen</span>
- <span lang="sv">det stora huset</span>
- <span lang="sv">de stora bilarna</span>

Dieses Muster wird oft doppelte Bestimmtheit genannt.

:::tip[Merktipp]
Notiere Substantive als <span lang="sv">en bil — bilen — bilar — bilarna</span>, nicht
als isoliertes Übersetzungspaar.
:::
