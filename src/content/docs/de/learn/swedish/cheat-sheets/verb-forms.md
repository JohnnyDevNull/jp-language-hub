## Formenkette

| Infinitiv | Imperativ | Präsens | Präteritum | Supinum | Perfekt |
| --- | --- | --- | --- | --- | --- |
| <span lang="sv">(att) tala</span> | <span lang="sv">tala!</span> | <span lang="sv">talar</span> | <span lang="sv">talade</span> | <span lang="sv">talat</span> | <span lang="sv">har talat</span> |
| <span lang="sv">(att) köpa</span> | <span lang="sv">köp!</span> | <span lang="sv">köper</span> | <span lang="sv">köpte</span> | <span lang="sv">köpt</span> | <span lang="sv">har köpt</span> |
| <span lang="sv">(att) bo</span> | <span lang="sv">bo!</span> | <span lang="sv">bor</span> | <span lang="sv">bodde</span> | <span lang="sv">bott</span> | <span lang="sv">har bott</span> |
| <span lang="sv">(att) skriva</span> | <span lang="sv">skriv!</span> | <span lang="sv">skriver</span> | <span lang="sv">skrev</span> | <span lang="sv">skrivit</span> | <span lang="sv">har skrivit</span> |

Die Form ist für jede Person gleich:

<span lang="sv">jag köper · du köper · hon köper · vi köper · de köper</span>

## Wahl der Zeitform

| Bedeutung | Muster | Beispiel |
| --- | --- | --- |
| Präsens, Gewohnheit, kontextuelles Futur | Präsens | <span lang="sv">Jag köper en bok.</span> |
| Abgeschlossener Vergangenheitsrahmen | Präteritum | <span lang="sv">Jag köpte boken i går.</span> |
| Vergangenheit mit Bezug zur Gegenwart | <span lang="sv">har</span> + Supinum | <span lang="sv">Jag har köpt boken.</span> |
| Früher als ein anderes Vergangenheitsereignis | <span lang="sv">hade</span> + Supinum | <span lang="sv">Jag hade köpt boken.</span> |

## Grundmuster der Verbgruppen

| Gruppe | Präsens | Präteritum | Supinum | Modell |
| --- | --- | --- | --- | --- |
| 1 | <span lang="sv">-ar</span> | <span lang="sv">-ade</span> | <span lang="sv">-at</span> | <span lang="sv">talar — talade — talat</span> |
| 2 | <span lang="sv">-er</span> | <span lang="sv">-de/-te</span> | <span lang="sv">-t</span> | <span lang="sv">köper — köpte — köpt</span> |
| 3 | <span lang="sv">-r</span> | <span lang="sv">-dde</span> | <span lang="sv">-tt</span> | <span lang="sv">bor — bodde — bott</span> |
| 4 / unregelmäßig | unterschiedlich | unterschiedlich | unterschiedlich | <span lang="sv">skriver — skrev — skrivit</span> |

## Passiv

| Passiv | Muster | Beispiel |
| --- | --- | --- |
| s-Passiv, Präsens | Präsensendung → <span lang="sv">-s</span> | <span lang="sv">Rummet städas varje dag.</span> |
| s-Passiv, Präteritum | Präteritum + <span lang="sv">-s</span> | <span lang="sv">Cykeln stals i går.</span> |
| s-Passiv, Supinum | Supinum + <span lang="sv">-s</span> | <span lang="sv">Dörren har öppnats.</span> |
| bli-Passiv | <span lang="sv">bli</span> + kongruierendes Partizip | <span lang="sv">Huset blev sålt.</span> |

Routine oder eine allgemeine Regel führt oft zum s-Passiv.
<span lang="sv">bli</span> + Partizip hebt ein Ereignis oder eine Veränderung
hervor, aber das s-Passiv kann auch ein konkretes Ereignis beschreiben. Der
Urheber wird mit <span lang="sv">av</span> angeschlossen:
<span lang="sv">skrevs av Astrid Lindgren</span>.

<span lang="sv">finns, hoppas, trivs, minns, lyckas, andas</span> enden auf
<span lang="sv">-s</span>, sind aber keine Passivformen.

:::tip[Schnelle Merkhilfe]
Lerne Präsens — Präteritum — Supinum als eine gesprochene Kette:
<span lang="sv">köper — köpte — köpt</span>.
:::

## Diese Fehler vermeiden

- Nach <span lang="sv">har</span> steht das Supinum:
  ✅ <span lang="sv">har köpt</span>, nicht ❌ <span lang="sv">har köpa</span>.
- Bilde unregelmäßige Vergangenheitsformen nicht mit einer regelmäßigen Endung:
  ✅ <span lang="sv">skrev</span>, nicht ❌ <span lang="sv">skrivade</span>.
