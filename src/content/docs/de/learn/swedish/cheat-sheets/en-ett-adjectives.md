## Genus-Faustregeln

| Hinweis | Genus | Beispiel |
| --- | --- | --- |
| Zusammengesetztes Substantiv | das **letzte** Element entscheidet | <span lang="sv">en cykel</span> + <span lang="sv">ett hjul</span> → <span lang="sv">ett cykelhjul</span> |
| <span lang="sv">-a, -are, -else, -het, -ning, -tion</span> | <span lang="sv">en</span> | <span lang="sv">en tidning</span>, <span lang="sv">en möjlighet</span> |
| <span lang="sv">-ande, -eri, -um, -ment, -tek, -gram</span> | <span lang="sv">ett</span> | <span lang="sv">ett meddelande</span>, <span lang="sv">ett museum</span> |
| Kein Hinweis vorhanden | rate <span lang="sv">en</span> — die Mehrheit | |

Produktive Komposita übernehmen normalerweise das Genus des letzten Elements.
Die Endungen sind starke Tendenzen, keine festen Regeln: Achte auf
<span lang="sv">ett öga</span>, <span lang="sv">en studerande</span> und das
gespaltene <span lang="sv">-skap</span>.

## Unbestimmte Formen

| Substantivform | Adjektivmuster | Beispiel |
| --- | --- | --- |
| Singular <span lang="sv">en</span> | Grundform | <span lang="sv">en stor bil</span> |
| Singular <span lang="sv">ett</span> | meist <span lang="sv">-t</span> | <span lang="sv">ett stort hus</span> |
| Plural | meist <span lang="sv">-a</span> | <span lang="sv">stora bilar</span> |

## Bestimmte Formen

| Substantivform | Muster | Beispiel |
| --- | --- | --- |
| Singular <span lang="sv">en</span> | <span lang="sv">den</span> + <span lang="sv">-a</span>-Adjektiv + bestimmtes Substantiv | <span lang="sv">den stora bilen</span> |
| Singular <span lang="sv">ett</span> | <span lang="sv">det</span> + <span lang="sv">-a</span>-Adjektiv + bestimmtes Substantiv | <span lang="sv">det stora huset</span> |
| Plural | <span lang="sv">de</span> + <span lang="sv">-a</span>-Adjektiv + bestimmtes Substantiv | <span lang="sv">de stora bilarna</span> |

## Adjektivschreibung

| Stamm | ett-form | Plural / bestimmt |
| --- | --- | --- |
| betonter Vokal: <span lang="sv">ny, blå</span> | <span lang="sv">nytt, blått</span> | <span lang="sv">nya, blåa</span> |
| Vokal + <span lang="sv">d/t</span>: <span lang="sv">röd, vit</span> | <span lang="sv">rött, vitt</span> | <span lang="sv">röda, vita</span> |
| <span lang="sv">-en</span>: <span lang="sv">öppen, mogen</span> | <span lang="sv">öppet, moget</span> | <span lang="sv">öppna, mogna</span> |
| <span lang="sv">-er, -el</span>: <span lang="sv">vacker, enkel</span> | <span lang="sv">vackert, enkelt</span> | <span lang="sv">vackra, enkla</span> |

Unregelmäßig: <span lang="sv">gammal → gammalt → gamla</span>,
<span lang="sv">liten → litet → små</span> (bestimmter Singular
<span lang="sv">lilla</span>).

Nie flektiert: <span lang="sv">bra, kul, äkta, rosa, lila, beige</span> —
<span lang="sv">ett bra hus</span>.

:::tip[Merktipp]
<span lang="sv">en stor — ett stort — flera stora</span>
:::

## Diese Fehler vermeiden

- ❌ <span lang="sv">ett stor hus</span> → ✅ <span lang="sv">ett stort hus</span>
- ❌ <span lang="sv">den stor bilen</span> → ✅ <span lang="sv">den stora bilen</span>
- ❌ <span lang="sv">en cykelhjul</span> → ✅ <span lang="sv">ett cykelhjul</span>
- ❌ <span lang="sv">öppena fönster</span> → ✅ <span lang="sv">öppna fönster</span>
- Lerne jedes Substantiv mit seinem Artikel; das Genus lässt sich nicht immer zuverlässig vorhersagen.
- Das sind grundlegende, häufige Muster, keine Regeln ohne Ausnahmen.
