## Hauptsatz: V2

Das <span lang="sv">finit verb</span> steht normalerweise an zweiter Satzposition.

| <span lang="sv">1 fundament</span> | <span lang="sv">2 finit verb</span> | <span lang="sv">3 subjekt</span> | <span lang="sv">objekt / predikativ</span> | <span lang="sv">adverbial</span> |
| --- | --- | --- | --- | --- |
| <span lang="sv">Jag</span> | <span lang="sv">köper</span> | — | <span lang="sv">en bok</span> | <span lang="sv">idag.</span> |
| <span lang="sv">Idag</span> | <span lang="sv">köper</span> | <span lang="sv">jag</span> | <span lang="sv">en bok.</span> | — |

✅ <span lang="sv">Idag köper jag en bok.</span>  
❌ <span lang="sv">Idag jag köper en bok.</span>

„Position“ bedeutet eine Konstituente. <span lang="sv">På måndag morgon</span>
kann die gesamte erste Position ausfüllen.

## Verneinung im Hauptsatz

> <span lang="sv">subjekt + finit verb + inte</span> + …

<span lang="sv">Jag kommer inte idag.</span>

Steht eine andere Konstituente an erster Stelle, löst V2 die Inversion aus:

> <span lang="sv">fundament + finit verb + subjekt + inte</span> + …

<span lang="sv">Idag kommer jag inte.</span>

## Nebensatz: BIFF

**B**isats **I**nte **F**öre **F**init: In einem Nebensatz steht
<span lang="sv">inte</span> normalerweise vor dem <span lang="sv">finit verb</span>.

> <span lang="sv">bisatsinledare + subjekt + inte + finit verb</span> + …

<span lang="sv">… eftersom jag inte kommer idag.</span>

| Satz | Schema | Beispiel |
| --- | --- | --- |
| Hauptsatz | <span lang="sv">subjekt + finit verb + inte</span> | <span lang="sv">Jag kommer inte.</span> |
| Nebensatz | <span lang="sv">bisatsinledare + subjekt + inte + finit verb</span> | <span lang="sv">… eftersom jag inte kommer.</span> |

:::caution[Geltungsbereich]
V2 und BIFF sind verlässliche Leitfäden für Anfänger, aber keiner von beiden
beschreibt jeden schwedischen Satztyp vollständig.
:::
