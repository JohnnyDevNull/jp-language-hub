## Drei Aufgaben, zwei Wörter

| Aufgabe | Wort | Beispiel |
| --- | --- | --- |
| <span lang="sv">infinitivmärke</span> — ein bloßes Verb folgt | <span lang="sv">att</span> | <span lang="sv">Vi planerar att flytta.</span> |
| <span lang="sv">bisatsinledare</span> — ein Gedanke oder eine Aussage folgt | <span lang="sv">att</span> | <span lang="sv">Jag tycker att huset är dyrt.</span> |
| <span lang="sv">relativpronomen</span> — es beschreibt das Substantiv davor | <span lang="sv">som</span> | <span lang="sv">en kompis som bor i Malmö</span> |

## Die Entscheidung in einer Frage

Was tut der Nebensatz?

- Beschreibt das Wort davor → <span lang="sv">som</span>
- Sagt, was jemand denkt, sagt oder weiß → <span lang="sv">att</span>
- Liefert ein Verb ohne neues Subjekt → <span lang="sv">att</span> + Infinitiv

Deutscher Test: Passt <span lang="de">der</span>, <span lang="de">die</span> oder
<span lang="de">das</span>, nimmt Schwedisch <span lang="sv">som</span>.

## Innerhalb des Nebensatzes

| Nebensatz | <span lang="sv">bisatsinledare</span> | <span lang="sv">subjekt</span> | <span lang="sv">finit verb</span> |
| --- | --- | --- | --- |
| Inhalt | <span lang="sv">att</span> | <span lang="sv">han</span> | <span lang="sv">kommer</span> |
| Relativ, Subjekt | <span lang="sv">som</span> | — | <span lang="sv">bor</span> |
| Relativ, Objekt | <span lang="sv">som</span> | <span lang="sv">jag</span> | <span lang="sv">läste</span> |

<span lang="sv">Som</span> ist selbst das Subjekt in Zeile zwei, deshalb bleibt
dieses Feld leer. <span lang="sv">Att</span> übernimmt nie eine Rolle, deshalb
folgt immer ein Subjekt danach.

## Kein att nach einem Modalverb

| Bloßer Infinitiv | Mit <span lang="sv">att</span> |
| --- | --- |
| <span lang="sv">Jag kan simma.</span> | <span lang="sv">Jag lär mig att simma.</span> |
| <span lang="sv">Vi ska åka.</span> | <span lang="sv">Vi kommer att åka.</span> |
| <span lang="sv">Du måste läsa.</span> | <span lang="sv">Du glömde att läsa.</span> |

## Wann es wegfallen kann

| Wort | Weglassbar? |
| --- | --- |
| <span lang="sv">att</span> + Satz | Oft in der Alltagssprache: <span lang="sv">Jag tror (att) han kommer.</span> |
| <span lang="sv">att</span> + Infinitiv | Nein, außer bei einigen Verben: <span lang="sv">Hon började (att) läsa.</span> |
| <span lang="sv">som</span> | Nur als Objekt, nie als Subjekt |

:::tip[Merktipp]
<span lang="sv">Något som min man vill göra.</span> — es beschreibt
<span lang="sv">något</span>.
<span lang="sv">Jag tycker att det blir bra.</span> — es ist, was ich denke.
:::

## Diese Fehler vermeiden

- ❌ <span lang="sv">en vän att bor här</span> → ✅ <span lang="sv">en vän som bor här</span>
- ❌ <span lang="sv">Jag kan att simma.</span> → ✅ <span lang="sv">Jag kan simma.</span>
- ❌ <span lang="sv">Han kom sent, som irriterade alla.</span> → ✅ <span lang="sv">…, vilket irriterade alla.</span>
- ❌ <span lang="sv">Boken som jag läste inte</span> → ✅ <span lang="sv">Boken som jag inte läste</span>
