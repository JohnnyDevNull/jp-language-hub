## som deckt fast alles ab

| Funktion | Beispiel |
| --- | --- |
| Subjekt — muss stehen bleiben | <span lang="sv">Mannen som bor här heter Erik.</span> |
| Objekt — kann wegfallen | <span lang="sv">Boken (som) jag läste var bra.</span> |
| Steht in der Alltagssprache nicht direkt nach einer einfachen Präposition | <span lang="sv">huset som jag bor i</span> |

<span lang="sv">Som</span> ist unveränderlich: kein Genus, kein Numerus, kein
Kasus, kein Genitiv.

## Wo die Präposition steht

| Schwedisch | Deutsch |
| --- | --- |
| <span lang="sv">bussen som vi väntar på</span> | <span lang="de">der Bus, auf den wir warten</span> |
| <span lang="sv">personen som jag talade med</span> | <span lang="de">die Person, mit der ich gesprochen habe</span> |

Im alltäglichen Muster bleibt die Präposition am **Ende** des Relativsatzes.
Die Schriftsprache kann eine schwerfälligere Konstruktion mit Präposition +
<span lang="sv">vilken</span>/<span lang="sv">vilket</span> wählen.

## Die anderen Relativpronomen

| Bedeutung | Wort | Beispiel |
| --- | --- | --- |
| Bezieht sich auf einen ganzen Satz | <span lang="sv">vilket</span> | <span lang="sv">Han kom sent, vilket irriterade alla.</span> |
| wessen | <span lang="sv">vars</span> | <span lang="sv">en författare vars böcker jag älskar</span> |
| wo (Ort) | <span lang="sv">där</span> | <span lang="sv">staden där jag bor</span> |
| wohin | <span lang="sv">dit</span> | <span lang="sv">staden dit jag flyttade</span> |

<span lang="sv">Vars</span> und Präposition + <span lang="sv">vilken</span>/
<span lang="sv">vilket</span> gehören zur Schriftsprache. Im Gespräch baust du
den Satz besser um.

## Wortstellung innerhalb des Relativsatzes

Ein Relativsatz ist ein Nebensatz, daher steht <span lang="sv">inte</span> vor
dem Verb: <span lang="sv">Mannen som **inte** bor här</span>.

:::tip[Merktipp]
<span lang="sv">Bussen som vi väntar på är sen.</span> — Präposition am Ende.
<span lang="sv">Han kom sent, vilket irriterade alla.</span> —
<span lang="sv">vilket</span> für einen ganzen Satz.
:::

## Diese Fehler vermeiden

- ❌ <span lang="sv">huset i som jag bor</span> → ✅ <span lang="sv">huset som jag bor i</span>
- ❌ <span lang="sv">Mannen vilken bor här</span> → ✅ <span lang="sv">Mannen som bor här</span>
- ❌ <span lang="sv">Han kom sent, som irriterade alla.</span> → ✅ <span lang="sv">…, vilket irriterade alla.</span>
- ❌ <span lang="sv">Mannen som bor inte här</span> → ✅ <span lang="sv">Mannen som inte bor här</span>
