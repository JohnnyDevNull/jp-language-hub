## Grundzahlen

| Bereich | Schwedisch |
| --- | --- |
| 1–10 | <span lang="sv">en/ett, två, tre, fyra, fem, sex, sju, åtta, nio, tio</span> |
| 11–20 | <span lang="sv">elva, tolv, tretton, fjorton, femton, sexton, sjutton, arton, nitton, tjugo</span> |
| Zehnerzahlen | <span lang="sv">trettio, fyrtio, femtio, sextio, sjuttio, åttio, nittio</span> |
| Größer | <span lang="sv">hundra, tusen, en miljon, en miljard</span> |

## Zahlen bilden

| Regel | Beispiel |
| --- | --- |
| Zehner zuerst, kein <span lang="sv">och</span>, ein Wort | 21 → <span lang="sv">tjugoett</span>, 156 → <span lang="sv">hundrafemtiosex</span> |
| Alleinstehende 1 richtet sich nach dem Substantiv | <span lang="sv">en bil</span>, <span lang="sv">ett hus</span> |
| Die End-1 nach Zehnerzahlen ist normalerweise <span lang="sv">-en</span> | <span lang="sv">tjugoen kronor</span>, <span lang="sv">trettioen fartyg</span> |
| Die End-<span lang="sv">-ett</span> bleibt in festen Kontexten erhalten | <span lang="sv">tjugoett år</span>, <span lang="sv">nummer tjugoett</span>, <span lang="sv">tjugoett öre</span> |
| Jede andere Zahl bleibt unverändert | <span lang="sv">två bilar</span>, <span lang="sv">två hus</span> |

## Ordnungszahlen

| Bereich | Schwedisch |
| --- | --- |
| 1.–10. | <span lang="sv">första, andra, tredje, fjärde, femte, sjätte, sjunde, åttonde, nionde, tionde</span> |
| 11.–12. | <span lang="sv">elfte, tolfte</span> |
| 13.–19. | meist Grundzahl + <span lang="sv">-de</span>: <span lang="sv">trettonde, fjortonde, nittonde</span> |
| Volle Zehner | Zehnerform: <span lang="sv">tjugo → tjugonde</span>, <span lang="sv">trettio → trettionde</span> |
| Zusammengesetzt | nur das letzte Element: <span lang="sv">tjugoförsta, fyrtioandra</span> |
| Als Ziffern | <span lang="sv">1:a, 2:a</span> — aber <span lang="sv">3:e, 4:e, 24:e</span> |

Ordnungszahlen folgen normalerweise auf <span lang="sv">den</span>:
<span lang="sv">den första maj</span>.

## Große Zahlen und Dezimalzahlen

| Wert | Schwedisch | Plural |
| --- | --- | --- |
| 10⁶ | <span lang="sv">en miljon</span> | <span lang="sv">miljoner</span> |
| 10⁹ | <span lang="sv">en miljard</span> | <span lang="sv">miljarder</span> |
| 10¹² | <span lang="sv">en biljon</span> | <span lang="sv">biljoner</span> |

Englisch *billion* entspricht <span lang="sv">en miljard</span>. Schwedisch
zählt wie das Deutsche. Das Dezimaltrennzeichen ist ein Komma:
<span lang="sv">3,5</span> = <span lang="sv">tre komma fem</span>.

:::tip[Merktipp]
<span lang="sv">tjugoett</span>, nicht <span lang="sv">ettochtjugo</span> — der
Zehner steht zuerst, genau wie im Englischen.
:::

## Diese Fehler vermeiden

- ❌ <span lang="sv">tjugo och ett</span> → ✅ <span lang="sv">tjugoett</span>
- ❌ <span lang="sv">tjugoett kronor</span> → ✅ <span lang="sv">tjugoen kronor</span>
- ❌ <span lang="sv">trettioett fartyg</span> → ✅ <span lang="sv">trettioen fartyg</span>
- ❌ <span lang="sv">fyrtiondeandra</span> → ✅ <span lang="sv">fyrtioandra</span>
- ❌ <span lang="sv">den 3:a maj</span> → ✅ <span lang="sv">den 3:e maj</span>
