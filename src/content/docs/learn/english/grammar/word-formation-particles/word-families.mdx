## Core rule
Common patterns include <span lang="en">-tion</span> for nouns, <span lang="en">-ive</span> for adjectives, and <span lang="en">-ly</span> for adverbs: <span lang="en">inform → information → informative → informatively</span>. These are clues, not guarantees; check spelling and meaning in context.

## Practical families

| Sentence job | Decide family | Success family |
| --- | --- | --- |
| verb: action | <span lang="en">We decided to leave.</span> | <span lang="en">She succeeded in finding it.</span> |
| noun: thing or result | <span lang="en">The decision was difficult.</span> | <span lang="en">The project was a success.</span> |
| adjective: description | <span lang="en">It was a decisive step.</span> | <span lang="en">It was a successful project.</span> |
| adverb: manner | — | <span lang="en">They completed it successfully.</span> |

The forms are related, but they do not always share the same spelling or allow
every sentence role. Learn each useful form with a short sentence.
## Use this now
Ask what the sentence needs: a thing or idea (noun), an action (verb), a description (adjective), or manner (adverb). Do not assume every possible form exists or keeps the same meaning.
