<KeyTakeaway>
- Use *Can you…?* for everyday requests and *Could you…?* when you want a softer request.
- Use *Would you mind + -ing?* for a more careful request; the answer is about willingness, not ability.
- Add *please*, a reason, or thanks to make the request cooperative rather than demanding.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Choose a pattern by relationship and situation. A direct imperative can be efficient among close colleagues, but it is not the default for a new contact or customer.

## Use this now

| Situation | Useful pattern | Example |
| --- | --- | --- |
| everyday | *Can you + base verb…?* | *Can you send the link?* |
| softer / more formal | *Could you + base verb…?* | *Could you send the link, please?* |
| careful request | *Would you mind + -ing…?* | *Would you mind sending the link?* |
| permission for yourself | *Could I…?* | *Could I leave early?* |

## Core rule

After *can/could*, use the base verb: *Could you help me?* After *Would you mind*, use **-ing**: *Would you mind waiting?* The grammar behind modals belongs to [Modal verbs](../../verb-patterns-voice/modal-verbs/); question formation belongs to [Questions and do-support](../../questions-negation/questions-and-do-support/).

<MistakeBox incorrect="Could you to help me?" correct="Could you help me?" lang="en">
Modal verbs take the base verb without *to*.
</MistakeBox>
