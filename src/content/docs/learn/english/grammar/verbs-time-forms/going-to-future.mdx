<KeyTakeaway>
- Use <span lang="en">going to</span> for an intention or plan that already
  exists.
- Use it for predictions based on visible evidence: something already points
  toward the result.
- Do not use <span lang="en">going to</span> for every German
  <span lang="de">werden</span> sentence.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

The going to future looks long, but its job is simple: it says that the future
comes from something already present now, such as an intention, a plan or
evidence you can see.

## Use this now

Choose <span lang="en">going to</span> for:

| Function | Example |
| --- | --- |
| plan or intention | <span lang="en">I am going to study tonight.</span> |
| visible evidence | <span lang="en">Look at those clouds. It is going to rain.</span> |
| expected result from now | <span lang="en">Be careful. You are going to fall.</span> |

For a promise or decision made while speaking, use [will future](../will-future/):
<span lang="en">I will help you.</span> For a fixed appointment, use the
present progressive naturally: <span lang="en">I am seeing the doctor on
Monday.</span>

## Core rule

**Pattern:** subject + <span lang="en">am/is/are going to</span> + base verb

| Subject | Form |
| --- | --- |
| <span lang="en">I</span> | <span lang="en">I am going to leave.</span> |
| <span lang="en">she/he/it</span> | <span lang="en">She is going to leave.</span> |
| <span lang="en">we/you/they</span> | <span lang="en">They are going to leave.</span> |

The main verb stays in the base form:
<span lang="en">going to leave</span>, <span lang="en">going to be</span>,
<span lang="en">going to have</span>.

## Questions and negatives

| Sentence type | Example |
| --- | --- |
| positive | <span lang="en">She is going to call.</span> |
| negative | <span lang="en">She is not going to call.</span> |
| question | <span lang="en">Is she going to call?</span> |

Only <span lang="en">be</span> changes position in a question. The words
<span lang="en">going to</span> stay together before the base verb.

## Direct comparison

<LanguageComparison title="Plan already exists" languages={['de', 'en']}>
	<p slot="de">Ich werde heute Abend lernen.</p>
	<p slot="en">I am going to study tonight.</p>
</LanguageComparison>

<LanguageComparison title="Prediction from evidence" languages={['de', 'en']}>
	<p slot="de">Es wird gleich regnen.</p>
	<p slot="en">It is going to rain.</p>
</LanguageComparison>

German can use <span lang="de">werden</span> in both sentences. English uses
<span lang="en">going to</span> because the plan or evidence is already there.

<MistakeBox
	incorrect="I going to study tonight."
	correct="I am going to study tonight."
	lang="en"
>
	The future expression is <span lang="en">am/is/are going to</span> plus a
	base verb. Without <span lang="en">am/is/are</span>, the construction is
	incomplete.
</MistakeBox>
