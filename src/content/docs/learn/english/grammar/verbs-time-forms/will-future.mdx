<KeyTakeaway>
- Use <span lang="en">will</span> for decisions made now, promises, offers and
  predictions.
- Many school grammars call this the simple future, but English future meaning
  is split across several forms.
- Use <span lang="en">going to</span> for plans and evidence, the present
  progressive for arrangements, and the simple present for schedules.
</KeyTakeaway>

The will future is not the one default future form for every situation. It is
one future tool: useful when the speaker decides, promises, offers or predicts
from the present moment.

## Use this now

Choose <span lang="en">will</span> when the sentence feels like one of these:

| Function | Example |
| --- | --- |
| decision now | <span lang="en">I will call her now.</span> |
| promise | <span lang="en">I will help you.</span> |
| offer | <span lang="en">I will open the window.</span> |
| prediction | <span lang="en">It will rain later.</span> |

For an existing plan, prefer [going to future](../going-to-future/). For an
arranged meeting, English often uses the present progressive:
<span lang="en">I am meeting Anna tomorrow.</span> For timetables, it often
uses the simple present: <span lang="en">The train leaves at eight.</span>

## Core rule

**Pattern:** subject + <span lang="en">will</span> + base verb

| Sentence type | Form |
| --- | --- |
| positive | <span lang="en">I will call you.</span> |
| negative | <span lang="en">I will not call you.</span> |
| contraction | <span lang="en">I won't call you.</span> |
| question | <span lang="en">Will you call me?</span> |

The verb after <span lang="en">will</span> stays in the base form:
<span lang="en">will go</span>, <span lang="en">will be</span>,
<span lang="en">will have</span>.

## Direct comparison

	<p slot="de">Ich werde sie morgen anrufen.</p>
	<p slot="en">I am going to call her tomorrow.</p>
</LanguageComparison>

German <span lang="de">werden</span> can cover many future meanings. English
usually asks what kind of future meaning you need before choosing the form.

## Better default

For a fixed personal arrangement, the present progressive is usually the better
default:

- <span lang="en">I am meeting Anna tomorrow at 8.</span>

<span lang="en">I will meet Anna tomorrow at 8</span> is grammatically possible,
but it sounds less like an arrangement that already exists. Use
<span lang="en">will</span> when the sentence is a decision, promise, offer or
prediction.
