<KeyTakeaway>
- Learn a dependent preposition with its word: *depend on, interested in, reason for*.
- The preposition is often not predictable from German, so store the whole chunk and an example.
- A verb after a preposition normally uses **-ing**: *interested in learning*.
</KeyTakeaway>

## Use this now
| Pattern | Example |
| --- | --- |
| *depend on / belong to* | *It depends on the weather.* |
| *wait for / listen to* | *We waited for the bus.* |
| *interested in / good at / afraid of* | *She is good at maths.* |
| *reason for / solution to* | *What is the reason for the delay?* |
## Core rule
These are vocabulary-and-grammar chunks, not a general system to calculate. Learn the expression with what follows it: *apply for a job*, *responsible for the result*. After the preposition, use a noun or **-ing** form: *apologize for being late*. [Gerunds and infinitives](../../verb-patterns-voice/gerunds-and-infinitives/) owns the wider verb-pattern choice.
<MistakeBox incorrect="She is interested on learning." correct="She is interested in learning." lang="en">Keep *interested in* together as one chunk.</MistakeBox>
