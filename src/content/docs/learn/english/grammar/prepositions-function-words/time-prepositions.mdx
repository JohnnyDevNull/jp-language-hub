<KeyTakeaway>
- Use *at* for points, *on* for days/dates, and *in* for longer periods.
- Use *since* for a start point and *for* for a duration.
- Use *by* for a deadline, *until* for an end point, and *during* for something happening within a period.
</KeyTakeaway>

## Use this now
| Question | Choice | Example |
| --- | --- | --- |
| exact point? | *at* | *at six, at night* |
| day/date? | *on* | *on Monday, on 3 May* |
| month/year/period? | *in* | *in July, in 2026, in the morning* |
| starting point / duration? | *since / for* | *since Monday / for two days* |
| deadline / end point / within period? | *by / until / during* | *by Friday / until Friday / during the meeting* |
## Core rule
*By Friday* means no later than Friday; *until Friday* means continuing up to Friday. *During the meeting* means at some point within it. In informal American English, *on the weekend* is common; British English often uses *at the weekend*.
