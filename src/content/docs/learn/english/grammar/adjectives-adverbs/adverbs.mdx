<KeyTakeaway>
- Many manner adverbs add *-ly*: *careful → carefully*, but not all do.
- *Fast, late,* and *early* work as adjectives and adverbs without *-ly*.
- Learn *good → well* and *hard → hardly* as different forms and meanings.

Use an adverb for how, how much, how often, or when an action happens. [Adverb placement](../../sentence-structure/adverb-placement/) owns its clause position.
## Use this now
| Meaning | Form | Example |
| --- | --- | --- |
| usual manner | adjective + *-ly* | *She explained it clearly.* |
| same form | *fast, late, early* | *a fast car / drive fast* |
| performance | *well* | *She sings well.* |
| effort / almost not | *hard / hardly* | *work hard / hardly work* |
## Core rule
Many forms use *-ly*: *careful → carefully*. But *fast, late,* and *early* do not: *The train was late; it arrived late.* Some **-ly** words are adjectives: *a friendly colleague, a lively discussion, a likely result*. Say *in a friendly way* for the manner meaning.
### Meaning changes
*Hard* means with effort; *hardly* means almost not. *Late* means not on time; *lately* means recently.
<MistakeBox incorrect="She sings good." correct="She sings well." lang="en">Use *well* for performance; *good* describes a noun or state.</MistakeBox>
