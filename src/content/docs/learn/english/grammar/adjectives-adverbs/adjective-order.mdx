<KeyTakeaway>
- Put opinion before factual description: *a lovely old house*.
- Broad qualities normally come before origin, material, and purpose near the noun.
- Prefer a short clear phrase to an exhaustive adjective string.
</KeyTakeaway>

## Use this now
| You have | Put it | Example |
| --- | --- | --- |
| opinion + fact | opinion first | *a beautiful old house* |
| size + material | size first | *a small wooden box* |
| origin/material/purpose | toward noun | *an Italian leather driving glove* |
## Core rule
Use the practical path **opinion → size → age → shape → colour → origin → material → purpose → noun**. It is a default, not a mnemonic lecture or a reason to include every category.

- *a charming small blue house*
- *two large old French windows*
- *a round black metal table*
- *a useful new kitchen tool*

Rewrite a heavy string when needed: *a table made of black metal* can be clearer.
<MemoryTip>Move toward the noun: broad impression first; material and purpose last.</MemoryTip>
