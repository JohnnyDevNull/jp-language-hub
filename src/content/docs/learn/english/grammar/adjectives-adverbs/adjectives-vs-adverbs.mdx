## Use this now
<span lang="en">a quick answer</span>; <span lang="en">The answer is quick</span>; <span lang="en">She answered quickly.</span>
## Core rule
After linking verbs such as <span lang="en">be, seem, feel</span>, use an adjective: <span lang="en">It feels strange.</span> After an action verb, use an adverb when you describe manner: <span lang="en">She spoke clearly.</span>
