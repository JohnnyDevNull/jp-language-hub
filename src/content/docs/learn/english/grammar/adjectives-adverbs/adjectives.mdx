<KeyTakeaway>- Put an adjective before a noun or after a linking verb such as <span lang="en">be</span>, <span lang="en">seem</span>, or <span lang="en">feel</span>.</KeyTakeaway><TagList levels={frontmatter.levels} tags={frontmatter.tags} />

## Use this now
<span lang="en">a useful guide</span>; <span lang="en">The guide is useful.</span> Do not put an ordinary adjective after the noun.
## Core rule
Attributive adjectives modify a noun; predicative adjectives complete a linking verb. Some adjectives mainly follow linking verbs: <span lang="en">The child is asleep.</span>
