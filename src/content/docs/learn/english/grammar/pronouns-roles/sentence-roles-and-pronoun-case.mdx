<KeyTakeaway>
- Use subject forms for the person or thing that does or is something in the
  clause: *I called her; they arrived.*
- Use object forms after a verb or preposition: *She called me; with them.*
- English nouns do not inflect through a German-style case system, but pronouns
  retain this practical contrast: *I/me, he/him, she/her, we/us, they/them*.
</KeyTakeaway>

This is the decision page for personal-pronoun form. The other pronoun pages are form-and-use lookups.

## Use this now

| Job                     | Use                      | Example            |
| ----------------------- | ------------------------ | ------------------ |
| subject                 | _I, he, she, we, they_   | _They called._     |
| object of a verb        | _me, him, her, us, them_ | _She called them._ |
| object of a preposition | _me, him, her, us, them_ | _Come with us._    |

## Core rule

Ask what the noun phrase does, not which German case name it might resemble. English word order normally marks roles, while personal pronouns still show a small form contrast. After _be_, everyday English commonly uses object forms: _It’s me._

<MistakeBox incorrect="Him called me." correct="He called me." lang="en">
  The caller is the subject, so use *he*. The receiver is the object, so use
  *me*.
</MistakeBox>
<MemoryTip>
  Before the verb, ask “Who does it?” After a verb or preposition, ask “Who
  receives it or is connected to it?”
</MemoryTip>
