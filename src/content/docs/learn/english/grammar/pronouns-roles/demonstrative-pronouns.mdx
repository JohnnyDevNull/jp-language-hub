<KeyTakeaway>
- Use *this/these* for something near in space, time, or attention.
- Use *that/those* for something more distant or less immediate.
- *This/that* are singular; *these/those* are plural.
</KeyTakeaway>
<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

## Use this now

|         | Singular                        | Plural                              |
| ------- | ------------------------------- | ----------------------------------- |
| near    | _this book_ / _This is useful._ | _these books_ / _These are useful._ |
| distant | _that book_ / _That is useful._ | _those books_ / _Those are useful._ |

## Core rule

Demonstratives can stand alone (_Those are mine_) or introduce a noun (_those shoes_). “Near” can be physical, temporal, or conversational: _this week_, _that idea_, _those days_.
