English clauses keep a stable subject--verb frame more often than German does.
Use this shelf to build a neutral statement, join it to another clause, add
extra information about a noun, or position adverbs naturally.

## Choose by

- Need the neutral frame for a statement? Start with [sentence order](./sentence-order/).
- Need to add a reason, condition, or time clause? See [subordinate clauses](./subordinate-clauses/).
- Need to identify or add information about a noun? See [relative clauses](./relative-clauses/).
- Need to place *often*, *carefully*, *at home*, or *tomorrow*? See [adverb placement](./adverb-placement/).
- Need to form a question or a negative clause? Go to [questions and negation](../questions-negation/).

## Learn in this order

1. [Sentence order](./sentence-order/) for the neutral clause frame.
2. [Subordinate clauses](./subordinate-clauses/) to connect two clauses.
3. [Relative clauses](./relative-clauses/) to add information about a noun.
4. [Adverb placement](./adverb-placement/) to make longer clauses sound natural.
