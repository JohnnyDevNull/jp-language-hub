<KeyTakeaway>
- Use an <span lang="en">-ing</span> form after common verbs such as <span lang="en">enjoy</span> and after prepositions.
- Use <span lang="en">to + base verb</span> after common verbs such as <span lang="en">want</span>, <span lang="en">need</span>, and <span lang="en">decide</span>.
- Some choices change meaning; learn those as individual contrasts, not as one universal rule.
</KeyTakeaway>

This page gives high-value pattern families, not a complete verb dictionary.

## Use this now
Use <span lang="en">-ing</span> after <span lang="en">enjoy, avoid, finish</span> and a preposition: <span lang="en">She enjoys cooking.</span>, <span lang="en">before leaving</span>. Use <span lang="en">to</span> after <span lang="en">want, need, plan, decide</span>: <span lang="en">They decided to leave.</span>

## Core rule
After a modal, use the base verb without <span lang="en">to</span>: <span lang="en">can help</span>. After an imperative, use the base verb: <span lang="en">Please wait.</span> These are separate patterns, covered by [modal verbs](../modal-verbs/) and [imperative](../imperative/).

## Meaning contrasts
<span lang="en">Stop smoking</span> means end the habit; <span lang="en">stop to smoke</span> means pause another activity in order to smoke. <span lang="en">Remember to call</span> means do not forget a future action; <span lang="en">remember calling</span> means recall a past action.
