<KeyTakeaway>
- Form the passive with <span lang="en">be + past participle</span>.
- Change tense through <span lang="en">be</span>: <span lang="en">is made</span>, <span lang="en">was made</span>, <span lang="en">will be made</span>.
- Add <span lang="en">by + agent</span> only when the doer matters.
</KeyTakeaway>
<TagList levels={frontmatter.levels} tags={frontmatter.tags} />
The passive makes the receiver of an action the subject. This page owns the form; [active vs passive](../active-vs-passive/) owns the choice between forms.

## Use this now
First check whether the active verb has an object that can become the passive
subject. <span lang="en">They delivered the report</span> becomes
<span lang="en">The report was delivered.</span> <span lang="en">He arrived</span>
has no ordinary object, so it has no ordinary passive. Then choose the correct
form of <span lang="en">be</span> for the time: <span lang="en">The report was sent yesterday.</span>
