<KeyTakeaway>
- A modal is followed by a base verb: <span lang="en">can go</span>, not <span lang="en">can goes</span>.
- Choose <span lang="en">can</span> for ability, <span lang="en">should</span> for advice, and <span lang="en">must/have to</span> for obligation.
</KeyTakeaway>

## Use this now
| Meaning | Common choice | Example |
| --- | --- | --- |
| ability / possibility | <span lang="en">can</span> | <span lang="en">I can help.</span> |
| advice | <span lang="en">should</span> | <span lang="en">You should rest.</span> |
| strong rule | <span lang="en">must</span> | <span lang="en">You must wear a badge.</span> |
| external requirement | <span lang="en">have to</span> | <span lang="en">We have to leave.</span> |

## Core rule
Modal + base verb: <span lang="en">She can drive.</span> Negate the modal directly: <span lang="en">She cannot drive.</span> For polite requests, use the dedicated [polite requests](../../mood-politeness-reports/polite-requests/) page.

## Negatives and questions
Most true modals invert directly in a question: <span lang="en">Can you
help?</span>, <span lang="en">Should we leave?</span> Their negatives express
the corresponding meaning: <span lang="en">cannot</span>, <span lang="en">should
not</span>, <span lang="en">must not</span>.

<span lang="en">Mustn't</span> means prohibition: <span lang="en">You mustn't
park here.</span> <span lang="en">Don't have to</span> means no necessity:
<span lang="en">You don't have to come early.</span> Because <span lang="en">have
to</span> is not a true modal, ask <span lang="en">Do I have to pay?</span>,
not *Have I to pay?*.
