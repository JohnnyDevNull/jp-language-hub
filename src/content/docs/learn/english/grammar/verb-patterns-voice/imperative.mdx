<KeyTakeaway>
- Use the base verb for an imperative: <span lang="en">Open the window.</span>
- Use <span lang="en">do not / don't + base verb</span> for a negative instruction.
- Add <span lang="en">please</span> or use a polite request when a direct command is too strong.

## Use this now
Use an imperative for clear instructions: <span lang="en">Turn left.</span>
Use <span lang="en">Don't touch that.</span> for a warning. For a request between adults, see [polite requests](../../mood-politeness-reports/polite-requests/).

## Core rule
The subject <span lang="en">you</span> is normally omitted. Use the base verb:
<span lang="en">Read the instructions.</span> Add <span lang="en">let's</span>
for a shared suggestion: <span lang="en">Let's start now.</span>

<MistakeBox incorrect="Don't to touch that." correct="Don't touch that." lang="en">After <span lang="en">don't</span>, use the base verb without <span lang="en">to</span>.</MistakeBox>
