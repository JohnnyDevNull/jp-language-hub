<KeyTakeaway>
- Use active voice when the doer is useful information.
- Use passive voice when the result, receiver, or process matters more than the doer.
- Omit the agent when it is unknown, obvious, or irrelevant.
</KeyTakeaway>
<TagList levels={frontmatter.levels} tags={frontmatter.tags} />
Both voices can describe the same event. Choose the form that gives the reader the most useful starting point; [passive](../passive/) explains how to build the passive.

## Use this now
Start with the information the reader needs first. <span lang="en">Maya approved the request</span> names the decision-maker. <span lang="en">The request was approved</span> foregrounds the result.

## Core rule
Active voice is often clearer for responsibility. Passive voice is natural for results, processes, reports, and cases where the agent is unknown: <span lang="en">My bike was stolen.</span>
