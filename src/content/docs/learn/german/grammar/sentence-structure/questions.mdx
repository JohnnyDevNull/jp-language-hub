Build German yes/no questions and question-word questions with verb position.

## Use this now

First decide whether the expected answer is yes/no or information. Then place
the finite verb first (yes/no) or after the question word (information).

## Core rule

German yes/no questions use verb-first order. Question-word questions keep the
question word in the first field and use V2 order for the rest of the clause.
