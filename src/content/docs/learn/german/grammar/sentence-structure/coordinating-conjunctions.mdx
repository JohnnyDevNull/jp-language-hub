<KeyTakeaway>
- `und`, `aber`, `denn`, and `oder` join equal clauses.
- A coordinating conjunction does not move the finite verb in the following main clause.
- The second clause therefore keeps its own V2 order.
</KeyTakeaway>

Connect main clauses with German coordinating conjunctions without changing verb position.

## Use this now

Choose a coordinating conjunction for the relationship between the clauses.
Then build each main clause independently, with its finite verb in position two.

## Core rule

Coordinating conjunctions join clauses of equal status. Unlike subordinating
conjunctions, they do not make the following main clause verb-final.
