German word order is easiest when you track the finite verb and the clause
type. Main clauses use verb second; yes/no questions often start with the
finite verb; subordinate clauses send the finite verb late.

## Transfer traps

Swedish V2 helps with German main clauses, but not with every subordinate
pattern. English subject-verb-object order is often too stable for German, so
fronted time phrases and objects need special attention.
