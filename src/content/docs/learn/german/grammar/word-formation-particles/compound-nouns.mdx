<KeyTakeaway>
- A German compound takes its gender from the final noun.
- The last noun is the head: it names what the whole compound is.
- Long compounds become easier if you read them from the end first.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Compound nouns look intimidating, but their head noun gives you a reliable
meaning and gender shortcut.

## Use this now

Find the last noun: <span lang="de">die Haustür</span> because <span lang="de">die Tür</span>;
<span lang="de">das Wörterbuch</span> because <span lang="de">das Buch</span>.

## Core rule

In a compound, earlier parts narrow the meaning; the final noun determines gender and core meaning.

## Build a useful lookup

Read from right to left to find the head, then attach the earlier noun or
modifier. The whole compound is written as one word:

| Compound | Head noun | Gender and meaning |
| --- | --- | --- |
| <span lang="de">die Haustür</span> | <span lang="de">Tür</span> | a door for a house; feminine |
| <span lang="de">der Fahrplan</span> | <span lang="de">Plan</span> | a travel timetable; masculine |
| <span lang="de">das Arbeitszimmer</span> | <span lang="de">Zimmer</span> | a workroom; neuter |
| <span lang="de">die Bücherregale</span> | <span lang="de">Regale</span> | bookshelves; plural |

The first element can narrow the meaning without changing the head’s gender.
Use the head noun as the dictionary lookup: learn <span lang="de">die Tür</span>
before you meet <span lang="de">Haustür</span> or
<span lang="de">Eingangstür</span>.

Some compounds use a linking element: <span lang="de">Arbeitszimmer</span> is
<span lang="de">Arbeit</span> + <span lang="de">-s-</span> +
<span lang="de">Zimmer</span>. The linking element does not change the head’s
gender, but it is part of the form you must check and learn.



<MistakeBox
	incorrect="Ich sehe der Fahrplan."
	correct="Ich sehe den Fahrplan."
	lang="de"
>
	The final noun is <span lang="de">Plan</span>, so the compound is masculine;
	in accusative, <span lang="de">der</span> becomes
	<span lang="de">den</span>.
</MistakeBox>

<MemoryTip>
The last noun wins.
</MemoryTip>
