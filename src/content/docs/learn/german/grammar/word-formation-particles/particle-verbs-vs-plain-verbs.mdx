Tell apart a verb plus particle from a plain verb plus prepositional phrase.

## Use this now

If the particle creates a new lexical meaning, learn the pair as a verb. If the small word introduces a normal object, treat it as a preposition.

## Core rule

<span lang="de">anfangen</span> is one verb meaning “begin”; <span lang="de">warten auf</span> is a verb plus prepositional object.

| What you see | Treat it as | Check |
| --- | --- | --- |
| <span lang="de">Ich fange an.</span> | a separable verb | the particle moves in a finite main clause |
| <span lang="de">Ich warte auf den Bus.</span> | a prepositional object | the preposition introduces its object |



<MistakeBox
	incorrect="Ich warte den Bus auf."
	correct="Ich warte auf den Bus."
	lang="de"
>
	<span lang="de">auf</span> belongs to the object phrase here, not as a separable particle.
</MistakeBox>

<MemoryTip>
