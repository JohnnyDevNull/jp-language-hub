Decide whether a German describing word needs an ending.

## Use this now

Use endings before nouns: <span lang="de">ein gutes Buch</span>. No ending after <span lang="de">sein</span> or with verbs: <span lang="de">Das Buch ist gut</span>, <span lang="de">Sie liest schnell</span>.

## Core rule

The position and function decide the ending, not the English translation.



<MistakeBox
	incorrect="Das ist ein gut Buch."
	correct="Das ist ein gutes Buch."
	lang="de"
>
	Before a noun, the adjective needs an ending.
</MistakeBox>

<MemoryTip>
Before noun: ending. After sein or modifying a verb: no agreement ending.
</MemoryTip>
