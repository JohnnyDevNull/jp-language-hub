Use German adverbs to modify verbs, adjectives, whole clauses, time, manner, place, and frequency.

## Use this now

Use the same base form in many adverbial uses: <span lang="de">Sie singt schön</span>.

## Core rule

Adverb placement depends on sentence structure and emphasis, but the finite verb position remains stable.
