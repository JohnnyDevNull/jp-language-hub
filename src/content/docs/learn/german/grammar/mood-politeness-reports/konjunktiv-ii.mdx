Use Konjunktiv II for hypothetical meaning, wishes, and polite distance.

## Use this now

Use Konjunktiv II when the sentence steps away from direct fact:

| Meaning | Common form | Example |
| --- | --- | --- |
| hypothetical condition | special forms such as <span lang="de">hätte</span>, <span lang="de">wäre</span> | <span lang="de">Wenn ich Zeit hätte...</span> |
| broad conditional action | <span lang="de">würde</span> + infinitive | <span lang="de">Ich würde kommen.</span> |
| polite request | modal Konjunktiv II | <span lang="de">Könnten Sie mir helfen?</span> |
| wish | often <span lang="de">wäre</span> or <span lang="de">hätte</span> | <span lang="de">Wenn ich doch mehr Zeit hätte!</span> |

## Core rule

Common high-value forms are <span lang="de">wäre</span>, <span lang="de">hätte</span>, <span lang="de">könnte</span>, <span lang="de">würde</span>.

For many verbs, modern German uses <span lang="de">würde</span> plus infinitive because older one-word Konjunktiv forms sound formal, literary, or ambiguous. For the highest-frequency verbs and modals, the one-word forms are still normal: <span lang="de">wäre</span>, <span lang="de">hätte</span>, <span lang="de">könnte</span>, <span lang="de">müsste</span>, <span lang="de">sollte</span>, <span lang="de">wollte</span>.

## English transfer

English "would" is not a one-to-one signal. German may use <span lang="de">würde</span>, but it may also use a one-word form, especially with <span lang="de">sein</span>, <span lang="de">haben</span>, and modal verbs.

<MistakeBox
	incorrect="Wenn ich Zeit habe, würde ich kommen."
	correct="Wenn ich Zeit hätte, würde ich kommen."
	lang="de"
>
	A hypothetical condition normally uses Konjunktiv II too.
</MistakeBox>
