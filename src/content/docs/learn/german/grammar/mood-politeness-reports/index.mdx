<KeyTakeaway>
- Use Konjunktiv II when a meaning is hypothetical, wished for, softened, or politely distant.
- Learn <span lang="de">hätte</span>, <span lang="de">wäre</span>, and <span lang="de">könnte</span> as frequent ready-made forms; use <span lang="de">würde</span> plus infinitive productively.

This shelf separates a speaker's stance from ordinary tense choice: what is not
presented as a plain fact, what is politely requested, and whose information is
being reported.

## Choose by meaning

| If you need to... | Start here |
| --- | --- |
| express a hypothetical, wish, or cautious suggestion | [Konjunktiv II](./konjunktiv-ii/) |
| build a productive hypothetical form | [Würde forms](./wuerde-forms/) |
| use high-frequency forms such as <span lang="de">hätte</span>, <span lang="de">wäre</span>, and <span lang="de">könnte</span> | [Hätte, wäre, könnte](./haette-waere-koennte/) |
| make a request less direct | [Polite requests](./polite-requests/) |
| report what someone said in ordinary speech or writing | [Reported speech](./reported-speech/) |
| recognize formal journalistic distancing | [Konjunktiv I](./konjunktiv-i/) |

## Conditions without a duplicate route

For a condition, [Subordinating conjunctions](../sentence-structure/subordinating-conjunctions/)
owns the clause order. For an unreal, wished-for, or tentative meaning,
[Konjunktiv II](./konjunktiv-ii/) owns the form choice. Together they answer
the condition question without a separate German conditionals route.

## Learn in this order

1. Start with [Konjunktiv II](./konjunktiv-ii/) and the frequent forms page.
2. Add [Würde forms](./wuerde-forms/) when you need an unfamiliar verb productively.
3. Use [Polite requests](./polite-requests/) for a practical interaction.
4. Use [Reported speech](./reported-speech/) for everyday source marking; keep
   [Konjunktiv I](./konjunktiv-i/) as formal reference material.
