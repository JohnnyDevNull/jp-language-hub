<KeyTakeaway>
- Politeness often uses distance rather than extra words.
- Use könnten, würden, or hätten for polite requests.
- Address, modal choice, and <span lang="de">bitte</span> work together; one polite marker rarely fixes an abrupt command.
</KeyTakeaway>

Use Konjunktiv II, bitte, and word order to make German requests polite.

## Use this now

Use <span lang="de">könnten</span>, <span lang="de">würden</span>, or <span lang="de">hätten</span> for polite requests.

## Core rule

<span lang="de">Bitte</span> helps, but grammar often carries the politeness.

| Situation | Direct | Polite everyday option |
| --- | --- | --- |
| ask for help | <span lang="de">Helfen Sie mir.</span> | <span lang="de">Könnten Sie mir bitte helfen?</span> |
| ask for an item | <span lang="de">Geben Sie mir Wasser.</span> | <span lang="de">Könnte ich bitte Wasser bekommen?</span> |
| state a wish | <span lang="de">Ich will einen Kaffee.</span> | <span lang="de">Ich hätte gern einen Kaffee.</span> |

<MemoryTip>
Polite German often asks through possibility, not command.
