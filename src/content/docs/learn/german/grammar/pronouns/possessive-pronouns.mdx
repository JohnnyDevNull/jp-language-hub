Use German possessives as ein-words with gender, number, and case endings.

## Use this now

Choose the possessor first, then match the possessed noun phrase for gender, number, and case.

## Core rule

<span lang="de">mein</span>, <span lang="de">dein</span>, <span lang="de">sein</span>, <span lang="de">ihr</span>, <span lang="de">unser</span>, <span lang="de">euer</span>, and <span lang="de">Ihr</span> take endings like ein-words.



<MistakeBox
	incorrect="Ich sehe mein Freund."
	correct="Ich sehe meinen Freund."
	lang="de"
>
	The possessed noun phrase is masculine accusative, so <span lang="de">mein</span> becomes <span lang="de">meinen</span>.
</MistakeBox>

<MemoryTip>
Possessor chooses the stem; case/gender/number choose the ending.
</MemoryTip>
