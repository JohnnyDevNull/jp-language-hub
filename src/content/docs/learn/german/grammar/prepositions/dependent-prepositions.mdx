<KeyTakeaway>
- Learn a dependent preposition together with the verb or adjective that selects it.
- The combination fixes the meaning; the preposition then fixes the case of a following noun phrase.
- Keep the whole phrase: <span lang="de">warten auf + Akkusativ</span>, not just <span lang="de">warten</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Some German verbs and adjectives regularly occur with one particular
preposition. English or Swedish may use a different preposition, so these are
best learned as chunks rather than translated word by word.

## Use this now

Store the pattern in three parts: **word + preposition + case**.

| Pattern | Example | Meaning |
| --- | --- | --- |
| <span lang="de">warten auf + Akk.</span> | <span lang="de">Ich warte auf den Bus.</span> | wait for the bus |
| <span lang="de">denken an + Akk.</span> | <span lang="de">Sie denkt an ihre Prüfung.</span> | think about her exam |
| <span lang="de">sprechen über + Akk.</span> | <span lang="de">Wir sprechen über das Projekt.</span> | talk about the project |
| <span lang="de">abhängen von + Dat.</span> | <span lang="de">Das hängt vom Wetter ab.</span> | depend on the weather |
| <span lang="de">teilnehmen an + Dat.</span> | <span lang="de">Er nimmt an der Sitzung teil.</span> | take part in the meeting |
| <span lang="de">stolz sein auf + Akk.</span> | <span lang="de">Sie ist stolz auf ihren Sohn.</span> | be proud of her son |
| <span lang="de">interessiert sein an + Dat.</span> | <span lang="de">Ich bin an Musik interessiert.</span> | be interested in music |
| <span lang="de">zufrieden sein mit + Dat.</span> | <span lang="de">Wir sind mit dem Ergebnis zufrieden.</span> | be satisfied with the result |

## Core rule

The verb or adjective chooses the preposition; the preposition chooses the
case. Compare <span lang="de">warten auf den Bus</span> (accusative) with
<span lang="de">abhängen von der Entscheidung</span> (dative). The case is not chosen by
the English translation of *for* or *on*.

### Make the phrase productive

Change the noun phrase while keeping the pattern:

- <span lang="de">Ich warte auf den Bus.</span> → <span lang="de">Ich warte auf meine Kollegin.</span>
- <span lang="de">Er ist stolz auf seinen Sohn.</span> → <span lang="de">Er ist stolz auf seine Arbeit.</span>
- <span lang="de">Das hängt vom Wetter ab.</span> → <span lang="de">Das hängt von der Entscheidung ab.</span>

With a thing or idea, a da-compound is often more natural:
<span lang="de">Ich warte darauf</span>, <span lang="de">Sie denkt daran</span>.
For a person, keep the preposition and pronoun separate:
<span lang="de">Ich warte auf ihn</span>. See [Prepositional adverbs](../prepositional-adverbs/)
for that distinction.
