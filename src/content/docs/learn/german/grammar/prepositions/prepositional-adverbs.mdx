<KeyTakeaway>
- Da-compounds replace preposition plus “it/that” for things and ideas.
- Wo-compounds ask about things and ideas.
- Use a personal pronoun after the preposition for people.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

German often does not say <span lang="de">mit es</span> or <span lang="de">für das</span>. It builds a compact adverb instead.

## Use this now

Use <span lang="de">damit</span> for “with it/that”, <span lang="de">dafür</span> for “for it/that”, and <span lang="de">woran</span> for “what ... on/about?”.

## Core rule

For non-person objects, combine <span lang="de">da-</span> or <span lang="de">wo-</span> with the preposition. Add -r- before a vowel: <span lang="de">darauf</span>, <span lang="de">woran</span>.



<MistakeBox
	incorrect="Ich warte auf es."
	correct="Ich warte darauf."
	lang="de"
>
	For things or ideas, German normally uses a da-compound instead of preposition plus pronoun.
</MistakeBox>

<MemoryTip>
People stay separate: <span lang="de">mit ihm</span>. Things become compounds: <span lang="de">damit</span>.
</MemoryTip>
