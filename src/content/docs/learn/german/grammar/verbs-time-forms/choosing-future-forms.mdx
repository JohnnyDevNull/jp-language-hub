Choose between present-for-future, werden-future, and future perfect.

## Use this now

Use present for concrete plans, werden-future for prediction or emphasis, and future perfect for completion before another future point.

## Core rule

If a future time word already makes the time clear, present tense is usually
enough. Add <span lang="de">werden</span> for prediction, promise, or explicit
future framing; use future perfect only when completion before a reference
point matters.

| Intended meaning | Form | Example |
| --- | --- | --- |
| fixed plan or schedule | present + time phrase | <span lang="de">Der Zug fährt morgen ab.</span> |
| prediction or promise | <span lang="de">werden</span> + infinitive | <span lang="de">Ich werde dir helfen.</span> |
| completed by a future point | <span lang="de">werden</span> + participle + auxiliary | <span lang="de">Bis acht Uhr werde ich angekommen sein.</span> |
