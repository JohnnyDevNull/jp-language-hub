Use German preterite for written narrative and common high-frequency verbs.

## Use this now

In speech, many lexical verbs prefer perfect, but <span lang="de">war</span>, <span lang="de">hatte</span>, and modal preterites are common.

## Core rule

Use preterite to narrate compactly. Regular verbs use a <span lang="de">-te</span>
pattern, while high-frequency verbs are irregular:

| Infinitive | Preterite | Example |
| --- | --- | --- |
| <span lang="de">machen</span> | <span lang="de">machte</span> | <span lang="de">Er machte die Tür zu.</span> |
| <span lang="de">gehen</span> | <span lang="de">ging</span> | <span lang="de">Er ging nach Hause.</span> |
| <span lang="de">sein</span> | <span lang="de">war</span> | <span lang="de">Sie war müde.</span> |

In conversation, perfect is often more natural for ordinary lexical verbs;
<span lang="de">war</span>, <span lang="de">hatte</span>, and modal preterites
remain common.
