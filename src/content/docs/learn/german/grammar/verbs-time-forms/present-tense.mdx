Use German present for current actions, habits, facts, and many future plans.

## Use this now

Use present for <span lang="de">ich arbeite</span> meaning both “I work” and “I am working”. Add context when ongoing meaning matters.

## Core rule

The present stem takes person endings; unlike English, the same form covers
simple and progressive meanings:

| Person | <span lang="de">arbeiten</span> |
| --- | --- |
| <span lang="de">ich</span> | <span lang="de">arbeite</span> |
| <span lang="de">du</span> | <span lang="de">arbeitest</span> |
| <span lang="de">er/sie/es</span> | <span lang="de">arbeitet</span> |
| <span lang="de">wir/sie/Sie</span> | <span lang="de">arbeiten</span> |

A future time expression can make present-tense German future:
<span lang="de">Morgen fahre ich nach Berlin</span>.



<MistakeBox
	incorrect="Ich bin arbeitend."
	correct="Ich arbeite."
	lang="de"
>
	German normally does not build an English-style progressive with <span lang="de">sein</span> plus participle.
</MistakeBox>
