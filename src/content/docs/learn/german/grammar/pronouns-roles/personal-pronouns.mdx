Use German personal pronouns in nominative, accusative, and dative forms.

## Use this now

Use nominative for subjects, accusative for direct objects, and dative for recipients or dative prepositions.

## Core rule

Personal pronouns replace noun phrases and keep the role of the phrase they replace.

| Person | Nominative | Accusative | Dative |
| --- | --- | --- | --- |
| 1st singular | <span lang="de">ich</span> | <span lang="de">mich</span> | <span lang="de">mir</span> |
| 2nd singular | <span lang="de">du</span> | <span lang="de">dich</span> | <span lang="de">dir</span> |
| 3rd singular masculine | <span lang="de">er</span> | <span lang="de">ihn</span> | <span lang="de">ihm</span> |
| 3rd singular feminine | <span lang="de">sie</span> | <span lang="de">sie</span> | <span lang="de">ihr</span> |
| 3rd singular neuter | <span lang="de">es</span> | <span lang="de">es</span> | <span lang="de">ihm</span> |
| 1st plural | <span lang="de">wir</span> | <span lang="de">uns</span> | <span lang="de">uns</span> |
| 2nd plural | <span lang="de">ihr</span> | <span lang="de">euch</span> | <span lang="de">euch</span> |
| 3rd plural | <span lang="de">sie</span> | <span lang="de">sie</span> | <span lang="de">ihnen</span> |
| formal singular/plural | <span lang="de">Sie</span> | <span lang="de">Sie</span> | <span lang="de">Ihnen</span> |

The same role logic applies across persons and numbers. A preposition can
select the form directly: <span lang="de">mit mir</span>,
<span lang="de">für ihn</span>, <span lang="de">zu uns</span>.



<MistakeBox
	incorrect="Ich sehe er."
	correct="Ich sehe ihn."
	lang="de"
>
	A direct-object masculine pronoun is accusative <span lang="de">ihn</span>.
</MistakeBox>

<MemoryTip>
Subject forms answer who does it; object forms answer who receives or is affected.
</MemoryTip>
