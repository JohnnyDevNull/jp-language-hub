Use jemand, niemand, etwas, nichts, man, and alle for unspecified people and things.

## Use this now

Some refer to people, some to things, and some to groups.

## Core rule

Use <span lang="de">man</span> for general people, <span lang="de">jemand/niemand</span> for someone/no one, and <span lang="de">etwas/nichts</span> for something/nothing.

<span lang="de">Man</span> is grammatically singular and takes third-person
singular verbs. <span lang="de">Jemand</span> and <span lang="de">niemand</span>
refer to people; <span lang="de">etwas</span> and <span lang="de">nichts</span>
refer to things or ideas. For a general set, use forms such as
<span lang="de">alle</span> or <span lang="de">jeder</span> with the relevant
case ending.
