<KeyTakeaway>
- Politeness often uses distance rather than extra words.
- Use könnten, würden, or hätten for polite requests.
- German verb forms become easier when you place them inside the verb bracket.
</KeyTakeaway>

Use Konjunktiv II, bitte, and word order to make German requests polite.

## Use this now

Use <span lang="de">könnten</span>, <span lang="de">würden</span>, or <span lang="de">hätten</span> for polite requests.

## Core rule

<span lang="de">Bitte</span> helps, but grammar often carries the politeness.



<MistakeBox
	incorrect="Gib mir Kaffee."
	correct="Könnten Sie mir bitte einen Kaffee geben?"
	lang="de"
>
	The second version uses Konjunktiv II and polite address.
</MistakeBox>

<MemoryTip>
Polite German often asks through possibility, not command.
</MemoryTip>
