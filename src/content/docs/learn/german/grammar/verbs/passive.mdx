Use German passive with werden plus participle when the affected object is foregrounded.

## Use this now

Use process passive with <span lang="de">werden</span> plus past participle when the event matters more than the actor: <span lang="de">Das Haus wird gebaut</span>. Add the actor only when the reader needs it: <span lang="de">Das Haus wird von der Firma gebaut</span>.

## Core rule

German process passive uses a finite form of <span lang="de">werden</span> plus a past participle in the right bracket.

Do not confuse process passive with state passive. <span lang="de">Das Haus wird gebaut</span> describes the building process. <span lang="de">Das Haus ist gebaut</span> describes the resulting state. Many beginner mistakes come from choosing <span lang="de">sein</span> when the sentence needs the process.

## Actor phrases

Use <span lang="de">von</span> for an actor or cause that behaves like an agent: <span lang="de">von der Firma</span>, <span lang="de">vom Lehrer</span>. Use <span lang="de">durch</span> more often for means, cause, or route: <span lang="de">durch einen Fehler</span>. If the actor is obvious or irrelevant, leave it out.
