Choose active or passive from what the sentence should foreground.

## Use this now

Use active for responsibility and agency. Use passive when the actor is unknown, obvious, irrelevant, or deliberately backgrounded.

## Core rule

German passive is a focus choice, not a politeness decoration.

| If the sentence should foreground... | Choose | Example |
| --- | --- | --- |
| the actor or responsibility | active | <span lang="de">Die Firma baut das Haus.</span> |
| the affected thing | passive | <span lang="de">Das Haus wird gebaut.</span> |
| the process without naming the actor | passive | <span lang="de">Hier wird gearbeitet.</span> |
| a general rule or instruction | often active or impersonal | <span lang="de">Man bezahlt an der Kasse.</span> |

## Spot `werden`

<LanguageComparison title="Werden future vs werden passive" languages={["de","en"]}>
	<p slot="de"><span lang="de">Er wird das Haus bauen.</span> = <span lang="de">werden</span> + infinitive.</p>
	<p slot="en">He will build the house.</p>
</LanguageComparison>

<LanguageComparison title="Process passive" languages={["de","en"]}>
	<p slot="de"><span lang="de">Das Haus wird gebaut.</span> = <span lang="de">werden</span> + past participle.</p>
	<p slot="en">The house is being built / is built.</p>
</LanguageComparison>

The word after <span lang="de">werden</span> tells you the job it is doing. An infinitive points to future meaning; a past participle points to passive voice.
