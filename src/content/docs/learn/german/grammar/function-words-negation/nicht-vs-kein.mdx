Use nicht for verbs, adjectives, adverbs, and definite nouns; use kein for no/not a.

## Use this now

If English could say “no” or “not a/an”, German usually uses <span lang="de">kein</span>. Otherwise use <span lang="de">nicht</span>.

## Core rule

<span lang="de">Kein</span> declines like an ein-word; <span lang="de">nicht</span> does not decline.

Replace an indefinite article or an unmarked noun with the matching
<span lang="de">kein</span> form: <span lang="de">ein Problem → kein Problem</span>,
<span lang="de">eine Idee → keine Idee</span>. Keep
<span lang="de">nicht</span> with definite noun phrases and with non-noun
targets: <span lang="de">nicht der Bus</span>, <span lang="de">nicht heute</span>,
<span lang="de">nicht kommen</span>.



<MistakeBox
	incorrect="Ich habe nicht einen Hund. (mit der neutralen Bedeutung: Ich habe keinen Hund)"
	correct="Ich habe keinen Hund."
	lang="de"
>
	For the neutral meaning “no dog / not a dog”, German normally uses
	<span lang="de">kein</span>. Contrastive <span lang="de">nicht einen</span>
	is grammatical when the numeral is focused, for example:
	<span lang="de">Ich habe nicht einen, sondern zwei Hunde.</span>
</MistakeBox>

<MemoryTip>
Kein negates a noun slot; nicht negates almost everything else.
</MemoryTip>
