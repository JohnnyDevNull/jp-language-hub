## Use this now

Choose the negative word that matches the missing person, thing, time, or place.

## Core rule

For one neutral negation, do not add a second negative word when the negative
pronoun or adverb already expresses the scope. Contrastive or idiomatic
multiple negatives are a separate advanced topic; this page covers the clear
everyday choice.

Use <span lang="de">niemand</span> for a person, <span lang="de">nichts</span>
for a thing, <span lang="de">nie</span> for time, and
<span lang="de">nirgends</span> for place. These words already carry negative
meaning, so the verb normally stays without an additional
<span lang="de">nicht</span>: <span lang="de">Niemand kommt</span>,
<span lang="de">Ich sehe nichts</span>, <span lang="de">Sie war nie dort</span>.
