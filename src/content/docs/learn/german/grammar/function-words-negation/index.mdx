<KeyTakeaway>
- Start negation by identifying its scope: noun phrase, focused phrase, or whole clause.
- Use <span lang="de">kein</span> for an indefinite noun phrase and <span lang="de">nicht</span> for other targets.
- Use <span lang="de">niemand</span>, <span lang="de">nichts</span>, <span lang="de">nie</span>, or <span lang="de">nirgends</span> when the negative word names the missing slot.

Negation is not just a vocabulary choice between <span lang="de">nicht</span>
and <span lang="de">kein</span>. The useful question is scope: what exactly is
being negated?

## Choose by negation problem

| If you need to negate... | Start with |
| --- | --- |
| the overall choice between negative forms | [Negation](./negation/) |
| an indefinite noun phrase such as <span lang="de">ein Buch</span> or <span lang="de">Kaffee</span> | [Nicht vs kein](./nicht-vs-kein/) |
| a verb, adjective, adverb, phrase, or whole clause | [Nicht placement](./nicht-placement/) |
| a person, thing, time, or place with one negative word | [Negative pronouns and adverbs](./negative-pronouns-and-adverbs/) |

## Learn in this order

1. Decide the scope on [Negation](./negation/).
2. Choose <span lang="de">kein</span> or <span lang="de">nicht</span> on
   [Nicht vs kein](./nicht-vs-kein/) when the target is a noun phrase or other
   focused phrase.
3. Place <span lang="de">nicht</span> precisely on [Nicht placement](./nicht-placement/).
4. Use [Negative pronouns and adverbs](./negative-pronouns-and-adverbs/) when
   the negative word itself names the missing person, thing, time, or place.

## Fast rule

- Use <span lang="de">kein</span> when the thing being negated is an indefinite
  noun phrase: <span lang="de">kein Kaffee</span>, <span lang="de">keine Zeit</span>.
- Use <span lang="de">nicht</span> when you negate a verb, adjective, adverb,
  definite noun phrase, prepositional phrase, or whole clause.
- Place <span lang="de">nicht</span> by asking what it negates, then check the
  [verb bracket](../sentence-structure/verb-bracket/) for late verb pieces.
