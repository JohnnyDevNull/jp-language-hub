Give German commands with du, ihr, Sie, and wir forms.

## Use this now

Use the verb stem for many <span lang="de">du</span> commands, the normal <span lang="de">ihr</span> form for plural informal commands, and verb-first with <span lang="de">Sie</span> for polite commands.

## Core rule

Command forms often drop the subject except for <span lang="de">Sie</span> and
<span lang="de">wir</span>:

| Addressee | Pattern | Example |
| --- | --- | --- |
| <span lang="de">du</span> | stem, often without ending | <span lang="de">Komm her!</span> |
| <span lang="de">ihr</span> | present <span lang="de">ihr</span> form | <span lang="de">Kommt her!</span> |
| <span lang="de">Sie</span> | infinitive + <span lang="de">Sie</span> | <span lang="de">Kommen Sie her!</span> |
| <span lang="de">wir</span> | infinitive + <span lang="de">wir</span> | <span lang="de">Gehen wir!</span> |
