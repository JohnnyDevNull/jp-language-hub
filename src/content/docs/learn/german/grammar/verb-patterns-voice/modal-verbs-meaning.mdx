<KeyTakeaway>
- Each modal carries a different speaker attitude.
- Choose können for ability, müssen for necessity, wollen for intention, sollen for advice/obligation, and dürfen for permission.
- Choose the modal by speaker meaning—ability, necessity, permission, intention, advice, or preference—not by translation alone.
</KeyTakeaway>

Choose the German modal from ability, necessity, wish, advice, permission, or preference.

## Use this now

Choose <span lang="de">können</span> for ability, <span lang="de">müssen</span> for necessity, <span lang="de">wollen</span> for intention, <span lang="de">sollen</span> for advice/obligation, and <span lang="de">dürfen</span> for permission.

## Core rule

Do not translate English “must”, “should”, and “may” one-to-one without
checking meaning:

| Meaning | Modal | Example |
| --- | --- | --- |
| ability | <span lang="de">können</span> | <span lang="de">Ich kann schwimmen.</span> |
| necessity | <span lang="de">müssen</span> | <span lang="de">Du musst gehen.</span> |
| intention/wish | <span lang="de">wollen</span> | <span lang="de">Wir wollen reisen.</span> |
| advice/indirect instruction | <span lang="de">sollen</span> | <span lang="de">Du sollst anrufen.</span> |
| permission | <span lang="de">dürfen</span> | <span lang="de">Darf ich eintreten?</span> |
| liking/preference | <span lang="de">mögen</span> | <span lang="de">Ich mag Tee.</span> |
| polite wish/offer | <span lang="de">möchten</span> | <span lang="de">Ich möchte Tee.</span> |

<span lang="de">Mögen</span> expresses liking or preference. Its polite wish
counterpart <span lang="de">möchten</span> is the form to use when ordering,
requesting, or stating what one would like.



<MistakeBox
	incorrect="Ich muss vielleicht kommen."
	correct="Ich sollte vielleicht kommen."
	lang="de"
>
	For mild advice or recommendation, <span lang="de">sollte</span> is often better than <span lang="de">muss</span>.
</MistakeBox>
