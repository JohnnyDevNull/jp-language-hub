<KeyTakeaway>
- Ein-words include ein, kein, mein, dein, sein, ihr, unser, euer, and Ihr.
- They behave like indefinite articles with shared endings.
- Nominative masculine and nominative/accusative neuter have no visible ending on ein.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Ein-words are not only “a/an”. They include negation and possessives too.

## Use this now

Use the same pattern for <span lang="de">ein Hund</span>, <span lang="de">kein Hund</span>, and <span lang="de">mein Hund</span>.

## Core rule

Ein-words carry article-like endings when the noun phrase needs a visible signal. Where <span lang="de">ein</span> has no ending, the adjective often carries more of the signal.

| Case | Masculine | Feminine | Neuter | Plural with kein |
| --- | --- | --- | --- | --- |
| nominative | <span lang="de">ein</span> | <span lang="de">eine</span> | <span lang="de">ein</span> | <span lang="de">keine</span> |
| accusative | <span lang="de">einen</span> | <span lang="de">eine</span> | <span lang="de">ein</span> | <span lang="de">keine</span> |
| dative | <span lang="de">einem</span> | <span lang="de">einer</span> | <span lang="de">einem</span> | <span lang="de">keinen</span> |

<span lang="de">Kein</span> has plural forms; <span lang="de">ein</span>
does not. Possessive determiners such as <span lang="de">mein</span> use the
same endings, but they are not interchangeable with <span lang="de">kein</span>
in meaning.



<MistakeBox
	incorrect="Ich habe ein guten Freund."
	correct="Ich habe einen guten Freund."
	lang="de"
>
	Masculine accusative needs <span lang="de">einen</span>.
</MistakeBox>

<MemoryTip>
If <span lang="de">ein</span> works, <span lang="de">kein</span> and <span lang="de">mein</span> usually follow the same slot.
</MemoryTip>
