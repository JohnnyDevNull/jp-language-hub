<KeyTakeaway>
- A German compound takes its gender from the final noun.
- The last noun is the head: it names what the whole compound is.
- Long compounds become easier if you read them from the end first.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Compound nouns look intimidating, but their gender rule is wonderfully reliable.

## Use this now

Find the last noun: <span lang="de">die Haustür</span> because <span lang="de">die Tür</span>; <span lang="de">das Wörterbuch</span> because <span lang="de">das Buch</span>.

## Core rule

In a compound, earlier parts narrow the meaning; the final noun determines gender and core meaning.



<MistakeBox
	incorrect="der Haustür"
	correct="die Haustür"
	lang="de"
>
	The final noun is <span lang="de">Tür</span>, so the compound is feminine.
</MistakeBox>

<MemoryTip>
The last noun wins.
</MemoryTip>
