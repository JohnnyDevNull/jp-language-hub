<KeyTakeaway>
- German plurals must be learned with the noun; there is no single default ending.
- Definite plural uses die in nominative and accusative.
- Dative plural often adds -n to the noun if possible.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Plural is part of the noun entry in German, just like gender.

## Use this now

Store nouns as a mini-pair: <span lang="de">der Tisch, die Tische</span>; <span lang="de">das Kind, die Kinder</span>.

## Core rule

Plural changes the article system and often the noun ending. In dative plural, the noun often gains -n: <span lang="de">mit den Kindern</span>.

There is no single plural ending. Learn the plural with the noun and watch for
common patterns:

| Pattern | Example |
| --- | --- |
| <span lang="de">-e</span> (often with umlaut) | <span lang="de">der Tisch → die Tische</span> |
| <span lang="de">-er</span> (often with umlaut) | <span lang="de">das Kind → die Kinder</span> |
| <span lang="de">-(e)n</span> | <span lang="de">die Frau → die Frauen</span> |
| <span lang="de">-s</span> | <span lang="de">das Auto → die Autos</span> |

The dative-plural <span lang="de">-n</span> is added only when the plural does
not already end in <span lang="de">-n</span> or <span lang="de">-s</span>:
<span lang="de">mit den Frauen</span>, but <span lang="de">mit den Autos</span>.
