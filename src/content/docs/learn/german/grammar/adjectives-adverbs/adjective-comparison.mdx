Form German comparative and superlative adjectives and adverbs.

## Use this now

Use <span lang="de">größer</span>, <span lang="de">am größten</span>, <span lang="de">der größte</span>. Some common adjectives change vowel or irregularly.

## Core rule

Comparison works for adjectives and many adverbs. The comparative usually uses
<span lang="de">-er</span>, while the superlative uses
<span lang="de">am ...-sten</span> adverbially or an article plus
<span lang="de">-ste/-sten</span> attributively.

| Function | Example |
| --- | --- |
| positive | <span lang="de">schnell</span> |
| comparative | <span lang="de">schneller als</span> |
| superlative, adverbial | <span lang="de">am schnellsten</span> |
| superlative, attributive | <span lang="de">der schnellste Zug</span> |

Common irregular forms include <span lang="de">gut – besser – am besten</span>,
<span lang="de">viel – mehr – am meisten</span>, and
<span lang="de">gern – lieber – am liebsten</span>.
