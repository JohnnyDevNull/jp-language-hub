This page collects the pronouns Swedish uses to talk about people in general
and about people in relation to each other.

## man for general statements

<span lang="sv">Man</span> works exactly like German
<span lang="de">man</span>: it makes a statement about people in general
without naming anyone.

- <span lang="sv">Man får inte parkera här.</span> — *You may not park here.*
- <span lang="sv">Så säger man i Sverige.</span> — *That is what people say in
  Sweden.*

English has no single equivalent, which is why English speakers tend to reach
for a passive instead. In Swedish, <span lang="sv">man</span> is often the more
natural choice.

<span lang="sv">Man</span> has its own object form and possessive:

| Function | Form | Example |
| --- | --- | --- |
| subject | <span lang="sv">man</span> | <span lang="sv">Man vet aldrig.</span> |
| object | <span lang="sv">en</span> | <span lang="sv">Det gör en glad.</span> |
| possessive | <span lang="sv">sin / sitt / sina</span> | <span lang="sv">Man måste ta sitt ansvar.</span> |

Because <span lang="sv">man</span> is a third-person subject, its possessive is
the reflexive <span lang="sv">sin</span>. See
[sin, sitt, and sina](../sin-sitt-sina/).

<RuleBox title="Do not confuse man with a noun">
	<span lang="sv">Man</span> as a pronoun is unstressed and never takes an
	article. <span lang="sv">En man</span> with an article is the noun *a man*.
	Only the article and the stress separate them.
</RuleBox>

## varandra for "each other"

<span lang="sv">Varandra</span> is invariable and appears only as an object,
never as a subject. Its genitive is <span lang="sv">varandras</span>:

- <span lang="sv">De hjälper varandra.</span> — *They help each other.*
- <span lang="sv">Vi läser varandras texter.</span> — *We read each other's
  texts.*

Many verbs express the same idea with an <span lang="sv">-s</span> form
instead:

- <span lang="sv">De träffas varje vecka.</span> = <span lang="sv">De träffar
  varandra varje vecka.</span>
- <span lang="sv">Vi ses!</span>

See [passive](../../verbs/passive/) for that
<span lang="sv">-s</span>.

## var sin: one each

<span lang="sv">Var sin</span> and <span lang="sv">var sitt</span> — also
written <span lang="sv">varsin</span> and <span lang="sv">varsitt</span> —
mean that each person has one of their own. The form follows the gender of the
thing possessed:

- <span lang="sv">De fick var sin bok.</span> — *They each got a book.*
- <span lang="sv">Barnen har var sitt rum.</span> — *The children each have
  their own room.*

## varje, var och en, and alla

| Swedish | Meaning | Note |
| --- | --- | --- |
| <span lang="sv">varje</span> | each, every | with an indefinite singular noun: <span lang="sv">varje dag</span> |
| <span lang="sv">var och en</span> | each one | stands alone: <span lang="sv">Var och en fick ett äpple.</span> |
| <span lang="sv">alla</span> | all, everyone | <span lang="sv">alla barn</span>, <span lang="sv">Alla kom.</span> |
| <span lang="sv">allt</span> | everything | <span lang="sv">Allt är klart.</span> |

For <span lang="sv">någon</span> and <span lang="sv">ingen</span>, see
[någon, något, ingen, and inget](../nagon-nagot-ingen-inget/).

## The som helst phrases

Adding <span lang="sv">som helst</span> to a question word gives the
*any-at-all* meaning:

| Swedish | English |
| --- | --- |
| <span lang="sv">vem som helst</span> | anyone at all |
| <span lang="sv">vad som helst</span> | anything at all |
| <span lang="sv">när som helst</span> | any time |
| <span lang="sv">var som helst</span> | anywhere |
| <span lang="sv">hur som helst</span> | anyhow, in any case |

<span lang="sv">Hur som helst</span> is also a very common discourse marker
meaning *anyway*.

<MemoryTip>
<span lang="sv"><strong>Man</strong></span> for people in general,
<span lang="sv"><strong>varandra</strong></span> for people to each other, and
<span lang="sv"><strong>var sin</strong></span> for one each. The
<span lang="sv">som helst</span> phrases are built on question words, so they
come free once those are secure.
</MemoryTip>

## Common mistakes

<MistakeBox title="Common mistakes">
	- ❌ <span lang="sv">Man måste ta hans ansvar.</span>
	  ✅ <span lang="sv">Man måste ta sitt ansvar.</span>
	- ❌ <span lang="sv">Varandra hjälper de.</span>
	  ✅ <span lang="sv">De hjälper varandra.</span> —
	  <span lang="sv">varandra</span> cannot be the subject
	- ❌ <span lang="sv">varje dagen</span>
	  ✅ <span lang="sv">varje dag</span>
	- ❌ <span lang="sv">Man är trevlig</span> meaning *a man is nice*
	  ✅ <span lang="sv">Mannen är trevlig.</span>
</MistakeBox>
