Swedish combines <span lang="sv">där</span>, <span lang="sv">här</span>, and
<span lang="sv">var</span> with a preposition to form single words. German
speakers already know the mechanism from <span lang="de">darum</span>,
<span lang="de">damit</span>, and <span lang="de">hiermit</span>; the Swedish
words are built the same way.

## The pattern

| Base | + preposition | Meaning |
| --- | --- | --- |
| <span lang="sv">där</span> | <span lang="sv">därför</span> | therefore, that is why |
| | <span lang="sv">därmed</span> | thereby, with that |
| | <span lang="sv">därefter</span> | after that |
| | <span lang="sv">därav</span> | hence, from that |
| | <span lang="sv">därifrån</span> | from there |
| <span lang="sv">här</span> | <span lang="sv">härmed</span> | hereby |
| | <span lang="sv">härefter</span> | from now on |
| | <span lang="sv">härav</span> | from this |
| <span lang="sv">var</span> | <span lang="sv">varför</span> | why |
| | <span lang="sv">varav</span> | of which |
| | <span lang="sv">varifrån</span> | from where |

The <span lang="sv">där-</span> words point back at something already
mentioned, the <span lang="sv">här-</span> words at something present or
immediate, and the <span lang="sv">var-</span> words ask or relate.

Register matters. <span lang="sv">Därför</span>,
<span lang="sv">därefter</span>, <span lang="sv">därifrån</span>, and
<span lang="sv">varför</span> are everyday words.
<span lang="sv">Härmed</span>, <span lang="sv">härav</span>,
<span lang="sv">därav</span>, and <span lang="sv">varav</span> belong to
formal writing — recognize them, but a preposition plus
<span lang="sv">det</span> is the normal spoken choice:
<span lang="sv">Jag är intresserad av det</span> rather than
<span lang="sv">Jag är intresserad därav</span>.

## därför and därför att are not the same word

This is the distinction that actually causes errors.
<span lang="sv">Därför</span> alone means *therefore* and introduces a main
clause. <span lang="sv">Därför att</span> means *because* and introduces a
subordinate clause.

- <span lang="sv">Jag var sjuk. Därför stannade jag hemma.</span> —
  *I was ill. That is why I stayed home.*
- <span lang="sv">Jag stannade hemma därför att jag var sjuk.</span> —
  *I stayed home because I was ill.*

<RuleBox title="Rule">
	<span lang="sv">Därför</span> = *therefore*, and because it stands first in
	its clause it triggers the V2 pattern:
	<span lang="sv">Därför **stannade** jag hemma.</span>
	<span lang="sv">Därför att</span> = *because*, and the clause after it
	follows subordinate-clause order.
</RuleBox>

Swedish also has <span lang="sv">eftersom</span> for *because*. Unlike
<span lang="sv">därför att</span>, it can open the sentence:

- <span lang="sv">Eftersom jag var sjuk stannade jag hemma.</span>
- <span lang="sv">Jag stannade hemma eftersom jag var sjuk.</span>

See [V2](../../sentence-structure/v2/) and
[BIFF and subordinate clauses](../../sentence-structure/biff/).

## varför asks, därför answers

- <span lang="sv">Varför stannade du hemma?</span> — *Why did you stay home?*
- <span lang="sv">Därför att jag var sjuk.</span> — *Because I was ill.*

As a short answer to <span lang="sv">varför</span>, both
<span lang="sv">därför att jag var sjuk</span> and the bare
<span lang="sv">därför!</span> — *because!* — are used. See
[question words](../interrogatives/).

<MemoryTip>
Keep one pair in your head:
<span lang="sv"><strong>Därför stannade jag hemma</strong></span> — therefore,
verb second. <span lang="sv"><strong>… därför att jag var sjuk</strong></span>
— because, subordinate clause. The extra
<span lang="sv">att</span> changes the whole sentence structure.
</MemoryTip>

## Common mistakes

<MistakeBox title="Common mistakes">
	- ❌ <span lang="sv">Jag stannade hemma därför jag var sjuk.</span>
	  ✅ <span lang="sv">Jag stannade hemma därför att jag var sjuk.</span>
	- ❌ <span lang="sv">Därför jag stannade hemma.</span>
	  ✅ <span lang="sv">Därför stannade jag hemma.</span> — verb second
	- ❌ <span lang="sv">Därför att jag var sjuk, stannade jag hemma.</span>
	  ✅ <span lang="sv">Eftersom jag var sjuk stannade jag hemma.</span>
	- Do not build formal <span lang="sv">därav</span> or
	  <span lang="sv">härmed</span> into everyday speech. Use a preposition plus
	  <span lang="sv">det</span>.
</MistakeBox>
