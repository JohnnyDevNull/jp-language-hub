<KeyTakeaway>
- Use agreement when an adjective describes a noun or subject.
- Use comparison when you need <span lang="sv">större</span>, <span lang="sv">störst</span>,

This shelf separates three lookup questions that often look similar in a
sentence: adjective form, degree of comparison, and adverb use.

## Choose by

| If you need to… | Start with… |
| --- | --- |
| match an adjective to an en-word, ett-word, plural, or definite phrase | [Adjective agreement](./agreement/) |
| choose <span lang="sv">-are</span>, <span lang="sv">-ast</span>, irregular degrees, or <span lang="sv">mer</span> / <span lang="sv">mest</span> | [Adjective comparison](./adjective-comparison/) |
| describe manner, degree, position, direction, or attitude | [Adverbs](./adverbs/) |

## Learn in this order

1. [Adjective agreement](./agreement/) gives the form pattern that appears in
   ordinary noun phrases and after verbs such as <span lang="sv">vara</span>.
2. [Adjective comparison](./adjective-comparison/) adds degree:
   <span lang="sv">stor</span>, <span lang="sv">större</span>, <span lang="sv">störst</span>.
3. [Adverbs](./adverbs/) reuses many adjective forms and adds independent
   adverbs such as <span lang="sv">hem</span>/<span lang="sv">hemma</span> and
   <span lang="sv">gärna</span>/<span lang="sv">hellre</span>/<span lang="sv">helst</span>.

## Watch for

- Agreement is about form: <span lang="sv">ett stort hus</span>,
  <span lang="sv">den stora bilen</span>.
- Comparison is about degree: <span lang="sv">större än</span>,
  <span lang="sv">den största bilen</span>.
- Adverbs are not a second adjective system. Many manner adverbs reuse the
  ett-form, but independent adverbs must be learned as words.
