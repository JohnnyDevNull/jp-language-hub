Swedish adjectives agree with the gender and number of the noun they describe.
Attributive adjectives inside noun phrases also reflect whether the phrase is
indefinite or definite. The central beginner pattern is **base form**, **-t**,
and **-a**.

## Core pattern

| Noun phrase | Adjective form | Example |
| --- | --- | --- |
| indefinite en singular | base form | <span lang="sv">en <strong>{stor.morphology.en}</strong> bil</span> |
| indefinite ett singular | often <span lang="sv">-t</span> | <span lang="sv">ett <strong>{stor.morphology.ett}</strong> hus</span> |
| indefinite plural | often <span lang="sv">-a</span> | <span lang="sv"><strong>{stor.morphology.plural}</strong> bilar</span> |
| definite | often <span lang="sv">-a</span> | <span lang="sv">den <strong>{stor.morphology.definite}</strong> bilen</span> |

The same plural adjective form is used with en-words and ett-words:

- <span lang="sv">stora bilar</span>
- <span lang="sv">stora hus</span>

## Indefinite forms

Start from the dictionary or en-form:

<p lang="sv">stor</p>

Add <span lang="sv">-t</span> for the regular ett-form and
<span lang="sv">-a</span> for the regular plural:

<p lang="sv">stor → stort → stora</p>

Another regular example:

<p lang="sv">{gul.morphology.en} → {gul.morphology.ett} → {gul.morphology.plural}</p>

Spelling can change when endings are added, and some adjectives are irregular.
For example:

- <span lang="sv">{glad.morphology.en} → {glad.morphology.ett} → {glad.morphology.plural}</span>
- <span lang="sv">liten → litet → små</span>
- <span lang="sv">bra → bra → bra</span>

Learn frequent exceptions through complete phrases.

## Spelling patterns

The <span lang="sv">-t</span> and <span lang="sv">-a</span> endings are
regular, but the stem often changes when they are attached. These patterns
cover most adjectives:

| Stem pattern | en-form | ett-form | plural / definite |
| --- | --- | --- | --- |
| stressed vowel | <span lang="sv">ny</span>, <span lang="sv">blå</span> | <span lang="sv">nytt</span>, <span lang="sv">blått</span> | <span lang="sv">nya</span>, <span lang="sv">blåa</span> |
| vowel + <span lang="sv">-d</span> | <span lang="sv">röd</span>, <span lang="sv">god</span> | <span lang="sv">rött</span>, <span lang="sv">gott</span> | <span lang="sv">röda</span>, <span lang="sv">goda</span> |
| consonant + <span lang="sv">-d</span> | <span lang="sv">hård</span> | <span lang="sv">hårt</span> | <span lang="sv">hårda</span> |
| vowel + <span lang="sv">-t</span> | <span lang="sv">vit</span>, <span lang="sv">söt</span> | <span lang="sv">vitt</span>, <span lang="sv">sött</span> | <span lang="sv">vita</span>, <span lang="sv">söta</span> |
| consonant + <span lang="sv">-t</span> | <span lang="sv">kort</span>, <span lang="sv">svart</span> | <span lang="sv">kort</span>, <span lang="sv">svart</span> | <span lang="sv">korta</span>, <span lang="sv">svarta</span> |
| <span lang="sv">-nn</span> | <span lang="sv">sann</span>, <span lang="sv">tunn</span> | <span lang="sv">sant</span>, <span lang="sv">tunt</span> | <span lang="sv">sanna</span>, <span lang="sv">tunna</span> |
| <span lang="sv">-en</span> | <span lang="sv">öppen</span>, <span lang="sv">mogen</span> | <span lang="sv">öppet</span>, <span lang="sv">moget</span> | <span lang="sv">öppna</span>, <span lang="sv">mogna</span> |
| <span lang="sv">-er</span>, <span lang="sv">-el</span> | <span lang="sv">vacker</span>, <span lang="sv">enkel</span> | <span lang="sv">vackert</span>, <span lang="sv">enkelt</span> | <span lang="sv">vackra</span>, <span lang="sv">enkla</span> |

Two frequent adjectives are irregular beyond these patterns:

- <span lang="sv">gammal → gammalt → gamla</span>
- <span lang="sv">liten → litet → små</span>, with
  <span lang="sv">lilla</span> in the definite singular:
  <span lang="sv">den lilla bilen</span>

The pattern worth internalizing first is the
<span lang="sv">-en</span> group, because the unstressed
<span lang="sv">e</span> disappears in the plural:
<span lang="sv">ett öppet fönster</span> but
<span lang="sv">öppna fönster</span>.

## Adjectives that never change

A small group takes no endings at all. Using them is easy once you know which
ones they are:

<span lang="sv">bra</span>, <span lang="sv">kul</span>,
<span lang="sv">äkta</span>, <span lang="sv">sakta</span>,
<span lang="sv">främmande</span>, and colour words such as
<span lang="sv">rosa</span>, <span lang="sv">lila</span>,
<span lang="sv">beige</span>.

- <span lang="sv">ett bra hus</span>, <span lang="sv">bra bilar</span>
- <span lang="sv">ett rosa hus</span>, <span lang="sv">rosa bilar</span>

## Participles as adjectives

Past participles inflect like ordinary adjectives:

| Noun phrase | Example |
| --- | --- |
| indefinite en | <span lang="sv">en stängd dörr</span> |
| indefinite ett | <span lang="sv">ett stängt fönster</span> |
| plural | <span lang="sv">stängda dörrar</span> |

The same applies to participles from other verb groups:
<span lang="sv">en målad vägg</span>,
<span lang="sv">ett målat hus</span>,
<span lang="sv">målade väggar</span>; and
<span lang="sv">en skriven text</span>,
<span lang="sv">ett skrivet brev</span>,
<span lang="sv">skrivna brev</span>.

Present participles in <span lang="sv">-ande</span> and
<span lang="sv">-ende</span> never inflect:

<p lang="sv">ett leende barn · en leende flicka · leende barn</p>

Past participles are also what the bli-passive is built from. See
[passive](../../verbs/passive/).

## The optional masculine -e

Referring to a male person, the definite form may take
<span lang="sv">-e</span> instead of <span lang="sv">-a</span>:

- <span lang="sv">den gamle mannen</span> beside
  <span lang="sv">den gamla mannen</span>
- <span lang="sv">min gode vän</span>

This is optional and belongs to a slightly formal or traditional register; it
also survives in fixed names such as
<span lang="sv">Karl den store</span>. The
<span lang="sv">-a</span> form is always acceptable, so treat
<span lang="sv">-e</span> as something to recognize rather than a rule to
apply.

## Definite noun phrases and double definiteness

A noun without an attributive adjective normally marks definiteness only with
its suffix:

<p lang="sv">bilen · huset · bilarna</p>

When an attributive adjective is added, standard Swedish normally marks
definiteness twice: with a separate definite article before the adjective and
with the definite suffix on the noun. This construction is called **double
definiteness**.

| Number and gender | Definite article | Adjective | Definite noun | Complete phrase |
| --- | --- | --- | --- | --- |
| en singular | <span lang="sv">den</span> | <span lang="sv">{stor.morphology.definite}</span> | <span lang="sv">bilen</span> | <span lang="sv">den {stor.morphology.definite} bilen</span> |
| ett singular | <span lang="sv">det</span> | <span lang="sv">{stor.morphology.definite}</span> | <span lang="sv">huset</span> | <span lang="sv">det {stor.morphology.definite} huset</span> |
| plural | <span lang="sv">de</span> | <span lang="sv">{stor.morphology.definite}</span> | <span lang="sv">bilarna</span> | <span lang="sv">de {stor.morphology.definite} bilarna</span> |

The three-part pattern is therefore:

<p lang="sv"><strong>den / det / de + definite adjective + definite noun</strong></p>

The article marks gender or number, the adjective commonly uses its
<span lang="sv">-a</span> form, and the noun keeps its definite suffix. English
usually marks the same phrase only once in <span lang="en">the big car</span>;
Swedish uses both <span lang="sv">den</span> and <span lang="sv">-en</span> in
<span lang="sv">den stora bilen</span>.

Possessives are an important exception to the standard pattern. The adjective
uses the definite form, but there is no separate definite article and the noun
does not take its definite suffix:

<p lang="sv">min stora bil</p>

Demonstratives such as <span lang="sv">den här</span> and
<span lang="sv">det där</span> follow the definite-noun rhythm:
<span lang="sv">den här stora bilen</span>,
<span lang="sv">det där stora huset</span>.

See [noun forms](../../nouns-articles/noun-forms/) for the
noun suffixes themselves.

## After verbs such as *vara* and *bli*

Predicative adjectives agree with the subject but do not use double
definiteness:

- <span lang="sv">Bilen är stor.</span>
- <span lang="sv">Huset är stort.</span>
- <span lang="sv">Bilarna är stora.</span>

## Direct comparison

| Language | Examples |
| --- | --- |
| <span lang="de">🇩🇪 Deutsch</span> | <span lang="de">ein großes Auto · große Autos · das große Auto</span> |
| <span lang="en">🇬🇧 English</span> | <span lang="en">a big car · big cars · the big car</span> |
| <span lang="sv">🇸🇪 Svenska</span> | <span lang="sv">en stor bil · stora bilar · den stora bilen</span> |

English adjectives do not agree with the noun. German adjectives agree too,
but German endings depend on case and article type as well as gender and number.
Do not transfer the German ending system directly to Swedish.

<MistakeBox title="Common mistakes">
Keep article, adjective, and noun compatible:

<span lang="sv">❌ ett stor hus</span>
<span lang="sv">✅ ett stort hus</span>

In a standard definite phrase, do not omit either part of double definiteness:

<span lang="sv">❌ det stora hus</span>
<span lang="sv">✅ det stora huset</span>
</MistakeBox>

<MemoryTip>
Remember the three-part rhythm:
<span lang="sv"><strong>en stor — ett stort — flera stora</strong></span>.
For a definite phrase, use the familiar <span lang="sv">-a</span> form:
<span lang="sv">den stora bilen</span>.
</MemoryTip>
