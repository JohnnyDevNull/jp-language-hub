Many Swedish manner adverbs are simply the ett-form of an adjective. That
makes the common formation easy — the harder parts are independent adverbs,
the position of sentence adverbs, and the pairs that distinguish place from
direction.

## Adverbs from adjectives

<RuleBox title="Rule">
	Many manner adverbs use the adjective's <span lang="sv">-t</span> form: the
	same form you already use with an ett-word.
</RuleBox>

| Adjective | Adverb | Example |
| --- | --- | --- |
| <span lang="sv">{snabb.morphology.en}</span> | <span lang="sv">{snabb.morphology.ett}</span> | <span lang="sv">Han springer snabbt.</span> |
| <span lang="sv">tydlig</span> | <span lang="sv">tydligt</span> | <span lang="sv">Hon talar tydligt.</span> |
| <span lang="sv">vacker</span> | <span lang="sv">vackert</span> | <span lang="sv">Hon sjunger vackert.</span> |
| <span lang="sv">försiktig</span> | <span lang="sv">försiktigt</span> | <span lang="sv">Kör försiktigt!</span> |

When an adverb reuses the ett-form, the spelling patterns are the same ones.
See
[adjective agreement](../agreement/#spelling-patterns).

English often marks the difference with *-ly*, while German often uses the same
visible form for adjective and adverb. Swedish frequently uses an ending, but
it is one you already know from ett-words.

## Irregular and independent adverbs

Some adverbs are not built from an adjective, or differ from the expected
form:

| Adverb | Meaning | Note |
| --- | --- | --- |
| <span lang="sv">bra</span> | well | also the adjective *good*; <span lang="sv">Han sjunger bra.</span> |
| <span lang="sv">väl</span> | well | narrower than <span lang="sv">bra</span>: <span lang="sv">väl gjort</span> |
| <span lang="sv">illa</span> | badly | <span lang="sv">Han mår illa.</span> |
| <span lang="sv">gärna</span> | gladly, willingly | no adjective behind it |
| <span lang="sv">mycket</span> | very, much | with adjectives: <span lang="sv">mycket bra</span> |

<span lang="sv">Gärna</span> is worth learning as a full set, because its
comparison is irregular and extremely frequent in polite speech:

<p lang="sv">gärna → hellre → helst</p>

- <span lang="sv">Jag vill gärna komma.</span> — *I would like to come.*
- <span lang="sv">Jag vill hellre stanna hemma.</span> — *I would rather stay
  home.*
- <span lang="sv">Jag vill helst åka på fredag.</span> — *I would most prefer
  to go on Friday.*

## Comparison

Adverbs compare like adjectives:

<p lang="sv">{snabb.morphology.ett} → {snabb.comparison?.comparative} → {snabb.comparison?.superlative}</p>

The irregular ones follow their own chains:

| Adverb | Comparative | Superlative |
| --- | --- | --- |
| <span lang="sv">bra / väl</span> | <span lang="sv">bättre</span> | <span lang="sv">bäst</span> |
| <span lang="sv">gärna</span> | <span lang="sv">hellre</span> | <span lang="sv">helst</span> |
| <span lang="sv">illa</span> | <span lang="sv">värre</span> | <span lang="sv">värst</span> |

<span lang="sv">Sämre</span> and <span lang="sv">värre</span> both translate as
*worse*, with <span lang="sv">sämre</span> tending towards lower quality and
<span lang="sv">värre</span> towards greater severity. The boundary is not
sharp, so learn them in phrases. See
[adjective comparison](../adjective-comparison/).

## Place and direction pairs

Swedish keeps position and direction apart with two separate words. German and
English do not use this exact Swedish set, so the pairs need to be learned as
pairs:

| Direction | Position | Example |
| --- | --- | --- |
| <span lang="sv">hem</span> | <span lang="sv">hemma</span> | <span lang="sv">Jag går hem.</span> · <span lang="sv">Jag är hemma.</span> |
| <span lang="sv">ut</span> | <span lang="sv">ute</span> | <span lang="sv">Vi går ut.</span> · <span lang="sv">Vi är ute.</span> |
| <span lang="sv">in</span> | <span lang="sv">inne</span> | <span lang="sv">Kom in!</span> · <span lang="sv">Hon är inne.</span> |
| <span lang="sv">upp</span> | <span lang="sv">uppe</span> | <span lang="sv">Han går upp.</span> · <span lang="sv">Han är uppe.</span> |
| <span lang="sv">ner</span> | <span lang="sv">nere</span> | <span lang="sv">Gå ner!</span> · <span lang="sv">Hon är nere.</span> |
| <span lang="sv">bort</span> | <span lang="sv">borta</span> | <span lang="sv">Han reste bort.</span> · <span lang="sv">Han är borta.</span> |
| <span lang="sv">dit</span> | <span lang="sv">där</span> | <span lang="sv">Vi åker dit.</span> · <span lang="sv">Vi är där.</span> |

The same split runs through the question words
<span lang="sv">vart</span> and <span lang="sv">var</span>. See
[question words](../../questions-negation/question-words/).

## Where sentence adverbs go

Many sentence adverbs, including <span lang="sv">alltid</span>,
<span lang="sv">aldrig</span>, and <span lang="sv">ofta</span>, follow the same placement
pattern as <span lang="sv">inte</span>: after the <span lang="sv">finit verb</span> in a main clause,
before it in a subordinate clause. Some adverbs have narrower behavior, so use
the word-order page when position is the main question.

- <span lang="sv">Hon kommer alltid sent.</span>
- <span lang="sv">…eftersom hon alltid kommer sent.</span>

See [Placement of *inte*](../../sentence-structure/inte-placement/).

## The small attitude words

<span lang="sv">Ju</span>, <span lang="sv">nog</span>,
<span lang="sv">väl</span>, and <span lang="sv">visst</span> add attitude
rather than information, much like German
<span lang="de">ja</span>, <span lang="de">wohl</span>, and
<span lang="de">doch</span>:

- <span lang="sv">Det är ju sant.</span> — *as we both know*
- <span lang="sv">Han kommer nog.</span> — *I expect he will*
- <span lang="sv">Du har väl gjort det?</span> — seeking agreement

They resist clean translation and are best picked up from context. German
speakers have an advantage here, because the mechanism is familiar.

	- ❌ <span lang="sv">Jag är hem.</span>
	  ✅ <span lang="sv">Jag är hemma.</span>
	- ❌ <span lang="sv">Jag går hemma.</span>
	  ✅ <span lang="sv">Jag går hem.</span>
	- ❌ <span lang="sv">Jag vill mer gärna stanna.</span>
	  ✅ <span lang="sv">Jag vill hellre stanna.</span>
	- ❌ <span lang="sv">…eftersom hon kommer alltid sent.</span>
	  ✅ <span lang="sv">…eftersom hon alltid kommer sent.</span>
</MistakeBox>

<MemoryTip>
Start from the ett-form for ordinary manner adverbs: if you can say
<span lang="sv"><strong>ett snabbt tåg</strong></span>, you can say
<span lang="sv"><strong>han springer snabbt</strong></span>. Then add the two
sets that are not derivable:
<span lang="sv"><strong>gärna — hellre — helst</strong></span> and
<span lang="sv"><strong>hem / hemma</strong></span>.
</MemoryTip>
