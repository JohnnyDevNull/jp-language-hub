<KeyTakeaway>
- Core modal verbs such as <span lang="sv">kan</span>, <span lang="sv">vill</span>, <span lang="sv">måste</span>,
  <span lang="sv">får</span>, <span lang="sv">bör</span>, and <span lang="sv">ska</span> normally take a bare infinitive.
- Ordinary verbs vary: some require <span lang="sv">att</span>, while others allow or prefer
  a bare infinitive in specific patterns.
- Learn the meaning and the following pattern together; do not add
  <span lang="sv">att</span> automatically between two verbs.
</KeyTakeaway>

Modal verbs express ability, desire, necessity, permission, advice, intention,
or expectation. They are finite; the following lexical verb stays in the
infinitive.

## Use this now

| Meaning | Modal | Example |
| --- | --- | --- |
| ability or possibility | <span lang="sv">kan</span> | <span lang="sv">Jag kan simma.</span> |
| desire | <span lang="sv">vill</span> | <span lang="sv">Hon vill stanna.</span> |
| necessity | <span lang="sv">måste</span> | <span lang="sv">Vi måste gå.</span> |
| permission | <span lang="sv">får</span> | <span lang="sv">Ni får komma in.</span> |
| advice | <span lang="sv">bör</span> | <span lang="sv">Du bör vila.</span> |
| plan, expectation, or obligation | <span lang="sv">ska</span> | <span lang="sv">Jag ska ringa.</span> |

## Core rule: bare infinitive after a modal

The core pattern is **finite modal + bare infinitive**:

- <span lang="sv">Jag kan tala svenska.</span>
- <span lang="sv">Vi vill beställa.</span>
- <span lang="sv">Du måste vänta.</span>

Do not insert <span lang="sv">att</span>: <span lang="sv">kan tala</span>, not <span lang="sv">kan att tala</span>.
The finite modal occupies the verb position used by Swedish word-order rules;
the infinitive follows as the second verb. See [V2](../../sentence-structure/v2/)
for the main-clause position pattern.

## Ordinary two-verb patterns

Outside the core modal set, learn the construction with the first verb:

- normally required <span lang="sv">att</span>: <span lang="sv">planera att resa</span>,
  <span lang="sv">lova att komma</span>
- established bare-infinitive patterns: <span lang="sv">brukar arbeta</span>,
  <span lang="sv">orkar vänta</span>
- optional variation in many contexts: <span lang="sv">börja arbeta</span> or
  <span lang="sv">börja att arbeta</span>; <span lang="sv">försöka förstå</span> or
  <span lang="sv">försöka att förstå</span>

Usage varies by verb and register, so one universal “two verbs need
<span lang="sv">att</span>” rule will fail. Store the complement pattern with the verb.

## <span lang="sv">Ska</span>: syntax here, future choice there

This page owns the pattern <span lang="sv">ska</span> + bare infinitive and its modal range.
Use [Future forms](../../verbs-time-forms/future-forms/) to decide whether
<span lang="sv">ska</span>, a contextual present, <span lang="sv">tänker</span>, or <span lang="sv">kommer att</span>
best expresses future time.

<MistakeBox title="Common mistakes">
	- ❌ <span lang="sv">Jag kan att simma.</span>
	  ✅ <span lang="sv">Jag kan simma.</span>
	- <span lang="sv">Får</span> often concerns permission; <span lang="sv">kan</span> often concerns ability
	  or practical possibility.
	- Do not use <span lang="sv">ska</span> as the automatic equivalent of every English
	  <em>will</em> or German <span lang="de">werden</span>.
</MistakeBox>

<MemoryTip>
Learn a short unit: <span lang="sv">kan simma</span>, <span lang="sv">vill stanna</span>,
<span lang="sv">försöker att förstå</span>. The first verb decides the pattern.
</MemoryTip>
