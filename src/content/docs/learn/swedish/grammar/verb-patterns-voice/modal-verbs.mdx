<KeyTakeaway>
- Core modal verbs such as <Sv>kan</Sv>, <Sv>vill</Sv>, <Sv>måste</Sv>,
  <Sv>får</Sv>, <Sv>bör</Sv>, and <Sv>ska</Sv> normally take a bare infinitive.
- Ordinary verbs vary: some require <Sv>att</Sv>, while others allow or prefer
  a bare infinitive in specific patterns.
- Learn the meaning and the following pattern together; do not add
  <Sv>att</Sv> automatically between two verbs.
</KeyTakeaway>

Modal verbs express ability, desire, necessity, permission, advice, intention,
or expectation. They are finite; the following lexical verb stays in the
infinitive.

## Use this now

| Meaning | Modal | Example |
| --- | --- | --- |
| ability or possibility | <Sv>kan</Sv> | <Sv>Jag kan simma.</Sv> |
| desire | <Sv>vill</Sv> | <Sv>Hon vill stanna.</Sv> |
| necessity | <Sv>måste</Sv> | <Sv>Vi måste gå.</Sv> |
| permission | <Sv>får</Sv> | <Sv>Ni får komma in.</Sv> |
| advice | <Sv>bör</Sv> | <Sv>Du bör vila.</Sv> |
| plan, expectation, or obligation | <Sv>ska</Sv> | <Sv>Jag ska ringa.</Sv> |

## Core rule: bare infinitive after a modal

The core pattern is **finite modal + bare infinitive**:

- <Sv>Jag kan tala svenska.</Sv>
- <Sv>Vi vill beställa.</Sv>
- <Sv>Du måste vänta.</Sv>

Do not insert <Sv>att</Sv>: <Sv>kan tala</Sv>, not <Sv>kan att tala</Sv>.
The finite modal occupies the verb position used by Swedish word-order rules;
the infinitive follows as the second verb. See [V2](../../sentence-structure/v2/)
for the main-clause position pattern.

## Ordinary two-verb patterns

Outside the core modal set, learn the construction with the first verb:

- normally required <Sv>att</Sv>: <Sv>planera att resa</Sv>,
  <Sv>lova att komma</Sv>
- established bare-infinitive patterns: <Sv>brukar arbeta</Sv>,
  <Sv>orkar vänta</Sv>
- optional variation in many contexts: <Sv>börja arbeta</Sv> or
  <Sv>börja att arbeta</Sv>; <Sv>försöka förstå</Sv> or
  <Sv>försöka att förstå</Sv>

Usage varies by verb and register, so one universal “two verbs need
<Sv>att</Sv>” rule will fail. Store the complement pattern with the verb.

## <Sv>Ska</Sv>: syntax here, future choice there

This page owns the pattern <Sv>ska</Sv> + bare infinitive and its modal range.
Use [Future forms](../../verbs-time-forms/future-forms/) to decide whether
<Sv>ska</Sv>, a contextual present, <Sv>tänker</Sv>, or <Sv>kommer att</Sv>
best expresses future time.

<MistakeBox title="Common mistakes">
	- ❌ <Sv>Jag kan att simma.</Sv>
	  ✅ <Sv>Jag kan simma.</Sv>
	- <Sv>Får</Sv> often concerns permission; <Sv>kan</Sv> often concerns ability
	  or practical possibility.
	- Do not use <Sv>ska</Sv> as the automatic equivalent of every English
	  <em>will</em> or German <span lang="de">werden</span>.
</MistakeBox>

<MemoryTip>
Learn a short unit: <Sv>kan simma</Sv>, <Sv>vill stanna</Sv>,
<Sv>försöker att förstå</Sv>. The first verb decides the pattern.
</MemoryTip>
