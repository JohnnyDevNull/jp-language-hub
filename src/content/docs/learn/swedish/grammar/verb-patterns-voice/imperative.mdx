<KeyTakeaway>
- The imperative is a verb form without an expressed subject:
  <span lang="sv">Kom!</span>, <span lang="sv">Vänta!</span>, <span lang="sv">Läs!</span>
- Use the negative pattern <span lang="sv">imperativ + inte</span>:
  <span lang="sv">Glöm inte biljetten!</span>
- The same form can be a direct command, an instruction, an invitation, or a
  friendly suggestion; context and softeners set the tone.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Use the imperative when you want another person to do something directly.
Swedish uses the same form whether speaking to one person or several.

## Use this now

| Purpose | Example |
| --- | --- |
| direct instruction | <span lang="sv">Tryck här.</span> |
| invitation | <span lang="sv">Kom in!</span> |
| friendly suggestion | <span lang="sv">Ta en bulle!</span> |
| negative instruction | <span lang="sv">Rör inte skärmen.</span> |

## Core rule

The imperative is part of the verb's form chain. For many verbs it is the stem
used before other endings:

| Infinitive | Imperative |
| --- | --- |
| <span lang="sv">att tala</span> | <span lang="sv">tala!</span> |
| <span lang="sv">att köpa</span> | <span lang="sv">köp!</span> |
| <span lang="sv">att ringa</span> | <span lang="sv">ring!</span> |
| <span lang="sv">att gå</span> | <span lang="sv">gå!</span> |

Frequent irregular forms should be learned with the verb, for example
<span lang="sv">vara → var!</span> and <span lang="sv">göra → gör!</span>

The subject is normally omitted. In a negative imperative, place
<span lang="sv">inte</span> after the imperative: <span lang="sv">Gå inte dit!</span> See
[Placement of *inte*](../../sentence-structure/inte-placement/) for the broader
position system.

## Tone and alternatives

A bare imperative can be neutral in recipes, signs, and clear instructions.
In conversation, add <span lang="sv">gärna</span>, <span lang="sv">snälla</span>, or a question frame when
the relationship or request needs more softness:

- <span lang="sv">Sitt gärna här.</span>
- <span lang="sv">Kan du öppna fönstret?</span>

[Polite requests](../../../sentence-patterns/polite-requests/) owns those
ready-to-use communicative frames.

<MistakeBox title="Common mistakes">
	- ❌ <span lang="sv">Inte glöm biljetten!</span>
	  ✅ <span lang="sv">Glöm inte biljetten!</span>
	- Do not add an obligatory subject by analogy with an ordinary statement.
	- Do not treat every imperative as impolite; the situation and wording
	  decide the tone.
</MistakeBox>
