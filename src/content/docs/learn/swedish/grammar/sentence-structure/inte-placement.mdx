<KeyTakeaway>
- <span lang="sv">inte</span> follows the <span lang="sv">finit verb</span> in a main clause and precedes it in a
  subordinate clause.
- If a <span lang="sv">subjekt</span> follows the <span lang="sv">finit verb</span>, <span lang="sv">inte</span> comes after that <span lang="sv">subjekt</span>.
- With two verbs, <span lang="sv">inte</span> sits between the <span lang="sv">finit verb</span> and the non-finite

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

The position of Swedish <span lang="sv">inte</span> depends on the type of clause. The central
contrast is simple: it normally follows the <span lang="sv">finit verb</span> in a main clause but
precedes the <span lang="sv">finit verb</span> in a subordinate clause. If you first need to choose
between <span lang="sv">inte</span> and another negative expression, start with
[Negation](../../questions-negation/negation/).

## Core rule

One set of fields covers both clause types. <span lang="sv">inte</span> always sits in the
same <span lang="sv">satsadverbial</span> field; what moves is the <span lang="sv">finit verb</span>. In the main clause it
holds position two, in the subordinate clause position two is empty and the verb
follows <span lang="sv">inte</span>:

The two German rows show both sides of the parallel. German splits main and
subordinate clauses just as Swedish does, but it moves the finite verb all the
way to the end of the subordinate clause, while Swedish moves it only past the
<span lang="sv">satsadverbial</span>.

## Main clauses

In a main clause, <span lang="sv">inte</span> normally comes after the <span lang="sv">finit verb</span> and after a
<span lang="sv">subjekt</span> that follows that verb:

- <span lang="sv">Jag <strong>kommer inte</strong> idag.</span>
- <span lang="sv">Idag <strong>kommer jag inte</strong>.</span>
- <span lang="sv">Jag <strong>har inte</strong> köpt bilen.</span>

With a compound verb phrase, <span lang="sv">inte</span> follows the finite auxiliary and
precedes the non-finite verb:

<p lang="sv">Hon <strong>vill inte gå</strong> hem.</p>

## Subordinate clauses

In a subordinate clause, <span lang="sv">inte</span> normally comes before the <span lang="sv">finit verb</span>:

- <span lang="sv">… eftersom jag <strong>inte kommer</strong> idag.</span>
- <span lang="sv">… att hon <strong>inte har</strong> köpt bilen.</span>
- <span lang="sv">… om vi <strong>inte kan</strong> träffas.</span>

This contrast is summarized by [BIFF](../biff/).

## Questions

In a yes/no question, the <span lang="sv">finit verb</span> comes first, followed by the <span lang="sv">subjekt</span> and
then <span lang="sv">inte</span>:

<p lang="sv">Kommer du inte imorgon?</p>

With a question word:

<p lang="sv">Varför kommer du inte imorgon?</p>

The intonation and context can make a negative question sound surprised or as
if the speaker expected a positive answer.

See [Questions](../../questions-negation/questions/) for the full question
frame.

## Imperatives and infinitives

With a negative imperative, place <span lang="sv">inte</span> after the verb:

<p lang="sv">Glöm inte nycklarna!</p>

When an infinitive itself is negated, <span lang="sv">inte</span> normally comes before it:

<p lang="sv">Det är svårt att inte tänka på det.</p>

<MistakeBox

Do not place <span lang="sv">inte</span> after the <span lang="sv">finit verb</span> merely because the clause
contains an explicit <span lang="sv">subjekt</span>. First decide whether it is a main clause or a
subordinate clause.
</MistakeBox>

<MemoryTip>
**Main clause:** <span lang="sv">finit verb</span> first, then <span lang="sv">inte</span>.  
**Subordinate clause:** <span lang="sv">inte</span> first, then <span lang="sv">finit verb</span>.
</MemoryTip>
