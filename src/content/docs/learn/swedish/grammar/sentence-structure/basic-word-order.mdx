Swedish word order carries grammatical meaning. The most useful starting point
is the neutral subject-first main clause; other pages handle fronting,
questions, and subordinate clauses.

## Core rule

In a neutral declarative main clause, Swedish usually follows this order:

> **<span lang="sv">subjekt + finit verb + satsadverbial + infinit verb + objekt / predikativ + adverbial</span>**

Read the clause as a row of fields. This is the neutral schema behind the
[V2 rule](../v2/):

In a neutral clause the <span lang="sv">subjekt</span> fills position one itself, so
position three stays empty. The German row fills the same opening fields, which
is why the neutral pattern feels familiar; German differs later in the clause,
where it sends non-finite verb forms to the very end.

- <span lang="sv">Jag</span> — <span lang="sv">subjekt</span>
- <span lang="sv">köper</span> — <span lang="sv">finit verb</span>
- <span lang="sv">inte</span> — <span lang="sv">satsadverbial</span>
- <span lang="sv">bilen</span> — <span lang="sv">objekt</span>
- <span lang="sv">idag</span> — time adverbial

The <span lang="sv">finit verb</span> carries tense and anchors the clause structure. Swedish verbs
do not change according to person:

- <span lang="sv">Jag arbetar.</span> — I work.
- <span lang="sv">Vi arbetar.</span> — We work.

## A constituent can contain several words

A sentence position is occupied by a **constituent**, not necessarily one word.

<p lang="sv">Min nya kollega börjar idag.</p>

The entire noun phrase <span lang="sv">min nya kollega</span> is the <span lang="sv">subjekt</span> and
occupies the first position. The <span lang="sv">finit verb</span> <span lang="sv">börjar</span> is therefore second.

## Choose the next pattern

- If something other than the subject comes first, use
  [Inversion](../inversion/).
- If the sentence asks for confirmation or missing information, use
  [Questions](../../questions-negation/questions/).
- If the clause depends on another clause, use
  [Subordinate clauses](../subordinate-clauses/).
- If you specifically need to place <span lang="sv">inte</span>, use
  [Placement of *inte*](../inte-placement/).

## Direct comparison

<LanguageComparison title="Neutral statement">
	<p slot="de">Ich kaufe heute ein Auto.</p>
	<p slot="en">I am buying a car today.</p>
	<p slot="sv">Jag köper en bil idag.</p>
</LanguageComparison>

The three languages can look similar in a neutral sentence. Swedish keeps one
finite form across persons, while English may use an auxiliary and German may
place later verb parts differently.

<MistakeBox
	incorrect="Jag inte köper bilen idag."
	correct="Jag köper inte bilen idag."
	lang="sv"
>
Keep the <span lang="sv">finit verb</span> before the <span lang="sv">satsadverbial</span> in a neutral main clause.
</MistakeBox>

parts, <span lang="sv">objekt</span>, and other information.
</MemoryTip>
