<KeyTakeaway>
- A subordinate clause is part of a larger sentence and often begins with a
  subordinator such as <span lang="sv">att</span>, <span lang="sv">eftersom</span>, <span lang="sv">om</span>, or <span lang="sv">när</span>.
- Its practical core frame is **<span lang="sv">bisatsinledare + subjekt + satsadverbial +
  finit verb + adverbial</span>**.
- If the whole subordinate clause comes first, the following main clause uses
  inversion.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

A subordinate clause adds content such as what someone says, why something
happens, a condition, or a time. It cannot normally stand alone with that same
function: <span lang="sv">eftersom jag är trött</span> needs a main clause around it.

## Use this now

| Meaning | Start the subordinate clause with… | Example |
| --- | --- | --- |
| that / reported content | <span lang="sv">att</span> | <span lang="sv">Jag vet att hon kommer.</span> |
| because | <span lang="sv">eftersom</span> | <span lang="sv">Jag stannar eftersom jag är trött.</span> |
| if / whether | <span lang="sv">om</span> | <span lang="sv">Vi går ut om det inte regnar.</span> |
| when | <span lang="sv">när</span> | <span lang="sv">Ring mig när du är klar.</span> |
| before | <span lang="sv">innan</span> | <span lang="sv">Ät innan du går.</span> |

## Core rule

Use this reliable frame when the subordinate clause contains a
<span lang="sv">satsadverbial</span> such as <span lang="sv">inte</span>:

<SentenceSchema
	caption="The Swedish subordinate-clause frame"
	rowHeader="Meaning"
	columns={['bisatsinledare', 'subjekt', 'satsadverbial', 'finit verb', 'infinit verb', 'objekt / predikativ', 'adverbial']}
	rows={[
		{ label: 'Reason', cells: ['eftersom', 'jag', 'inte', 'kan', 'komma', '', 'idag'] },
		{ label: 'Content', cells: ['att', 'hon', 'redan', 'har', 'köpt', 'biljetten', ''] },
		{ label: 'Condition', cells: ['om', 'det', 'inte', 'regnar', '', '', ''] },
	]}
/>

Without a <span lang="sv">satsadverbial</span>, the <span lang="sv">subjekt</span> is followed
directly by the <span lang="sv">finit verb</span>:

- <span lang="sv">Jag vet **att hon kommer**.</span>
- <span lang="sv">Ring mig **när du är klar**.</span>

The [BIFF rule](../biff/) owns the narrower question of why <span lang="sv">inte</span> and
other <span lang="sv">satsadverbial</span> precede the <span lang="sv">finit verb</span> here.

## When the subordinate clause comes first

The whole subordinate clause can fill the first field of a following main
clause. The main clause then places its <span lang="sv">finit verb</span> before its
<span lang="sv">subjekt</span>:

<SentenceSchema
	caption="A subordinate clause before a main clause"
	rowHeader="Clause"
	columns={['1 fundament', '2 finit verb', '3 subjekt', 'adverbial']}
	rows={[
		{
			label: 'Subordinate + main',
			cells: ['När mötet är slut', 'går', 'vi', 'hem.'],
		},
	]}
/>

That main-clause shift belongs to [Inversion](../inversion/), not to the internal
order of the subordinate clause itself.

## Indirect questions

An indirect question also behaves as a subordinate clause:

- <span lang="sv">Jag vet inte **var hon bor**.</span>
- <span lang="sv">Han frågade **om tåget var sent**.</span>

[Question words](../../questions-negation/question-words/) owns the lexical choices
and the direct-versus-indirect question pattern.

## Direct comparison

<LanguageComparison title="Because-clause">
	<p slot="de">… weil ich heute nicht kommen kann.</p>
	<p slot="en">… because I cannot come today.</p>
	<p slot="sv">… eftersom jag inte kan komma idag.</p>
</LanguageComparison>

German also marks subordinate clauses with special word order, but sends the
finite verb to the end. Swedish keeps the <span lang="sv">finit verb</span> after the
<span lang="sv">satsadverbial</span> and before any non-finite verb.

<MistakeBox
	incorrect="Jag stannar hemma eftersom jag kan inte komma."
	correct="Jag stannar hemma eftersom jag inte kan komma."
	lang="sv"
>
Do not carry main-clause <span lang="sv">satsadverbial</span> placement into a subordinate
clause.
</MistakeBox>

<MemoryTip>
Build the dependent block from left to right: **<span lang="sv">bisatsinledare → subjekt →
satsadverbial → finit verb → adverbial</span>**.
</MemoryTip>
