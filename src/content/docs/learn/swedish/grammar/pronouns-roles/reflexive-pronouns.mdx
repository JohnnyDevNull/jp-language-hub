<KeyTakeaway>
- Use <Sv>mig, dig, sig, oss,</Sv> or <Sv>er</Sv> when the object refers back
  to the subject of the same clause.
- Third-person subjects use <Sv>sig</Sv>: <Sv>hon tvättar sig</Sv>,
  <Sv>de skyndar sig</Sv>.
- Reflexive possession belongs to <Sv>sin, sitt, sina</Sv>; reciprocal meaning
  belongs to <Sv>varandra</Sv>.
</KeyTakeaway>

A reflexive pronoun shows that the subject and object refer to the same person
or group. Swedish also uses reflexive forms as part of several common verbs.

## Use this now

| Subject | Reflexive object | Example |
| --- | --- | --- |
| <Sv>jag</Sv> | <Sv>mig</Sv> | <Sv>Jag tvättar mig.</Sv> |
| <Sv>du</Sv> | <Sv>dig</Sv> | <Sv>Du skyndar dig.</Sv> |
| <Sv>han, hon, den, det, man</Sv> | <Sv>sig</Sv> | <Sv>Hon sätter sig.</Sv> |
| <Sv>vi</Sv> | <Sv>oss</Sv> | <Sv>Vi lär oss svenska.</Sv> |
| <Sv>ni</Sv> | <Sv>er</Sv> | <Sv>Ni måste skynda er.</Sv> |
| <Sv>de</Sv> | <Sv>sig</Sv> | <Sv>De känner sig trötta.</Sv> |

## Core rule

Choose the reflexive form from the clause subject. Compare:

- <Sv>Hon tvättar sig.</Sv> — she washes herself
- <Sv>Hon tvättar henne.</Sv> — she washes another woman
- <Sv>De ser sig i spegeln.</Sv> — they see themselves in the mirror
- <Sv>De ser dem.</Sv> — they see another group

The form points back within the same clause. In
<Sv>Anna säger att Erik skyndar sig</Sv>, <Sv>sig</Sv> points to Erik, the
subject of the subordinate clause.

## Common reflexive verbs

Learn these as complete expressions:

| Expression | Meaning |
| --- | --- |
| <Sv>skynda sig</Sv> | hurry |
| <Sv>sätta sig</Sv> | sit down |
| <Sv>känna sig</Sv> | feel |
| <Sv>lära sig</Sv> | learn |
| <Sv>gifta sig</Sv> | get married |

The reflexive pronoun still changes with the subject:
<Sv>jag skyndar mig</Sv>, <Sv>vi skyndar oss</Sv>, <Sv>de skyndar sig</Sv>.

## Keep three systems apart

- <Sv>Hon tvättar sig.</Sv> — reflexive object: the action returns to her.
- <Sv>Hon tar sin jacka.</Sv> — reflexive possession: the jacket is hers.
- <Sv>De hjälper varandra.</Sv> — reciprocal: each person helps another.

English sometimes omits a reflexive form where Swedish and German use one as
part of the verb expression.

<MistakeBox title="Common mistakes">
- <Sv>❌ Hon skyndar henne.</Sv> → <Sv>✅ Hon skyndar sig.</Sv>
- <Sv>❌ Vi känner sig trötta.</Sv> → <Sv>✅ Vi känner oss trötta.</Sv>
- Do not use <Sv>sig</Sv> for possession; choose
  <Sv>sin, sitt,</Sv> or <Sv>sina</Sv> from the possessed noun.
</MistakeBox>
