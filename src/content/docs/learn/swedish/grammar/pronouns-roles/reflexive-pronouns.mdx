<KeyTakeaway>
- Use <span lang="sv">mig, dig, sig, oss,</span> or <span lang="sv">er</span> when the object refers back
  to the subject of the same clause.
- Third-person subjects use <span lang="sv">sig</span>: <span lang="sv">hon tvättar sig</span>,
  <span lang="sv">de skyndar sig</span>.
- Reflexive possession belongs to <span lang="sv">sin, sitt, sina</span>; reciprocal meaning
  belongs to <span lang="sv">varandra</span>.
</KeyTakeaway>

A reflexive pronoun shows that the subject and object refer to the same person
or group. Swedish also uses reflexive forms as part of several common verbs.

## Use this now

| Subject | Reflexive object | Example |
| --- | --- | --- |
| <span lang="sv">jag</span> | <span lang="sv">mig</span> | <span lang="sv">Jag tvättar mig.</span> |
| <span lang="sv">du</span> | <span lang="sv">dig</span> | <span lang="sv">Du skyndar dig.</span> |
| <span lang="sv">han, hon, den, det, man</span> | <span lang="sv">sig</span> | <span lang="sv">Hon sätter sig.</span> |
| <span lang="sv">vi</span> | <span lang="sv">oss</span> | <span lang="sv">Vi lär oss svenska.</span> |
| <span lang="sv">ni</span> | <span lang="sv">er</span> | <span lang="sv">Ni måste skynda er.</span> |
| <span lang="sv">de</span> | <span lang="sv">sig</span> | <span lang="sv">De känner sig trötta.</span> |

## Core rule

Choose the reflexive form from the clause subject. Compare:

- <span lang="sv">Hon tvättar sig.</span> — she washes herself
- <span lang="sv">Hon tvättar henne.</span> — she washes another woman
- <span lang="sv">De ser sig i spegeln.</span> — they see themselves in the mirror
- <span lang="sv">De ser dem.</span> — they see another group

The form points back within the same clause. In
<span lang="sv">Anna säger att Erik skyndar sig</span>, <span lang="sv">sig</span> points to Erik, the
subject of the subordinate clause.

## Common reflexive verbs

Learn these as complete expressions:

| Expression | Meaning |
| --- | --- |
| <span lang="sv">skynda sig</span> | hurry |
| <span lang="sv">sätta sig</span> | sit down |
| <span lang="sv">känna sig</span> | feel |
| <span lang="sv">lära sig</span> | learn |
| <span lang="sv">gifta sig</span> | get married |

The reflexive pronoun still changes with the subject:
<span lang="sv">jag skyndar mig</span>, <span lang="sv">vi skyndar oss</span>, <span lang="sv">de skyndar sig</span>.

## Keep three systems apart

- <span lang="sv">Hon tvättar sig.</span> — reflexive object: the action returns to her.
- <span lang="sv">Hon tar sin jacka.</span> — reflexive possession: the jacket is hers.
- <span lang="sv">De hjälper varandra.</span> — reciprocal: each person helps another.

English sometimes omits a reflexive form where Swedish and German use one as
part of the verb expression.

<MistakeBox title="Common mistakes">
- <span lang="sv">❌ Hon skyndar henne.</span> → <span lang="sv">✅ Hon skyndar sig.</span>
- <span lang="sv">❌ Vi känner sig trötta.</span> → <span lang="sv">✅ Vi känner oss trötta.</span>
- Do not use <span lang="sv">sig</span> for possession; choose
  <span lang="sv">sin, sitt,</span> or <span lang="sv">sina</span> from the possessed noun.
</MistakeBox>
