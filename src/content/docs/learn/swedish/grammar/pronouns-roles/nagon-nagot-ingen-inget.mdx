<KeyTakeaway>
- Before a noun, the form follows the noun: <span lang="sv">någon</span> for an <span lang="sv">en</span>
  noun, <span lang="sv">något</span> for an <span lang="sv">ett</span> noun, <span lang="sv">några</span> for a plural.
- Standing alone, <span lang="sv">någon</span> is a person, <span lang="sv">något</span> is a thing, and
  <span lang="sv">några</span> refers to a plural group.
- <span lang="sv">ingen</span>, <span lang="sv">inget</span>, and <span lang="sv">inga</span> are the negative forms of
  the same three-way choice.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Swedish uses <span lang="sv">någon</span>, <span lang="sv">något</span>, and
<span lang="sv">några</span> for indefinite meaning: “some”, “any”,
“someone”, or “something”. Their negative forms are
<span lang="sv">ingen</span>, <span lang="sv">inget</span>, and
<span lang="sv">inga</span>: “no”, “not any”, “nobody”, or “nothing”.

## Core forms

When one of these words stands before a noun, choose the form from the noun:

| Meaning | <span lang="sv">en</span> noun | <span lang="sv">ett</span> noun | Plural noun |
| --- | --- | --- | --- |
| some / any | <span lang="sv">någon</span> | <span lang="sv">något</span> | <span lang="sv">några</span> |
| no / not any | <span lang="sv">ingen</span> | <span lang="sv">inget</span> | <span lang="sv">inga</span> |

## Before a noun

Use <span lang="sv">någon</span> before a singular
<span lang="sv">en</span> noun:

<span lang="sv">Finns det någon mataffär?</span>

<span lang="de">Gibt es einen Supermarkt?</span>

Use <span lang="sv">något</span> before a singular
<span lang="sv">ett</span> noun:

<span lang="sv">Har du något smultronställe?</span>

<span lang="de">Hast du einen Lieblingsplatz?</span>

Use <span lang="sv">några</span> before a plural noun:

<span lang="sv">Har ni några lediga rum?</span>

<span lang="de">Habt ihr irgendwelche freien Zimmer?</span>

## Negative forms

For negation, use <span lang="sv">ingen</span>,
<span lang="sv">inget</span>, or <span lang="sv">inga</span> with the same
noun pattern:

| Question | Negative answer |
| --- | --- |
| <span lang="sv">Finns det någon kyrka?</span> | <span lang="sv">Nej, det finns ingen kyrka.</span> |
| <span lang="sv">Finns det något hav här?</span> | <span lang="sv">Nej, det finns inget hav här.</span> |
| <span lang="sv">Har ni några lediga rum?</span> | <span lang="sv">Nej, vi har inga lediga rum.</span> |

The German meaning is often “kein”, “keine”, or “nicht irgendein”:

<span lang="de">Gibt es hier ein Meer? Nein, es gibt hier kein Meer.</span>

## Standing alone

<span lang="sv">Någon</span> and <span lang="sv">något</span> can also stand
alone. Then the choice is about person or thing:

| Swedish | Meaning | Example |
| --- | --- | --- |
| <span lang="sv">någon</span> | someone / anyone | <span lang="sv">Ska någon gå till spaavdelningen?</span> |
| <span lang="sv">något</span> | something / anything | <span lang="sv">Finns det något att äta?</span> |
| <span lang="sv">ingen</span> | nobody / no one | <span lang="sv">Ingen behöver köpa ägg.</span> |
| <span lang="sv">inget</span> | nothing / not anything | <span lang="sv">Jag förstår inget.</span> |
| <span lang="sv">några</span> | some / a few people or things | <span lang="sv">Några kom tidigt.</span> |
| <span lang="sv">inga</span> | none / no people or things | <span lang="sv">Inga kom för sent.</span> |

The plural forms can also replace an understood plural noun:
<span lang="sv">Jag köpte några</span> (“I bought some”) and
<span lang="sv">Jag hittade inga</span> (“I found none”).

## Questions and statements

In questions, <span lang="sv">någon</span>, <span lang="sv">något</span>, and
<span lang="sv">några</span> often mean “any” or “some”:

- <span lang="sv">Finns det någon kyrka?</span>
- <span lang="sv">Finns det något hav här?</span>
- <span lang="sv">Har du några planer för semestern?</span>

In statements, <span lang="sv">några</span> can also mean “a few” or “some”:

<span lang="sv">Jag tar några tomater också.</span>

<span lang="de">Ich nehme auch ein paar Tomaten.</span>

## Spoken forms

In everyday speech, <span lang="sv">någon</span> is often pronounced and
written informally as <span lang="sv">nån</span>. Likewise,
<span lang="sv">något</span> often becomes <span lang="sv">nåt</span>.

| Standard | Informal | Meaning |
| --- | --- | --- |
| <span lang="sv">någon</span> | <span lang="sv">nån</span> | someone / any <span lang="sv">en</span> noun |
| <span lang="sv">något</span> | <span lang="sv">nåt</span> | something / any <span lang="sv">ett</span> noun |

Use the standard forms in careful writing unless the tone is intentionally
informal.

## Fast decision table

| Context | Choose by | Use |
| --- | --- | --- |
| A noun follows | <span lang="sv">en</span>, <span lang="sv">ett</span>, or plural | <span lang="sv">någon</span> / <span lang="sv">något</span> / <span lang="sv">några</span> |
| A negative noun phrase follows | <span lang="sv">en</span>, <span lang="sv">ett</span>, or plural | <span lang="sv">ingen</span> / <span lang="sv">inget</span> / <span lang="sv">inga</span> |
| No noun follows | person, thing, or plural group | <span lang="sv">någon</span> = someone, <span lang="sv">något</span> = something, <span lang="sv">några</span> = some / a few |
| Negative and no noun follows | person, thing, or plural group | <span lang="sv">ingen</span> = nobody, <span lang="sv">inget</span> = nothing, <span lang="sv">inga</span> = none |

This page owns the forms and their noun-phrase agreement. For the broader
choice between clause negation, a negative noun phrase, and a negative adverb,
use [Negation](../../questions-negation/negation/).

## Common mistakes

<MistakeBox title="Common mistakes">
	- ❌ <span lang="sv">något kyrka</span>
	  ✅ <span lang="sv">någon kyrka</span>
	- ❌ <span lang="sv">någon hav</span>
	  ✅ <span lang="sv">något hav</span>
	- ❌ <span lang="sv">ingen lediga rum</span>
	  ✅ <span lang="sv">inga lediga rum</span>
	- ❌ Choosing <span lang="sv">någon</span> and <span lang="sv">något</span>
	  by person or thing when a noun follows. Before a noun, choose by
	  <span lang="sv">en</span>, <span lang="sv">ett</span>, or plural.
</MistakeBox>

<MemoryTip title="Noun or no noun?">
If a noun follows, check whether it is an <span lang="sv">en</span> noun, an
<span lang="sv">ett</span> noun, or plural. If no noun follows, ask whether
you mean a person, a thing, or a plural group.
</MemoryTip>
