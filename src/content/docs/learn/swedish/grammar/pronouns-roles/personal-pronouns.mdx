Swedish personal pronouns change mainly according to subject or object role.
This is a compact form-and-role lookup, not a Swedish version of the productive
German nominative–accusative–dative noun system.

## Use this now

| Role | Ask | Example |
| --- | --- | --- |
| subject | Who performs or experiences the clause? | <span lang="sv">Hon väntar.</span> |
| object | Who or what does the action affect? | <span lang="sv">Jag ser henne.</span> |
| after a preposition | Which form follows words such as <span lang="sv">med</span> or <span lang="sv">till</span>? | <span lang="sv">med henne</span> |

## Core forms

| Meaning | Subject | Object / after a preposition |
| --- | --- | --- |
| I / me | <span lang="sv">jag</span> | <span lang="sv">mig</span> |
| you (singular) | <span lang="sv">du</span> | <span lang="sv">dig</span> |
| he / him | <span lang="sv">han</span> | <span lang="sv">honom</span> |
| she / her | <span lang="sv">hon</span> | <span lang="sv">henne</span> |
| singular gender-neutral person | <span lang="sv">hen</span> | <span lang="sv">hen</span> |
| it, en-word | <span lang="sv">den</span> | <span lang="sv">den</span> |
| it, ett-word | <span lang="sv">det</span> | <span lang="sv">det</span> |
| people in general | <span lang="sv">man</span> | <span lang="sv">en</span> |
| we / us | <span lang="sv">vi</span> | <span lang="sv">oss</span> |
| you (plural) | <span lang="sv">ni</span> | <span lang="sv">er</span> |
| they / them | <span lang="sv">de</span> | <span lang="sv">dem</span> |

<span lang="sv">Ni</span> is primarily plural. It can address one person in some service
encounters or deliberately formal contexts, but it is not a blanket Swedish
equivalent of polite German <span lang="de">Sie</span>. <span lang="sv">Du</span> is the
normal singular default in modern Swedish.

## Subject or object

- <span lang="sv">Hon ringer mig.</span> — She calls me.
- <span lang="sv">Jag hjälper honom.</span> — I help him.
- <span lang="sv">De väntar på oss.</span> — They are waiting for us.
- <span lang="sv">Vi åker med dem.</span> — We travel with them.

Prepositions take the object form: <span lang="sv">med mig</span>, <span lang="sv">till dig</span>,
<span lang="sv">från henne</span>.

## Referring to things

Use <span lang="sv">den</span> for an en-word and <span lang="sv">det</span> for an ett-word when a
personal pronoun refers to a specific thing:

- <span lang="sv">Var är bilen? Den står ute.</span>
- <span lang="sv">Var är brevet? Det ligger här.</span>

This reference use is separate from demonstrative phrases such as
<span lang="sv">den här bilen</span>.

## Spoken *dom* and written *de/dem*

In standard writing, use <span lang="sv">de</span> as subject and <span lang="sv">dem</span> as object:
<span lang="sv">De såg oss</span>; <span lang="sv">vi såg dem</span>. In speech, both are normally
pronounced <span lang="sv">dom</span>, and <span lang="sv">dom</span> also appears in informal writing.

## Direct comparison

<LanguageComparison title="After a preposition">
	<p slot="de">mit ihr</p>
	<p slot="en">with her</p>
	<p slot="sv">med henne</p>
</LanguageComparison>

German has a broader productive case system across articles, adjectives, and
nouns. Swedish keeps the subject–object contrast mainly in personal pronouns.

<MistakeBox title="Common mistakes">
- <span lang="sv">❌ med jag</span> → <span lang="sv">✅ med mig</span>
- <span lang="sv">❌ henne kommer</span> → <span lang="sv">✅ hon kommer</span>
- In standard writing, use <span lang="sv">de</span> as subject and <span lang="sv">dem</span> as object.
</MistakeBox>

<MemoryTip>
Learn each pair as a small rhythm: <span lang="sv"><strong>jag–mig, du–dig, hon–henne,
vi–oss, de–dem</strong></span>.
</MemoryTip>
