<KeyTakeaway>
- Pick the connector by the relationship you mean: addition, contrast,
  alternative, reason, result, condition, or example.
- Connectors can join main clauses, introduce subordinate clauses, or act as
  adverbs that point back to earlier information.
- When the connector affects word order, follow the canonical clause page:
  V2 for main clauses and Subordinate clauses for dependent clauses.
</KeyTakeaway>

Swedish connectors help you join one idea to the next. This page is a choice
map: it tells you which word family to reach for and where to look for the
word-order rule when the connector changes the clause shape.

## Use this now

| Meaning | Everyday choices | Use it for |
| --- | --- | --- |
| addition | <span lang="sv">och</span>, <span lang="sv">också</span>, <span lang="sv">dessutom</span> | adding information |
| contrast | <span lang="sv">men</span>, <span lang="sv">fast</span>, <span lang="sv">däremot</span> | soft or strong contrast |
| alternative | <span lang="sv">eller</span>, <span lang="sv">annars</span> | choices and warnings |
| reason | <span lang="sv">för att</span>, <span lang="sv">eftersom</span>, <span lang="sv">därför att</span> | why something happens |
| result | <span lang="sv">så</span>, <span lang="sv">därför</span> | what follows from something |
| condition | <span lang="sv">om</span>, <span lang="sv">ifall</span>, <span lang="sv">annars</span> | if-frames and consequences |
| example | <span lang="sv">till exempel</span>, <span lang="sv">som</span> | examples and specification |

## Addition, contrast, and alternatives

The smallest connectors join words, phrases, or clauses:

- <span lang="sv">Jag dricker kaffe och te.</span>
- <span lang="sv">Jag vill gå, men jag hinner inte.</span>
- <span lang="sv">Vill du ha kaffe eller te?</span>

For a stronger written link, Swedish often uses an adverbial connector such as
<span lang="sv">dessutom</span> or <span lang="sv">däremot</span>. When it starts the next main clause,
follow [V2](../../sentence-structure/v2/).

## Reasons and results

Use a reason connector when the second clause explains why something happened:

- <span lang="sv">Jag stannade hemma eftersom jag var sjuk.</span>
- <span lang="sv">Jag stannade hemma därför att jag var sjuk.</span>

Use a result connector when the second clause says what followed:

- <span lang="sv">Jag var sjuk. Därför stannade jag hemma.</span>
- <span lang="sv">Det regnade, så vi stannade inne.</span>

<span lang="sv">Därför</span> and <span lang="sv">därför att</span> are easy to confuse because they share
the same first word. The focused lexical contrast belongs to
[*där-* and *här-* adverbs](../dar-har-adverbs/).

## Conditions and consequences

<span lang="sv">Om</span> and <span lang="sv">ifall</span> introduce a condition:

- <span lang="sv">Om det regnar stannar vi hemma.</span>
- <span lang="sv">Vi stannar hemma om det regnar.</span>

<span lang="sv">Annars</span> gives the consequence if the condition is not met:

- <span lang="sv">Ta med jacka. Annars blir du kall.</span>

For production frames such as warnings, offers, and consequences, use
[conditions and consequences](../../../sentence-patterns/conditions-and-consequences/).
For the grammar system behind conditional meaning, use
[conditionals](../../mood-politeness-reports/conditionals/).

## Examples

For examples, the safest everyday expression is
<span lang="sv">till exempel</span>:

- <span lang="sv">Jag gillar svensk mat, till exempel köttbullar.</span>

In compact definitions, <span lang="sv">som</span> can introduce an example:

- <span lang="sv">Städer som Malmö och Uppsala växer.</span>

For ready-made explanation phrases, use
[reasons and examples](../../../sentence-patterns/reasons-and-examples/).

<MistakeBox title="Common mistakes">
	- Do not use one Swedish connector for every German
	  <span lang="de">weil / deshalb / damit</span> or English
	  <span lang="en">because / so / therefore</span>.
	- Keep <span lang="sv">därför</span> for *therefore* and
	  <span lang="sv">därför att</span> for *because*.
	- When a connector changes the clause type, do not guess the word order.
	  Use [V2](../../sentence-structure/v2/) or
	  [subordinate clauses](../../sentence-structure/subordinate-clauses/).
</MistakeBox>

<MemoryTip>
Choose the relationship before the word: add with <span lang="sv">och</span>, contrast with
<span lang="sv">men</span>, explain with <span lang="sv">eftersom</span>, show a result with
<span lang="sv">därför</span>, and set a condition with <span lang="sv">om</span>.
</MemoryTip>
