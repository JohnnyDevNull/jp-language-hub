<KeyTakeaway>
- Use the question frame to ask for confirmation; use a question word to ask
  for a missing person, thing, place, time, reason, or choice.
- Choose the negative expression first, then use the separate placement rule if
  the expression is *inte*.
- Direct and indirect questions use different word order.
</KeyTakeaway>

This section separates two decisions that often get mixed together: how to
frame a question and how to choose a negative expression.

## Choose by

| If you need to… | Start with… |
| --- | --- |
| ask a yes/no question | [Questions](./questions/) |
| choose *who, what, which, where, when, how,* or *why* | [Question words](./question-words/) |
| turn a direct question into an indirect one | [Question words](./question-words/#indirect-questions-no-inversion) |
| say *not, never, nobody, nothing,* or *nowhere* | [Negation](./negation/) |
| decide where *inte* belongs | [Placement of *inte*](../sentence-structure/inte-placement/) |

## Learn in this order

1. [Questions](./questions/) gives you the reusable yes/no frame and distinguishes
   it from statements and question-word questions.
2. [Question words](./question-words/) adds lexical choice, agreement, and
   direct-versus-indirect word order.
3. [Negation](./negation/) helps you choose between clause negation and a
   negative noun or adverb expression.
4. [Placement of *inte*](../sentence-structure/inte-placement/) handles the
   position of *inte* in each clause type.

## Watch for

- [Questions](./questions/) owns the question frame; [Question words](./question-words/)
  owns which question expression to use and its special patterns.
- [Negation](./negation/) owns meaning and form; [Placement of *inte*](../sentence-structure/inte-placement/)
  owns position.
- [*Någon, något, ingen, inget*](../pronouns-roles/nagon-nagot-ingen-inget/)
  is the full noun-phrase lookup; Negation only shows when that contrast matters.
