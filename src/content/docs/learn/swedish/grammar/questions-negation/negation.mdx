<KeyTakeaway>
- Use <span lang="sv">inte</span> to negate a clause: <span lang="sv">Jag kommer inte.</span>
- Use one negative noun or adverb expression when it carries the negative
  meaning itself: <span lang="sv">Ingen kom.</span>, <span lang="sv">Jag såg ingenting.</span>
- In ordinary standard Swedish, do not add <span lang="sv">inte</span> when another negative
  expression already negates the same clause.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Negation is first a choice of meaning and form. This page helps you choose the
negative expression; [Placement of *inte*](../../sentence-structure/inte-placement/)
owns where <span lang="sv">inte</span> goes in each clause type.

## Use this now

| Meaning | Use | Example |
| --- | --- | --- |
| not | <span lang="sv">inte</span> | <span lang="sv">Jag arbetar inte idag.</span> |
| nobody / no one | <span lang="sv">ingen</span> | <span lang="sv">Ingen ringde.</span> |
| nothing | <span lang="sv">ingenting</span> or <span lang="sv">inget</span> + noun | <span lang="sv">Jag hörde ingenting.</span> / <span lang="sv">Jag hörde inget ljud.</span> |
| never | <span lang="sv">aldrig</span> | <span lang="sv">Hon röker aldrig.</span> |
| nowhere | <span lang="sv">ingenstans</span> | <span lang="sv">Jag hittar den ingenstans.</span> |
| not … either | <span lang="sv">inte … heller</span> | <span lang="sv">Jag kommer inte heller.</span> |

## Core rule

Use <span lang="sv">inte</span> when you negate the clause as a whole or reject one part in
context:

- <span lang="sv">Jag **kommer inte** imorgon.</span>
- <span lang="sv">Hon köpte **inte den röda** bilen.</span>

Use a negative expression when the missing person, thing, time, or place itself
is negative:

- <span lang="sv">**Ingen** väntar utanför.</span>
- <span lang="sv">Jag såg **ingenting**.</span>
- <span lang="sv">Vi går **aldrig** dit.</span>
- <span lang="sv">Nyckeln finns **ingenstans**.</span>

## Indefinite under clause negation

When <span lang="sv">inte</span> negates the clause, Swedish normally uses a non-negative
indefinite expression inside its scope:

- <span lang="sv">Jag har **inte någon** bil.</span>
- <span lang="sv">Jag såg **inte något** problem.</span>
- <span lang="sv">Vi har **inte några** frågor.</span>

The compact negative noun phrase often gives the same real-world result:

- <span lang="sv">Jag har **ingen** bil.</span>
- <span lang="sv">Jag såg **inget** problem.</span>
- <span lang="sv">Vi har **inga** frågor.</span>

The two patterns are not mechanically interchangeable in every context.
<span lang="sv">Ingen / inget / inga</span> packages the absence inside the noun phrase;
<span lang="sv">inte någon / något / några</span> keeps clause negation visible and can carry
different focus or contrast.

The full agreement and noun-phrase choice belongs to
[*någon, något, ingen, inget*](../../pronouns-roles/nagon-nagot-ingen-inget/).

## Direct comparison

<LanguageComparison title="No car">
	<p slot="de">Ich habe kein Auto.</p>
	<p slot="en">I do not have a car.</p>
	<p slot="sv">Jag har ingen bil.</p>
</LanguageComparison>

<LanguageComparison title="Nothing">
	<p slot="de">Ich habe nichts gesehen.</p>
	<p slot="en">I did not see anything.</p>
	<p slot="sv">Jag såg ingenting.</p>
</LanguageComparison>

English often combines *not* with an indefinite form such as *anything*.
Swedish can use either <span lang="sv">inte</span> + an indefinite expression or one negative
expression, but the choice can shift focus and scope.

<MistakeBox
	title="Avoid ordinary double negation"
	incorrect="Ingen kom inte."
	correct="Ingen kom."
	lang="sv"
>
In ordinary standard Swedish, one expression normally carries the negative
force. If <span lang="sv">ingen</span> already means “nobody,” a second <span lang="sv">inte</span> normally
changes or obscures the intended meaning instead of strengthening it.
</MistakeBox>

<MemoryTip>
Choose **one carrier of the negative meaning** first: clause-wide <span lang="sv">inte</span>,
or a negative person, thing, time, or place expression.
</MemoryTip>
