<KeyTakeaway>
- In a direct question the question word comes first and the <span lang="sv">finit verb</span>
  second: <span lang="sv">Var bor du?</span>
- An indirect question is a subordinate clause, so the <span lang="sv">subjekt</span> comes
  back before the verb: <span lang="sv">Jag vet inte var hon bor.</span>
- In an indirect question, <span lang="sv">vem</span> and <span lang="sv">vad</span> add <span lang="sv">som</span> when
  they are the <span lang="sv">subjekt</span> of their own clause.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Swedish question words nearly all begin with <span lang="sv">v-</span>, which
makes them easy to recognize. The harder part is the word order, which differs
between direct and indirect questions.

## Use this now

| Swedish | Use it to ask about… |
| --- | --- |
| <span lang="sv">vem</span> | a person |
| <span lang="sv">vems</span> | an owner |
| <span lang="sv">vad</span> | a thing, event, or identity |
| <span lang="sv">vilken / vilket / vilka</span> | a choice from a set |
| <span lang="sv">var</span> | a location |
| <span lang="sv">vart</span> | a direction |
| <span lang="sv">när</span> | a time |
| <span lang="sv">hur</span> | a manner or condition |
| <span lang="sv">varför</span> | a reason |
| <span lang="sv">hur mycket / hur många</span> | an amount or number |

<span lang="sv">Vem</span> is invariable — there is no separate object form,
so <span lang="sv">Vem såg du?</span> and <span lang="sv">Vem såg dig?</span>
differ only in word order, not in the pronoun.

## Core rule: direct questions

When the question word is not the <span lang="sv">subjekt</span>, it fills the first field
and the <span lang="sv">finit verb</span> follows it. Compare that frame with a yes/no question:

<SentenceSchema
	caption="Direct question frames"
	rowHeader="Question"
	columns={['fundament', 'finit verb', 'subjekt', 'adverbial']}
	rows={[
		{ label: 'Question word', cells: ['Var', 'bor', 'du', ''] },
		{ label: 'Question phrase', cells: ['Vilken bok', 'läser', 'du', ''] },
		{ label: 'Yes/no', cells: ['', 'Bor', 'du', 'här?'] },
	]}
/>

When the question word itself is the <span lang="sv">subjekt</span>, it occupies the
<span lang="sv">subjekt</span> role and no separate <span lang="sv">subjekt</span> follows:
<span lang="sv">Vem ringde?</span> and <span lang="sv">Vad hände?</span>

<RuleBox title="No do-support">
	Swedish has nothing like English *do*. <span lang="sv">Bor du här?</span> is
	*Do you live here?*, and <span lang="sv">Vad sa han?</span> is *What did he
	say?* The verb itself moves; no helper is added.
</RuleBox>

See [Questions](../questions/) for the shared yes/no frame and
[V2](../../sentence-structure/v2/) for declarative main clauses.

## var or vart

Standard Swedish separates position from direction, as German does:

- <span lang="sv">Var bor du?</span> — *Where do you live?*
- <span lang="sv">Vart går du?</span> — *Where are you going?*

For *where from*, the preposition goes to the end:
<span lang="sv">Var kommer du ifrån?</span>

## vilken agrees with the noun

The <span lang="sv">vilken</span> series agrees with the noun's gender and number:

- <span lang="sv">Vilken bok läser du?</span> — an en-word
- <span lang="sv">Vilket hus är ditt?</span> — an ett-word
- <span lang="sv">Vilka böcker har du läst?</span> — plural

For *what kind of*, Swedish uses <span lang="sv">vad för</span> or
<span lang="sv">vad för sorts</span>:
<span lang="sv">Vad för sorts musik lyssnar du på?</span>

See [en / ett](../../nouns-articles/en-ett/) for the gender
behind the choice.

## Indirect questions: no inversion

An indirect question is a subordinate clause. The <span lang="sv">subjekt</span> therefore
comes before the <span lang="sv">finit verb</span>, and a <span lang="sv">satsadverbial</span> such as
<span lang="sv">inte</span> comes before that verb:

	caption="Direct question order"

		{ label: 'Direct', cells: ['Var', 'bor', 'hon', '', ''] },

/>

	caption="Indirect question order"
	rowHeader="Question"
	columns={['bisatsinledare', 'subjekt', 'satsadverbial', 'finit verb', 'adverbial']}
	rows={[
		{ label: 'Neutral', cells: ['var', 'hon', '', 'bor', ''] },
		{ label: 'Negative', cells: ['varför', 'hon', 'inte', 'kommer', ''] },

/>

- <span lang="sv">Var bor hon?</span> → <span lang="sv">Jag vet inte var hon bor.</span>
- <span lang="sv">Varför kommer hon?</span> → <span lang="sv">Jag förstår inte varför hon kommer.</span>

See [Subordinate clauses](../../sentence-structure/subordinate-clauses/) for the
general dependent-clause frame. [Questions](../questions/#indirect-yesno-questions-with-om)
handles indirect yes/no questions with <span lang="sv">om</span>.

## Insert som when the question word is the <span lang="sv">subjekt</span>

In an indirect question, <span lang="sv">vem</span> and
<span lang="sv">vad</span> take <span lang="sv">som</span> when they are the
<span lang="sv">subjekt</span> of their own clause:

- <span lang="sv">Jag vet inte vem som ringde.</span> — *I do not know who
  called.*
- <span lang="sv">Berätta vad som hände!</span> — *Tell me what happened!*

When they are the <span lang="sv">objekt</span>, no <span lang="sv">som</span> appears:

- <span lang="sv">Jag vet inte vem hon ringde.</span> — *…who she called.*
- <span lang="sv">Berätta vad du gjorde!</span> — *…what you did.*

Direct questions do not need it: <span lang="sv">Vem ringde?</span>,
<span lang="sv">Vad hände?</span>

## Common mistakes

<MistakeBox title="Common mistakes">
	- ❌ <span lang="sv">Jag vet inte var bor hon.</span>
	  ✅ <span lang="sv">Jag vet inte var hon bor.</span>
	- ❌ <span lang="sv">Jag vet inte vem ringde.</span>
	  ✅ <span lang="sv">Jag vet inte vem som ringde.</span>
	- ❌ <span lang="sv">Vart bor du?</span>
	  ✅ <span lang="sv">Var bor du?</span>
	- ❌ <span lang="sv">Vilken hus är ditt?</span>
	  ✅ <span lang="sv">Vilket hus är ditt?</span>
</MistakeBox>

<MemoryTip>
Contrast one pair until it is automatic:
<span lang="sv"><strong>Vem som ringde</strong></span> — the caller is the
<span lang="sv">subjekt</span>. <span lang="sv"><strong>Vem hon ringde</strong></span> — the caller is
someone else. The extra <span lang="sv">som</span> marks the <span lang="sv">subjekt</span>.
</MemoryTip>
