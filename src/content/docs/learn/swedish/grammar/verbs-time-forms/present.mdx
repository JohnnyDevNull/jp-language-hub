<KeyTakeaway>
- The present form is the same for every subject: <span lang="sv">jag arbetar</span>,
  <span lang="sv">hon arbetar</span>, <span lang="sv">de arbetar</span>.
- The ending follows the verb group: <span lang="sv">-ar</span>, <span lang="sv">-er</span> or plain
  <span lang="sv">-r</span>.

  <span lang="en">I am working</span> and, in a clear context, a planned future.

The Swedish present tense describes what happens now, what happens regularly,
and—in a clear context—what is planned or expected to happen later.

## Core rule

The present form is identical for every subject:

| Subject | Example |
| --- | --- |
| <span lang="sv">jag</span> | <span lang="sv">Jag arbetar.</span> |
| <span lang="sv">du</span> | <span lang="sv">Du arbetar.</span> |
| <span lang="sv">hon / han / hen</span> | <span lang="sv">Hon arbetar.</span> |
| <span lang="sv">vi / ni / de</span> | <span lang="sv">De arbetar.</span> |

The ending depends on the verb group. One representative verb per group:

Some frequent verbs are irregular, for example <span lang="sv">vara → är</span> and
<span lang="sv">göra → gör</span>. See [verb groups](../../verb-patterns-voice/verb-groups/) for the full patterns.

## Main uses

### Happening now

<span lang="sv">Jag läser just nu.</span> — I am reading right now.

Swedish normally uses the ordinary present here. It does not require an English-style
<span lang="en">am/is/are + -ing</span> form.

### Habits and repeated events

<span lang="sv">Vi tränar varje torsdag.</span> — We train every Thursday.

### General facts and states

<span lang="sv">Stockholm ligger i Sverige.</span> — Stockholm is in Sweden.

### Future meaning from context

<span lang="sv">Jag åker till Malmö i morgon.</span> — I am going to Malmö tomorrow.

The time expression makes the future meaning clear. Other future constructions
are used when the context requires them.

## Negation and word order

In a main clause, <span lang="sv">inte</span> normally follows the finite verb:

<span lang="sv">Jag arbetar inte idag.</span>

In a subordinate clause, the order normally changes:

<span lang="sv">… eftersom jag inte arbetar idag.</span>

This is a word-order rule, not a different present-tense form. See the pages on
[V2](../../sentence-structure/v2/) and
[BIFF](../../sentence-structure/biff/).

## Common mistakes

<MistakeBox title="Common mistakes">
	- Do not add a person ending modeled on English or German: Swedish uses
	  <span lang="sv">jag kommer</span> and <span lang="sv">hon kommer</span>.
	- Do not translate the English progressive word for word. Usually
	  <span lang="en">I am working</span> becomes <span lang="sv">jag arbetar</span>.
	- Learn irregular present forms individually.
</MistakeBox>
