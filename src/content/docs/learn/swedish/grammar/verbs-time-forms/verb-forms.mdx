<KeyTakeaway>
- A Swedish verb has one finite form per tense: the same form for
  <span lang="sv">jag</span>, <span lang="sv">du</span>, <span lang="sv">hon</span> and <span lang="sv">de</span>.
- Five core forms organize the basic active form chain: infinitive, imperative,
  present, preterite and supine. Participles and passive forms add further
  patterns when you need them.
- The supine is the form after <span lang="sv">har</span> or <span lang="sv">hade</span>; it is never the
  infinitive and never the preterite.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Swedish verbs do not change according to person or number. The main learning
task is therefore recognizing the form and choosing the right tense.

## Core rule

Learn every new verb with the core chain **infinitive — imperative — present —
preterite — supine**. It is a practical learning frame, not a claim that these
are the only forms Swedish verbs can have. Using <span lang="sv">köpa</span> (“buy”) as an
example:

	caption="köpa — core forms"
	forms={[
		{ label: 'Infinitive', value: `att ${buy.lemma}` },
		{ label: 'Imperative', value: `${buy.morphology.imperative}!` },
		{ label: 'Present', value: buy.morphology.present },
		{ label: 'Preterite', value: buy.morphology.preterite },
		{ label: 'Supine', value: buy.morphology.supine },
		{ label: 'Perfect', value: `har ${buy.morphology.supine}` },
	]}
/>

Each form has one job:

- Infinitive after a modal verb: <span lang="sv">Jag vill köpa boken.</span>
- Imperative for a command: <span lang="sv">Köp boken!</span>
- Present for now, generally or repeatedly: <span lang="sv">Jag köper en bok.</span>
- Preterite for a completed past event: <span lang="sv">Jag köpte en bok.</span>
- Supine after <span lang="sv">har</span> or <span lang="sv">hade</span>: <span lang="sv">Jag har köpt en bok.</span>

:::note[One form for every person]
<span lang="sv">Jag köper</span>, <span lang="sv">du köper</span> and <span lang="sv">de köper</span> all use the same
present form.
:::

## The form chain

Learning a verb as a short form chain is more useful than learning only its
infinitive:

			<th scope="col">Present</th>
			<th scope="col">Preterite</th>

				<td lang="sv">{data.morphology.imperative}!</td>

These examples represent different
[verb groups](../../verb-patterns-voice/verb-groups/).
The group is useful as a pattern, but irregular forms still need to be learned.

For choosing between present, preterite, perfect, pluperfect and future
constructions, see [tense perspectives](../tense-perspectives/).

## Building compound tenses

The supine combines with a finite form of <span lang="sv">ha</span>:

- Perfect: <span lang="sv">Jag har köpt en bok.</span> — I have bought a book.
- Pluperfect: <span lang="sv">Jag hade köpt boken.</span> — I had bought the book.

The supine is not the same as the infinitive or the preterite:

- <span lang="sv">Jag vill köpa boken.</span> — infinitive after a modal verb
- <span lang="sv">Jag köpte boken i går.</span> — preterite
- <span lang="sv">Jag har köpt boken.</span> — supine after <span lang="sv">har</span>

English may use a progressive form where Swedish uses the ordinary present.
The similar-looking perfect constructions are useful bridges, but their usage
does not match perfectly in every context.

## Common mistakes

<MistakeBox
	incorrect={`Jag har ${buy.lemma} en bok.`}
	correct={`Jag har ${buy.morphology.supine} en bok.`}
	lang="sv"
>
	Use the supine after <span lang="sv">har</span> or <span lang="sv">hade</span>.
</MistakeBox>

<MistakeBox
	incorrect={`Hon ${buy.morphology.present} och jag ${buy.morphology.present}er.`}
	correct={`Hon ${buy.morphology.present} och jag ${buy.morphology.present}.`}
	lang="sv"
>
	Swedish verb forms do not change according to person or number. Do not infer
	the preterite or supine from the infinitive alone when a verb is irregular;
	learn the form chain.
</MistakeBox>

<MemoryTip>
Store each verb as at least three forms: present — preterite — supine. Add the
infinitive when it is not already obvious.
</MemoryTip>
