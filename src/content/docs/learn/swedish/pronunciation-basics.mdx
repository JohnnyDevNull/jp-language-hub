<KeyTakeaway>
- A doubled consonant is the strongest beginner clue for a **short vowel**,
  while a single consonant often points to a long one; the difference
  distinguishes words: <span lang="sv">glas</span> is a drinking glass, <span lang="sv">glass</span> is

- <span lang="sv">g</span>, <span lang="sv">k</span> and <span lang="sv">sk</span> often change their sound before the soft

- Spelling gets you close, but not all the way: the <span lang="sv">u</span> and <span lang="sv">y</span>

  by ear.

Swedish pronunciation is not fully predictable from spelling, but a handful of
patterns cover most of what a beginner reads aloud.

## Core rule

> Read the consonants after a stressed vowel first. A doubled consonant usually
> marks a short vowel; one consonant or the end of the word often points to a
> long vowel. Then check whether the vowel that *follows* a <span lang="sv">g</span>,
> <span lang="sv">k</span> or <span lang="sv">sk</span> is hard or soft.

## The alphabet

Swedish has 29 letters. The three extra vowels come **at the end** of the
alphabet, after <span lang="sv">z</span>: <span lang="sv">… x, y, z, å, ä, ö</span>.

This is not only trivia: dictionaries, indexes, name lists and sorted tables
follow that order, so <span lang="sv">Ångström</span> is filed after <span lang="sv">Zetterberg</span>, not
next to <span lang="sv">Andersson</span>.

## Vowels

Swedish has the vowel letters <span lang="sv">a, e, i, o, u, y, å, ä, ö</span>. Several look
familiar to German speakers, but their exact sound and length can differ.

| Letter | Beginner cue |
| --- | --- |
| <span lang="sv">a</span> | often more open than German <span lang="de">a</span> |
| <span lang="sv">e</span> | long in <span lang="sv">resa</span>, short in <span lang="sv">hem</span> |
| <span lang="sv">i</span> | often close to German <span lang="de">i</span> |
| <span lang="sv">o</span> | often closer to German <span lang="de">u</span> when long |
| <span lang="sv">u</span> | a rounded Swedish sound; not simply German <span lang="de">u</span> |
| <span lang="sv">y</span> | rounded front vowel; keep the lips rounded |
| <span lang="sv">å</span> | often close to German <span lang="de">o</span> |
| <span lang="sv">ä</span> | often close to German <span lang="de">ä</span> |
| <span lang="sv">ö</span> | often close to German <span lang="de">ö</span> |

### Vowel length changes the word

| Long vowel | Short vowel |
| --- | --- |
| <span lang="sv">glas</span> — drinking glass | <span lang="sv">glass</span> — ice cream |
| <span lang="sv">tak</span> — roof | <span lang="sv">tack</span> — thanks |
| <span lang="sv">vit</span> — white | <span lang="sv">vitt</span> — white (<span lang="sv">ett</span>-form) |

Consonant doubling is the common spelling signal for a short stressed vowel,
so <span lang="sv">glas</span> and <span lang="sv">glass</span> differ mainly in vowel length, not in the
s-sound.

<MistakeBox
	incorrect="reading “glass” with the same long a as “glas”"
	correct="glass has a short a; glas has a long one"

>
	German spelling does not use consonant doubling this consistently, so it is
	easy to skip. In Swedish it is a strong length signal, and length carries
	meaning.
</MistakeBox>

## Hard and soft vowels

| Vowel type | Letters |
| --- | --- |
| hard vowels | <span lang="sv">a, o, u, å</span> |
| soft vowels | <span lang="sv">e, i, y, ä, ö</span> |

## Common consonant patterns

| Spelling | Typical beginner rule | Examples |
| --- | --- | --- |
| <span lang="sv">g</span> before hard vowels | pronounced hard | <span lang="sv">gata</span> |
| <span lang="sv">g</span> before soft vowels | often sounds like Swedish <span lang="sv">j</span> | <span lang="sv">gärna</span> |
| <span lang="sv">k</span> before hard vowels | like German <span lang="de">k</span> | <span lang="sv">karta</span> |
| <span lang="sv">k</span> before soft vowels | often close to German <span lang="de">ch</span> in <span lang="de">ich</span> | <span lang="sv">kyrka</span> |
| <span lang="sv">sk</span> before soft vowels | often the Swedish sj-sound | <span lang="sv">sked</span> |
| <span lang="sv">tj</span>, <span lang="sv">kj</span> | often a front "ch-like" sound | <span lang="sv">tjugo</span>, <span lang="sv">kjol</span> |
| <span lang="sv">sj</span> | Swedish sj-sound | <span lang="sv">sju</span> |
| <span lang="sv">rs</span> | often merges into a retroflex "sh-like" sound | <span lang="sv">första</span> |
| <span lang="sv">gn</span> | the <span lang="sv">g</span> sounds like <span lang="sv">ng</span> | <span lang="sv">regn</span>, <span lang="sv">lugn</span> |
| <span lang="sv">-tion</span>, <span lang="sv">-sion</span> | often contain an sj-like sound | <span lang="sv">station</span> |

In words beginning with <span lang="sv">dj</span>, <span lang="sv">gj</span>, <span lang="sv">hj</span> or <span lang="sv">lj</span>,
only the <span lang="sv">j</span> is heard clearly.

## Word accent

Swedish distinguishes two word accents — a single-peak accent 1 and a two-peak
accent 2. A few pairs are told apart by nothing else:

| Word | Accent 1 | Accent 2 |
| --- | --- | --- |
| <span lang="sv">anden</span> | the duck | the spirit |
| <span lang="sv">tomten</span> | the plot of land | Father Christmas |

Do not chase this early. Native listeners understand you without it, and it is
learned far more effectively by imitating whole phrases than by studying the
rule. Knowing that it exists is enough to explain why a word you pronounced
"correctly" was still misheard.

## Spoken reductions

- <span lang="sv">de</span> is commonly pronounced like <span lang="sv">dom</span>.
- <span lang="sv">är</span> is commonly pronounced like <span lang="sv">e</span>.
- <span lang="sv">någon</span> and <span lang="sv">något</span> often sound like <span lang="sv">nån</span> and
  <span lang="sv">nåt</span>.
- The <span lang="sv">g</span> in the <span lang="sv">-ig</span> and <span lang="sv">-igt</span> endings is usually not
  pronounced: <span lang="sv">roligt</span> sounds like <span lang="sv">rolit</span>.
- <span lang="sv">och</span> is often reduced in fast speech, and <span lang="sv">att</span> can be reduced
  before an infinitive.

<MemoryTip>
Two questions answer many reading-aloud problems: **is there a doubled
consonant after the stressed vowel** (length), and **is the next vowel soft**
(does <span lang="sv">g</span>, <span lang="sv">k</span> or <span lang="sv">sk</span> change).
</MemoryTip>
