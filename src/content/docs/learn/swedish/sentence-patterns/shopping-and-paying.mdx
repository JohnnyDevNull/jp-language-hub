Shopping Swedish is mostly a set of ready-made moves: find the item, check the
price or size, choose, and pay. Learn the short answers too, because cashiers
often ask without a full sentence.

## Finding and asking

| Pattern | Use it when | Register |
| --- | --- | --- |
| <span lang="sv">Jag letar efter …</span> | you are looking for something | neutral |
| <span lang="sv">Har ni …?</span> | asking whether the shop has it | neutral |
| <span lang="sv">Var finns …?</span> | asking where something is | neutral |
| <span lang="sv">Finns den i en annan storlek?</span> | asking for another size | neutral |
| <span lang="sv">Finns den i en annan färg?</span> | asking for another color | neutral |
| <span lang="sv">Kan jag prova den?</span> | asking to try it on | neutral |

Use <span lang="sv">den</span> for an <span lang="sv">en</span>-word item and <span lang="sv">det</span> for an
<span lang="sv">ett</span>-word item. If you do not know the gender yet, point and use
<span lang="sv">den här</span> for "this one" in everyday speech.

## Choosing and paying

| Pattern | Use it when | Register |
| --- | --- | --- |
| <span lang="sv">Hur mycket kostar den?</span> | asking the price of one item | neutral |
| <span lang="sv">Jag tar den här.</span> | choosing this one | spoken |
| <span lang="sv">Det blir bra.</span> | that will be fine | spoken |
| <span lang="sv">Kan jag betala med kort?</span> | asking to pay by card | neutral |
| <span lang="sv">Jag betalar med kort.</span> | stating how you pay | neutral |
| <span lang="sv">Kan jag få kvittot?</span> | asking for the receipt | neutral |

## Checkout replies

| If they ask | Reply |
| --- | --- |
| <span lang="sv">Kvitto?</span> | <span lang="sv">Ja tack.</span> / <span lang="sv">Nej tack.</span> |
| <span lang="sv">Påse?</span> | <span lang="sv">Ja, en påse tack.</span> |
| <span lang="sv">Är det bra så?</span> | <span lang="sv">Ja, det är bra.</span> |
| <span lang="sv">Medlemskap?</span> | <span lang="sv">Nej, jag är inte medlem.</span> |

## Tiny checkout

<p lang="sv">
	A: Hej! Behöver du hjälp?
	<br />
	B: Ja, jag letar efter en laddare.
	<br />
	A: De finns där borta.
	<br />
	B: Tack. Jag tar den här. Kan jag betala med kort?
</p>

## Direct comparison

<LanguageComparison title="Looking for something">
	<p slot="de">Ich suche ein Ladegerät.</p>
	<p slot="en">I'm looking for a charger.</p>
	<p slot="sv">Jag letar efter en laddare.</p>
</LanguageComparison>

The Swedish pattern is <span lang="sv">leta efter</span>, not a direct copy of German
<span lang="de">suchen</span> or English "look for" word by word.

<LanguageComparison title="Choosing this one">
	<p slot="de">Ich nehme das hier.</p>
	<p slot="en">I'll take this one.</p>
	<p slot="sv">Jag tar den här.</p>
</LanguageComparison>
