<KeyTakeaway>
- Start with <span lang="sv">Ursäkta, var ligger …?</span> for places and
  <span lang="sv">Hur kommer jag till …?</span> for routes.
- Use <span lang="sv">till</span> for destination, <span lang="sv">mot</span> for direction, and
  <span lang="sv">förbi</span> for "past".
- Direction answers are often imperatives:
  <span lang="sv">Gå rakt fram</span>, <span lang="sv">sväng vänster</span>, <span lang="sv">ta höger</span>.
</KeyTakeaway>

This page is for the street moment: you need to stop someone, ask simply, and
recognize the words that tell you where to go next.

For the imperative form itself, use
[Imperative](../../grammar/verb-patterns-voice/imperative/). This page keeps to
the route script.

## Asking the question

| Pattern | Use it when | Register |
| --- | --- | --- |
| <span lang="sv">Ursäkta, var ligger …?</span> | asking where a place is | neutral |
| <span lang="sv">Vet du var … ligger?</span> | softer: do you know where it is | neutral |
| <span lang="sv">Hur kommer jag till …?</span> | asking how to get there | neutral |
| <span lang="sv">Är det långt härifrån?</span> | asking whether it is far from here | neutral |
| <span lang="sv">Är det åt rätt håll?</span> | checking whether this is the right direction | neutral |
| <span lang="sv">Kan du visa på kartan?</span> | asking someone to show it on the map | neutral |

A common Swedish location question is <span lang="sv">Var ligger stationen?</span> For the
full question-word pattern, see
[Question words](../../grammar/questions-negation/question-words/). For a
route, use <span lang="sv">till</span>: <span lang="sv">Hur kommer jag till stationen?</span>

## Understanding the answer

| Pattern | Meaning |
| --- | --- |
| <span lang="sv">Gå rakt fram.</span> | go straight ahead |
| <span lang="sv">Sväng vänster.</span> / <span lang="sv">Ta vänster.</span> | turn left |
| <span lang="sv">Sväng höger.</span> / <span lang="sv">Ta höger.</span> | turn right |
| <span lang="sv">Gå förbi kyrkan.</span> | go past the church |
| <span lang="sv">Det ligger bredvid apoteket.</span> | it is next to the pharmacy |
| <span lang="sv">Det ligger mittemot stationen.</span> | it is opposite the station |
| <span lang="sv">Det är på vänster sida.</span> | it is on the left-hand side |

## Tiny street exchange

<p lang="sv">
	A: Ursäkta, var ligger biblioteket?
	<br />
	B: Gå rakt fram och sväng höger vid torget.
	<br />
	A: Är det långt härifrån?
	<br />
	B: Nej, det tar fem minuter.
</p>

## Direct comparison

<LanguageComparison title="Where is it located?">
	<p slot="de">Wo ist der Bahnhof?</p>
	<p slot="en">Where is the station?</p>
	<p slot="sv">Var ligger stationen?</p>
</LanguageComparison>

Swedish often uses <span lang="sv">ligger</span> for where buildings and places are located.
The question is not about an object lying down; it is the normal location verb.

<LanguageComparison title="How do I get to it?">
	<p slot="de">Wie komme ich zum Bahnhof?</p>
	<p slot="en">How do I get to the station?</p>
	<p slot="sv">Hur kommer jag till stationen?</p>
</LanguageComparison>
