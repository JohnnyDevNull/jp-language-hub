<KeyTakeaway>
- Start with <Sv>Ursäkta, var ligger …?</Sv> for places and
  <Sv>Hur kommer jag till …?</Sv> for routes.
- Use <Sv>till</Sv> for destination, <Sv>mot</Sv> for direction, and
  <Sv>förbi</Sv> for "past".
- Direction answers are often imperatives:
  <Sv>Gå rakt fram</Sv>, <Sv>sväng vänster</Sv>, <Sv>ta höger</Sv>.
</KeyTakeaway>

This page is for the street moment: you need to stop someone, ask simply, and
recognize the words that tell you where to go next.

For the imperative form itself, use
[Imperative](../../grammar/verb-patterns-voice/imperative/). This page keeps to
the route script.

## Asking the question

| Pattern | Use it when | Register |
| --- | --- | --- |
| <Sv>Ursäkta, var ligger …?</Sv> | asking where a place is | neutral |
| <Sv>Vet du var … ligger?</Sv> | softer: do you know where it is | neutral |
| <Sv>Hur kommer jag till …?</Sv> | asking how to get there | neutral |
| <Sv>Är det långt härifrån?</Sv> | asking whether it is far from here | neutral |
| <Sv>Är det åt rätt håll?</Sv> | checking whether this is the right direction | neutral |
| <Sv>Kan du visa på kartan?</Sv> | asking someone to show it on the map | neutral |

A common Swedish location question is <Sv>Var ligger stationen?</Sv> For the
full question-word pattern, see
[Question words](../../grammar/questions-negation/question-words/). For a
route, use <Sv>till</Sv>: <Sv>Hur kommer jag till stationen?</Sv>

## Understanding the answer

| Pattern | Meaning |
| --- | --- |
| <Sv>Gå rakt fram.</Sv> | go straight ahead |
| <Sv>Sväng vänster.</Sv> / <Sv>Ta vänster.</Sv> | turn left |
| <Sv>Sväng höger.</Sv> / <Sv>Ta höger.</Sv> | turn right |
| <Sv>Gå förbi kyrkan.</Sv> | go past the church |
| <Sv>Det ligger bredvid apoteket.</Sv> | it is next to the pharmacy |
| <Sv>Det ligger mittemot stationen.</Sv> | it is opposite the station |
| <Sv>Det är på vänster sida.</Sv> | it is on the left-hand side |

## Tiny street exchange

<p lang="sv">
	A: Ursäkta, var ligger biblioteket?
	<br />
	B: Gå rakt fram och sväng höger vid torget.
	<br />
	A: Är det långt härifrån?
	<br />
	B: Nej, det tar fem minuter.
</p>

## Direct comparison

<LanguageComparison title="Where is it located?">
	<p slot="de">Wo ist der Bahnhof?</p>
	<p slot="en">Where is the station?</p>
	<p slot="sv">Var ligger stationen?</p>
</LanguageComparison>

Swedish often uses <Sv>ligger</Sv> for where buildings and places are located.
The question is not about an object lying down; it is the normal location verb.

<LanguageComparison title="How do I get to it?">
	<p slot="de">Wie komme ich zum Bahnhof?</p>
	<p slot="en">How do I get to the station?</p>
	<p slot="sv">Hur kommer jag till stationen?</p>
</LanguageComparison>
