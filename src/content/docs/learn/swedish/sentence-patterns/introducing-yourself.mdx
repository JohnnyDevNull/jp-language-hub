<KeyTakeaway>
- Use <span lang="sv">Jag heter ...</span> as the normal first sentence; it means "I am
  called", not literally "I name".
- Use <span lang="sv">kommer från</span> for origin and <span lang="sv">bor i</span> for where you live now.
- Ask back with the same frame: <span lang="sv">Vad heter du?</span>,
  <span lang="sv">Var kommer du ifrån?</span>, <span lang="sv">Vad gör du?</span>
</KeyTakeaway>

This is the smallest useful self-introduction: name, origin, place, one reason
you are here, and one question back.

## Basic introduction moves

| Pattern | Use it for | Example |
| --- | --- | --- |
| <span lang="sv">Hej, jag heter ...</span> | opening with your name | <span lang="sv">Hej, jag heter Philipp.</span> |
| <span lang="sv">Jag kommer från ...</span> | country, city, background | <span lang="sv">Jag kommer från Tyskland.</span> |
| <span lang="sv">Jag bor i ...</span> | where you live now | <span lang="sv">Jag bor i Stockholm.</span> |
| <span lang="sv">Jag jobbar som ...</span> | job role | <span lang="sv">Jag jobbar som utvecklare.</span> |
| <span lang="sv">Jag pluggar ...</span> | subject you study | <span lang="sv">Jag pluggar svenska.</span> |
| <span lang="sv">Jag lär mig svenska.</span> | why you are speaking slowly | <span lang="sv">Jag lär mig svenska.</span> |
| <span lang="sv">Trevligt att träffas.</span> | nice to meet you | <span lang="sv">Trevligt att träffas!</span> |

## Asking back

| Question | What it asks | Natural answer |
| --- | --- | --- |
| <span lang="sv">Vad heter du?</span> | name | <span lang="sv">Jag heter Anna.</span> |
| <span lang="sv">Var kommer du ifrån?</span> | origin | <span lang="sv">Jag kommer från Malmö.</span> |
| <span lang="sv">Var bor du?</span> | current home | <span lang="sv">Jag bor i Uppsala.</span> |
| <span lang="sv">Vad gör du?</span> | work or studies, in context | <span lang="sv">Jag pluggar.</span> |
| <span lang="sv">Hur länge har du bott här?</span> | time living here | <span lang="sv">I två år.</span> |

With cities and countries, <span lang="sv">i</span> is the safe early pattern:
<span lang="sv">i Sverige</span>, <span lang="sv">i Stockholm</span>, <span lang="sv">i Tyskland</span>. Street names and
some institutions often use <span lang="sv">på</span>, but save that for the preposition page.

## Tiny sequence

| Speaker | Swedish |
| --- | --- |
| A | <span lang="sv">Hej, jag heter Anna. Vad heter du?</span> |
| B | <span lang="sv">Jag heter Philipp. Trevligt att träffas.</span> |
| A | <span lang="sv">Trevligt! Var kommer du ifrån?</span> |
| B | <span lang="sv">Jag kommer från Tyskland, men jag bor i Stockholm.</span> |
| A | <span lang="sv">Vad gör du?</span> |
| B | <span lang="sv">Jag jobbar som utvecklare och jag lär mig svenska.</span> |

## Direct comparison

<LanguageComparison title="Name">
	<p slot="de">Ich heiße Philipp.</p>
	<p slot="en">My name is Philipp.</p>
	<p slot="sv">Jag heter Philipp.</p>
</LanguageComparison>

German is the better bridge here: <span lang="de">heißen</span> and
<span lang="sv">heta</span> both behave like "be called". English tempts you toward a noun
phrase, but the everyday Swedish sentence is the verb frame.

<LanguageComparison title="Origin and current home">
	<p slot="de">Ich komme aus Deutschland, aber ich wohne in Stockholm.</p>
	<p slot="en">I am from Germany, but I live in Stockholm.</p>
	<p slot="sv">Jag kommer från Tyskland, men jag bor i Stockholm.</p>
</LanguageComparison>
