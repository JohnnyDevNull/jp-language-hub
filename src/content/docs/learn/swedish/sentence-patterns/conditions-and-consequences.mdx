<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Use these frames when you need to react, negotiate an alternative, warn about a
result, or say what follows. For choosing present, hypothetical, or past
counterfactual forms, use [Conditionals](../../grammar/mood-politeness-reports/conditionals/).

## Expressing a condition

| Pattern | What it does | Register |
| --- | --- | --- |
| <span lang="sv">Om …</span> | plain condition | neutral |
| <span lang="sv">Om … så …</span> | marks the main clause explicitly; common in speech | spoken |
| <span lang="sv">Ifall …</span> | in case, if | neutral |
| <span lang="sv">om … inte …</span> | if not; often unless | neutral |
| <span lang="sv">så länge …</span> | as long as | neutral |
| <span lang="sv">Om jag var du skulle jag …</span> | if I were you | neutral |
| <span lang="sv">Tänk om …</span> | what if, imagine if | spoken |
| <span lang="sv">Vad händer om …?</span> | what happens if | neutral |
| <span lang="sv">i så fall</span> | in that case | neutral |

## Expressing a consequence

| Pattern | What it does | Register |
| --- | --- | --- |
| <span lang="sv">… så …</span> | so, joining result to cause | spoken |
| <span lang="sv">därför</span> | therefore; finite verb follows it | neutral |
| <span lang="sv">annars</span> | otherwise; finite verb follows it | neutral |
| <span lang="sv">Det innebär att …</span> | that means, that entails | formal |
| <span lang="sv">vilket betyder att …</span> | which means that | neutral |
| <span lang="sv">Det leder till att …</span> | that leads to | neutral to formal |
| <span lang="sv">… så att …</span> | so that, marking the result | neutral |

When <span lang="sv">därför</span> or <span lang="sv">annars</span> fills position one, Swedish uses the V2
pattern: <span lang="sv">annars kommer vi för sent</span>. See
[Inversion](../../grammar/sentence-structure/inversion/) for the position rule.

## Direct comparison

<LanguageComparison title="Condition first">
	<p slot="de">Wenn es regnet, bleibe ich zu Hause.</p>
	<p slot="en">If it rains, I'll stay home.</p>
	<p slot="sv">Om det regnar stannar jag hemma.</p>
</LanguageComparison>

German behaves the same way — the fronted clause forces the verb into second
position — so German is the right model here and English the misleading one.

<LanguageComparison title="Unless">
	<p slot="de">Wir gehen raus, wenn es nicht regnet.</p>
	<p slot="en">We'll go out unless it rains.</p>
	<p slot="sv">Vi går ut om det inte regnar.</p>
</LanguageComparison>

<span lang="sv">Om det inte regnar</span> is the plain everyday choice here. Swedish also has
more restrictive or formal alternatives such as <span lang="sv">såvida inte</span>; there is
no single replacement that fits every English use of *unless*.

<LanguageComparison title="Counterfactual">
	<p slot="de">Wenn ich Zeit hätte, würde ich mitkommen.</p>
	<p slot="en">If I had time, I would come along.</p>
	<p slot="sv">Om jag hade tid skulle jag följa med.</p>
</LanguageComparison>

The example is a useful ready-made frame. The grammar behind hypothetical and
past counterfactual choices belongs on the
[Conditionals](../../grammar/mood-politeness-reports/conditionals/) page.

<LanguageComparison title="Otherwise">
	<p slot="de">Beeil dich, sonst kommen wir zu spät.</p>
	<p slot="en">Hurry up, otherwise we'll be late.</p>
	<p slot="sv">Skynda dig, annars kommer vi för sent.</p>
</LanguageComparison>
