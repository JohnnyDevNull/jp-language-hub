<KeyTakeaway>
- Use <Sv>Jag skulle vilja ha ...</Sv> as the safe polite order frame.
- Use <Sv>Kan jag få ...?</Sv> when you ask for one item, a menu, water, or the
  bill.
- Adjust the order with <Sv>med</Sv>, <Sv>utan</Sv>, <Sv>extra</Sv>, and
  <Sv>vid sidan av</Sv>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

This page gives you a usable restaurant or cafe script: ask what exists, order,
adjust, respond to a question, and pay.

## Ordering

| Pattern | Use it for | Example |
| --- | --- | --- |
| <Sv>Jag skulle vilja ha ...</Sv> | polite default order | <Sv>Jag skulle vilja ha en kaffe.</Sv> |
| <Sv>Kan jag få ...?</Sv> | asking for one thing | <Sv>Kan jag få menyn?</Sv> |
| <Sv>Jag tar ...</Sv> | quick choice | <Sv>Jag tar dagens lunch.</Sv> |
| <Sv>Har ni ...?</Sv> | checking availability | <Sv>Har ni något vegetariskt?</Sv> |
| <Sv>Vad rekommenderar du?</Sv> | asking for advice | <Sv>Vad rekommenderar du?</Sv> |
| <Sv>Vad ingår?</Sv> | what is included | <Sv>Vad ingår i dagens lunch?</Sv> |

## Adjusting the order

| Pattern | Use it for | Example |
| --- | --- | --- |
| <Sv>med ...</Sv> | with something | <Sv>med mjölk</Sv> |
| <Sv>utan ...</Sv> | without something | <Sv>utan lök</Sv> |
| <Sv>extra ...</Sv> | extra | <Sv>extra sås</Sv> |
| <Sv>vid sidan av</Sv> | on the side | <Sv>Kan jag få såsen vid sidan av?</Sv> |
| <Sv>att dricka</Sv> | to drink | <Sv>En kaffe att dricka här.</Sv> |
| <Sv>att ta med</Sv> | to go | <Sv>En kaffe att ta med, tack.</Sv> |

## Paying and closing

| Pattern | Use it for | Example |
| --- | --- | --- |
| <Sv>Kan jag få notan?</Sv> | asking for the bill | <Sv>Kan jag få notan?</Sv> |
| <Sv>Kan jag betala med kort?</Sv> | card payment | <Sv>Kan jag betala med kort?</Sv> |
| <Sv>Det var allt, tack.</Sv> | that is all | <Sv>Det var allt, tack.</Sv> |
| <Sv>Tack, det var jättegott.</Sv> | thanking after eating | <Sv>Tack, det var jättegott.</Sv> |

## Tiny dialogue

| Speaker | Swedish |
| --- | --- |
| A | <Sv>Hej! Vad vill du ha?</Sv> |
| B | <Sv>Jag skulle vilja ha en kaffe och en bulle.</Sv> |
| A | <Sv>Vill du ha mjölk i kaffet?</Sv> |
| B | <Sv>Ja tack, lite mjölk. Och kan jag få ett glas vatten?</Sv> |
| A | <Sv>Självklart.</Sv> |
| B | <Sv>Tack. Det var allt.</Sv> |

## Direct comparison

<LanguageComparison title="Polite order">
	<p slot="de">Ich hätte gern einen Kaffee.</p>
	<p slot="en">I would like a coffee.</p>
	<p slot="sv">Jag skulle vilja ha en kaffe.</p>
</LanguageComparison>

This is the safest full frame because it includes the conditional
<Sv>skulle</Sv>, the wanting verb <Sv>vilja</Sv>, and the receiving verb
<Sv>ha</Sv>.

<LanguageComparison title="To go">
	<p slot="de">Einen Kaffee zum Mitnehmen, bitte.</p>
	<p slot="en">A coffee to go, please.</p>
	<p slot="sv">En kaffe att ta med, tack.</p>
</LanguageComparison>

Swedish uses an infinitive phrase: literally "a coffee to take with". Learn
<Sv>att ta med</Sv> as one cafe unit.
