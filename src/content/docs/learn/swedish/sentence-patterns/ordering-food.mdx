<KeyTakeaway>
- Use <span lang="sv">Jag skulle vilja ha ...</span> as the safe polite order frame.
- Use <span lang="sv">Kan jag få ...?</span> when you ask for one item, a menu, water, or the
  bill.
- Adjust the order with <span lang="sv">med</span>, <span lang="sv">utan</span>, <span lang="sv">extra</span>, and
  <span lang="sv">vid sidan av</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

This page gives you a usable restaurant or cafe script: ask what exists, order,
adjust, respond to a question, and pay.

## Ordering

| Pattern | Use it for | Example |
| --- | --- | --- |
| <span lang="sv">Jag skulle vilja ha ...</span> | polite default order | <span lang="sv">Jag skulle vilja ha en kaffe.</span> |
| <span lang="sv">Kan jag få ...?</span> | asking for one thing | <span lang="sv">Kan jag få menyn?</span> |
| <span lang="sv">Jag tar ...</span> | quick choice | <span lang="sv">Jag tar dagens lunch.</span> |
| <span lang="sv">Har ni ...?</span> | checking availability | <span lang="sv">Har ni något vegetariskt?</span> |
| <span lang="sv">Vad rekommenderar du?</span> | asking for advice | <span lang="sv">Vad rekommenderar du?</span> |
| <span lang="sv">Vad ingår?</span> | what is included | <span lang="sv">Vad ingår i dagens lunch?</span> |

## Adjusting the order

| Pattern | Use it for | Example |
| --- | --- | --- |
| <span lang="sv">med ...</span> | with something | <span lang="sv">med mjölk</span> |
| <span lang="sv">utan ...</span> | without something | <span lang="sv">utan lök</span> |
| <span lang="sv">extra ...</span> | extra | <span lang="sv">extra sås</span> |
| <span lang="sv">vid sidan av</span> | on the side | <span lang="sv">Kan jag få såsen vid sidan av?</span> |
| <span lang="sv">att dricka</span> | to drink | <span lang="sv">En kaffe att dricka här.</span> |
| <span lang="sv">att ta med</span> | to go | <span lang="sv">En kaffe att ta med, tack.</span> |

## Paying and closing

| Pattern | Use it for | Example |
| --- | --- | --- |
| <span lang="sv">Kan jag få notan?</span> | asking for the bill | <span lang="sv">Kan jag få notan?</span> |
| <span lang="sv">Kan jag betala med kort?</span> | card payment | <span lang="sv">Kan jag betala med kort?</span> |
| <span lang="sv">Det var allt, tack.</span> | that is all | <span lang="sv">Det var allt, tack.</span> |
| <span lang="sv">Tack, det var jättegott.</span> | thanking after eating | <span lang="sv">Tack, det var jättegott.</span> |

## Tiny dialogue

| Speaker | Swedish |
| --- | --- |
| A | <span lang="sv">Hej! Vad vill du ha?</span> |
| B | <span lang="sv">Jag skulle vilja ha en kaffe och en bulle.</span> |
| A | <span lang="sv">Vill du ha mjölk i kaffet?</span> |
| B | <span lang="sv">Ja tack, lite mjölk. Och kan jag få ett glas vatten?</span> |
| A | <span lang="sv">Självklart.</span> |
| B | <span lang="sv">Tack. Det var allt.</span> |

## Direct comparison

<LanguageComparison title="Polite order">
	<p slot="de">Ich hätte gern einen Kaffee.</p>
	<p slot="en">I would like a coffee.</p>
	<p slot="sv">Jag skulle vilja ha en kaffe.</p>
</LanguageComparison>

This is the safest full frame because it includes the conditional
<span lang="sv">skulle</span>, the wanting verb <span lang="sv">vilja</span>, and the receiving verb
<span lang="sv">ha</span>.

<LanguageComparison title="To go">
	<p slot="de">Einen Kaffee zum Mitnehmen, bitte.</p>
	<p slot="en">A coffee to go, please.</p>
	<p slot="sv">En kaffe att ta med, tack.</p>
</LanguageComparison>

Swedish uses an infinitive phrase: literally "a coffee to take with". Learn
<span lang="sv">att ta med</span> as one cafe unit.
