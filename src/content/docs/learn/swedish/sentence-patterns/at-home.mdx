This page covers the home situation: finding things, saying what you do there,
and making small guest or household requests without building a long sentence.

## Finding things

| Pattern | Use it when | Register |
| --- | --- | --- |
| <span lang="sv">Var är …?</span> | asking where something is | neutral |
| <span lang="sv">Har du sett …?</span> | asking whether someone has seen it | neutral |
| <span lang="sv">Den ligger på bordet.</span> | saying where an item is lying | neutral |
| <span lang="sv">Det står i köket.</span> | saying where something stands or is placed | neutral |
| <span lang="sv">Jag hittar inte …</span> | saying you cannot find something | neutral |
| <span lang="sv">Kan du lägga den på bordet?</span> | asking someone to put it on the table | neutral |

Use <span lang="sv">ligger</span> for many loose objects and <span lang="sv">står</span> for things that
stand upright, are parked, or are placed somewhere as fixtures.

## Home routines and needs

| Pattern | Use it when | Register |
| --- | --- | --- |
| <span lang="sv">Jag är hemma idag.</span> | saying you are at home today | neutral |
| <span lang="sv">Jag går hem nu.</span> | saying you are going home now | neutral |
| <span lang="sv">På morgonen …</span> | talking about morning routines | neutral |
| <span lang="sv">Jag måste städa.</span> | saying you have to clean | neutral |
| <span lang="sv">Kan du hjälpa mig?</span> | asking for help | neutral |
| <span lang="sv">Det är slut på kaffe.</span> | saying something has run out | spoken |

## Guest phrases

| Pattern | Use it when | Register |
| --- | --- | --- |
| <span lang="sv">Kom in!</span> | inviting someone in | spoken |
| <span lang="sv">Känn dig som hemma.</span> | make yourself at home | neutral |
| <span lang="sv">Vill du ha kaffe?</span> | offering coffee | neutral |
| <span lang="sv">Kan jag få lite vatten?</span> | asking for water | neutral |
| <span lang="sv">Var är toaletten?</span> | asking for the bathroom | neutral |

## Tiny home exchange

<p lang="sv">
	A: Var är nycklarna?
	<br />
	B: De ligger på bordet.
	<br />
	A: Tack. Jag går hem nu.
	<br />
	B: Okej, vi ses imorgon!
</p>

## Direct comparison

<LanguageComparison title="At home vs going home">
	<p slot="de">Ich bin zu Hause. / Ich gehe nach Hause.</p>
	<p slot="en">I am at home. / I am going home.</p>
	<p slot="sv">Jag är hemma. / Jag går hem.</p>
</LanguageComparison>

German and English both change the whole phrase. Swedish changes the adverb:
<span lang="sv">hemma</span> is location, <span lang="sv">hem</span> is direction.

<LanguageComparison title="Something has run out">
	<p slot="de">Der Kaffee ist alle.</p>
	<p slot="en">We're out of coffee.</p>
	<p slot="sv">Det är slut på kaffe.</p>
</LanguageComparison>

The Swedish phrase is impersonal: literally "it is finished on coffee". Learn
<span lang="sv">slut på</span> as one household pattern.
