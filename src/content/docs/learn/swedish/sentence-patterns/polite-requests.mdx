<KeyTakeaway>
- <Sv>Kan jag få ...?</Sv> is the default pattern when you ask to receive one
  thing.
- <Sv>Kan du ...?</Sv> asks someone to do something; <Sv>Skulle du kunna ...?</Sv>
  makes the same request softer.
- Put <Sv>tack</Sv> at the end of small service requests:
  <Sv>En kaffe, tack.</Sv>
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Polite Swedish is usually direct but softened by the right frame, tone, and
<Sv>tack</Sv>. You do not need a long apology before every request.

## Asking for one thing

| Pattern | Use it for | Example |
| --- | --- | --- |
| <Sv>Kan jag få ...?</Sv> | can I have, can I get | <Sv>Kan jag få ett kvitto?</Sv> |
| <Sv>Jag skulle vilja ha ...</Sv> | I would like; polite default | <Sv>Jag skulle vilja ha en kaffe.</Sv> |
| <Sv>En ..., tack.</Sv> | short counter request | <Sv>En bulle, tack.</Sv> |
| <Sv>Har ni ...?</Sv> | do you have | <Sv>Har ni havremjölk?</Sv> |
| <Sv>Finns det ...?</Sv> | is there, are there | <Sv>Finns det en toalett här?</Sv> |

## Asking someone to do something

| Pattern | Use it for | Example |
| --- | --- | --- |
| <Sv>Kan du ...?</Sv> | simple request | <Sv>Kan du hjälpa mig?</Sv> |
| <Sv>Skulle du kunna ...?</Sv> | softer request | <Sv>Skulle du kunna skriva ner det?</Sv> |
| <Sv>Kan du säga det igen?</Sv> | repeat something | <Sv>Kan du säga det igen?</Sv> |
| <Sv>Kan du prata lite långsammare?</Sv> | ask for slower speech | <Sv>Kan du prata lite långsammare?</Sv> |
| <Sv>Ursäkta, var ligger ...?</Sv> | ask for a place | <Sv>Ursäkta, var ligger stationen?</Sv> |

## Softening and closing

| Pattern | Use it for | Example |
| --- | --- | --- |
| <Sv>Ursäkta ...</Sv> | get attention | <Sv>Ursäkta, kan du hjälpa mig?</Sv> |
| <Sv>lite</Sv> | soften an amount or degree | <Sv>Kan du prata lite långsammare?</Sv> |
| <Sv>om det går</Sv> | if possible | <Sv>Jag skulle vilja byta tid, om det går.</Sv> |
| <Sv>Tack så mycket.</Sv> | thanks a lot | <Sv>Tack så mycket!</Sv> |
| <Sv>Ingen fara.</Sv> | no problem | <Sv>Ingen fara.</Sv> |

## Tiny sequence

| Speaker | Swedish |
| --- | --- |
| A | <Sv>Ursäkta, kan du hjälpa mig?</Sv> |
| B | <Sv>Ja, absolut.</Sv> |
| A | <Sv>Kan du säga det igen, lite långsammare?</Sv> |
| B | <Sv>Självklart.</Sv> |
| A | <Sv>Tack så mycket.</Sv> |

## Direct comparison

<LanguageComparison title="Can I have?">
	<p slot="de">Kann ich bitte eine Quittung bekommen?</p>
	<p slot="en">Can I have a receipt, please?</p>
	<p slot="sv">Kan jag få ett kvitto?</p>
</LanguageComparison>

<Sv>få</Sv> is the useful service verb here: you are asking to receive
something. A final <Sv>tack</Sv> may be added, but the frame is already polite
in a normal service situation.

<LanguageComparison title="Could you?">
	<p slot="de">Könntest du das bitte aufschreiben?</p>
	<p slot="en">Could you write that down, please?</p>
	<p slot="sv">Skulle du kunna skriva ner det?</p>
</LanguageComparison>

Swedish uses <Sv>skulle</Sv> + <Sv>kunna</Sv> to soften the request, much like
German and English use a conditional modal.
