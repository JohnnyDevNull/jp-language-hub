<KeyTakeaway>
- <span lang="sv">Kan jag få ...?</span> is the default pattern when you ask to receive one
  thing.
- <span lang="sv">Kan du ...?</span> asks someone to do something; <span lang="sv">Skulle du kunna ...?</span>
  makes the same request softer.
- Put <span lang="sv">tack</span> at the end of small service requests:
  <span lang="sv">En kaffe, tack.</span>
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Polite Swedish is usually direct but softened by the right frame, tone, and
<span lang="sv">tack</span>. You do not need a long apology before every request.

## Asking for one thing

| Pattern | Use it for | Example |
| --- | --- | --- |
| <span lang="sv">Kan jag få ...?</span> | can I have, can I get | <span lang="sv">Kan jag få ett kvitto?</span> |
| <span lang="sv">Jag skulle vilja ha ...</span> | I would like; polite default | <span lang="sv">Jag skulle vilja ha en kaffe.</span> |
| <span lang="sv">En ..., tack.</span> | short counter request | <span lang="sv">En bulle, tack.</span> |
| <span lang="sv">Har ni ...?</span> | do you have | <span lang="sv">Har ni havremjölk?</span> |
| <span lang="sv">Finns det ...?</span> | is there, are there | <span lang="sv">Finns det en toalett här?</span> |

## Asking someone to do something

| Pattern | Use it for | Example |
| --- | --- | --- |
| <span lang="sv">Kan du ...?</span> | simple request | <span lang="sv">Kan du hjälpa mig?</span> |
| <span lang="sv">Skulle du kunna ...?</span> | softer request | <span lang="sv">Skulle du kunna skriva ner det?</span> |
| <span lang="sv">Kan du säga det igen?</span> | repeat something | <span lang="sv">Kan du säga det igen?</span> |
| <span lang="sv">Kan du prata lite långsammare?</span> | ask for slower speech | <span lang="sv">Kan du prata lite långsammare?</span> |
| <span lang="sv">Ursäkta, var ligger ...?</span> | ask for a place | <span lang="sv">Ursäkta, var ligger stationen?</span> |

## Softening and closing

| Pattern | Use it for | Example |
| --- | --- | --- |
| <span lang="sv">Ursäkta ...</span> | get attention | <span lang="sv">Ursäkta, kan du hjälpa mig?</span> |
| <span lang="sv">lite</span> | soften an amount or degree | <span lang="sv">Kan du prata lite långsammare?</span> |
| <span lang="sv">om det går</span> | if possible | <span lang="sv">Jag skulle vilja byta tid, om det går.</span> |
| <span lang="sv">Tack så mycket.</span> | thanks a lot | <span lang="sv">Tack så mycket!</span> |
| <span lang="sv">Ingen fara.</span> | no problem | <span lang="sv">Ingen fara.</span> |

## Tiny sequence

| Speaker | Swedish |
| --- | --- |
| A | <span lang="sv">Ursäkta, kan du hjälpa mig?</span> |
| B | <span lang="sv">Ja, absolut.</span> |
| A | <span lang="sv">Kan du säga det igen, lite långsammare?</span> |
| B | <span lang="sv">Självklart.</span> |
| A | <span lang="sv">Tack så mycket.</span> |

## Direct comparison

<LanguageComparison title="Can I have?">
	<p slot="de">Kann ich bitte eine Quittung bekommen?</p>
	<p slot="en">Can I have a receipt, please?</p>
	<p slot="sv">Kan jag få ett kvitto?</p>
</LanguageComparison>

<span lang="sv">få</span> is the useful service verb here: you are asking to receive
something. A final <span lang="sv">tack</span> may be added, but the frame is already polite
in a normal service situation.

<LanguageComparison title="Could you?">
	<p slot="de">Könntest du das bitte aufschreiben?</p>
	<p slot="en">Could you write that down, please?</p>
	<p slot="sv">Skulle du kunna skriva ner det?</p>
</LanguageComparison>

Swedish uses <span lang="sv">skulle</span> + <span lang="sv">kunna</span> to soften the request, much like
German and English use a conditional modal.
