<KeyTakeaway>
- Use <span lang="sv">Jag vill åka till …</span> for destination and
  <span lang="sv">Vilken buss går till …?</span> to find the right line.
- Use <span lang="sv">När går …?</span> for scheduled departures and
  <span lang="sv">Är tåget försenat?</span> for delays.
- Travel Swedish uses <span lang="sv">till</span> for destination but often <span lang="sv">på</span> for
  being on a bus, train, or platform.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

The useful travel phrases are short because the situation is noisy. Build the
sentence around the destination, the departure time, and whether something has
changed.

## Finding the right connection

| Pattern | Use it when | Register |
| --- | --- | --- |
| <span lang="sv">Jag vill åka till …</span> | saying where you want to go | neutral |
| <span lang="sv">Vilken buss går till …?</span> | asking which bus goes there | neutral |
| <span lang="sv">Går den här bussen till …?</span> | checking this bus | neutral |
| <span lang="sv">Varifrån går tåget?</span> | asking where the train leaves from | neutral |
| <span lang="sv">Vilken perrong?</span> | asking which platform | spoken |
| <span lang="sv">Måste jag byta?</span> | asking whether you need to change | neutral |

<span lang="sv">åka</span> is the general travel-by-vehicle verb. Use <span lang="sv">gå</span> for a
scheduled service: <span lang="sv">När går tåget?</span>

## Tickets and departures

| Pattern | Use it when | Register |
| --- | --- | --- |
| <span lang="sv">En biljett till …, tack.</span> | buying one ticket | neutral |
| <span lang="sv">En enkelbiljett, tack.</span> | one single ticket | neutral |
| <span lang="sv">En tur och retur, tack.</span> | a return ticket | neutral |
| <span lang="sv">När går nästa tåg?</span> | asking for the next train | neutral |
| <span lang="sv">När kommer bussen?</span> | asking when the bus arrives | neutral |
| <span lang="sv">Är tåget försenat?</span> | asking whether the train is delayed | neutral |

## Tiny station sequence

<p lang="sv">
	A: Hej, en biljett till Uppsala, tack.
	<br />
	B: Enkel eller tur och retur?
	<br />
	A: Enkel, tack. När går nästa tåg?
	<br />
	B: Det går klockan halv tre från perrong fyra.
</p>

## Direct comparison

<LanguageComparison title="Wanting to travel somewhere">
	<p slot="de">Ich möchte nach Uppsala fahren.</p>
	<p slot="en">I want to go to Uppsala.</p>
	<p slot="sv">Jag vill åka till Uppsala.</p>
</LanguageComparison>

Swedish does not use one verb for every kind of "go". <span lang="sv">åka</span> means going
by vehicle; <span lang="sv">gå</span> can mean walking or a scheduled departure.

<LanguageComparison title="Scheduled departure">
	<p slot="de">Wann fährt der nächste Zug?</p>
	<p slot="en">When does the next train leave?</p>
	<p slot="sv">När går nästa tåg?</p>
</LanguageComparison>
