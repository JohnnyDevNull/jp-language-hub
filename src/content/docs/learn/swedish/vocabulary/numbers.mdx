Swedish numbers are practical vocabulary for prices, dates, time, addresses,
and quantities. Once the first twenty are secure, most everyday forms follow a
predictable pattern.

## Use this now

| If you need to… | Use |
| --- | --- |
| count from 0 to 20 | memorize the base list |
| build 21, 42, or 156 | ten before unit, no <span lang="sv">och</span>: <span lang="sv">tjugoett</span>, <span lang="sv">fyrtiotvå</span>, <span lang="sv">hundrafemtiosex</span> |
| count one noun by itself | choose <span lang="sv">en</span> or <span lang="sv">ett</span> by noun gender |
| build 21, 31, 41 before a noun | normally use final <span lang="sv">-en</span>: <span lang="sv">trettioen fartyg</span> |
| use conventional t-word number contexts | use <span lang="sv">-ett</span>: <span lang="sv">tjugoett år</span>, <span lang="sv">nummer tjugoett</span>, <span lang="sv">tjugoett öre</span> |
| write dates | use the ordinal after <span lang="sv">den</span>: <span lang="sv">den tredje maj</span> |
| write decimals | use a comma: <span lang="sv">3,5</span> |

## Cardinal numbers

| Number | Swedish | Number | Swedish |
| --- | --- | --- | --- |
| 0 | <span lang="sv">noll</span> | 11 | <span lang="sv">elva</span> |
| 1 | <span lang="sv">en / ett</span> | 12 | <span lang="sv">tolv</span> |
| 2 | <span lang="sv">två</span> | 13 | <span lang="sv">tretton</span> |
| 3 | <span lang="sv">tre</span> | 14 | <span lang="sv">fjorton</span> |
| 4 | <span lang="sv">fyra</span> | 15 | <span lang="sv">femton</span> |
| 5 | <span lang="sv">fem</span> | 16 | <span lang="sv">sexton</span> |
| 6 | <span lang="sv">sex</span> | 17 | <span lang="sv">sjutton</span> |
| 7 | <span lang="sv">sju</span> | 18 | <span lang="sv">arton</span> |
| 8 | <span lang="sv">åtta</span> | 19 | <span lang="sv">nitton</span> |
| 9 | <span lang="sv">nio</span> | 20 | <span lang="sv">tjugo</span> |
| 10 | <span lang="sv">tio</span> | | |

The tens are formed with <span lang="sv">-tio</span>:

| Number | Swedish | Number | Swedish |
| --- | --- | --- | --- |
| 30 | <span lang="sv">trettio</span> | 70 | <span lang="sv">sjuttio</span> |
| 40 | <span lang="sv">fyrtio</span> | 80 | <span lang="sv">åttio</span> |
| 50 | <span lang="sv">femtio</span> | 90 | <span lang="sv">nittio</span> |
| 60 | <span lang="sv">sextio</span> | 100 | <span lang="sv">hundra</span> |

Note the spelling <span lang="sv">fyrtio</span> for 40, which does not follow
<span lang="sv">fyra</span>. Several number words also contain the sj- and
tj-sounds: <span lang="sv">sju</span>, <span lang="sv">sjutton</span>,
<span lang="sv">sjuttio</span>, <span lang="sv">tjugo</span>. See
[pronunciation basics](../../pronunciation-basics/).

## Building larger numbers

Everyday compound numbers are assembled from the largest part down. Two-part
and three-part compounds are normally written as one word:

- 21 — <span lang="sv">tjugoett</span>
- 42 — <span lang="sv">fyrtiotvå</span>
- 156 — <span lang="sv">hundrafemtiosex</span>
- 3 000 — <span lang="sv">tretusen</span>

<RuleBox title="Swedish does not reverse the digits">
	German says <span lang="de">einundzwanzig</span>, with the unit first.
	Swedish, like English, says the ten first:
	<span lang="sv">tjugoett</span> — *twenty-one*. There is no
	<span lang="sv">och</span> between the parts.
</RuleBox>

<span lang="sv">Hundra</span> and <span lang="sv">tusen</span> can stand alone
or take <span lang="sv">ett</span> for emphasis or clarity:
<span lang="sv">hundra kronor</span> or
<span lang="sv">etthundra kronor</span>.

## en or ett for "one"

By itself, the number 1 agrees with the gender of the noun it counts, exactly
like the indefinite article:

- <span lang="sv">en bil</span> — one car
- <span lang="sv">ett hus</span> — one house

After a ten, however, the final 1 is normally <span lang="sv">-en</span>, even before many
ett-words:

- <span lang="sv">tjugoen kronor</span> — 21 kronor
- <span lang="sv">trettioen fartyg</span> — 31 vessels, even though <span lang="sv">ett fartyg</span> is
  an ett-word

Use <span lang="sv">-ett</span> in conventional t-word number contexts, especially
<span lang="sv">år</span>, <span lang="sv">nummer</span>, <span lang="sv">öre</span>, and clock readings:

- <span lang="sv">tjugoett år</span>
- <span lang="sv">nummer tjugoett</span>
- <span lang="sv">tjugoett öre</span>
- <span lang="sv">klockan tjugoett</span>

Every other number is uninflected. See
[en / ett](../../grammar/nouns-articles/en-ett/) for noun gender.

## Ordinal numbers

| Number | Swedish | Number | Swedish |
| --- | --- | --- | --- |
| 1st | <span lang="sv">första</span> | 11th | <span lang="sv">elfte</span> |
| 2nd | <span lang="sv">andra</span> | 12th | <span lang="sv">tolfte</span> |
| 3rd | <span lang="sv">tredje</span> | 13th | <span lang="sv">trettonde</span> |
| 4th | <span lang="sv">fjärde</span> | 14th | <span lang="sv">fjortonde</span> |
| 5th | <span lang="sv">femte</span> | 15th | <span lang="sv">femtonde</span> |
| 6th | <span lang="sv">sjätte</span> | 16th | <span lang="sv">sextonde</span> |
| 7th | <span lang="sv">sjunde</span> | 17th | <span lang="sv">sjuttonde</span> |
| 8th | <span lang="sv">åttonde</span> | 18th | <span lang="sv">artonde</span> |
| 9th | <span lang="sv">nionde</span> | 19th | <span lang="sv">nittonde</span> |
| 10th | <span lang="sv">tionde</span> | 20th | <span lang="sv">tjugonde</span> |

The first twelve are worth memorizing. From 13 to 19, Swedish usually adds
<span lang="sv">-de</span> to the cardinal number:
<span lang="sv">trettonde</span>, <span lang="sv">fjortonde</span>,
<span lang="sv">nittonde</span>. Full tens have their own forms, such as
<span lang="sv">tjugo → tjugonde</span> and
<span lang="sv">trettio → trettionde</span>.

In a compound ordinal, **only the last element** becomes an ordinal. If the
final element is 1 or 2, use <span lang="sv">första</span> or <span lang="sv">andra</span>:

- 21st — <span lang="sv">tjugoförsta</span>
- 42nd — <span lang="sv">fyrtioandra</span>
- 100th — <span lang="sv">hundrade</span>

## Ordinals in dates and writing

Ordinals normally follow <span lang="sv">den</span>:

- <span lang="sv">Vi ses den första maj.</span> — *We will meet on 1 May.*
- <span lang="sv">Det är hennes tredje bok.</span> — *It is her third book.*

Written as digits, Swedish marks the ordinal with a colon plus the ending:
<span lang="sv">1:a</span> and <span lang="sv">2:a</span> for the forms in
<span lang="sv">-a</span>, and <span lang="sv">3:e</span>,
<span lang="sv">4:e</span>, <span lang="sv">24:e</span> for the rest.

## Millions, billions, and decimals

<span lang="sv">Miljon</span> and <span lang="sv">miljard</span> are nouns:
they take an article and a plural.

| Value | Swedish | Plural |
| --- | --- | --- |
| 10⁶ | <span lang="sv">en miljon</span> | <span lang="sv">två miljoner</span> |
| 10⁹ | <span lang="sv">en miljard</span> | <span lang="sv">två miljarder</span> |
| 10¹² | <span lang="sv">en biljon</span> | <span lang="sv">två biljoner</span> |

<MistakeBox title="A dangerous false friend">
Swedish <span lang="sv">en biljon</span> is 10¹², not a billion. English
*billion* is <span lang="sv">en miljard</span>. Swedish counts the way German
does: <span lang="de">Milliarde</span> → <span lang="sv">miljard</span>,
<span lang="de">Billion</span> → <span lang="sv">biljon</span>.
</MistakeBox>

Like German, Swedish uses a **comma** as the decimal separator and a space to
group thousands: <span lang="sv">3,5</span> is read
<span lang="sv">tre komma fem</span>, and 10 000 is written with a space.

<MistakeBox title="Common mistakes">
	- ❌ <span lang="sv">ettochtjugo</span> — German digit order
	  ✅ <span lang="sv">tjugoett</span>
	- ❌ <span lang="sv">tjugo och ett</span>
	  ✅ <span lang="sv">tjugoett</span>
	- ❌ <span lang="sv">tjugoett kronor</span>
	  ✅ <span lang="sv">tjugoen kronor</span>
	- ❌ <span lang="sv">trettioett fartyg</span>
	  ✅ <span lang="sv">trettioen fartyg</span>
	- ❌ <span lang="sv">den 3:a maj</span>
	  ✅ <span lang="sv">den 3:e maj</span>
	- Do not make both parts of a compound ordinal an ordinal:
	  <span lang="sv">❌ fyrtiondeandra</span>,
	  <span lang="sv">✅ fyrtioandra</span>.
</MistakeBox>

<MemoryTip>
Drill the numbers you actually need first: prices, house numbers, years, and
your own phone number. Say them aloud in Swedish rhythm —
<span lang="sv">tjugoett, tjugotvå, tjugotre</span> — so the ten-before-unit
order becomes automatic instead of translated.
</MemoryTip>
