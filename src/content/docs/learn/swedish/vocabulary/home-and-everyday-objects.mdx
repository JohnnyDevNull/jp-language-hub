<KeyTakeaway>
- Home vocabulary is a good place to practise <span lang="sv">en</span>, <span lang="sv">ett</span>, and
  plural forms.
- Use <span lang="sv">i</span> for rooms and enclosed places: <span lang="sv">i köket</span>.
- Use <span lang="sv">på</span> for many surfaces and home activities: <span lang="sv">på bordet</span>,
  <span lang="sv">på jobbet</span>.
</KeyTakeaway>

Use this page to name rooms and ordinary objects, then put them into short
sentences about where something is.

## Rooms

| Swedish | English |
| --- | --- |
| <span lang="sv">ett rum, rum</span> | room |
| <span lang="sv">ett kök, kök</span> | kitchen |
| <span lang="sv">ett badrum, badrum</span> | bathroom |
| <span lang="sv">ett sovrum, sovrum</span> | bedroom |
| <span lang="sv">ett vardagsrum, vardagsrum</span> | living room |
| <span lang="sv">en hall, hallar</span> | hallway |

## Everyday objects

| Swedish | English |
| --- | --- |
| <span lang="sv">ett bord, bord</span> | table |
| <span lang="sv">en stol, stolar</span> | chair |
| <span lang="sv">en säng, sängar</span> | bed |
| <span lang="sv">en dörr, dörrar</span> | door |
| <span lang="sv">ett fönster, fönster</span> | window |
| <span lang="sv">en lampa, lampor</span> | lamp |
| <span lang="sv">en nyckel, nycklar</span> | key |
| <span lang="sv">en väska, väskor</span> | bag |

## Location frames

| Need | Swedish frame |
| --- | --- |
| say where something is | <span lang="sv">Väskan ligger i hallen.</span> |
| say something is on a surface | <span lang="sv">Nyckeln ligger på bordet.</span> |
| ask where something is | <span lang="sv">Var är nyckeln?</span> |
| say a room has something | <span lang="sv">Det finns ett bord i köket.</span> |
| say you are at home | <span lang="sv">Jag är hemma.</span> |

The definite form often appears naturally when the object is known:
<span lang="sv">nyckeln</span>, <span lang="sv">väskan</span>, <span lang="sv">bordet</span>.
