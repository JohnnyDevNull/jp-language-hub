<KeyTakeaway>
- Home vocabulary is a good place to practise <Sv>en</Sv>, <Sv>ett</Sv>, and
  plural forms.
- Use <Sv>i</Sv> for rooms and enclosed places: <Sv>i köket</Sv>.
- Use <Sv>på</Sv> for many surfaces and home activities: <Sv>på bordet</Sv>,
  <Sv>på jobbet</Sv>.
</KeyTakeaway>

Use this page to name rooms and ordinary objects, then put them into short
sentences about where something is.

## Rooms

| Swedish | English |
| --- | --- |
| <Sv>ett rum, rum</Sv> | room |
| <Sv>ett kök, kök</Sv> | kitchen |
| <Sv>ett badrum, badrum</Sv> | bathroom |
| <Sv>ett sovrum, sovrum</Sv> | bedroom |
| <Sv>ett vardagsrum, vardagsrum</Sv> | living room |
| <Sv>en hall, hallar</Sv> | hallway |

## Everyday objects

| Swedish | English |
| --- | --- |
| <Sv>ett bord, bord</Sv> | table |
| <Sv>en stol, stolar</Sv> | chair |
| <Sv>en säng, sängar</Sv> | bed |
| <Sv>en dörr, dörrar</Sv> | door |
| <Sv>ett fönster, fönster</Sv> | window |
| <Sv>en lampa, lampor</Sv> | lamp |
| <Sv>en nyckel, nycklar</Sv> | key |
| <Sv>en väska, väskor</Sv> | bag |

## Location frames

| Need | Swedish frame |
| --- | --- |
| say where something is | <Sv>Väskan ligger i hallen.</Sv> |
| say something is on a surface | <Sv>Nyckeln ligger på bordet.</Sv> |
| ask where something is | <Sv>Var är nyckeln?</Sv> |
| say a room has something | <Sv>Det finns ett bord i köket.</Sv> |
| say you are at home | <Sv>Jag är hemma.</Sv> |

The definite form often appears naturally when the object is known:
<Sv>nyckeln</Sv>, <Sv>väskan</Sv>, <Sv>bordet</Sv>.
