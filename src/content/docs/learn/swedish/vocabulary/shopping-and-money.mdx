Use this page when you need to buy one thing, ask the price, or understand the
basic checkout words.

## Core words

| Use | Swedish | English |
| --- | --- | --- |
| place | <span lang="sv">en affär, affärer</span> | shop |
| place | <span lang="sv">en butik, butiker</span> | store |
| object | <span lang="sv">en vara, varor</span> | item, product |
| object | <span lang="sv">ett kvitto, kvitton</span> | receipt |
| money | <span lang="sv">ett pris, priser</span> | price |
| money | <span lang="sv">en krona, kronor</span> | krona |
| payment | <span lang="sv">ett kort, kort</span> | card |
| payment | <span lang="sv">kontanter</span> | cash |

## Shop frames

| Need | Swedish frame |
| --- | --- |
| ask the price | <span lang="sv">Vad kostar den?</span> |
| ask about a neuter thing | <span lang="sv">Vad kostar det här?</span> |
| say you want this one | <span lang="sv">Jag tar den här.</span> |
| ask for help | <span lang="sv">Kan du hjälpa mig?</span> |
| pay by card | <span lang="sv">Jag betalar med kort.</span> |
| ask for a receipt | <span lang="sv">Kan jag få kvitto?</span> |

## Price words

| Swedish | English |
| --- | --- |
| <span lang="sv">billig</span> | cheap |
| <span lang="sv">dyr</span> | expensive |
| <span lang="sv">rea</span> | sale |
| <span lang="sv">rabatt</span> | discount |
| <span lang="sv">öppet</span> | open |
| <span lang="sv">stängt</span> | closed |

With prices, Swedish normally says the number plus <span lang="sv">kronor</span>:
<span lang="sv">Det kostar femtio kronor.</span>
