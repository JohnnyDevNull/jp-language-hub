- Prices use <Sv>kostar</Sv>: <Sv>Vad kostar den?</Sv>

Use this page when you need to buy one thing, ask the price, or understand the
basic checkout words.

## Core words

| Use | Swedish | English |
| --- | --- | --- |
| place | <Sv>en affär, affärer</Sv> | shop |
| place | <Sv>en butik, butiker</Sv> | store |
| object | <Sv>en vara, varor</Sv> | item, product |
| object | <Sv>ett kvitto, kvitton</Sv> | receipt |
| money | <Sv>ett pris, priser</Sv> | price |
| money | <Sv>en krona, kronor</Sv> | krona |
| payment | <Sv>ett kort, kort</Sv> | card |
| payment | <Sv>kontanter</Sv> | cash |

## Shop frames

| Need | Swedish frame |
| --- | --- |
| ask the price | <Sv>Vad kostar den?</Sv> |
| ask about a neuter thing | <Sv>Vad kostar det här?</Sv> |
| say you want this one | <Sv>Jag tar den här.</Sv> |
| ask for help | <Sv>Kan du hjälpa mig?</Sv> |
| pay by card | <Sv>Jag betalar med kort.</Sv> |
| ask for a receipt | <Sv>Kan jag få kvitto?</Sv> |

## Price words

| Swedish | English |
| --- | --- |
| <Sv>billig</Sv> | cheap |
| <Sv>dyr</Sv> | expensive |
| <Sv>rea</Sv> | sale |
| <Sv>rabatt</Sv> | discount |
| <Sv>öppet</Sv> | open |
| <Sv>stängt</Sv> | closed |

With prices, Swedish normally says the number plus <Sv>kronor</Sv>:
<Sv>Det kostar femtio kronor.</Sv>
