export const requireEntry = async (id) => {
	const entry = await getEntry('vocabulary', id);
	if (!entry) {
		throw new Error(`Missing required vocabulary entry: ${id}`);
	}
	return entry.data;
};

export const car = await requireEntry('sv-bil');
export const apple = await requireEntry('sv-apple');

export const starterIds = [

	'sv-tid',
	'sv-klocka',
	'sv-van',
	'sv-stad',
	'sv-hund',
	'sv-hus',
	'sv-barn',
	'sv-bord',
];

export const allNouns = await getCollection('vocabulary');
export const starters = starterIds.map((id) => {
	const entry = allNouns.find((candidate) => candidate.id === id);
	if (!entry) {
		throw new Error(`Missing required vocabulary entry: ${id}`);
	}
	return entry.data;
});

<KeyTakeaway>
- Record a Swedish noun with its article, never as a bare translation pair:
  <Sv>en bil</Sv>, not just <Sv>bil</Sv> = "car".
- The article alone is not enough. Learn the four forms together —
  indefinite and definite singular, indefinite and definite plural.
- The plural ending follows from the lemma's shape, so learning it once per
  word is cheaper than guessing it every time you speak.
</KeyTakeaway>

Most of the work in Swedish vocabulary is not the meaning of a word, it is its
gender and its plural. Both are unpredictable from German, so they belong in the
entry from the start.

## Core rule

> A usable noun entry holds five things: the lemma, the gender
> (<Sv>en</Sv> or <Sv>ett</Sv>), the definite singular, the indefinite plural
> and the definite plural.

<Sv>Ett hus</Sv> is neuter in Swedish and neuter in German, but <Sv>ett bord</Sv>
is an <Sv>ett</Sv>-word while German <span lang="de">der Tisch</span> is
masculine. Copying the German gender fails often enough that it cannot be a
strategy.

## Starter words

A small set of everyday nouns, with the forms rather than the translation only.
Each one comes from the same entries as the cards above.

				<td lang="en">{noun.translations?.en}</td>
				<td lang="sv">{noun.morphology.definiteSingular}</td>
				<td lang="sv">{noun.morphology.indefinitePlural}</td>
				<td lang="sv">{noun.morphology.definitePlural}</td>
			</tr>
		))}
	</tbody>
</table>

Read the plural column downwards and the patterns appear on their own:
<Sv>-ar</Sv> and <Sv>-or</Sv> and <Sv>-er</Sv> for <Sv>en</Sv>-words, and no
ending at all for many one-syllable <Sv>ett</Sv>-words such as <Sv>hus</Sv>,
<Sv>barn</Sv> and <Sv>bord</Sv>.
