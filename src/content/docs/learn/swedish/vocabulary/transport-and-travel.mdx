<KeyTakeaway>
- Use <span lang="sv">till</span> for the destination and <span lang="sv">mot</span> for the route or sign.
- Public transport often uses <span lang="sv">på</span>: <span lang="sv">på bussen</span>,
  <span lang="sv">på tåget</span>.
- Store ticket words with the trip type: <span lang="sv">en enkelbiljett</span>,
  <span lang="sv">en tur och retur</span>.
</KeyTakeaway>

This page gives you the words needed to find a route, buy or mention a ticket,
and ask when something leaves.

## Transport words

| Use | Swedish | English |
| --- | --- | --- |
| vehicle | <span lang="sv">en buss, bussar</span> | bus |
| vehicle | <span lang="sv">ett tåg, tåg</span> | train |
| system | <span lang="sv">tunnelbanan</span> | the metro |
| vehicle | <span lang="sv">en spårvagn, spårvagnar</span> | tram |
| place | <span lang="sv">en hållplats, hållplatser</span> | stop |
| place | <span lang="sv">en station, stationer</span> | station |
| ticket | <span lang="sv">en biljett, biljetter</span> | ticket |
| time | <span lang="sv">en avgång, avgångar</span> | departure |

## Travel frames

| Need | Swedish frame |
| --- | --- |
| ask where a bus goes | <span lang="sv">Går den här bussen till centrum?</span> |
| ask when it leaves | <span lang="sv">När går tåget?</span> |
| say your destination | <span lang="sv">Jag ska till Malmö.</span> |
| ask for the stop | <span lang="sv">Var är hållplatsen?</span> |
| read the sign | <span lang="sv">bussen mot centrum</span> |
| buy a ticket | <span lang="sv">En biljett till Lund, tack.</span> |

## Direction words

| Swedish | English |
| --- | --- |
| <span lang="sv">till</span> | to, destination |
| <span lang="sv">från</span> | from |
| <span lang="sv">mot</span> | towards, route sign |
| <span lang="sv">nästa</span> | next |
| <span lang="sv">sista</span> | last |
| <span lang="sv">här</span> | here |
| <span lang="sv">där</span> | there |

## Tiny route

<p lang="sv">A: Ursäkta, går den här bussen till stationen?</p>
<p lang="sv">B: Nej, ta buss 5 mot centrum.</p>
<p lang="sv">A: Tack! Var är hållplatsen?</p>
<p lang="sv">B: Där borta, vid apoteket.</p>
