<KeyTakeaway>
- Use <Sv>till</Sv> for the destination and <Sv>mot</Sv> for the route or sign.
- Public transport often uses <Sv>på</Sv>: <Sv>på bussen</Sv>,
  <Sv>på tåget</Sv>.
- Store ticket words with the trip type: <Sv>en enkelbiljett</Sv>,
  <Sv>en tur och retur</Sv>.
</KeyTakeaway>

This page gives you the words needed to find a route, buy or mention a ticket,
and ask when something leaves.

## Transport words

| Use | Swedish | English |
| --- | --- | --- |
| vehicle | <Sv>en buss, bussar</Sv> | bus |
| vehicle | <Sv>ett tåg, tåg</Sv> | train |
| system | <Sv>tunnelbanan</Sv> | the metro |
| vehicle | <Sv>en spårvagn, spårvagnar</Sv> | tram |
| place | <Sv>en hållplats, hållplatser</Sv> | stop |
| place | <Sv>en station, stationer</Sv> | station |
| ticket | <Sv>en biljett, biljetter</Sv> | ticket |
| time | <Sv>en avgång, avgångar</Sv> | departure |

## Travel frames

| Need | Swedish frame |
| --- | --- |
| ask where a bus goes | <Sv>Går den här bussen till centrum?</Sv> |
| ask when it leaves | <Sv>När går tåget?</Sv> |
| say your destination | <Sv>Jag ska till Malmö.</Sv> |
| ask for the stop | <Sv>Var är hållplatsen?</Sv> |
| read the sign | <Sv>bussen mot centrum</Sv> |
| buy a ticket | <Sv>En biljett till Lund, tack.</Sv> |

## Direction words

| Swedish | English |
| --- | --- |
| <Sv>till</Sv> | to, destination |
| <Sv>från</Sv> | from |
| <Sv>mot</Sv> | towards, route sign |
| <Sv>nästa</Sv> | next |
| <Sv>sista</Sv> | last |
| <Sv>här</Sv> | here |
| <Sv>där</Sv> | there |

## Tiny route

<p lang="sv">A: Ursäkta, går den här bussen till stationen?</p>
<p lang="sv">B: Nej, ta buss 5 mot centrum.</p>
<p lang="sv">A: Tack! Var är hållplatsen?</p>
<p lang="sv">B: Där borta, vid apoteket.</p>
