<KeyTakeaway>
- The present tense does not change by person: <span lang="sv">jag jobbar</span>,
  <span lang="sv">vi jobbar</span>.
- Time-first routine sentences reuse the V2 pattern:
  <span lang="sv">På morgonen dricker jag kaffe.</span>
- Store routines as whole frames: <span lang="sv">gå upp</span>, <span lang="sv">gå och lägga sig</span>.
</KeyTakeaway>

Use this page to talk about what usually happens in a day. The words are simple,
but they practise the present tense and common time expressions. For the word
order behind time-first sentences, see
[V2 rule](../../grammar/sentence-structure/v2/).

## Routine verbs

| Swedish | English |
| --- | --- |
| <span lang="sv">gå upp</span> | get up |
| <span lang="sv">äta frukost</span> | eat breakfast |
| <span lang="sv">dricka kaffe</span> | drink coffee |
| <span lang="sv">gå till jobbet</span> | go to work |
| <span lang="sv">jobba</span> | work |
| <span lang="sv">plugga</span> | study |
| <span lang="sv">laga mat</span> | cook |
| <span lang="sv">titta på tv</span> | watch TV |
| <span lang="sv">läsa</span> | read |
| <span lang="sv">gå och lägga sig</span> | go to bed |

## Time words

| Swedish | English |
| --- | --- |
| <span lang="sv">på morgonen</span> | in the morning |
| <span lang="sv">på förmiddagen</span> | in the late morning |
| <span lang="sv">på eftermiddagen</span> | in the afternoon |
| <span lang="sv">på kvällen</span> | in the evening |
| <span lang="sv">på natten</span> | at night |
| <span lang="sv">varje dag</span> | every day |
| <span lang="sv">ofta</span> | often |
| <span lang="sv">ibland</span> | sometimes |

## Daily frames

| Need | Swedish frame |
| --- | --- |
| say what you do | <span lang="sv">Jag dricker kaffe på morgonen.</span> |
| put time first | <span lang="sv">På morgonen dricker jag kaffe.</span> |
| say when you start | <span lang="sv">Jag börjar klockan åtta.</span> |
| say how often | <span lang="sv">Jag tränar ofta.</span> |
| ask about habit | <span lang="sv">Vad gör du på kvällen?</span> |

## Tiny routine

<p lang="sv">På morgonen går jag upp klockan sju.</p>
<p lang="sv">Jag äter frukost och dricker kaffe.</p>
<p lang="sv">Sedan går jag till jobbet.</p>
<p lang="sv">På kvällen lagar jag mat och läser.</p>
