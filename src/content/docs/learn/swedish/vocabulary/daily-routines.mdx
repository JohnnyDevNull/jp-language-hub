<KeyTakeaway>
- The present tense does not change by person: <Sv>jag jobbar</Sv>,
  <Sv>vi jobbar</Sv>.
- Time-first routine sentences reuse the V2 pattern:
  <Sv>På morgonen dricker jag kaffe.</Sv>
- Store routines as whole frames: <Sv>gå upp</Sv>, <Sv>gå och lägga sig</Sv>.
</KeyTakeaway>

Use this page to talk about what usually happens in a day. The words are simple,
but they practise the present tense and common time expressions. For the word
order behind time-first sentences, see
[V2 rule](../../grammar/sentence-structure/v2/).

## Routine verbs

| Swedish | English |
| --- | --- |
| <Sv>gå upp</Sv> | get up |
| <Sv>äta frukost</Sv> | eat breakfast |
| <Sv>dricka kaffe</Sv> | drink coffee |
| <Sv>gå till jobbet</Sv> | go to work |
| <Sv>jobba</Sv> | work |
| <Sv>plugga</Sv> | study |
| <Sv>laga mat</Sv> | cook |
| <Sv>titta på tv</Sv> | watch TV |
| <Sv>läsa</Sv> | read |
| <Sv>gå och lägga sig</Sv> | go to bed |

## Time words

| Swedish | English |
| --- | --- |
| <Sv>på morgonen</Sv> | in the morning |
| <Sv>på förmiddagen</Sv> | in the late morning |
| <Sv>på eftermiddagen</Sv> | in the afternoon |
| <Sv>på kvällen</Sv> | in the evening |
| <Sv>på natten</Sv> | at night |
| <Sv>varje dag</Sv> | every day |
| <Sv>ofta</Sv> | often |
| <Sv>ibland</Sv> | sometimes |

## Daily frames

| Need | Swedish frame |
| --- | --- |
| say what you do | <Sv>Jag dricker kaffe på morgonen.</Sv> |
| put time first | <Sv>På morgonen dricker jag kaffe.</Sv> |
| say when you start | <Sv>Jag börjar klockan åtta.</Sv> |
| say how often | <Sv>Jag tränar ofta.</Sv> |
| ask about habit | <Sv>Vad gör du på kvällen?</Sv> |

## Tiny routine

<p lang="sv">På morgonen går jag upp klockan sju.</p>
<p lang="sv">Jag äter frukost och dricker kaffe.</p>
<p lang="sv">Sedan går jag till jobbet.</p>
<p lang="sv">På kvällen lagar jag mat och läser.</p>
