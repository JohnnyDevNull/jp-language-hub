This is a map, not a lesson. Every entry links to the page that does the
teaching; the note says only why it sits at that point.

## Start here today

If you want a small first pass, take these five wins and stop there:

1. [Pronunciation basics](../pronunciation-basics/) — hear why vowel length
   changes meaning.
2. [en / ett](../grammar/nouns-articles/en-ett/) — store every noun with its
   gender.
3. [Basic word order](../grammar/sentence-structure/basic-word-order/) — build
   the first normal sentence.
4. [V2 rule](../grammar/sentence-structure/v2/) — move one phrase to the front
   without breaking the sentence.
5. [Present tense](../grammar/verbs/present/) — say what happens now, usually,
   or soon.
