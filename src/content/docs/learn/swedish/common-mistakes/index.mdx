<KeyTakeaway>
- Most errors in Swedish are not gaps in knowledge but patterns imported from a
  language you already speak.
- Diagnose by source language first: German transfer and English transfer
  produce different mistakes.
- Word-level traps (<span lang="sv">rolig</span>, <span lang="sv">full</span>) and construction-level traps
  (*es gibt*, *ich habe Hunger*) have their own pages.
</KeyTakeaway>

Four pages, split by where the mistake comes from.

## By source language

| Page | Consult it when |
| --- | --- |
| [Carried over from German](./from-german/) | You guessed <span lang="sv">en</span>/<span lang="sv">ett</span> from German gender, put <span lang="sv">inte</span> at the end of the clause, or used <span lang="sv">hans</span> where <span lang="sv">sin</span> belongs. |
| [Carried over from English](./from-english/) | You built a progressive ("I am working"), used do-support in a question, or wrote a separate word for *the*. |

## Across language pairs

| Page | Consult it when |
| --- | --- |
| [False friends](../../../false-friends/) | A single word looks familiar and the sentence still came out wrong. |
| [Direct translation errors](../../../direct-translation-errors/) | Every word is right but the construction is not Swedish. |

Both cross-pair pages sit outside the learning trees, because a false friend
belongs to a language pair rather than to one learning language.
