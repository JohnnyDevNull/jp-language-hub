## Three jobs, two words

| Job | Word | Example |
| --- | --- | --- |
| <span lang="sv">infinitivmärke</span> — a bare verb follows | <span lang="sv">att</span> | <span lang="sv">Vi planerar att flytta.</span> |
| <span lang="sv">bisatsinledare</span> — a thought or statement follows | <span lang="sv">att</span> | <span lang="sv">Jag tycker att huset är dyrt.</span> |
| <span lang="sv">relativpronomen</span> — it describes the noun before it | <span lang="sv">som</span> | <span lang="sv">en kompis som bor i Malmö</span> |

## The decision in one question

What does the clause do?

- Describes the word in front of it → <span lang="sv">som</span>
- Says what someone thinks, says, or knows → <span lang="sv">att</span>
- Supplies a verb with no new subject → <span lang="sv">att</span> + infinitive

English test: if *which* or *who* fits, Swedish takes
<span lang="sv">som</span>.

## Inside the clause

| Clause | <span lang="sv">bisatsinledare</span> | <span lang="sv">subjekt</span> | <span lang="sv">finit verb</span> |
| --- | --- | --- | --- |
| Content | <span lang="sv">att</span> | <span lang="sv">han</span> | <span lang="sv">kommer</span> |
| Relative, subject | <span lang="sv">som</span> | — | <span lang="sv">bor</span> |
| Relative, object | <span lang="sv">som</span> | <span lang="sv">jag</span> | <span lang="sv">läste</span> |

<span lang="sv">Som</span> is itself the subject in row two, so that field stays
empty. <span lang="sv">Att</span> never fills a role, so a subject always follows it.

## No att after a modal

| Bare infinitive | With <span lang="sv">att</span> |
| --- | --- |
| <span lang="sv">Jag kan simma.</span> | <span lang="sv">Jag lär mig att simma.</span> |
| <span lang="sv">Vi ska åka.</span> | <span lang="sv">Vi kommer att åka.</span> |
| <span lang="sv">Du måste läsa.</span> | <span lang="sv">Du glömde att läsa.</span> |

## When it can disappear

| Word | Droppable? |
| --- | --- |
| <span lang="sv">att</span> + clause | Often in speech: <span lang="sv">Jag tror (att) han kommer.</span> |
| <span lang="sv">att</span> + infinitive | No, except after a few verbs: <span lang="sv">Hon började (att) läsa.</span> |
| <span lang="sv">som</span> | Object only, never subject |

:::tip[Fast recall]
<span lang="sv">Något som min man vill göra.</span> — it describes
<span lang="sv">något</span>.
<span lang="sv">Jag tycker att det blir bra.</span> — it is what I think.
:::

## Avoid these mistakes

- ❌ <span lang="sv">en vän att bor här</span> → ✅ <span lang="sv">en vän som bor här</span>
- ❌ <span lang="sv">Jag kan att simma.</span> → ✅ <span lang="sv">Jag kan simma.</span>
- ❌ <span lang="sv">Han kom sent, som irriterade alla.</span> → ✅ <span lang="sv">…, vilket irriterade alla.</span>
- ❌ <span lang="sv">Boken som jag läste inte</span> → ✅ <span lang="sv">Boken som jag inte läste</span>
