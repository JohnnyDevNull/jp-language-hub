## Word order

| Rule | Example |
| --- | --- |
| Particle stands before the object | <span lang="sv">Han slog på radion.</span> |
| Also before a pronoun object | <span lang="sv">Han slog på den.</span> |
| <span lang="sv">inte</span> goes between verb and particle | <span lang="sv">Jag tycker inte om henne.</span> |
| Particle follows the supine | <span lang="sv">Jag har tagit med boken.</span> |

The particle never moves to the end of the clause the way a German separable
prefix does: <span lang="de">Ich rufe ihn an</span> →
<span lang="sv">Jag ringer upp honom.</span>

## Particle or preposition?

| Test | Particle | Preposition |
| --- | --- | --- |
| Stress | on the particle: <span lang="sv">tycka **om**</span> | on the verb: <span lang="sv">**tit**ta på</span> |
| With <span lang="sv">inte</span> | <span lang="sv">tycker inte om</span> | <span lang="sv">tittar inte på</span> |

## Frequent particle verbs

| Swedish | English |
| --- | --- |
| <span lang="sv">tycka om</span> | to like |
| <span lang="sv">komma ihåg</span> | to remember |
| <span lang="sv">komma på</span> | to think of, to realize |
| <span lang="sv">se ut</span> | to look, to appear |
| <span lang="sv">känna igen</span> | to recognize |
| <span lang="sv">ta med</span> | to bring along |
| <span lang="sv">ta på sig</span> / <span lang="sv">ta av sig</span> | to put on / take off |
| <span lang="sv">ta reda på</span> | to find out |
| <span lang="sv">slå på</span> / <span lang="sv">stänga av</span> | to switch on / off |
| <span lang="sv">tala om</span> | to tell |
| <span lang="sv">hålla på</span> | to be in the middle of something |
| <span lang="sv">passa på</span> | to seize the opportunity, to pay attention |

## Separated or written together

| Separated | Prefixed |
| --- | --- |
| <span lang="sv">tala om</span> — to tell | <span lang="sv">tilltala</span> — to address, to appeal to |
| <span lang="sv">gå av</span> — to get off | <span lang="sv">avgå</span> — to resign, to depart |
| <span lang="sv">gå ut</span> — to go out | <span lang="sv">utgå</span> — to be omitted |

As an adjective or noun, the parts join:
<span lang="sv">radion är påslagen</span>,
<span lang="sv">tågets avgång</span>.

:::tip[Fast recall]
<span lang="sv">Jag tycker inte om det.</span> — <span lang="sv">inte</span>
first, particle second, object last.
:::

## Avoid these mistakes

- ❌ <span lang="sv">Han slog den på.</span> → ✅ <span lang="sv">Han slog på den.</span>
- ❌ <span lang="sv">Jag tycker om inte henne.</span> → ✅ <span lang="sv">Jag tycker inte om henne.</span>
- Do not learn one translation for <span lang="sv">hålla på</span> or
  <span lang="sv">passa på</span>; the construction after the particle decides
  the meaning.
