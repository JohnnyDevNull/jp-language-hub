## som covers almost everything

| Function | Example |
| --- | --- |
| Subject — must stay | <span lang="sv">Mannen som bor här heter Erik.</span> |
| Object — may be dropped | <span lang="sv">Boken (som) jag läste var bra.</span> |
| Never after a preposition | <span lang="sv">huset som jag bor i</span> |

<span lang="sv">Som</span> is invariable: no gender, no number, no case, no
genitive.

## Where the preposition goes

| Swedish | German |
| --- | --- |
| <span lang="sv">bussen som vi väntar på</span> | <span lang="de">der Bus, auf den wir warten</span> |
| <span lang="sv">personen som jag talade med</span> | <span lang="de">die Person, mit der ich gesprochen habe</span> |

The preposition stays at the **end** of the relative clause.

## The other relatives

| Meaning | Word | Example |
| --- | --- | --- |
| Refers to a whole clause | <span lang="sv">vilket</span> | <span lang="sv">Han kom sent, vilket irriterade alla.</span> |
| whose | <span lang="sv">vars</span> | <span lang="sv">en författare vars böcker jag älskar</span> |
| where (place) | <span lang="sv">där</span> | <span lang="sv">staden där jag bor</span> |
| where to | <span lang="sv">dit</span> | <span lang="sv">staden dit jag flyttade</span> |

<span lang="sv">Vars</span> and preposition + <span lang="sv">vilken</span>
belong to formal writing. In speech, rebuild the sentence instead.

## Word order inside the clause

A relative clause is subordinate, so <span lang="sv">inte</span> comes before
the verb: <span lang="sv">Mannen som **inte** bor här</span>.

:::tip[Fast recall]
<span lang="sv">Bussen som vi väntar på är sen.</span> — preposition last.
<span lang="sv">Han kom sent, vilket irriterade alla.</span> —
<span lang="sv">vilket</span> for a whole clause.
:::

## Avoid these mistakes

- ❌ <span lang="sv">huset i som jag bor</span> → ✅ <span lang="sv">huset som jag bor i</span>
- ❌ <span lang="sv">Mannen vilken bor här</span> → ✅ <span lang="sv">Mannen som bor här</span>
- ❌ <span lang="sv">Han kom sent, som irriterade alla.</span> → ✅ <span lang="sv">…, vilket irriterade alla.</span>
- ❌ <span lang="sv">Mannen som bor inte här</span> → ✅ <span lang="sv">Mannen som inte bor här</span>
