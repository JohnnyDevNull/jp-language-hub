## Main clause: V2

The <span lang="sv">finit verb</span> normally takes the second sentence position.

| <span lang="sv">1 fundament</span> | <span lang="sv">2 finit verb</span> | <span lang="sv">3 subjekt</span> | <span lang="sv">objekt / predikativ</span> | <span lang="sv">adverbial</span> |
| --- | --- | --- | --- | --- |
| <span lang="sv">Jag</span> | <span lang="sv">köper</span> | — | <span lang="sv">en bok</span> | <span lang="sv">idag.</span> |
| <span lang="sv">Idag</span> | <span lang="sv">köper</span> | <span lang="sv">jag</span> | <span lang="sv">en bok.</span> | — |

✅ <span lang="sv">Idag köper jag en bok.</span>  
❌ <span lang="sv">Idag jag köper en bok.</span>

“Position” means a constituent. <span lang="sv">På måndag morgon</span> can
fill the whole first position.

## Main-clause negation

> <span lang="sv">subjekt + finit verb + inte</span> + …

<span lang="sv">Jag kommer inte idag.</span>

When another constituent comes first, V2 triggers inversion:

> <span lang="sv">fundament + finit verb + subjekt + inte</span> + …

<span lang="sv">Idag kommer jag inte.</span>

## Subordinate clause: BIFF

**B**isats **I**nte **F**öre **F**init: in a subordinate clause,
<span lang="sv">inte</span> normally comes before the <span lang="sv">finit verb</span>.

> <span lang="sv">bisatsinledare + subjekt + inte + finit verb</span> + …

<span lang="sv">… eftersom jag inte kommer idag.</span>

| Clause | Template | Example |
| --- | --- | --- |
| Main | <span lang="sv">subjekt + finit verb + inte</span> | <span lang="sv">Jag kommer inte.</span> |
| Subordinate | <span lang="sv">bisatsinledare + subjekt + inte + finit verb</span> | <span lang="sv">… eftersom jag inte kommer.</span> |

:::caution[Scope]
V2 and BIFF are reliable beginner guides, but neither is a complete description
of every Swedish clause type.
:::
