Swedish pronunciation is not fully predictable from spelling, but some spelling
patterns are common enough to be worth learning early.

## Vowels

Swedish has the vowel letters <span lang="sv">a, e, i, o, u, y, å, ä, ö</span>.
Several of them look familiar to German speakers, but their exact sound and
length can differ.

| Letter | Beginner cue |
| --- | --- |
| <span lang="sv">a</span> | often more open than German <span lang="de">a</span> |
| <span lang="sv">e</span> | can be long as in <span lang="sv">resa</span> or short as in <span lang="sv">hem</span> |
| <span lang="sv">i</span> | often close to German <span lang="de">i</span> |
| <span lang="sv">o</span> | often sounds closer to German <span lang="de">u</span> when long |
| <span lang="sv">u</span> | a rounded Swedish sound; do not simply read it as German <span lang="de">u</span> |
| <span lang="sv">y</span> | rounded front vowel; keep the lips rounded |
| <span lang="sv">å</span> | often close to German <span lang="de">o</span> |
| <span lang="sv">ä</span> | often close to German <span lang="de">ä</span> |
| <span lang="sv">ö</span> | often close to German <span lang="de">ö</span> |

Vowel length matters. A long vowel often appears before one consonant or at the
end of a word; a short vowel often appears before two consonants. This is a
helpful tendency, not a complete rule.

## Hard and soft vowels

Some consonants change pronunciation depending on the following vowel.

| Vowel type | Letters |
| --- | --- |
| hard vowels | <span lang="sv">a, o, u, å</span> |
| soft vowels | <span lang="sv">e, i, y, ä, ö</span> |

## Common consonant patterns

| Spelling | Typical beginner rule | Examples |
| --- | --- | --- |
| hard <span lang="sv">g</span> before hard vowels | pronounced hard | <span lang="sv">gata</span> |
| soft <span lang="sv">g</span> before soft vowels | often sounds like Swedish <span lang="sv">j</span> | <span lang="sv">gärna</span> |
| hard <span lang="sv">k</span> before hard vowels | pronounced like <span lang="de">k</span> | <span lang="sv">karta</span> |
| soft <span lang="sv">k</span> before soft vowels | often close to German <span lang="de">ch</span> in <span lang="de">ich</span> | <span lang="sv">kyrka</span> |
| <span lang="sv">sk</span> before soft vowels | often pronounced like the Swedish sj-sound | <span lang="sv">sked</span> |
| <span lang="sv">tj</span>, <span lang="sv">kj</span> | often a front “ch-like” sound | <span lang="sv">tjugo</span>, <span lang="sv">kjol</span> |
| <span lang="sv">sj</span> | Swedish sj-sound | <span lang="sv">sju</span> |
| <span lang="sv">rs</span> | often merges into a retroflex “sh-like” sound | <span lang="sv">första</span> |
| <span lang="sv">-tion</span>, <span lang="sv">-sion</span> | often contain an sj-like sound | <span lang="sv">station</span> |

Some letter combinations with <span lang="sv">j</span> are pronounced with the
<span lang="sv">j</span> sound while the other letter is not heard clearly, for
example in words beginning with <span lang="sv">dj</span>, <span lang="sv">gj</span>,
<span lang="sv">hj</span>, or <span lang="sv">lj</span>.

## Spoken reductions

Everyday speech can reduce or blend sounds:

- <span lang="sv">de</span> is commonly pronounced like <span lang="sv">dom</span>.
- <span lang="sv">och</span> is often reduced in fast speech.
- <span lang="sv">att</span> can be reduced before an infinitive.
- <span lang="sv">någon</span> and <span lang="sv">något</span> often sound like
  <span lang="sv">nån</span> and <span lang="sv">nåt</span>.

## Learning tip

Do not try to solve Swedish pronunciation only from spelling rules. Use these
patterns as lookup help, then attach the sound to whole words and short phrases.
