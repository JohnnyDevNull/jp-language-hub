## Gender shortcuts

| Clue | Gender | Example |
| --- | --- | --- |
| Compound noun | the **last** element decides | <span lang="sv">en cykel</span> + <span lang="sv">ett hjul</span> → <span lang="sv">ett cykelhjul</span> |
| <span lang="sv">-a, -are, -else, -het, -ning, -tion</span> | <span lang="sv">en</span> | <span lang="sv">en tidning</span>, <span lang="sv">en möjlighet</span> |
| <span lang="sv">-ande, -eri, -um, -ment, -tek, -gram</span> | <span lang="sv">ett</span> | <span lang="sv">ett meddelande</span>, <span lang="sv">ett museum</span> |
| No clue at all | guess <span lang="sv">en</span> — the majority | |

The compound rule has no exceptions. The endings are strong tendencies: watch
out for <span lang="sv">ett öga</span>, <span lang="sv">en studerande</span>,
and the split <span lang="sv">-skap</span>.

## Indefinite forms

| Noun form | Adjective pattern | Example |
| --- | --- | --- |
| Singular <span lang="sv">en</span> | base form | <span lang="sv">en stor bil</span> |
| Singular <span lang="sv">ett</span> | usually <span lang="sv">-t</span> | <span lang="sv">ett stort hus</span> |
| Plural | usually <span lang="sv">-a</span> | <span lang="sv">stora bilar</span> |

## Definite forms

| Noun form | Pattern | Example |
| --- | --- | --- |
| Singular <span lang="sv">en</span> | <span lang="sv">den</span> + <span lang="sv">-a</span> adjective + definite noun | <span lang="sv">den stora bilen</span> |
| Singular <span lang="sv">ett</span> | <span lang="sv">det</span> + <span lang="sv">-a</span> adjective + definite noun | <span lang="sv">det stora huset</span> |
| Plural | <span lang="sv">de</span> + <span lang="sv">-a</span> adjective + definite noun | <span lang="sv">de stora bilarna</span> |

## Adjective spelling

| Stem | ett-form | plural / definite |
| --- | --- | --- |
| stressed vowel: <span lang="sv">ny, blå</span> | <span lang="sv">nytt, blått</span> | <span lang="sv">nya, blåa</span> |
| vowel + <span lang="sv">d/t</span>: <span lang="sv">röd, vit</span> | <span lang="sv">rött, vitt</span> | <span lang="sv">röda, vita</span> |
| <span lang="sv">-en</span>: <span lang="sv">öppen, mogen</span> | <span lang="sv">öppet, moget</span> | <span lang="sv">öppna, mogna</span> |
| <span lang="sv">-er, -el</span>: <span lang="sv">vacker, enkel</span> | <span lang="sv">vackert, enkelt</span> | <span lang="sv">vackra, enkla</span> |

Irregular: <span lang="sv">gammal → gammalt → gamla</span>,
<span lang="sv">liten → litet → små</span> (definite singular
<span lang="sv">lilla</span>).

Never inflected: <span lang="sv">bra, kul, äkta, rosa, lila, beige</span> —
<span lang="sv">ett bra hus</span>.

:::tip[Fast recall]
<span lang="sv">en stor — ett stort — flera stora</span>
:::

## Avoid these mistakes

- ❌ <span lang="sv">ett stor hus</span> → ✅ <span lang="sv">ett stort hus</span>
- ❌ <span lang="sv">den stor bilen</span> → ✅ <span lang="sv">den stora bilen</span>
- ❌ <span lang="sv">en cykelhjul</span> → ✅ <span lang="sv">ett cykelhjul</span>
- ❌ <span lang="sv">öppena fönster</span> → ✅ <span lang="sv">öppna fönster</span>
- Learn each noun with its article; gender cannot always be predicted reliably.
- These are high-frequency basic patterns, not rules without exceptions.
