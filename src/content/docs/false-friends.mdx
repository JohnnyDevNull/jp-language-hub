<KeyTakeaway>
- A familiar-looking Swedish word is a warning sign, not a translation.
- The dangerous pairs are the everyday ones: <span lang="sv">rolig</span>, <span lang="sv">full</span>,
  <span lang="sv">gift</span>, <span lang="sv">semester</span>, <span lang="sv">middag</span>.
- Store a false friend with the word you actually meant, so the correct form is
  one lookup away.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Similar spelling does not guarantee the same meaning. Each entry below gives the
misleading word, what it really means, and the word you probably wanted.

## Traps for German speakers

| Swedish | Actually means | You probably meant | Example |
| --- | --- | --- | --- |
| <span lang="sv">snäll</span> | kind, nice | *schnell* → <span lang="sv">snabb</span> | <span lang="sv">Han är snäll mot alla.</span> |
| <span lang="sv">rolig</span> | funny, enjoyable | *ruhig* → <span lang="sv">lugn</span> | <span lang="sv">Filmen var rolig.</span> |
| <span lang="sv">kul</span> | fun | *kühl* → <span lang="sv">sval</span> | <span lang="sv">Det var kul!</span> |
| <span lang="sv">middag</span> | dinner (evening meal) | *Mittag* → <span lang="sv">lunch</span> | <span lang="sv">Vi äter middag klockan sju.</span> |
| <span lang="sv">semester</span> | holiday, vacation | *Semester* → <span lang="sv">termin</span> | <span lang="sv">Jag har semester i juli.</span> |
| <span lang="sv">öl</span> | beer | *Öl* → <span lang="sv">olja</span> | <span lang="sv">En öl, tack.</span> |
| <span lang="sv">glass</span> | ice cream | *Glas* → <span lang="sv">glas</span> | <span lang="sv">Barnen vill ha glass.</span> |
| <span lang="sv">springa</span> | to run | *springen* → <span lang="sv">hoppa</span> | <span lang="sv">Jag springer varje morgon.</span> |
| <span lang="sv">bekant</span> | an acquaintance | *bekannt* (famous) → <span lang="sv">känd</span> | <span lang="sv">Hon är en gammal bekant.</span> |
| <span lang="sv">art</span> | species | *Art* (kind) → <span lang="sv">sort</span>, <span lang="sv">slag</span> | <span lang="sv">Vilken art är det?</span> |
| <span lang="sv">nödig</span> | needing the toilet | *nötig* → <span lang="sv">nödvändig</span> | <span lang="sv">Jag är nödig.</span> |
| <span lang="sv">rar</span> | sweet, endearing | *rar* (scarce) → <span lang="sv">sällsynt</span> | <span lang="sv">Vilken rar liten katt.</span> |
| <span lang="sv">by</span> | village | *bei* → <span lang="sv">hos</span>, <span lang="sv">vid</span> | <span lang="sv">Vi bor i en liten by.</span> |
| <span lang="sv">kör</span> | drives; also choir | *Chor* → only the noun <span lang="sv">kör</span> | <span lang="sv">Hon kör bil.</span> / <span lang="sv">Vi sjunger i kör.</span> |
| <span lang="sv">hemsk</span> | awful, horrible | *heimisch* → <span lang="sv">hemtrevlig</span> | <span lang="sv">Vädret var hemskt.</span> |

<MistakeBox
	incorrect="Jag är full."
	correct="Jag är mätt."
	lang="sv"
>
	<span lang="sv">full</span> said about a person means **drunk**. After a meal you are
	<span lang="sv">mätt</span>. The literal sense survives for containers:
	<span lang="sv">Glaset är fullt.</span>
</MistakeBox>

<MistakeBox
	incorrect="Jag vill ha ett rum som är rolig."
	correct="Jag vill ha ett rum som är lugnt."
	lang="sv"
>
	Asking for a *ruhig* hotel room with <span lang="sv">rolig</span> asks for an amusing one.
	Note the agreement too: <span lang="sv">ett lugnt rum</span>.
</MistakeBox>

## Traps for English speakers

| Swedish | Actually means | You probably meant | Example |
| --- | --- | --- | --- |
| <span lang="sv">fart</span> | speed | flatulence → <span lang="sv">fjärt</span>, <span lang="sv">prutt</span> | <span lang="sv">Bilen har hög fart.</span> |
| <span lang="sv">slut</span> | end, finished, sold out | (no shared meaning) | <span lang="sv">Filmen är slut.</span> |
| <span lang="sv">barn</span> | child, children | barn → <span lang="sv">lada</span> | <span lang="sv">Vi har två barn.</span> |
| <span lang="sv">bra</span> | good, well | bra → <span lang="sv">behå</span> | <span lang="sv">Maten var bra.</span> |
| <span lang="sv">kock</span> | cook, chef | (no shared meaning) | <span lang="sv">Han är kock på en restaurang.</span> |
| <span lang="sv">sex</span> | six; also sex | usually just the number | <span lang="sv">Klockan är sex.</span> |
| <span lang="sv">sky</span> | meat juices, gravy; to shun | sky → <span lang="sv">himmel</span> | <span lang="sv">Kött med sky.</span> / <span lang="sv">Han skyr socker.</span> |
| <span lang="sv">hyra</span> | to rent | hire a person → <span lang="sv">anställa</span> | <span lang="sv">Vi hyr en bil i Malmö.</span> |

<MistakeBox
	incorrect="Tack för giftet!"
	correct="Tack för gåvan!"
	lang="sv"
>
	<span lang="sv">gift</span> is either the adjective **married** (<span lang="sv">Hon är gift.</span>) or
	the noun <span lang="sv">ett gift</span>, **poison** — so <span lang="sv">Tack för giftet!</span> is
	perfectly grammatical and thanks your host for the poison. A present is <span lang="sv">en gåva</span> or
	<span lang="sv">en present</span>.
</MistakeBox>
