isolation.

## Translating the preposition in *wait for*

<MistakeBox
	incorrect="Jag väntar för bussen."
	correct="Jag väntar på bussen."
	lang="sv"
>
	German uses `warten auf`, English uses `wait for`, and Swedish uses `vänta på`.
	The preposition belongs to the construction. See the
	[vocabulary reference](../../vocabulary/) for the collocation-based approach.
</MistakeBox>
