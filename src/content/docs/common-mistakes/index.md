description: Typical transfer errors between German, English, and Swedish.

This section collects mistakes caused by transferring familiar patterns from
one language into another.

## Categories

- German to English
- German to Swedish
- English to Swedish
- False friends
- Direct translation errors

The first entries will focus on word order, prepositions, articles, Swedish
en/ett choices, adjective agreement, tense transfer, and pronoun confusion.

Each mistake will show the incorrect form, its correction, and the underlying
rule instead of presenting only an isolated answer.
