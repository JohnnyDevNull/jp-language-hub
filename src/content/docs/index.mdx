## Where to start

There are many pages here, so it helps to have an order. The
[Swedish learning path](./learn/swedish/learning-path/) lists the pages from
beginner (A1) to upper intermediate (B2) and says for each one why it comes at
that point. If you only want a short start, it begins with five pages.
