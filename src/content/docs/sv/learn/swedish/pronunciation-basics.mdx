<KeyTakeaway>
- En dubblerad konsonant är den starkaste nybörjarledtråden för en **kort
  vokal**, medan en enkel konsonant ofta pekar mot en lång; skillnaden
  åtskiljer ord: <span lang="sv">glas</span> är ett dricksglas, <span lang="sv">glass</span> är en kall
  efterrätt av grädde.
- <span lang="sv">g</span>, <span lang="sv">k</span> och <span lang="sv">sk</span> byter ofta ljud framför de mjuka
  vokalerna <span lang="sv">e, i, y, ä, ö</span>, men vanliga undantag finns kvar.
- Stavningen tar dig nära, men inte hela vägen: vokalerna <span lang="sv">u</span> och
  <span lang="sv">y</span>, sj- och tj-ljuden och de två ordaccenterna måste läras in genom
  att lyssna.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenskt uttal går inte att förutsäga helt utifrån stavningen, men en handfull
mönster täcker det mesta som en nybörjare läser högt.

## Grundregel

> Läs först konsonanterna efter en betonad vokal. En dubblerad konsonant
> markerar oftast en kort vokal; en enkel konsonant eller ordets slut pekar
> ofta mot en lång vokal. Kontrollera sedan om vokalen som *följer* efter ett
> <span lang="sv">g</span>, <span lang="sv">k</span> eller <span lang="sv">sk</span> är hård eller mjuk.

## Alfabetet

Svenskan har 29 bokstäver. De tre extra vokalerna kommer **sist** i alfabetet,
efter <span lang="sv">z</span>: <span lang="sv">… x, y, z, å, ä, ö</span>.

Det här är inte bara en kuriositet: ordböcker, register, namnlistor och
sorterade tabeller följer den ordningen, så <span lang="sv">Ångström</span> sorteras efter
<span lang="sv">Zetterberg</span>, inte bredvid <span lang="sv">Andersson</span>.

## Vokaler

Svenskan har vokalbokstäverna <span lang="sv">a, e, i, o, u, y, å, ä, ö</span>. Flera känns
igen för tysktalande, men deras exakta ljud och längd kan skilja sig åt.

| Bokstav | Ledtråd för nybörjare |
| --- | --- |
| <span lang="sv">a</span> | ofta öppnare än tyskans <span lang="de">a</span> |
| <span lang="sv">e</span> | lång i <span lang="sv">resa</span>, kort i <span lang="sv">hem</span> |
| <span lang="sv">i</span> | ofta nära tyskans <span lang="de">i</span> |
| <span lang="sv">o</span> | lång ofta närmare tyskans <span lang="de">u</span> |
| <span lang="sv">u</span> | ett rundat svenskt ljud; inte helt enkelt tyskans <span lang="de">u</span> |
| <span lang="sv">y</span> | rundad framvokal; håll läpparna rundade |
| <span lang="sv">å</span> | ofta nära tyskans <span lang="de">o</span> |
| <span lang="sv">ä</span> | ofta nära tyskans <span lang="de">ä</span> |
| <span lang="sv">ö</span> | ofta nära tyskans <span lang="de">ö</span> |

### Vokallängden ändrar ordet

| Lång vokal | Kort vokal |
| --- | --- |
| <span lang="sv">glas</span> — dricksglas | <span lang="sv">glass</span> — kall efterrätt av grädde |
| <span lang="sv">tak</span> — det som täcker ett hus upptill | <span lang="sv">tack</span> — vad man säger för att visa tacksamhet |
| <span lang="sv">vit</span> — färgen som snö har | <span lang="sv">vitt</span> — samma färg (<span lang="sv">ett</span>-form) |

Konsonantdubblering är den vanliga stavningssignalen för en kort betonad
vokal, så <span lang="sv">glas</span> och <span lang="sv">glass</span> skiljer sig främst i vokallängd,
inte i s-ljudet.

<MistakeBox
	incorrect="att läsa glass med samma långa a som i glas"
	correct="glass har ett kort a, glas har ett långt a"
	lang="sv"
>
	Tysk stavning använder inte konsonantdubblering lika konsekvent, så det är
	lätt att missa den. På svenska är den en stark längdsignal, och längden bär
	betydelse.
</MistakeBox>

## Hårda och mjuka vokaler

| Vokaltyp | Bokstäver |
| --- | --- |
| hårda vokaler | <span lang="sv">a, o, u, å</span> |
| mjuka vokaler | <span lang="sv">e, i, y, ä, ö</span> |

## Vanliga konsonantmönster

| Stavning | Typisk nybörjarregel | Exempel |
| --- | --- | --- |
| <span lang="sv">g</span> framför hårda vokaler | uttalas hårt | <span lang="sv">gata</span> |
| <span lang="sv">g</span> framför mjuka vokaler | låter ofta som svenskt <span lang="sv">j</span> | <span lang="sv">gärna</span> |
| <span lang="sv">k</span> framför hårda vokaler | som tyskans <span lang="de">k</span> | <span lang="sv">karta</span> |
| <span lang="sv">k</span> framför mjuka vokaler | ofta nära tyskans <span lang="de">ch</span> i <span lang="de">ich</span> | <span lang="sv">kyrka</span> |
| <span lang="sv">sk</span> framför mjuka vokaler | ofta sj-ljudet | <span lang="sv">sked</span> |
| <span lang="sv">tj</span>, <span lang="sv">kj</span> | ofta ett främre, tje-liknande ljud | <span lang="sv">tjugo</span>, <span lang="sv">kjol</span> |
| <span lang="sv">sj</span> | sj-ljudet | <span lang="sv">sju</span> |
| <span lang="sv">rs</span> | smälter ofta ihop till ett retroflext, sje-liknande ljud | <span lang="sv">första</span> |
| <span lang="sv">gn</span> | <span lang="sv">g</span>:et låter som <span lang="sv">ng</span> | <span lang="sv">regn</span>, <span lang="sv">lugn</span> |
| <span lang="sv">-tion</span>, <span lang="sv">-sion</span> | innehåller ofta ett sj-liknande ljud | <span lang="sv">station</span> |

I ord som börjar med <span lang="sv">dj</span>, <span lang="sv">gj</span>, <span lang="sv">hj</span> eller <span lang="sv">lj</span>
hörs bara <span lang="sv">j</span>:et tydligt.

## Ordaccent

Svenskan skiljer mellan två ordaccenter — en enkeltoppig accent 1 och en
tvåtoppig accent 2. Några ordpar särskiljs av ingenting annat:

| Ord | Accent 1 | Accent 2 |
| --- | --- | --- |
| <span lang="sv">anden</span> | fågeln som simmar i vattnet | själen |
| <span lang="sv">tomten</span> | marken där ett hus kan byggas | gestalten som kommer med julklappar |

Jaga inte det här för tidigt. Infödda talare förstår dig ändå, och det lärs in
mycket effektivare genom att imitera hela fraser än genom att studera regeln.
Att veta att den finns räcker för att förklara varför ett ord du uttalade
”rätt” ändå missuppfattades.

## Reduktioner i talat språk

- <span lang="sv">de</span> uttalas vanligen som <span lang="sv">dom</span>.
- <span lang="sv">är</span> uttalas vanligen som <span lang="sv">e</span>.
- <span lang="sv">någon</span> och <span lang="sv">något</span> låter ofta som <span lang="sv">nån</span> och
  <span lang="sv">nåt</span>.
- <span lang="sv">g</span>:et i ändelserna <span lang="sv">-ig</span> och <span lang="sv">-igt</span> uttalas oftast
  inte: <span lang="sv">roligt</span> låter som <span lang="sv">rolit</span>.
- <span lang="sv">och</span> reduceras ofta i snabbt tal, och <span lang="sv">att</span> kan reduceras
  framför en infinitiv.

<MemoryTip>
Två frågor svarar på många lässvårigheter: **finns det en dubblerad konsonant
efter den betonade vokalen** (längd), och **är nästa vokal mjuk** (ändras
<span lang="sv">g</span>, <span lang="sv">k</span> eller <span lang="sv">sk</span>).
</MemoryTip>
