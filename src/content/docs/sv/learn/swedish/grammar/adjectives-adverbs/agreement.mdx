<KeyTakeaway>
- Det obestämda mönstret är grundform, <span lang="sv">-t</span>, <span lang="sv">-a</span>:
  <span lang="sv">en stor bil</span>, <span lang="sv">ett stort hus</span>, <span lang="sv">stora bilar</span>.
- Pluralformen är samma för en-ord och ett-ord.
- En bestämd nominalfras markerar bestämdhet två gånger: artikel plus
  bestämt adjektiv plus bestämt substantiv — <span lang="sv">den stora bilen</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenska adjektiv kongruerar med genus och numerus hos substantivet de
beskriver. Attributiva adjektiv i nominalfraser visar också om frasen är
obestämd eller bestämd. Grundmönstret för nybörjare är **grundform**, **-t**
och **-a**.

## Använd detta nu

För att snabbt välja rätt adjektivform, fråga dig vilken typ av fras du
bygger:

| Fråga | Använd | Exempel |
| --- | --- | --- |
| Är det ett obestämt en-ord? | grundform | <span lang="sv">en stor bil</span> |
| Är det ett obestämt ett-ord? | oftast lägg till <span lang="sv">-t</span> | <span lang="sv">ett stort hus</span> |
| Är det plural? | oftast lägg till <span lang="sv">-a</span> | <span lang="sv">stora bilar</span>, <span lang="sv">stora hus</span> |
| Är det en bestämd nominalfras? | artikel + <span lang="sv">-a</span>-adjektiv + bestämt substantiv | <span lang="sv">den stora bilen</span>, <span lang="sv">det stora huset</span> |

Kontrollera sedan om ett av de vanliga undantagen gäller:

- Vissa adjektiv ändrar stavning framför en ändelse:
  <span lang="sv">röd → rött → röda</span>, <span lang="sv">öppen → öppet → öppna</span>.
- Vissa vanliga adjektiv är oregelbundna eller oböjliga:
  <span lang="sv">liten → litet → små</span>, men <span lang="sv">bra → bra → bra</span>.
- Efter verb som <span lang="sv">vara</span> och <span lang="sv">bli</span> kongruerar adjektivet med
  subjektets genus eller numerus, men utan dubbel bestämdhet:
  <span lang="sv">Huset är stort.</span>

Är du osäker, bygg hela nominalfrasen först:
<span lang="sv">en stor bil</span>, <span lang="sv">ett stort hus</span>,
<span lang="sv">stora bilar</span>, <span lang="sv">den stora bilen</span>.

## Kärnmönster

| Nominalfras | Adjektivform | Exempel |
| --- | --- | --- |
| obestämd en-singular | grundform | <span lang="sv">en <strong>{stor.morphology.en}</strong> bil</span> |
| obestämd ett-singular | ofta <span lang="sv">-t</span> | <span lang="sv">ett <strong>{stor.morphology.ett}</strong> hus</span> |
| obestämd plural | ofta <span lang="sv">-a</span> | <span lang="sv"><strong>{stor.morphology.plural}</strong> bilar</span> |
| bestämd | ofta <span lang="sv">-a</span> | <span lang="sv">den <strong>{stor.morphology.definite}</strong> bilen</span> |

Samma pluralform av adjektivet används för en-ord och ett-ord:

- <span lang="sv">stora bilar</span>
- <span lang="sv">stora hus</span>

## Obestämda former

Utgå från grundformen (en-formen):

<p lang="sv">stor</p>

Lägg till <span lang="sv">-t</span> för den regelbundna ett-formen och
<span lang="sv">-a</span> för den regelbundna pluralformen:

<p lang="sv">stor → stort → stora</p>

Ytterligare ett regelbundet exempel:

<p lang="sv">{gul.morphology.en} → {gul.morphology.ett} → {gul.morphology.plural}</p>

Stavningen kan ändras när ändelser läggs till, och vissa adjektiv är
oregelbundna. Till exempel:

- <span lang="sv">{glad.morphology.en} → {glad.morphology.ett} → {glad.morphology.plural}</span>
- <span lang="sv">liten → litet → små</span>
- <span lang="sv">bra → bra → bra</span>

Lär dig vanliga undantag genom hela fraser.

## Stavningsmönster

Ändelserna <span lang="sv">-t</span> och <span lang="sv">-a</span> är regelbundna, men stammen ändras
ofta när de läggs till. Dessa mönster täcker de flesta adjektiv:

| Stammönster | en-form | ett-form | plural/bestämd form |
| --- | --- | --- | --- |
| betonad vokal | <span lang="sv">ny</span>, <span lang="sv">blå</span> | <span lang="sv">nytt</span>, <span lang="sv">blått</span> | <span lang="sv">nya</span>, <span lang="sv">blåa</span> |
| vokal + <span lang="sv">-d</span> | <span lang="sv">röd</span>, <span lang="sv">god</span> | <span lang="sv">rött</span>, <span lang="sv">gott</span> | <span lang="sv">röda</span>, <span lang="sv">goda</span> |
| konsonant + <span lang="sv">-d</span> | <span lang="sv">hård</span> | <span lang="sv">hårt</span> | <span lang="sv">hårda</span> |
| vokal + <span lang="sv">-t</span> | <span lang="sv">vit</span>, <span lang="sv">söt</span> | <span lang="sv">vitt</span>, <span lang="sv">sött</span> | <span lang="sv">vita</span>, <span lang="sv">söta</span> |
| konsonant + <span lang="sv">-t</span> | <span lang="sv">kort</span>, <span lang="sv">svart</span> | <span lang="sv">kort</span>, <span lang="sv">svart</span> | <span lang="sv">korta</span>, <span lang="sv">svarta</span> |
| <span lang="sv">-nn</span> | <span lang="sv">sann</span>, <span lang="sv">tunn</span> | <span lang="sv">sant</span>, <span lang="sv">tunt</span> | <span lang="sv">sanna</span>, <span lang="sv">tunna</span> |
| <span lang="sv">-en</span> | <span lang="sv">öppen</span>, <span lang="sv">mogen</span> | <span lang="sv">öppet</span>, <span lang="sv">moget</span> | <span lang="sv">öppna</span>, <span lang="sv">mogna</span> |
| <span lang="sv">-er</span>, <span lang="sv">-el</span> | <span lang="sv">vacker</span>, <span lang="sv">enkel</span> | <span lang="sv">vackert</span>, <span lang="sv">enkelt</span> | <span lang="sv">vackra</span>, <span lang="sv">enkla</span> |

Två vanliga adjektiv är oregelbundna utöver dessa mönster:

- <span lang="sv">gammal → gammalt → gamla</span>
- <span lang="sv">liten → litet → små</span>, med
  <span lang="sv">lilla</span> i den bestämda singularformen:
  <span lang="sv">den lilla bilen</span>

Mönstret som är viktigast att lära sig först är
<span lang="sv">-en</span>-gruppen, eftersom det obetonade
<span lang="sv">e</span>-et försvinner i pluralformen:
<span lang="sv">ett öppet fönster</span> men
<span lang="sv">öppna fönster</span>.

## Adjektiv som aldrig böjs

En liten grupp tar inga ändelser alls. De är lätta att använda så snart du
vet vilka de är:

<span lang="sv">bra</span>, <span lang="sv">kul</span>,
<span lang="sv">äkta</span>, <span lang="sv">sakta</span>,
<span lang="sv">främmande</span>, samt färgord som
<span lang="sv">rosa</span>, <span lang="sv">lila</span>,
<span lang="sv">beige</span>.

- <span lang="sv">ett bra hus</span>, <span lang="sv">bra bilar</span>
- <span lang="sv">ett rosa hus</span>, <span lang="sv">rosa bilar</span>

## Particip som adjektiv

Perfektparticip böjs som vanliga adjektiv:

| Nominalfras | Exempel |
| --- | --- |
| obestämd en | <span lang="sv">en stängd dörr</span> |
| obestämd ett | <span lang="sv">ett stängt fönster</span> |
| plural | <span lang="sv">stängda dörrar</span> |

Samma sak gäller particip från andra verbgrupper:
<span lang="sv">en målad vägg</span>,
<span lang="sv">ett målat hus</span>,
<span lang="sv">målade väggar</span>; och
<span lang="sv">en skriven text</span>,
<span lang="sv">ett skrivet brev</span>,
<span lang="sv">skrivna brev</span>.

Presensparticip på <span lang="sv">-ande</span> och
<span lang="sv">-ende</span> böjs aldrig:

<p lang="sv">ett leende barn · en leende flicka · leende barn</p>

Perfektparticip ligger också till grund för bli-passivet. Se
[passiv](../../verb-patterns-voice/passive/).

## Det valfria maskulina -e

När man syftar på en man kan den bestämda formen ta
<span lang="sv">-e</span> i stället för <span lang="sv">-a</span>:

- <span lang="sv">den gamle mannen</span> vid sidan av
  <span lang="sv">den gamla mannen</span>
- <span lang="sv">min gode vän</span>

Detta är valfritt och hör till ett något formellt eller traditionellt
register; det lever också kvar i fasta namn som
<span lang="sv">Karl den store</span>. <span lang="sv">-a</span>-formen är
alltid godtagbar, så behandla <span lang="sv">-e</span> som något att känna igen snarare
än en regel att tillämpa.

## Bestämda nominalfraser och dubbel bestämdhet

Ett substantiv utan attributivt adjektiv markerar normalt bestämdhet bara med
sin ändelse:

<p lang="sv">bilen · huset · bilarna</p>

När ett attributivt adjektiv läggs till markerar standardsvenskan normalt
bestämdhet två gånger: med en separat bestämd artikel framför adjektivet och
med den bestämda ändelsen på substantivet. Denna konstruktion kallas
**dubbel bestämdhet**.

| Numerus och genus | Bestämd artikel | Adjektiv | Bestämt substantiv | Hel fras |
| --- | --- | --- | --- | --- |
| en-singular | <span lang="sv">den</span> | <span lang="sv">{stor.morphology.definite}</span> | <span lang="sv">bilen</span> | <span lang="sv">den {stor.morphology.definite} bilen</span> |
| ett-singular | <span lang="sv">det</span> | <span lang="sv">{stor.morphology.definite}</span> | <span lang="sv">huset</span> | <span lang="sv">det {stor.morphology.definite} huset</span> |
| plural | <span lang="sv">de</span> | <span lang="sv">{stor.morphology.definite}</span> | <span lang="sv">bilarna</span> | <span lang="sv">de {stor.morphology.definite} bilarna</span> |

Det tredelade mönstret är alltså:

<p lang="sv"><strong>den / det / de + bestämt adjektiv + bestämt substantiv</strong></p>

Artikeln markerar genus eller numerus, adjektivet använder oftast sin
<span lang="sv">-a</span>-form, och substantivet behåller sin bestämda ändelse. Engelskan
markerar vanligen samma fras bara en gång i <span lang="en">the big car</span>;
svenskan använder både <span lang="sv">den</span> och <span lang="sv">-en</span> i
<span lang="sv">den stora bilen</span>.

Possessiver är ett viktigt undantag från standardmönstret. Adjektivet
använder den bestämda formen, men det finns ingen separat bestämd artikel,
och substantivet tar inte sin bestämda ändelse:

<p lang="sv">min stora bil</p>

Demonstrativ som <span lang="sv">den här</span> och
<span lang="sv">det där</span> följer samma rytm som en bestämd nominalfras:
<span lang="sv">den här stora bilen</span>,
<span lang="sv">det där stora huset</span>.

Se [substantivformer](../../nouns-articles/noun-forms/) för själva
substantivändelserna.

## Efter verb som *vara* och *bli*

Predikativa adjektiv kongruerar med subjektet men använder inte dubbel
bestämdhet:

- <span lang="sv">Bilen är stor.</span>
- <span lang="sv">Huset är stort.</span>
- <span lang="sv">Bilarna är stora.</span>

## Direkt jämförelse

<LanguageComparison title="Obestämd plural">

</LanguageComparison>

<LanguageComparison title="Bestämd singular">
	<p slot="de">das große Auto</p>
	<p slot="en">the big car</p>
	<p slot="sv">den stora bilen</p>
</LanguageComparison>

Engelska adjektiv kongruerar inte med substantivet. Tyska adjektiv
kongruerar också, men tyska ändelser beror dessutom på kasus och artikeltyp,
inte bara på genus och numerus. Överför inte det tyska ändelsesystemet
direkt till svenskan.

<MistakeBox title="Vanliga misstag">
Se till att artikel, adjektiv och substantiv stämmer överens:

<span lang="sv">❌ ett stor hus</span>
<span lang="sv">✅ ett stort hus</span>

I en vanlig bestämd fras, utelämna inte någon del av den dubbla
bestämdheten:

<span lang="sv">❌ det stora hus</span>
<span lang="sv">✅ det stora huset</span>
</MistakeBox>

<MemoryTip>
Kom ihåg den tredelade rytmen:
<span lang="sv"><strong>en stor — ett stort — flera stora</strong></span>.
I en bestämd fras, använd den välbekanta <span lang="sv">-a</span>-formen:
<span lang="sv">den stora bilen</span>.
</MemoryTip>
