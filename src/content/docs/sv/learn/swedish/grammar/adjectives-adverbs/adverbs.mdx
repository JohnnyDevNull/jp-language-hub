Många svenska sätt-adverb är helt enkelt adjektivets ett-form. Det gör den
vanligaste bildningen enkel – svårare är de självständiga adverben,
satsadverbens placering och paren som skiljer plats från riktning.

## Adverb av adjektiv

<RuleBox title="Regel">
	Många sätt-adverb använder adjektivets <span lang="sv">-t</span>-form: samma form som
	du redan använder med ett ett-ord.
</RuleBox>

| Adjektiv | Adverb | Exempel |
| --- | --- | --- |
| <span lang="sv">{snabb.morphology.en}</span> | <span lang="sv">{snabb.morphology.ett}</span> | <span lang="sv">Han springer snabbt.</span> |
| <span lang="sv">tydlig</span> | <span lang="sv">tydligt</span> | <span lang="sv">Hon talar tydligt.</span> |
| <span lang="sv">vacker</span> | <span lang="sv">vackert</span> | <span lang="sv">Hon sjunger vackert.</span> |
| <span lang="sv">försiktig</span> | <span lang="sv">försiktigt</span> | <span lang="sv">Kör försiktigt!</span> |

När ett adverb återanvänder ett-formen gäller samma stavningsmönster. Se
[adjektivkongruens](../agreement/#stavningsmönster).

Engelskan markerar ofta skillnaden med *-ly*, medan tyskan ofta använder
samma synliga form för adjektiv och adverb. Svenskan använder oftast en
ändelse, men det är en du redan känner från ett-ord.

## Oregelbundna och självständiga adverb

Vissa adverb bildas inte av ett adjektiv eller avviker från den väntade
formen:

| Adverb | Betydelse | Anmärkning |
| --- | --- | --- |
| <span lang="sv">bra</span> | på ett bra sätt | även adjektivet bra: <span lang="sv">Han sjunger bra.</span> |
| <span lang="sv">väl</span> | på ett gott sätt | snävare än <span lang="sv">bra</span>: <span lang="sv">väl gjort</span> |
| <span lang="sv">illa</span> | på ett dåligt sätt | <span lang="sv">Han mår illa.</span> |
| <span lang="sv">gärna</span> | villigt, med glädje | inget adjektiv bakom sig |
| <span lang="sv">mycket</span> | väldigt | med adjektiv: <span lang="sv">mycket bra</span> |

<span lang="sv">Gärna</span> är värt att lära in som en hel uppsättning, eftersom dess
komparation är oregelbunden och extremt vanlig i artigt tal:

<p lang="sv">gärna → hellre → helst</p>

- <span lang="sv">Jag vill gärna komma.</span> — *en artig, mjukad önskan*
- <span lang="sv">Jag vill hellre stanna hemma.</span> — *ett milt föredragande*
- <span lang="sv">Jag vill helst åka på fredag.</span> — *den starkaste preferensen*

## Komparation

Adverb komparerar som adjektiv:

<p lang="sv">{snabb.morphology.ett} → {snabb.comparison?.comparative} → {snabb.comparison?.superlative}</p>

De oregelbundna följer sina egna kedjor:

| Adverb | Komparativ | Superlativ |
| --- | --- | --- |
| <span lang="sv">bra / väl</span> | <span lang="sv">bättre</span> | <span lang="sv">bäst</span> |
| <span lang="sv">gärna</span> | <span lang="sv">hellre</span> | <span lang="sv">helst</span> |
| <span lang="sv">illa</span> | <span lang="sv">värre</span> | <span lang="sv">värst</span> |

<span lang="sv">Sämre</span> och <span lang="sv">värre</span> ligger nära varandra i betydelse, men
<span lang="sv">sämre</span> lutar mot lägre kvalitet och <span lang="sv">värre</span> mot större
allvar. Gränsen är inte skarp, så lär dig dem i fraser. Se
[adjektivets komparation](../adjective-comparison/).

## Plats- och riktningspar

Svenskan håller isär läge och riktning med två separata ord. Tyskan och
engelskan använder inte exakt denna svenska uppdelning, så paren måste läras
som par:

| Riktning | Läge | Exempel |
| --- | --- | --- |
| <span lang="sv">hem</span> | <span lang="sv">hemma</span> | <span lang="sv">Jag går hem.</span> · <span lang="sv">Jag är hemma.</span> |
| <span lang="sv">ut</span> | <span lang="sv">ute</span> | <span lang="sv">Vi går ut.</span> · <span lang="sv">Vi är ute.</span> |
| <span lang="sv">in</span> | <span lang="sv">inne</span> | <span lang="sv">Kom in!</span> · <span lang="sv">Hon är inne.</span> |
| <span lang="sv">upp</span> | <span lang="sv">uppe</span> | <span lang="sv">Han går upp.</span> · <span lang="sv">Han är uppe.</span> |
| <span lang="sv">ner</span> | <span lang="sv">nere</span> | <span lang="sv">Gå ner!</span> · <span lang="sv">Hon är nere.</span> |
| <span lang="sv">bort</span> | <span lang="sv">borta</span> | <span lang="sv">Han reste bort.</span> · <span lang="sv">Han är borta.</span> |
| <span lang="sv">dit</span> | <span lang="sv">där</span> | <span lang="sv">Vi åker dit.</span> · <span lang="sv">Vi är där.</span> |

Samma uppdelning går igen i frågeorden <span lang="sv">vart</span> och <span lang="sv">var</span>. Se
[frågeord](../../questions-negation/question-words/).

## Var satsadverb står

Många satsadverb, bland annat <span lang="sv">alltid</span>, <span lang="sv">aldrig</span> och
<span lang="sv">ofta</span>, följer samma placeringsmönster som <span lang="sv">inte</span>: efter det
finita verbet i en huvudsats, före det i en bisats. Vissa adverb beter sig
snävare, så använd ordföljdssidan när positionen är huvudfrågan.

- <span lang="sv">Hon kommer alltid sent.</span>
- <span lang="sv">…eftersom hon alltid kommer sent.</span>

Se [Placering av *inte*](../../sentence-structure/inte-placement/).

## De små attitydorden

<span lang="sv">Ju</span>, <span lang="sv">nog</span>, <span lang="sv">väl</span> och <span lang="sv">visst</span> tillför attityd
snarare än information, ungefär som de tyska orden
<span lang="de">ja</span>, <span lang="de">wohl</span> och
<span lang="de">doch</span>:

- <span lang="sv">Det är ju sant.</span> — *något vi båda redan vet*
- <span lang="sv">Han kommer nog.</span> — *jag räknar med att han kommer*
- <span lang="sv">Du har väl gjort det?</span> — söker medhåll

De motstår en ren översättning och lärs bäst in genom sammanhang.
Tysktalande har en fördel här, eftersom mekanismen är bekant för dem.

<MemoryTip>
Utgå från ett-formen för vanliga sätt-adverb: om du kan säga
<span lang="sv"><strong>ett snabbt tåg</strong></span>, kan du säga
<span lang="sv"><strong>han springer snabbt</strong></span>. Lägg sedan till de två
grupper som inte går att härleda:
<span lang="sv"><strong>gärna — hellre — helst</strong></span> och
<span lang="sv"><strong>hem / hemma</strong></span>.
</MemoryTip>
