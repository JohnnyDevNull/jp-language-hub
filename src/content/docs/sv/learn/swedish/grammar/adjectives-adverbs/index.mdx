<KeyTakeaway>
- Använd kongruens när ett adjektiv beskriver ett substantiv eller subjekt.
- Använd komparation när du behöver <Sv>större</Sv>, <Sv>störst</Sv>,
  <Sv>mer</Sv> eller <Sv>mest</Sv>.

Den här hyllan skiljer mellan tre frågor som ofta liknar varandra i en sats:
adjektivets form, komparationsgrad och användning av adverb.

## Välj efter behov

| Om du behöver … | Börja med … |
| --- | --- |
| anpassa ett adjektiv till ett en-ord, ett ett-ord, plural eller en bestämd nominalfras | [Adjektivkongruens](./agreement/) |
| välja <Sv>-are</Sv>, <Sv>-ast</Sv>, oregelbundna grader eller <Sv>mer</Sv> / <Sv>mest</Sv> | [Adjektivets komparation](./adjective-comparison/) |
| beskriva sätt, grad, plats, riktning eller inställning | [Adverb](./adverbs/) |

## Lär dig i den här ordningen

1. [Adjektivkongruens](./agreement/) ger formmönstret i vanliga nominalfraser och efter verb som <Sv>vara</Sv>.
2. [Adjektivets komparation](./adjective-comparison/) lägger till grad:
   <Sv>stor</Sv>, <Sv>större</Sv>, <Sv>störst</Sv>.
3. [Adverb](./adverbs/) återanvänder många adjektivformer och lägger till fristående adverb som <Sv>hem</Sv>/<Sv>hemma</Sv> och
   <Sv>gärna</Sv>/<Sv>hellre</Sv>/<Sv>helst</Sv>.

## Se upp med

- Kongruens handlar om form: <Sv>ett stort hus</Sv>,
  <Sv>den stora bilen</Sv>.
- Komparation handlar om grad: <Sv>större än</Sv>,
  <Sv>den största bilen</Sv>.
- Adverb är inte ett andra adjektivsystem. Många sättsadverb använder ett-formen, men fristående adverb måste läras in som ord.
