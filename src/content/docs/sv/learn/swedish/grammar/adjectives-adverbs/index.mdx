<KeyTakeaway>
- Använd kongruens när ett adjektiv beskriver ett substantiv eller subjekt.
- Använd komparation när du behöver <span lang="sv">större</span>, <span lang="sv">störst</span>,
  <span lang="sv">mer</span> eller <span lang="sv">mest</span>.
- Använd adverb när ett ord beskriver hur, var eller i vilken grad något händer.

Den här hyllan skiljer mellan tre frågor som ofta liknar varandra i en sats:
adjektivets form, komparationsgrad och användning av adverb.

## Välj efter behov

| Om du behöver … | Börja med … |
| --- | --- |
| anpassa ett adjektiv till ett en-ord, ett ett-ord, plural eller en bestämd nominalfras | [Adjektivkongruens](./agreement/) |
| välja <span lang="sv">-are</span>, <span lang="sv">-ast</span>, oregelbundna grader eller <span lang="sv">mer</span> / <span lang="sv">mest</span> | [Adjektivets komparation](./adjective-comparison/) |
| beskriva sätt, grad, plats, riktning eller inställning | [Adverb](./adverbs/) |

## Lär dig i den här ordningen

1. [Adjektivkongruens](./agreement/) ger formmönstret i vanliga nominalfraser och efter verb som <span lang="sv">vara</span>.
2. [Adjektivets komparation](./adjective-comparison/) lägger till grad:
   <span lang="sv">stor</span>, <span lang="sv">större</span>, <span lang="sv">störst</span>.
3. [Adverb](./adverbs/) återanvänder många adjektivformer och lägger till fristående adverb som <span lang="sv">hem</span>/<span lang="sv">hemma</span> och
   <span lang="sv">gärna</span>/<span lang="sv">hellre</span>/<span lang="sv">helst</span>.

## Se upp med

- Kongruens handlar om form: <span lang="sv">ett stort hus</span>,
  <span lang="sv">den stora bilen</span>.
- Komparation handlar om grad: <span lang="sv">större än</span>,
  <span lang="sv">den största bilen</span>.
- Adverb är inte ett andra adjektivsystem. Många sättsadverb använder ett-formen, men fristående adverb måste läras in som ord.
