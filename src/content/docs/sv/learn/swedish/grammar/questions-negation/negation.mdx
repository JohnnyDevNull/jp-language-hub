<KeyTakeaway>
- Använd <span lang="sv">inte</span> för att negera en sats: <span lang="sv">Jag kommer inte.</span>
- Använd ett negativt substantiv- eller adverbuttryck när det självt bär
  negationen: <span lang="sv">Ingen kom.</span>, <span lang="sv">Jag såg ingenting.</span>
- I vanlig standardsvenska lägger du inte till <span lang="sv">inte</span> när ett annat
  negativt uttryck redan negerar samma sats.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Negation är först ett val av betydelse och form. Den här sidan hjälper dig att
välja negativt uttryck; [Placering av *inte*](../../sentence-structure/inte-placement/)
äger var <span lang="sv">inte</span> står i varje satstyp.

## Använd detta nu

| Betydelse | Använd | Exempel |
| --- | --- | --- |
| nekande | <span lang="sv">inte</span> | <span lang="sv">Jag arbetar inte idag.</span> |
| avsaknad av person | <span lang="sv">ingen</span> | <span lang="sv">Ingen ringde.</span> |
| avsaknad av sak | <span lang="sv">ingenting</span> eller <span lang="sv">inget</span> + substantiv | <span lang="sv">Jag hörde ingenting.</span> / <span lang="sv">Jag hörde inget ljud.</span> |
| inte en enda gång | <span lang="sv">aldrig</span> | <span lang="sv">Hon röker aldrig.</span> |
| ingen plats | <span lang="sv">ingenstans</span> | <span lang="sv">Jag hittar den ingenstans.</span> |
| samma negation igen | <span lang="sv">inte … heller</span> | <span lang="sv">Jag kommer inte heller.</span> |

## Kärnregel

Använd <span lang="sv">inte</span> för att negera hela satsen eller avvisa en del i
sammanhanget:

- <span lang="sv">Jag **kommer inte** imorgon.</span>
- <span lang="sv">Hon köpte **inte den röda** bilen.</span>

Använd ett negativt uttryck när den saknade personen, saken, tiden eller
platsen själv är negativ:

- <span lang="sv">**Ingen** väntar utanför.</span>
- <span lang="sv">Jag såg **ingenting**.</span>
- <span lang="sv">Vi går **aldrig** dit.</span>
- <span lang="sv">Nyckeln finns **ingenstans**.</span>

## Indefinit under satsnegation

När <span lang="sv">inte</span> negerar satsen används normalt ett icke-negativt indefinit
uttryck inom dess räckvidd:

- <span lang="sv">Jag har **inte någon** bil.</span>
- <span lang="sv">Jag såg **inte något** problem.</span>
- <span lang="sv">Vi har **inte några** frågor.</span>

Den kompakta negativa nominalfrasen ger ofta samma resultat i verkligheten:

- <span lang="sv">Jag har **ingen** bil.</span>
- <span lang="sv">Jag såg **inget** problem.</span>
- <span lang="sv">Vi har **inga** frågor.</span>

De två mönstren går inte att byta ut mekaniskt i alla sammanhang.
<span lang="sv">Ingen / inget / inga</span> paketerar frånvaron i nominalfrasen;
<span lang="sv">inte någon / något / några</span> håller satsnegationen synlig och kan flytta
fokus eller kontrast.

Den fullständiga kongruensen och valet av nominalfras hör till
[*någon, något, ingen, inget*](../../pronouns-roles/nagon-nagot-ingen-inget/).

## Direkt jämförelse

<LanguageComparison title="Ingen bil">
	<p slot="de">Ich habe kein Auto.</p>
	<p slot="en">I do not have a car.</p>
	<p slot="sv">Jag har ingen bil.</p>
</LanguageComparison>

<LanguageComparison title="Ingenting">
	<p slot="de">Ich habe nichts gesehen.</p>
	<p slot="en">I did not see anything.</p>
	<p slot="sv">Jag såg ingenting.</p>
</LanguageComparison>

Engelskan kombinerar ofta *not* med *anything*. Svenskan kan använda
<span lang="sv">inte</span> plus ett indefinit uttryck eller ett negativt uttryck; valet kan
påverka fokus och räckvidd.

<MistakeBox
	title="Undvik vanlig dubbel negation"
	incorrect="Ingen kom inte."
	correct="Ingen kom."
	lang="sv"
>
I vanlig standardsvenska bär ett uttryck normalt negationen. Om <span lang="sv">ingen</span>
redan bär den negativa betydelsen ensam, ändrar ett andra <span lang="sv">inte</span> normalt
betydelsen istället för att förstärka den.
</MistakeBox>

<MemoryTip>
Välj först **en bärare av den negativa betydelsen**: satsomfattande
<span lang="sv">inte</span>, eller ett negativt person-, sak-, tids- eller platsuttryck.
</MemoryTip>
