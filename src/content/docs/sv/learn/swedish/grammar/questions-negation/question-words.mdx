<KeyTakeaway>
- I en direkt fråga kommer frågeordet först och det finita verbet på andra
  plats: <span lang="sv">Var bor du?</span>
- En indirekt fråga är en bisats, så subjektet kommer tillbaka före verbet:
  <span lang="sv">Jag vet inte var hon bor.</span>
- I en indirekt fråga får <span lang="sv">vem</span> och <span lang="sv">vad</span> tillägget
  <span lang="sv">som</span> när de är subjekt i sin egen sats.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenska frågeord börjar nästan alla på <span lang="sv">v-</span>, vilket gör dem lätta att
känna igen. Det svåra är ordföljden, som skiljer sig mellan direkta och
indirekta frågor.

## Använd detta nu

| Svenska | Frågar om … |
| --- | --- |
| <span lang="sv">vem</span> | en person |
| <span lang="sv">vems</span> | en ägare |
| <span lang="sv">vad</span> | en sak, en händelse eller en identitet |
| <span lang="sv">vilken / vilket / vilka</span> | ett val ur en mängd |
| <span lang="sv">var</span> | en plats |
| <span lang="sv">vart</span> | en riktning |
| <span lang="sv">när</span> | en tidpunkt |
| <span lang="sv">hur</span> | ett sätt eller ett tillstånd |
| <span lang="sv">varför</span> | en orsak |
| <span lang="sv">hur mycket / hur många</span> | en mängd eller ett antal |

<span lang="sv">Vem</span> böjs inte — det finns ingen egen objektsform, så
<span lang="sv">Vem såg du?</span> och <span lang="sv">Vem såg dig?</span> skiljs bara åt av
ordföljden, inte av pronomenet.

## Kärnregel: direkta frågor

När frågeordet inte är subjekt fyller det den första platsen, och det finita
verbet följer direkt efter. Jämför den ramen med en ja/nej-fråga:

<SentenceSchema
	caption="Ramar för direkta frågor"
	rowHeader="Fråga"
	columns={['fundament', 'finit verb', 'subjekt', 'adverbial']}
	rows={[
		{ label: 'Frågeord', cells: ['Var', 'bor', 'du', ''] },
		{ label: 'Frågefras', cells: ['Vilken bok', 'läser', 'du', ''] },
		{ label: 'Ja/nej', cells: ['', 'Bor', 'du', 'här?'] },
	]}
/>

Är frågeordet självt subjekt, tar det subjektsrollen och inget separat
subjekt följer: <span lang="sv">Vem ringde?</span> och <span lang="sv">Vad hände?</span>

<RuleBox title="Inget do-stöd">
	Svenskan har inget som motsvarar engelskans *do*. <span lang="sv">Bor du här?</span>
	betyder *Do you live here?*, och <span lang="sv">Vad sa han?</span> betyder *What did
	he say?* Verbet flyttar sig självt; inget hjälpverb läggs till.
</RuleBox>

Se [Frågor](../questions/) för den gemensamma ja/nej-ramen och
[V2](../../sentence-structure/v2/) för påståendesatser i huvudsats.

## Var eller vart

Standardsvenskan skiljer läge från riktning:

- <span lang="sv">Var bor du?</span> frågar var någon befinner sig.
- <span lang="sv">Vart går du?</span> frågar vart någon är på väg.

För utgångspunkt hamnar prepositionen sist:
<span lang="sv">Var kommer du ifrån?</span>

## Vilken stämmer med substantivet

Serien med <span lang="sv">vilken</span> stämmer med substantivets genus och numerus:

- <span lang="sv">Vilken bok läser du?</span> — ett en-ord
- <span lang="sv">Vilket hus är ditt?</span> — ett ett-ord
- <span lang="sv">Vilka böcker har du läst?</span> — plural

För att fråga vilken sort använder svenskan <span lang="sv">vad för</span> eller
<span lang="sv">vad för sorts</span>:
<span lang="sv">Vad för sorts musik lyssnar du på?</span>

Se [en / ett](../../nouns-articles/en-ett/) för genuset bakom valet.

## Indirekta frågor: ingen inversion

En indirekt fråga är en bisats. Subjektet kommer därför före det finita
verbet, och ett satsadverbial som <span lang="sv">inte</span> kommer också före det
verbet:

	caption="Ordföljd i direkt fråga"
	rowHeader="Fråga"
	columns={['fundament', 'finit verb', 'subjekt', 'satsadverbial', 'adverbial']}
	rows={[
		{ label: 'Direkt', cells: ['Var', 'bor', 'hon', '', ''] },
	]}
/>

<SentenceSchema
	caption="Ordföljd i indirekt fråga"
	rowHeader="Fråga"
	columns={['bisatsinledare', 'subjekt', 'satsadverbial', 'finit verb', 'adverbial']}
	rows={[
		{ label: 'Neutral', cells: ['var', 'hon', '', 'bor', ''] },
		{ label: 'Nekande', cells: ['varför', 'hon', 'inte', 'kommer', ''] },

/>

- <span lang="sv">Var bor hon?</span> → <span lang="sv">Jag vet inte var hon bor.</span>
- <span lang="sv">Varför kommer hon?</span> → <span lang="sv">Jag förstår inte varför hon kommer.</span>

Se [Bisatser](../../sentence-structure/subordinate-clauses/) för den
allmänna ramen för bisatser. [Frågor](../questions/#indirect-yesno-questions-with-om)
tar upp indirekta ja/nej-frågor med <span lang="sv">om</span>.

## Lägg till som när frågeordet är subjekt

I en indirekt fråga får <span lang="sv">vem</span> och <span lang="sv">vad</span> tillägget
<span lang="sv">som</span> när de är subjekt i sin egen sats:

- <span lang="sv">Jag vet inte vem som ringde.</span> — frågeordet är subjekt i bisatsen.
- <span lang="sv">Berätta vad som hände!</span> — samma mönster i en uppmaning.

När de i stället är objekt, uteblir <span lang="sv">som</span>:

- <span lang="sv">Jag vet inte vem hon ringde.</span> — frågeordet är objekt, inte
  subjekt.
- <span lang="sv">Berätta vad du gjorde!</span> — objektet i uppmaningen.

Direkta frågor behöver det inte: <span lang="sv">Vem ringde?</span>,
<span lang="sv">Vad hände?</span>

## Vanliga misstag

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">Jag vet inte var bor hon.</span>
	  ✅ <span lang="sv">Jag vet inte var hon bor.</span>
	- ❌ <span lang="sv">Jag vet inte vem ringde.</span>
	  ✅ <span lang="sv">Jag vet inte vem som ringde.</span>
	- ❌ <span lang="sv">Vart bor du?</span>
	  ✅ <span lang="sv">Var bor du?</span>
	- ❌ <span lang="sv">Vilken hus är ditt?</span>
	  ✅ <span lang="sv">Vilket hus är ditt?</span>
</MistakeBox>

<MemoryTip>
Kontrastera ett par tills det sitter automatiskt:
<span lang="sv"><strong>Vem som ringde</strong></span> — den som ringde är subjektet.
<span lang="sv"><strong>Vem hon ringde</strong></span> — den som ringde är någon annan.
Det extra <span lang="sv">som</span> markerar subjektet.
</MemoryTip>
