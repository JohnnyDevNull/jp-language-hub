<KeyTakeaway>
- En bisats är del av en större mening och börjar ofta med en subjunktion som
  <span lang="sv">att</span>, <span lang="sv">eftersom</span>, <span lang="sv">om</span> eller <span lang="sv">när</span>.
- Den praktiska grundramen är **bisatsinledare + subjekt + satsadverbial + finit
  verb + adverbial**.
- Om hela bisatsen kommer först använder följande huvudsats inversion.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

En bisats lägger till innehåll som vad någon säger, varför något händer, ett
villkor eller en tidpunkt. Den kan vanligtvis inte stå ensam med samma
funktion: <span lang="sv">eftersom jag är trött</span> behöver en huvudsats omkring sig.

## Använd detta nu

| Betydelse | Inled bisatsen med … | Exempel |
| --- | --- | --- |
| återgivet innehåll | <span lang="sv">att</span> | <span lang="sv">Jag vet att hon kommer.</span> |
| därför att | <span lang="sv">eftersom</span> | <span lang="sv">Jag stannar eftersom jag är trött.</span> |
| villkor / huruvida | <span lang="sv">om</span> | <span lang="sv">Vi går ut om det inte regnar.</span> |
| tidpunkt | <span lang="sv">när</span> | <span lang="sv">Ring mig när du är klar.</span> |
| före | <span lang="sv">innan</span> | <span lang="sv">Ät innan du går.</span> |

## Kärnregel

Använd det här pålitliga mönstret när bisatsen innehåller ett satsadverbial
som <span lang="sv">inte</span>:

	caption="Den svenska bisatsramen"
	rowHeader="Betydelse"
	columns={['bisatsinledare', 'subjekt', 'satsadverbial', 'finit verb', 'infinit verb', 'objekt / predikativ', 'adverbial']}
	rows={[
		{ label: 'Orsak', cells: ['eftersom', 'jag', 'inte', 'kan', 'komma', '', 'idag'] },
		{ label: 'Innehåll', cells: ['att', 'hon', 'redan', 'har', 'köpt', 'biljetten', ''] },
		{ label: 'Villkor', cells: ['om', 'det', 'inte', 'regnar', '', '', ''] },
	]}
/>

Utan satsadverbial följer det finita verbet direkt på subjektet:

- <span lang="sv">Jag vet **att hon kommer**.</span>
- <span lang="sv">Ring mig **när du är klar**.</span>

[BIFF-regeln](../biff/) tar upp den snävare frågan om varför <span lang="sv">inte</span> och
andra satsadverbial står före det finita verbet här.

## När bisatsen kommer först

Hela bisatsen kan fylla huvudsatsens första fält. Huvudsatsen placerar då sitt
finita verb före subjektet:

<SentenceSchema
	caption="En bisats före en huvudsats"
	rowHeader="Sats"
	columns={['1 fundament', '2 finit verb', '3 subjekt', 'adverbial']}
	rows={[
		{
			label: 'Bisats + huvudsats',
			cells: ['När mötet är slut', 'går', 'vi', 'hem.'],
		},
	]}
/>

Den förskjutningen i huvudsatsen hör till [Inversion](../inversion/), inte
till bisatsens egen ordföljd.

## Indirekta frågor

Även en indirekt fråga uppför sig som en bisats:

- <span lang="sv">Jag vet inte **var hon bor**.</span>
- <span lang="sv">Han frågade **om tåget var sent**.</span>

[Frågeord](../../questions-negation/question-words/) tar upp ordvalet och
mönstret för direkta jämfört med indirekta frågor.

## Direkt jämförelse

<LanguageComparison title="Eftersom-sats">
	<p slot="de">… weil ich heute nicht kommen kann.</p>
	<p slot="en">… because I cannot come today.</p>
	<p slot="sv">… eftersom jag inte kan komma idag.</p>
</LanguageComparison>

Tyskan markerar också bisatser med särskild ordföljd men skickar det finita
verbet till slutet. Svenskan behåller det finita verbet efter satsadverbialet
och före ett eventuellt icke-finit verb.

<MistakeBox
	incorrect="Jag stannar hemma eftersom jag kan inte komma."
	correct="Jag stannar hemma eftersom jag inte kan komma."
	lang="sv"
>
För inte in huvudsatsens satsadverbialplacering i en bisats.
</MistakeBox>

<MemoryTip>
Bygg det beroende blocket från vänster till höger: **bisatsinledare → subjekt →
satsadverbial → finit verb → adverbial**.
</MemoryTip>
