- Återge ett påstående med <span lang="sv">att</span>, en ja/nej-fråga med <span lang="sv">om</span> och

Indirekt tal återger innehållet i någons ord utan att upprepa den
ursprungliga meningen som citat.

## Använd detta nu

| Ursprungligt yttrande | Länkord | Återgivning |
| --- | --- | --- |
| påstående | <span lang="sv">att</span> | <span lang="sv">Hon säger att hon kommer.</span> |
| ja/nej-fråga | <span lang="sv">om</span> | <span lang="sv">Han frågar om jag kommer.</span> |
| frågeordsfråga | samma frågeord | <span lang="sv">Hon frågar när tåget går.</span> |

## Påståenden med <span lang="sv">att</span>

Använd ett återgivande verb som <span lang="sv">säga</span>, <span lang="sv">berätta</span> eller
<span lang="sv">förklara</span> följt av en <span lang="sv">att</span>-sats:

<span lang="sv">Lisa säger: “Jag är trött.”</span> →
<span lang="sv">Lisa säger att hon är trött.</span>

## Indirekta frågor

En ja/nej-fråga blir en <span lang="sv">om</span>-sats. En frågeordsfråga behåller sitt
frågeord. Båda har bisatsordföljd:

<SentenceSchema
	caption="Ordföljd i indirekta frågor"
	columns={['bisatsinledare', 'subjekt', 'satsadverbial', 'finit verb', 'infinit verb', 'adverbial']}
	rows={[
		{ label: 'Ja/nej', lang: 'sv', cells: ['om', 'du', 'inte', 'kan', 'komma', ''] },
		{ label: 'Frågeord', lang: 'sv', cells: ['varför', 'hon', '', 'gick', '', 'hem'] },
	]}
/>

- <span lang="sv">Han frågar om du inte kan komma.</span>
- <span lang="sv">Jag undrar varför hon gick hem.</span>

Behåll inte den direkta frågans inversion: <span lang="sv">varför hon gick</span>, inte
<span lang="sv">varför gick hon</span> inuti återgivningen.

## Perspektivbyten

Ändra former endast när återgivningssituationen kräver det:

- person: <span lang="sv">jag</span> kan bli <span lang="sv">hon</span> eller <span lang="sv">han</span>
- ägande: <span lang="sv">min</span> kan bli <span lang="sv">hennes</span>, <span lang="sv">hans</span> eller ett
  reflexivt possessivt pronomen i den aktuella satsen
- tid: <span lang="sv">i dag</span> kan bli <span lang="sv">den dagen</span>
- plats: <span lang="sv">här</span> kan bli <span lang="sv">där</span>

Om det ursprungliga perspektivet fortfarande delas kan en ändring vara
onödig.

## Tempus i återgivningen

Svenskan behåller ofta ett tempus som fortfarande är sant eller relevant:
<span lang="sv">Hon sa att hon bor i Malmö.</span> kan återge ett fortfarande gällande
faktum. En dåtidsform är också naturlig när återgivningen hör hemma i en
förfluten ram eller situationen inte längre gäller:
<span lang="sv">Hon sa att hon bodde i Malmö.</span>

Använd inte en mekanisk bakåtförskjutningsregel enligt engelskt mönster.
Välj tempus utifrån talarens nuvarande tidsperspektiv och den avsedda
betydelsen.

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">Han frågar att jag kommer.</span>
	  ✅ <span lang="sv">Han frågar om jag kommer.</span>
	- ❌ <span lang="sv">Hon frågar var bor du.</span>
	  ✅ <span lang="sv">Hon frågar var du bor.</span>
	- Ändra inte varje presens till preteritum bara för att det återgivande
	  verbet står i preteritum.
</MistakeBox>
