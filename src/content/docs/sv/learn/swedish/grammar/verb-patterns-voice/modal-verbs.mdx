<KeyTakeaway>
- De centrala modala verben <span lang="sv">kan</span>, <span lang="sv">vill</span>, <span lang="sv">måste</span>,
  <span lang="sv">får</span>, <span lang="sv">bör</span> och <span lang="sv">ska</span> följs normalt av en naken
  infinitiv.
- Vanliga verb varierar: vissa kräver <span lang="sv">att</span>, andra tillåter eller
  föredrar en naken infinitiv i specifika mönster.
- Lär dig betydelsen och anslutningsmönstret tillsammans; lägg inte
  automatiskt till <span lang="sv">att</span> mellan två verb.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Modala verb uttrycker förmåga, önskan, nödvändighet, tillåtelse, råd, avsikt
eller förväntan. De är finita; det efterföljande lexikala verbet står kvar i
infinitiv.

## Använd detta nu

| Betydelse | Modalt verb | Exempel |
| --- | --- | --- |
| förmåga eller möjlighet | <span lang="sv">kan</span> | <span lang="sv">Jag kan simma.</span> |
| önskan | <span lang="sv">vill</span> | <span lang="sv">Hon vill stanna.</span> |
| nödvändighet | <span lang="sv">måste</span> | <span lang="sv">Vi måste gå.</span> |
| tillåtelse | <span lang="sv">får</span> | <span lang="sv">Ni får komma in.</span> |
| råd | <span lang="sv">bör</span> | <span lang="sv">Du bör vila.</span> |
| plan, förväntan eller skyldighet | <span lang="sv">ska</span> | <span lang="sv">Jag ska ringa.</span> |

## Kärnregel: naken infinitiv efter ett modalt verb

Grundmönstret är **finit modalt verb + naken infinitiv**:

- <span lang="sv">Jag kan tala svenska.</span>
- <span lang="sv">Vi vill beställa.</span>
- <span lang="sv">Du måste vänta.</span>

Lägg inte till <span lang="sv">att</span>: <span lang="sv">kan tala</span>, inte <span lang="sv">kan att tala</span>.
Det finita modala verbet upptar den verbposition som svenskans
ordföljdsregler styr; infinitiven följer som andra verb. Se
[V2](../../sentence-structure/v2/) för mönstret i huvudsatsen.

## Vanliga tvåverbsmönster

Utanför den centrala modalgruppen lär du dig konstruktionen tillsammans med
det första verbet:

- normalt krävs <span lang="sv">att</span>: <span lang="sv">planera att resa</span>,
  <span lang="sv">lova att komma</span>
- etablerade mönster med naken infinitiv: <span lang="sv">brukar arbeta</span>,
  <span lang="sv">orkar vänta</span>
- valfri variation i många sammanhang: <span lang="sv">börja arbeta</span> eller
  <span lang="sv">börja att arbeta</span>; <span lang="sv">försöka förstå</span> eller
  <span lang="sv">försöka att förstå</span>

Bruket varierar med verb och register, så en enda universell regel om att
„två verb kräver <span lang="sv">att</span>“ håller inte. Lägg anslutningsmönstret på minnet
tillsammans med verbet.

## <span lang="sv">Ska</span>: syntax här, framtidsval där

Den här sidan behandlar mönstret <span lang="sv">ska</span> + naken infinitiv och dess
modala användningsområde. Använd [Futurumformer](../../verbs-time-forms/future-forms/)
för att avgöra om <span lang="sv">ska</span>, ett kontextuellt presens, <span lang="sv">tänker</span>
eller <span lang="sv">kommer att</span> uttrycker framtiden bäst.

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">Jag kan att simma.</span>
	  ✅ <span lang="sv">Jag kan simma.</span>
	- <span lang="sv">Får</span> gäller oftast tillåtelse; <span lang="sv">kan</span> gäller oftast förmåga
	  eller praktisk möjlighet.
	- Använd inte <span lang="sv">ska</span> som automatisk motsvarighet till varje engelskt
	  <em>will</em> eller tyskt <span lang="de">werden</span>.
</MistakeBox>

<MemoryTip>
Lär dig en kort enhet: <span lang="sv">kan simma</span>, <span lang="sv">vill stanna</span>,
<span lang="sv">försöker att förstå</span>. Det första verbet avgör mönstret.
</MemoryTip>
