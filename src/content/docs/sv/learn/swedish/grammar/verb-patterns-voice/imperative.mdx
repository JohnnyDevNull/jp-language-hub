<KeyTakeaway>
- Imperativ är en verbform utan uttryckt subjekt:
  <span lang="sv">Kom!</span>, <span lang="sv">Vänta!</span>, <span lang="sv">Läs!</span>
- Använd det nekande mönstret <span lang="sv">imperativ + inte</span>:
  <span lang="sv">Glöm inte biljetten!</span>
- Samma form kan vara en direkt befallning, en instruktion, en inbjudan eller
  ett vänligt förslag; sammanhang och mildrande ord avgör tonen.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Använd imperativ när du vill att någon annan ska göra något direkt. Svenskan
använder samma form oavsett om du talar till en person eller flera.

## Använd detta nu

| Syfte | Exempel |
| --- | --- |
| direkt instruktion | <span lang="sv">Tryck här.</span> |
| inbjudan | <span lang="sv">Kom in!</span> |
| vänligt förslag | <span lang="sv">Ta en bulle!</span> |
| nekande instruktion | <span lang="sv">Rör inte skärmen.</span> |

## Kärnregel

Imperativ är en del av verbets formkedja. För många verb är det stammen som
används före andra ändelser:

| Infinitiv | Imperativ |
| --- | --- |
| <span lang="sv">att tala</span> | <span lang="sv">tala!</span> |
| <span lang="sv">att köpa</span> | <span lang="sv">köp!</span> |
| <span lang="sv">att ringa</span> | <span lang="sv">ring!</span> |
| <span lang="sv">att gå</span> | <span lang="sv">gå!</span> |

Vanliga oregelbundna former bör läras in tillsammans med verbet, till exempel
<span lang="sv">vara → var!</span> och <span lang="sv">göra → gör!</span>

Subjektet utelämnas normalt. I en nekande imperativsats placeras <span lang="sv">inte</span>
efter imperativet: <span lang="sv">Gå inte dit!</span> Se
[Placering av inte](../../sentence-structure/inte-placement/) för det
bredare placeringssystemet.

## Ton och alternativ

Ett rakt imperativ kan vara neutralt i recept, på skyltar och i tydliga
instruktioner. I samtal, lägg till <span lang="sv">gärna</span>, <span lang="sv">snälla</span> eller en
frågeform när relationen eller önskemålet behöver mer mjukhet:

- <span lang="sv">Sitt gärna här.</span>
- <span lang="sv">Kan du öppna fönstret?</span>

[Artiga önskemål](../../../sentence-patterns/polite-requests/) samlar
dessa färdiga kommunikationsmönster.

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">Inte glöm biljetten!</span>
	  ✅ <span lang="sv">Glöm inte biljetten!</span>
	- Lägg inte till ett obligatoriskt subjekt av analogi med ett vanligt
	  påstående.
	- Behandla inte varje imperativ som oartigt; situationen och ordvalet
	  avgör tonen.
</MistakeBox>
