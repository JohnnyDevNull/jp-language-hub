<KeyTakeaway>
- S-passiv använder en <span lang="sv">-s</span>-form genom de vanliga mönstren infinitiv,
  presens, preteritum och supinum; den exakta formen följer verbets
  morfologi.
- <span lang="sv">Bli</span> + particip presenterar en händelse eller förändring, medan
  <span lang="sv">vara</span> + particip presenterar ett tillstånd; participet böjs efter
  subjektet.
- En <span lang="sv">-s</span>-form är inte alltid passiv: <span lang="sv">hoppas</span> och
  <span lang="sv">Vi ses!</span> är det inte.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenskan har ett **s-passiv** inbyggt i verbformen samt particip-
passivkonstruktioner med <span lang="sv">bli</span> eller <span lang="sv">vara</span>. Den som talar
tyska känner ofta igen den bekanta formen <span lang="sv">bli</span> + particip, men
konstruktionerna motsvarar inte varandra rakt av mellan språken.

Den här sidan handlar om bildning och igenkänning. För informationsfokus,
uteslutande av aktören och valet mellan aktiv och passiv formulering, se
[Aktiv vs. passiv](../active-vs-passive/).

## S-passiv

Mönstret med <span lang="sv">-s</span> förekommer i infinitiv, presens, preteritum och
supinum. Den exakta presensformen beror på verbmönstret: grupp 1 har oftast
<span lang="sv">-as</span>, många andra verb använder stammen plus <span lang="sv">-s</span>, och stammar
som redan slutar på ett s-ljud använder ibland <span lang="sv">-es</span>, som i
<span lang="sv">läsa → läses</span>. Preteritum och supinum lägger vanligen till <span lang="sv">-s</span>
till motsvarande aktiva form. Använd formkedjan i stället för en regel utan
undantag:

| Form | Aktiv | Passiv |
| --- | --- | --- |
| Infinitiv | <span lang="sv">öppna</span> | <span lang="sv">öppnas</span> |
| Presens | <span lang="sv">öppnar</span> | <span lang="sv">öppnas</span> |
| Preteritum | <span lang="sv">öppnade</span> | <span lang="sv">öppnades</span> |
| Supinum | <span lang="sv">öppnat</span> | <span lang="sv">öppnats</span> |

Andra verbgrupper ger former som dessa:

| Verb | Presens | Preteritum | Supinum |
| --- | --- | --- | --- |
| <span lang="sv">köpa</span> | <span lang="sv">köps</span> | <span lang="sv">köptes</span> | <span lang="sv">köpts</span> |
| <span lang="sv">skriva</span> | <span lang="sv">skrivs</span> | <span lang="sv">skrevs</span> | <span lang="sv">skrivits</span> |

Exempel i bruk:

- <span lang="sv">Rummet städas varje dag.</span> — *en rutin som upprepas varje dag*
- <span lang="sv">Cykeln stals i går.</span> — *en enskild händelse i det förflutna*
- <span lang="sv">Boken skrevs av Astrid Lindgren.</span> — *aktören nämns uttryckligen
  med "av"*

Aktören, om den alls nämns, införs med
<span lang="sv">av</span>.

<RuleBox title="Känna igen s-passiv">
	Bestäm grundverbet och kontrollera om subjektet är den påverkade parten:
	<span lang="sv">Dörrarna stängs automatiskt.</span> En <span lang="sv">-s</span>-ändelse ensam bevisar
	inte passiv betydelse.
</RuleBox>

## Particip-passiv med <span lang="sv">bli</span> och <span lang="sv">vara</span>

<span lang="sv">Bli</span> plus perfektparticip presenterar oftast en händelse eller en
förändring:

- <span lang="sv">Dörren blev öppnad.</span> — *händelsen framställs som en enskild
  förändring*
- <span lang="sv">Han blev vald till ordförande.</span> — *ett resultat av ett val, inte
  en pågående process*

Particip beter sig som ett adjektiv och böjs efter subjektet:

| Subjekt | Exempel |
| --- | --- |
| en-ord | <span lang="sv">Bilen blev såld.</span> |
| ett-ord | <span lang="sv">Huset blev sålt.</span> |
| plural | <span lang="sv">Böckerna blev sålda.</span> |

Se [Adjektivkongruens](../../adjectives-adverbs/agreement/)
för ändelserna.

Med <span lang="sv">vara</span> i stället för <span lang="sv">bli</span> beskriver samma
particip ett resulterande tillstånd i stället för händelsen:
<span lang="sv">Huset är sålt.</span>

## Bildningsöversikt

| Konstruktion | Form | Exempel |
| --- | --- | --- |
| s-passiv, presens | presensstam/-form + <span lang="sv">-s</span> | <span lang="sv">Biljetter köps i appen.</span> |
| s-passiv, preteritum | preteritum + <span lang="sv">-s</span> | <span lang="sv">Boken skrevs 1950.</span> |
| händelse-/förändringspassiv | finit <span lang="sv">bli</span> + kongruerande particip | <span lang="sv">Han blev bjuden.</span> |
| resulterande tillstånd | finit <span lang="sv">vara</span> + kongruerande particip | <span lang="sv">Dörren är stängd.</span> |

## Direkt jämförelse

<LanguageComparison title="Rutin, ingen aktör">
	<p slot="de">Das Zimmer wird jeden Tag geputzt.</p>
	<p slot="en">The room is cleaned every day.</p>
	<p slot="sv">Rummet städas varje dag.</p>
</LanguageComparison>

<LanguageComparison title="Händelse framställd som förändring">
	<p slot="de">Die Tür wurde geöffnet.</p>
	<p slot="en">The door was opened.</p>
	<p slot="sv">Dörren blev öppnad.</p>
</LanguageComparison>

S-passiv kan också beskriva en konkret händelse, som i <span lang="sv">Cykeln stals i
går</span>. <span lang="sv">Bli</span> lyfter fram händelsen eller övergången mer explicit;
det äger inte varje enskild händelses passiv. Se
[Aktiv vs. passiv](../active-vs-passive/) för det kommunikativa valet och det
aktiva alternativet med <span lang="sv">man</span>.

## S-verb som inte är passiva

Vissa verb slutar helt enkelt på <span lang="sv">-s</span> och saknar aktiv form.
De är inga passiver, och att behandla dem som sådana leder ingenstans:

| Verb | Betydelse |
| --- | --- |
| <span lang="sv">finns</span> | existerar, förekommer |
| <span lang="sv">hoppas</span> | önskar att något ska hända |
| <span lang="sv">trivs</span> | mår bra och känner sig hemma |
| <span lang="sv">minns</span> | kommer ihåg |
| <span lang="sv">lyckas</span> | klarar av något; når ett resultat |
| <span lang="sv">andas</span> | för in och ut luft genom lungorna |

- <span lang="sv">Jag hoppas att du mår bra.</span>
- <span lang="sv">Jag trivs i Malmö.</span>

## Det reciproka -s

En <span lang="sv">-s</span>-form kan också betyda att två eller fler personer gör något
*med varandra*:

- <span lang="sv">Vi ses!</span> — *ett avskedsuttryck, inte en passiv händelse*
- <span lang="sv">De träffas varje vecka.</span> — *en återkommande ömsesidig handling*
- <span lang="sv">De kramades.</span> — *en ömsesidig handling i dåtid*

## Vanliga misstag

<MistakeBox title="Vanliga misstag">
	- <span lang="sv">Rummet städas varje dag</span> är det kompakta rutinmönstret; dra inte
	  slutsatsen att <span lang="sv">bli</span> är reserverat för varje enskild händelse.
	- ❌ <span lang="sv">Huset blev sålld</span>
	  ✅ <span lang="sv">Huset blev sålt.</span> — participet böjs efter
	  subjektet
	- ❌ <span lang="sv">Jag hoppar att du mår bra</span>
	  ✅ <span lang="sv">Jag hoppas att du mår bra.</span> —
	  <span lang="sv">hoppas</span> saknar aktiv form
	- ❌ <span lang="sv">Boken skrevs från Astrid Lindgren</span>
	  ✅ <span lang="sv">Boken skrevs av Astrid Lindgren.</span>
	- Ta inte till <span lang="sv">bli</span> bara för att tyskan använder
	  <span lang="de">werden</span>.
	</MistakeBox>

<MemoryTip>
Tre korta meningar skiljer de centrala mönstren åt:
<span lang="sv"><strong>Rummet städas varje dag</strong></span> — rutin.
<span lang="sv"><strong>Dörren blev öppnad</strong></span> — händelse eller förändring.
<span lang="sv"><strong>Vi ses!</strong></span> — med varandra, inte passiv alls.
</MemoryTip>
