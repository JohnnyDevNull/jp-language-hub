<KeyTakeaway>
- Använd presens när ett tidsuttryck eller situationen redan gör framtiden
  tydlig.
- Använd <span lang="sv">ska</span> för beslut, löften, överenskommelser eller förväntade
  händelser; använd <span lang="sv">tänker</span> för en personlig avsikt.
- Använd <span lang="sv">kommer att</span> framför allt för en förutsägelse eller
  utveckling som inte presenteras som någons plan.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenskan uttrycker framtid med flera vanliga konstruktioner. Välj efter
betydelse i stället för att mekaniskt översätta engelskans *will* eller
tyskans *werden*.

## Använd detta nu

| Betydelse | Lämpligt val | Exempel |
| --- | --- | --- |
| planerat eller tydligt av sammanhanget | presens | <span lang="sv">Tåget går klockan åtta.</span> |
| beslut, löfte, överenskommelse, förväntning | <span lang="sv">ska</span> + infinitiv | <span lang="sv">Jag ska ringa i kväll.</span> |
| personlig avsikt | <span lang="sv">tänker</span> + infinitiv | <span lang="sv">Jag tänker söka jobbet.</span> |
| förutsägelse eller utveckling | <span lang="sv">kommer att</span> + infinitiv | <span lang="sv">Det kommer att regna.</span> |

Det här är tendenser, inte fyra vattentäta fack. Sammanhang och talarens
perspektiv kan göra mer än ett val naturligt.

## Kärnregel

Det kontextuella presens behöver ett tydligt framtidsankare som
<span lang="sv">i morgon</span>, <span lang="sv">nästa vecka</span> eller en planerad händelse.
<span lang="sv">Ska</span> och avsikts-<span lang="sv">tänker</span> tar en ren infinitiv, medan
<span lang="sv">kommer att</span> innehåller infinitivmarkören <span lang="sv">att</span>:

- <span lang="sv">Jag ska resa.</span>
- <span lang="sv">Jag tänker resa.</span>
- <span lang="sv">Det kommer att regna.</span>

Ordet <span lang="sv">att</span> i <span lang="sv">kommer att</span> hör till just den konstruktionen; det är
inte en del av mönstret med ren infinitiv som används efter <span lang="sv">ska</span> och
avsikts-<span lang="sv">tänker</span>.

## Direkt jämförelse

<LanguageComparison title="En personlig plan">
	<p slot="de">Ich werde morgen anrufen.</p>

</LanguageComparison>

<LanguageComparison title="En förutsägelse">
	<p slot="de">Es wird später regnen.</p>

	<p slot="sv">Det kommer att regna senare.</p>
</LanguageComparison>

<MistakeBox title="Vanliga misstag">
	- Översätt inte varje engelskt <em>will</em> eller tyskt
	  <span lang="de">werden</span> med <span lang="sv">ska</span>.
	- ❌ <span lang="sv">Jag ska att ringa.</span>
	  ✅ <span lang="sv">Jag ska ringa.</span>
	- En presensform kan syfta på framtiden när tiden redan är tydlig:
	  <span lang="sv">Vi ses i morgon.</span>
</MistakeBox>
