<KeyTakeaway>
- Välj först pronomen efter betydelse och sedan efter dess roll i satsen eller nominalfrasen.
- Personliga, possessiva, reflexiva, reciproka, indefinita, demonstrativa och relativa former svarar på olika frågor.
- Svenskan har subjekts- och objektsformer, men den här hyllan är inte ett tyskt kasusssystem för substantiv.
</KeyTakeaway>

Använd avsnittet för att ersätta eller peka ut en person, sak, ägare eller relation utan att blanda ihop de olika pronomen-systemen.

## Välj efter behov

| Om du behöver … | Börja med … |
| --- | --- |
| säga *jag/mig, du/dig, han/honom, hon/henne, vi/oss* eller *de/dem* | [Personliga pronomen](./personal-pronouns/) |
| säga *min, din, hans, hennes, vår* eller *deras* | [Possessiva pronomen](./possessive-pronouns/) |
| hänvisa till tredje personens egen sak | [<span lang="sv">sin, sitt, sina</span>](./sin-sitt-sina/) |
| säga *någon, något, några, ingen, inget* eller *inga* | [<span lang="sv">någon, något, ingen, inget</span>](./nagon-nagot-ingen-inget/) |
| peka på det här eller det där substantivet | [Demonstrativa med <span lang="sv">här</span> och <span lang="sv">där</span>](./demonstratives-har-dar/) |
| inleda en relativsats med <span lang="sv">som</span>, <span lang="sv">vilket</span> eller <span lang="sv">vars</span> | [Relativa pronomen](./relative-pronouns/) |
| säga att subjektet gör något med sig självt | [Reflexiva pronomen](./reflexive-pronouns/) |
| säga *människor i allmänhet, varandra* eller *en var* | [<span lang="sv">man, varandra, var sin</span>](./man-varandra-varsin/) |

## Lär i denna ordning

1. [Personliga pronomen](./personal-pronouns/) ger subjekts- och objektsrollerna.
2. [Possessiva pronomen](./possessive-pronouns/) lägger till ägarformer; [<span lang="sv">sin, sitt, sina</span>](./sin-sitt-sina/) tar sedan hand om subjektets reflexiva ägande.
3. [<span lang="sv">Någon, något, ingen, inget</span>](./nagon-nagot-ingen-inget/) och [demonstrativa](./demonstratives-har-dar/) breddar vardagliga nominalfraser.
4. [Relativa pronomen](./relative-pronouns/) binder samman information mellan satser.
5. [Reflexiva pronomen](./reflexive-pronouns/) och [<span lang="sv">man, varandra, var sin</span>](./man-varandra-varsin/) avslutar de viktigaste rollkontrasterna.

## Var uppmärksam på

- [Reflexiva pronomen](./reflexive-pronouns/) äger <span lang="sv">mig, dig, sig, oss, er</span> när subjekt och objekt syftar på samma deltagare; [<span lang="sv">sin, sitt, sina</span>](./sin-sitt-sina/) äger reflexivt ägande.
- [Demonstrativa](./demonstratives-har-dar/) pekar ut substantiv; [frågeord](../questions-negation/question-words/) frågar efter saknad information; [<span lang="sv">där-</span>- och <span lang="sv">här-</span>-adverb](../prepositions-function-words/dar-har-adverbs/) äger sammansättningar som <span lang="sv">därför</span>.
- [<span lang="sv">Varandra</span>](./man-varandra-varsin/) är reciprokt: deltagarna gör något med varandra. Ett reflexivt pronomen syftar tillbaka på en deltagare i samma sats.
