<KeyTakeaway>
- Före ett substantiv följer formen substantivet: <span lang="sv">någon</span> för ett
  <span lang="sv">en</span>-ord, <span lang="sv">något</span> för ett <span lang="sv">ett</span>-ord och <span lang="sv">några</span> i plural.
- När orden står ensamma är <span lang="sv">någon</span> en person, <span lang="sv">något</span> en sak och
  <span lang="sv">några</span> en grupp i plural.
- <span lang="sv">ingen</span>, <span lang="sv">inget</span> och <span lang="sv">inga</span> är negativa former i samma
  tredelning.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenskan använder <span lang="sv">någon</span>, <span lang="sv">något</span> och <span lang="sv">några</span> för
obestämd betydelse: ”ett visst antal”, ”vilken som helst” eller ”en person
eller sak”. De negativa formerna är <span lang="sv">ingen</span>, <span lang="sv">inget</span> och
<span lang="sv">inga</span>: ”inte alls”, ”ingen alls” eller ”ingenting”.

## Grundformer

När ett av orden står före ett substantiv väljer du efter substantivet:

| Betydelse | <span lang="sv">en</span>-ord | <span lang="sv">ett</span>-ord | Pluralord |
| --- | --- | --- | --- |
| bekräftande | <span lang="sv">någon</span> | <span lang="sv">något</span> | <span lang="sv">några</span> |
| nekande | <span lang="sv">ingen</span> | <span lang="sv">inget</span> | <span lang="sv">inga</span> |

## Före ett substantiv

Använd <span lang="sv">någon</span> före ett <span lang="sv">en</span>-ord i singular:

<span lang="sv">Finns det någon mataffär?</span>

<span lang="de">Gibt es einen Supermarkt?</span>

Använd <span lang="sv">något</span> före ett <span lang="sv">ett</span>-ord i singular:

<span lang="sv">Har du något smultronställe?</span>

<span lang="de">Hast du einen Lieblingsplatz?</span>

Använd <span lang="sv">några</span> före ett pluralord:

<span lang="sv">Har ni några lediga rum?</span>

<span lang="de">Habt ihr irgendwelche freien Zimmer?</span>

## Negativa former

Vid negation använder du <span lang="sv">ingen</span>, <span lang="sv">inget</span> eller <span lang="sv">inga</span>
enligt samma substantivmönster:

| Fråga | Nekande svar |
| --- | --- |
| <span lang="sv">Finns det någon kyrka?</span> | <span lang="sv">Nej, det finns ingen kyrka.</span> |
| <span lang="sv">Finns det något hav här?</span> | <span lang="sv">Nej, det finns inget hav här.</span> |
| <span lang="sv">Har ni några lediga rum?</span> | <span lang="sv">Nej, vi har inga lediga rum.</span> |

På tyska motsvaras det ofta av ”kein”, ”keine” eller ”nicht irgendein”:

<span lang="de">Gibt es hier ein Meer? Nein, es gibt hier kein Meer.</span>

## När orden står ensamma

<span lang="sv">Någon</span> och <span lang="sv">något</span> kan också stå ensamma. Då väljer du mellan
person och sak:

| Svenska | Betydelse | Exempel |
| --- | --- | --- |
| <span lang="sv">någon</span> | en person | <span lang="sv">Ska någon gå till spaavdelningen?</span> |
| <span lang="sv">något</span> | en sak | <span lang="sv">Finns det något att äta?</span> |
| <span lang="sv">ingen</span> | ingen person | <span lang="sv">Ingen behöver köpa ägg.</span> |
| <span lang="sv">inget</span> | ingen sak | <span lang="sv">Jag förstår inget.</span> |
| <span lang="sv">några</span> | några personer eller saker | <span lang="sv">Några kom tidigt.</span> |
| <span lang="sv">inga</span> | inga personer eller saker | <span lang="sv">Inga kom för sent.</span> |

Pluralformerna kan också ersätta ett underförstått pluralord:
<span lang="sv">Jag köpte några</span> och <span lang="sv">Jag hittade inga</span>.

Jämför:

<LanguageComparison title="Någon, en person"><p slot="de">Siehst du jemanden dort?</p><p slot="en">Do you see anyone there?</p><p slot="sv">Ser du någon där?</p></LanguageComparison>

<LanguageComparison title="Något, en sak"><p slot="de">Möchtest du etwas zu trinken?</p><p slot="en">Would you like something to drink?</p><p slot="sv">Vill du ha något att dricka?</p></LanguageComparison>

## Frågor och påståenden

I frågor betyder <span lang="sv">någon</span>, <span lang="sv">något</span> och <span lang="sv">några</span> ofta
”vilken/vilket som helst” eller ”en del”:

- <span lang="sv">Finns det någon kyrka?</span>
- <span lang="sv">Finns det något hav här?</span>
- <span lang="sv">Har du några planer för semestern?</span>

I påståenden kan <span lang="sv">några</span> också betyda ”ett par”:

<span lang="sv">Jag tar några tomater också.</span>

<span lang="de">Ich nehme auch ein paar Tomaten.</span>

## Talspråksformer

I vardagligt tal uttalas och skrivs <span lang="sv">någon</span> ofta som <span lang="sv">nån</span>.
På samma sätt blir <span lang="sv">något</span> ofta <span lang="sv">nåt</span>.

| Standardspråk | Informellt | Betydelse |
| --- | --- | --- |
| <span lang="sv">någon</span> | <span lang="sv">nån</span> | en person / ett <span lang="sv">en</span>-ord |
| <span lang="sv">något</span> | <span lang="sv">nåt</span> | en sak / ett <span lang="sv">ett</span>-ord |

Använd standardformerna i vårdad skrift om inte tonen medvetet ska vara ledig.

## Snabb beslutstabell

| Kontext | Välj efter | Använd |
| --- | --- | --- |
| Ett substantiv följer | <span lang="sv">en</span>, <span lang="sv">ett</span> eller plural | <span lang="sv">någon</span> / <span lang="sv">något</span> / <span lang="sv">några</span> |
| En negativ nominalfras följer | <span lang="sv">en</span>, <span lang="sv">ett</span> eller plural | <span lang="sv">ingen</span> / <span lang="sv">inget</span> / <span lang="sv">inga</span> |
| Inget substantiv följer | person, sak eller pluralgrupp | <span lang="sv">någon</span> = en person, <span lang="sv">något</span> = en sak, <span lang="sv">några</span> = ett antal personer eller saker |
| Negativt utan substantiv | person, sak eller pluralgrupp | <span lang="sv">ingen</span> = ingen person, <span lang="sv">inget</span> = ingen sak, <span lang="sv">inga</span> = inga personer eller saker |

Den här sidan handlar om formerna och deras kongruens i nominalfrasen. För det
större valet mellan satsnegation, negativ nominalfras och negativt adverb, se
[Negation](../../questions-negation/negation/).

## Vanliga misstag

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">något kyrka</span> ✅ <span lang="sv">någon kyrka</span>
	- ❌ <span lang="sv">någon hav</span> ✅ <span lang="sv">något hav</span>
	- ❌ <span lang="sv">ingen lediga rum</span> ✅ <span lang="sv">inga lediga rum</span>
	- ❌ Välj <span lang="sv">någon</span> och <span lang="sv">något</span> efter person eller sak när ett
	  substantiv följer. Välj då efter <span lang="sv">en</span>, <span lang="sv">ett</span> eller plural.
</MistakeBox>
