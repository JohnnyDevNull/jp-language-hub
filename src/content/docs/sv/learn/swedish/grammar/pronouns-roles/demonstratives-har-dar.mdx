<KeyTakeaway>
- Välj <span lang="sv">den</span> för ett en-ord och <span lang="sv">det</span> för ett ett-ord; lägg sedan
  till <span lang="sv">här</span> för något nära och <span lang="sv">där</span> för något längre bort.
- Substantivet efter <span lang="sv">den här</span> och <span lang="sv">den där</span> står i bestämd form:
  <span lang="sv">den här nyckeln</span>.
- Formella <span lang="sv">denna</span>, <span lang="sv">detta</span> och <span lang="sv">dessa</span> lämnar substantivet
  obestämt: <span lang="sv">denna bok</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenskan använder ofta <span lang="sv">här</span> och <span lang="sv">där</span> med demonstrativa ord för
att skilja mellan „det här“ och „det där“. Formen före substantivet följer
substantivets genus.

## Grundformer

| Avstånd | en-ord | ett-ord |
| --- | --- | --- |
| nära talaren | <span lang="sv">den här jackan</span> | <span lang="sv">det här paraplyet</span> |
| längre bort | <span lang="sv">den där cykeln</span> | <span lang="sv">det där biblioteket</span> |

Använd <span lang="sv">den</span> med en-ord och <span lang="sv">det</span> med ett-ord:

- <span lang="sv">den här nyckeln</span>
- <span lang="sv">det här mejlet</span>
- <span lang="sv">den där cykeln</span>
- <span lang="sv">det där biblioteket</span>

## Substantivet står i bestämd form

Efter <span lang="sv">den här</span>, <span lang="sv">det här</span>, <span lang="sv">den där</span> och <span lang="sv">det där</span>
står substantivet normalt i bestämd form:

| Obestämd form | Demonstrativ fras |
| --- | --- |
| <span lang="sv">en nyckel</span> | <span lang="sv">den här nyckeln</span> |
| <span lang="sv">ett paraply</span> | <span lang="sv">det här paraplyet</span> |
| <span lang="sv">en cykel</span> | <span lang="sv">den där cykeln</span> |
| <span lang="sv">ett bibliotek</span> | <span lang="sv">det där biblioteket</span> |

Det är en anledning att lära sig de fyra substantivformerna tidigt.

## När ordet står ensamt

När substantivet inte sägs direkt efter demonstrativet använder svenskan
normalt <span lang="sv">det här</span> eller <span lang="sv">det där</span> som ett allmänt „det här“ eller
„det där“:

<LanguageComparison title="Det här">
	<p slot="de">Das hier ist mein Platz.</p>
	<p slot="en">This is my seat.</p>
	<p slot="sv">Det här är min plats.</p>
</LanguageComparison>

<LanguageComparison title="Det där">
	<p slot="de">Das dort ist unser Bus.</p>
	<p slot="en">That is our bus.</p>
	<p slot="sv">Det där är vår buss.</p>
</LanguageComparison>

I <span lang="sv">Det här är min plats</span> är demonstrativet inte knutet till nominalfrasen
<span lang="sv">min plats</span>. Det pekar på situationen som „det här“.

## Med adjektiv

Om ett adjektiv står i den demonstrativa nominalfrasen använder svenskan
adjektivets bestämda form, och substantivet förblir bestämt:

| Fras | Mönster |
| --- | --- |
| <span lang="sv">den här varma jackan</span> | <span lang="sv">den här</span> + bestämt adjektiv + bestämt substantiv |
| <span lang="sv">det där nya biblioteket</span> | <span lang="sv">det där</span> + bestämt adjektiv + bestämt substantiv |

Det hänger nära ihop med [dubbel bestämdhet](../../adjectives-adverbs/agreement/#bestämda-nominalfraser-och-dubbel-bestämdhet).

## Det formella alternativet: denna, detta, dessa

<span lang="sv">Denna</span>, <span lang="sv">detta</span> och <span lang="sv">dessa</span> betyder samma sak som
<span lang="sv">den här</span>, <span lang="sv">det här</span> och <span lang="sv">de här</span>, men hör hemma i
skriven och formell svenska: rapporter, meddelanden, avtal och akademisk prosa.

De fungerar annorlunda på en viktig punkt: Substantivet efter dem förblir
**obestämt**:

| Vardagligt | Formellt |
| --- | --- |
| <span lang="sv">den här boken</span> | <span lang="sv">denna bok</span> |
| <span lang="sv">det här huset</span> | <span lang="sv">detta hus</span> |
| <span lang="sv">de här böckerna</span> | <span lang="sv">dessa böcker</span> |

- <span lang="sv">Denna fråga är viktig.</span> — *Den här frågan är viktig.*
- <span lang="sv">Detta beslut gäller från januari.</span>

Ett mellanliggande adjektiv får som alltid den bestämda <span lang="sv">-a</span>-formen:
<span lang="sv">denna viktiga fråga</span>.

När man syftar på en man har formell svenska också <span lang="sv">denne</span>:
<span lang="sv">denne författare</span>. Precis som den maskulina <span lang="sv">-e</span>-formen på
adjektiv är den viktig att känna igen snarare än att själv använda.

<RuleBox title="Vilken form ska du välja?">
	I tal och vardaglig skrift använder du <span lang="sv">den här</span> med ett bestämt
	substantiv. Välj <span lang="sv">denna</span> bara i formell skrift — och låt då
	substantivet vara obestämt.
</RuleBox>

## Håll isär pekande, frågor och sammansatta adverb

Den här sidan behandlar demonstrativa nominalfraser som <span lang="sv">den här boken</span>
och <span lang="sv">det där huset</span>. Använd [frågeord](../../questions-negation/question-words/)
för <span lang="sv">vilken, vilket, vilka</span> när du frågar „vilken?“, och använd
[*där-* och *här*-adverb](../../prepositions-function-words/dar-har-adverbs/)
för sammansättningar som <span lang="sv">därför</span> och <span lang="sv">härmed</span>.

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">den här nyckel</span>
	  ✅ <span lang="sv">den här nyckeln</span>
	- ❌ <span lang="sv">det här jackan</span>
	  ✅ <span lang="sv">den här jackan</span>
	- ❌ <span lang="sv">den här varm jackan</span>
	  ✅ <span lang="sv">den här varma jackan</span>
	- ❌ <span lang="sv">denna boken</span>
	  ✅ <span lang="sv">denna bok</span> — substantivet förblir obestämt efter
	  <span lang="sv">denna</span>
	- ❌ <span lang="sv">detta bok</span>
	  ✅ <span lang="sv">denna bok</span> — <span lang="sv">bok</span> är ett en-ord
</MistakeBox>

<MemoryTip>
Välj först <span lang="sv">den</span> eller <span lang="sv">det</span> efter substantivets genus. Använd
sedan dess bestämda form:
<span lang="sv"><strong>en nyckel → den här nyckeln</strong></span>.
</MemoryTip>
