Här samlas pronomen som svenskan använder för människor i allmänhet och för
människor i förhållande till varandra.

## man för allmänna påståenden

<span lang="sv">Man</span> fungerar som tyskans <span lang="de">man</span> när båda är
pronomen: det gör ett påstående om människor i allmänhet utan att nämna någon.

- <span lang="sv">Man får inte parkera här.</span>
- <span lang="sv">Så säger man i Sverige.</span> — Så säger folk i Sverige.

Engelskan saknar en enda motsvarighet och använder därför ofta passiv i stället.
På svenska är <span lang="sv">man</span> ofta det naturligare valet.

<span lang="sv">Man</span> har objektform, genitivform och ett särskilt reflexivt possessiv:

| Funktion | Form | Exempel |
| --- | --- | --- |
| subjekt | <span lang="sv">man</span> | <span lang="sv">Man vet aldrig.</span> |
| objekt | <span lang="sv">en</span> | <span lang="sv">Det gör en glad.</span> |
| genitiv / vanligt possessiv | <span lang="sv">ens</span> | <span lang="sv">Det påverkar ens hälsa.</span> |
| reflexivt possessiv | <span lang="sv">sin / sitt / sina</span> | <span lang="sv">Man måste ta sitt ansvar.</span> |

Använd <span lang="sv">ens</span> för allmänt ”ens” när ägaren inte är subjektet som äger
något i samma sats. När <span lang="sv">man</span> är subjekt och ägandet syftar tillbaka på
det, används <span lang="sv">sin / sitt / sina</span>: <span lang="sv">Man måste ta sitt ansvar</span>.
Se [*sin, sitt, sina*](../sin-sitt-sina/) för satsgränsen.

<RuleBox title="Blanda inte ihop man med substantivet">
	<span lang="sv">Man</span> som pronomen är obetonat och har aldrig artikel. <span lang="sv">En man</span>
	med artikel är substantivet ”en man”. Bara artikel och betoning skiljer dem åt.
</RuleBox>

## varandra för ömsesidighet

<span lang="sv">Varandra</span> är oböjligt och aldrig subjekt. Det kan vara objekt till ett
verb eller komplement efter en preposition. Genitivformen är <span lang="sv">varandras</span>:

- <span lang="sv">De hjälper varandra.</span>
- <span lang="sv">De talar med varandra.</span>
- <span lang="sv">Vi läser varandras texter.</span>

Många verb uttrycker samma idé med en <span lang="sv">-s</span>-form:

- <span lang="sv">De träffas varje vecka.</span> = <span lang="sv">De träffar varandra varje vecka.</span>
- <span lang="sv">Vi ses!</span>

Se [passiv](../../verb-patterns-voice/passive/) för detta <span lang="sv">-s</span>.

Eftersom <span lang="sv">varandra</span> är objekt kan det ändå stå först enligt V2-regeln:
<span lang="sv">Varandra hjälper de</span> är markerat men grammatiskt. Första plats gör det
inte till subjekt.

## var sin: en var

<span lang="sv">Var sin</span> och <span lang="sv">var sitt</span> — även <span lang="sv">varsin</span> och
<span lang="sv">varsitt</span> — betyder att varje person har en egen. Formen följer genus hos
det ägda:

- <span lang="sv">De fick var sin bok.</span> — De fick en bok var.
- <span lang="sv">Barnen har var sitt rum.</span> — Barnen har ett eget rum var.

## varje, var och en och alla

| Svenska | Betydelse | Kommentar |
| --- | --- | --- |
| <span lang="sv">varje</span> | var och en för sig, inte som grupp | med obestämt singular: <span lang="sv">varje dag</span> |
| <span lang="sv">var och en</span> | varje person | står ensamt: <span lang="sv">Var och en fick ett äpple.</span> |
| <span lang="sv">alla</span> | samtliga | <span lang="sv">alla barn</span>, <span lang="sv">Alla kom.</span> |
| <span lang="sv">allt</span> | alltsammans, hela mängden | <span lang="sv">Allt är klart.</span> |

För <span lang="sv">någon</span> och <span lang="sv">ingen</span>, se
[någon, något, ingen och inget](../nagon-nagot-ingen-inget/).

## Uttryck med som helst

Att lägga <span lang="sv">som helst</span> till ett frågeord ger betydelsen ”vilken som helst”:

| Svenska | Betydelse |
| --- | --- |
| <span lang="sv">vem som helst</span> | vilken person som helst |
| <span lang="sv">vad som helst</span> | vilken sak som helst |
| <span lang="sv">när som helst</span> | vilken tidpunkt som helst |
| <span lang="sv">var som helst</span> | på vilken plats som helst |
| <span lang="sv">hur som helst</span> | på vilket sätt som helst, i alla fall |

<span lang="sv">Hur som helst</span> är också en vanlig diskursmarkör med betydelsen
”i alla fall”.

## Vanliga misstag

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">Man måste ta hans ansvar.</span>
	  ✅ <span lang="sv">Man måste ta sitt ansvar.</span>
	- ❌ <span lang="sv">Varandra hjälper.</span> när du menar ”De hjälper varandra.”
	  ✅ <span lang="sv">De hjälper varandra.</span> — <span lang="sv">varandra</span> kan inte vara subjekt
	- ❌ <span lang="sv">varje dagen</span>
	  ✅ <span lang="sv">varje dag</span>
	- ❌ <span lang="sv">Man är trevlig</span> med betydelsen ”en man är trevlig”
	  ✅ <span lang="sv">En man är trevlig.</span>
</MistakeBox>

byggs av frågeord.
</MemoryTip>
