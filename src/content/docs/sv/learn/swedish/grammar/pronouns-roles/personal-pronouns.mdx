<KeyTakeaway>
- Använd subjektsformen för den som gör eller upplever något i satsen: <span lang="sv">hon kommer</span>.
- Använd objektsformen efter verb eller preposition: <span lang="sv">jag ser henne</span>, <span lang="sv">med henne</span>.
- Skrivet <span lang="sv">de</span> och <span lang="sv">dem</span> uttalas vanligen båda <span lang="sv">dom</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenska personliga pronomen ändras främst efter subjekts- eller objektsroll. Det här är en kort uppslagsguide till form och roll, inte en svensk version av tyskans produktiva nominativ-, ackusativ- och dativsystem för substantiv.

## Använd detta nu

| Roll | Fråga | Exempel |
| --- | --- | --- |
| subjekt | Vem gör eller upplever något i satsen? | <span lang="sv">Hon väntar.</span> |
| objekt | Vem eller vad påverkas av handlingen? | <span lang="sv">Jag ser henne.</span> |
| efter preposition | Vilken form följer ord som <span lang="sv">med</span> eller <span lang="sv">till</span>? | <span lang="sv">med henne</span> |

## Grundformer

| Betydelse | Subjekt | Objekt / efter preposition |
| --- | --- | --- |
| jag / mig | <span lang="sv">jag</span> | <span lang="sv">mig</span> |
| du / dig | <span lang="sv">du</span> | <span lang="sv">dig</span> |
| han / honom | <span lang="sv">han</span> | <span lang="sv">honom</span> |
| hon / henne | <span lang="sv">hon</span> | <span lang="sv">henne</span> |
| könsneutral person i singular | <span lang="sv">hen</span> | <span lang="sv">hen</span> |
| den, en-ord | <span lang="sv">den</span> | <span lang="sv">den</span> |
| det, ett-ord | <span lang="sv">det</span> | <span lang="sv">det</span> |
| människor i allmänhet | <span lang="sv">man</span> | <span lang="sv">en</span> |
| vi / oss | <span lang="sv">vi</span> | <span lang="sv">oss</span> |
| ni / er | <span lang="sv">ni</span> | <span lang="sv">er</span> |
| de / dem | <span lang="sv">de</span> | <span lang="sv">dem</span> |

<span lang="sv">Ni</span> är främst plural. Ordet kan tilltala en person i vissa servicesituationer eller medvetet formella sammanhang, men är ingen allmän svensk motsvarighet till tyskans artiga <span lang="de">Sie</span>. <span lang="sv">Du</span> är den vanliga singularformen i modern svenska.

## Subjekt eller objekt

- <span lang="sv">Hon ringer mig.</span>
- <span lang="sv">Jag hjälper honom.</span>
- <span lang="sv">De väntar på oss.</span>
- <span lang="sv">Vi åker med dem.</span>

Prepositioner tar objektsform: <span lang="sv">med mig</span>, <span lang="sv">till dig</span>, <span lang="sv">från henne</span>.

## Hänvisa till saker

Använd <span lang="sv">den</span> för ett en-ord och <span lang="sv">det</span> för ett ett-ord när ett personligt pronomen syftar på en bestämd sak:

- <span lang="sv">Var är bilen? Den står ute.</span>
- <span lang="sv">Var är brevet? Det ligger här.</span>

Den här syftningen är skild från demonstrativa fraser som <span lang="sv">den här bilen</span>.

## Talat *dom* och skrivet *de/dem*

I standardskrift används <span lang="sv">de</span> som subjekt och <span lang="sv">dem</span> som objekt: <span lang="sv">De såg oss</span>; <span lang="sv">vi såg dem</span>. I tal uttalas båda vanligen <span lang="sv">dom</span>, och <span lang="sv">dom</span> förekommer också i informell skrift.

## Direkt jämförelse

<LanguageComparison title="Efter en preposition">
  <p slot="de">mit ihr</p>
  <p slot="en">with her</p>
  <p slot="sv">med henne</p>
</LanguageComparison>

Tyskan har ett bredare produktivt kasusssystem för artiklar, adjektiv och substantiv. Svenskan behåller främst kontrasten mellan subjekt och objekt i personliga pronomen.

<MistakeBox title="Vanliga misstag">
- <span lang="sv">❌ med jag</span> → <span lang="sv">✅ med mig</span>
- <span lang="sv">❌ henne kommer</span> → <span lang="sv">✅ hon kommer</span>
- Använd <span lang="sv">de</span> som subjekt och <span lang="sv">dem</span> som objekt i standardskrift.
</MistakeBox>

<MemoryTip>
Lär varje par som en liten rytm: <span lang="sv"><strong>jag–mig, du–dig, hon–henne, vi–oss, de–dem</strong></span>.
</MemoryTip>
