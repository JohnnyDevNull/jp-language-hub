<KeyTakeaway>
- Använd <span lang="sv">mig, dig, sig, oss,</span> eller <span lang="sv">er</span> när objektet syftar
  tillbaka på subjektet i samma sats.
- Subjekt i tredje person använder <span lang="sv">sig</span>: <span lang="sv">hon tvättar sig</span>,
  <span lang="sv">de skyndar sig</span>.
- Reflexivt ägande hör till <span lang="sv">sin, sitt, sina</span>; ömsesidig betydelse hör
  till <span lang="sv">varandra</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Ett reflexivt pronomen visar att subjekt och objekt syftar på samma person eller
grupp. Svenskan använder också reflexiva former som del av flera vanliga verb.

## Använd detta nu

| Subjekt | Reflexivt objekt | Exempel |
| --- | --- | --- |
| <span lang="sv">jag</span> | <span lang="sv">mig</span> | <span lang="sv">Jag tvättar mig.</span> |
| <span lang="sv">du</span> | <span lang="sv">dig</span> | <span lang="sv">Du skyndar dig.</span> |
| <span lang="sv">han, hon, den, det, man</span> | <span lang="sv">sig</span> | <span lang="sv">Hon sätter sig.</span> |
| <span lang="sv">vi</span> | <span lang="sv">oss</span> | <span lang="sv">Vi lär oss svenska.</span> |
| <span lang="sv">ni</span> | <span lang="sv">er</span> | <span lang="sv">Ni måste skynda er.</span> |
| <span lang="sv">de</span> | <span lang="sv">sig</span> | <span lang="sv">De känner sig trötta.</span> |

## Grundregel

Välj reflexiv form efter satsens subjekt. Jämför:

- <span lang="sv">Hon tvättar sig.</span> — Hon tvättar sig själv.
- <span lang="sv">Hon tvättar henne.</span> — Hon tvättar en annan kvinna.
- <span lang="sv">De ser sig i spegeln.</span> — De ser sig själva i spegeln.
- <span lang="sv">De ser dem.</span> — De ser en annan grupp.

Formen syftar tillbaka inom samma sats. I
<span lang="sv">Anna säger att Erik skyndar sig</span> syftar <span lang="sv">sig</span> på Erik, subjektet
i bisatsen.

## Vanliga reflexiva verb

Lär dig dessa som hela uttryck:

| Uttryck | Betydelse |
| --- | --- |
| <span lang="sv">skynda sig</span> | skynda |
| <span lang="sv">sätta sig</span> | sätta sig ner |
| <span lang="sv">känna sig</span> | må, uppleva sig vara (t.ex. glad, trött) |
| <span lang="sv">lära sig</span> | tillägna sig en kunskap eller färdighet |
| <span lang="sv">gifta sig</span> | ingå äktenskap |

Det reflexiva pronomenet ändras ändå med subjektet:
<span lang="sv">jag skyndar mig</span>, <span lang="sv">vi skyndar oss</span>, <span lang="sv">de skyndar sig</span>.

## Håll isär tre system

- <span lang="sv">Hon tvättar sig.</span> — reflexivt objekt: Handlingen går tillbaka till henne.
- <span lang="sv">Hon tar sin jacka.</span> — reflexivt ägande: Jackan är hennes.
- <span lang="sv">De hjälper varandra.</span> — reciprokt: Varje person hjälper en annan.

## Direkt jämförelse

Engelskan utelämnar ibland en reflexiv form som svenskan och tyskan använder
som en del av verbuttrycket.

<MistakeBox title="Vanliga misstag">
- <span lang="sv">❌ Hon skyndar henne.</span> → <span lang="sv">✅ Hon skyndar sig.</span>
- <span lang="sv">❌ Vi känner sig trötta.</span> → <span lang="sv">✅ Vi känner oss trötta.</span>
- Använd inte <span lang="sv">sig</span> för ägande; välj <span lang="sv">sin, sitt,</span> eller
  <span lang="sv">sina</span> efter det ägda substantivet.
</MistakeBox>

<MemoryTip>
Koppla objektet tillbaka till subjektet:
<span lang="sv"><strong>jag–mig, du–dig, hon–sig, vi–oss, ni–er, de–sig</strong></span>.
</MemoryTip>
