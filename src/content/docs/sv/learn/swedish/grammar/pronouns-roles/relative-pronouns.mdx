Svenska relativsatser är enklare än tyska: relativpronomenet ändras inte efter genus, antal eller kasus. I nästan varje vardaglig mening är ordet <span lang="sv">som</span>.

## som är standardformen

<span lang="sv">Som</span> är oböjligt. Det fungerar för personer och saker, både som subjekt och objekt i relativsatsen:

- <span lang="sv">Mannen som bor här heter Erik.</span>
- <span lang="sv">Boken som jag läste var bra.</span>
- <span lang="sv">Barnen som vi träffade var trevliga.</span>

Jämför de tyska motsvarigheterna, som ändrar form: <span lang="de">der Mann, **der** hier wohnt</span> jämfört med <span lang="de">das Buch, **das** ich gelesen habe</span>. Svenskan behåller <span lang="sv">som</span> i båda fallen.

## Prepositionen står vanligen sent

Det här är den viktigaste regeln för tyskspråkiga. <span lang="sv">Som</span> följer inte efter en preposition. I vanlig svenska hamnar prepositionen sent i relativsatsen, ofta sist:

	<p slot="de">das Haus, in dem ich wohne</p>
	<p slot="en">the house I live in</p>
	<p slot="sv">huset som jag bor i</p>
</LanguageComparison>

<LanguageComparison title="För bussen">
	<p slot="de">der Bus, auf den wir warten</p>
	<p slot="en">the bus we are waiting for</p>
	<p slot="sv">bussen som vi väntar på</p>
</LanguageComparison>

<LanguageComparison title="Med personen">
	<p slot="de">die Person, mit der ich gesprochen habe</p>
	<p slot="en">the person I talked to</p>
	<p slot="sv">personen som jag talade med</p>
</LanguageComparison>

Engelskan sätter ofta också prepositionen sist; tyskan flyttar den till början tillsammans med relativpronomenet.

<RuleBox title="Regel">
	Skriv inte en preposition direkt före <span lang="sv">som</span>. I det vanliga mönstret står den sent i relativsatsen, ofta sist: <span lang="sv">❌ huset i som jag bor</span>, <span lang="sv">✅ huset som jag bor i</span>.
</RuleBox>

## som kan utelämnas som objekt

När <span lang="sv">som</span> är **objekt** i relativsatsen kan det utelämnas, precis som engelskans *that* kan utelämnas:

- <span lang="sv">Boken (som) jag läste var bra.</span>

När det är **subjekt** måste det stå kvar:

- <span lang="sv">Mannen som bor här</span> — inte <span lang="sv">❌ Mannen bor här</span>; det är en helt annan sats.

## vilket syftar på en hel sats

<span lang="sv">Vilken / vilket / vilka</span> är det böjda relativpronomenet. I modern vardagssvenska behöver du främst en användning: <span lang="sv">vilket</span> syftar tillbaka på en hel föregående sats, där engelskan använder *which*:

- <span lang="sv">Han kom för sent, vilket irriterade alla.</span>
- <span lang="sv">Det regnade hela veckan, vilket vi inte hade väntat oss.</span>

Observera att tyskan vanligen använder <span lang="de">was</span> här, inte en form av <span lang="de">welcher</span>.

Efter en preposition är <span lang="sv">vilken</span> den grammatiskt möjliga formen, men resultatet blir formellt och skriftligt: <span lang="sv">ett problem för vilket det inte finns någon lösning</span>. I tal är det bättre att formulera om satsen.

## vars för ägande

<span lang="sv">Vars</span> är det genitiva relativpronomenet. Det är oböjligt, tar ingen artikel efter sig och hör till ett något formellt register:

- <span lang="sv">en författare vars böcker jag älskar</span>

Med ett pluralt huvudord använder formell svenska <span lang="sv">vilkas</span>. I vardagligt tal undviker man oftast båda formerna och bygger i stället om satsen med <span lang="sv">som</span> och ett possessiv.

## där och dit för platser

För en plats ersätter <span lang="sv">där</span> ofta <span lang="sv">som … i</span>, och <span lang="sv">dit</span> uttrycker riktning:

- <span lang="sv">staden där jag bor</span> = <span lang="sv">staden som jag bor i</span>
- <span lang="sv">staden dit jag flyttade</span> — *staden som jag flyttade till*

## Ordföljd i relativsatsen

En relativsats är en bisats och följer därför bisatsmönstret: <span lang="sv">inte</span> och liknande adverb står **före** verbet.

- <span lang="sv">Mannen som inte bor här</span>
- <span lang="sv">Boken som jag aldrig läste</span>

Se [Bisatser](../../sentence-structure/subordinate-clauses/) för den allmänna satsramen och [BIFF](../../sentence-structure/biff/) för den snävare placeringen av satsadverb.

## Vanliga misstag

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">huset i som jag bor</span>
	  ✅ <span lang="sv">huset som jag bor i</span>
	- ❌ <span lang="sv">Mannen vilken bor här</span>
	  ✅ <span lang="sv">Mannen som bor här</span>
	- ❌ <span lang="sv">Han kom sent, som irriterade alla.</span>
	  ✅ <span lang="sv">Han kom sent, vilket irriterade alla.</span>
	- ❌ <span lang="sv">Mannen som bor inte här</span>
	  ✅ <span lang="sv">Mannen som inte bor här</span>
	- Böj inte <span lang="sv">som</span> efter genus eller kasus, som tyskan böjer <span lang="de">der / die / das</span>.
</MistakeBox>

<MemoryTip>
Två meningar täcker det mesta du behöver: <span lang="sv"><strong>Bussen som vi väntar på är sen.</strong></span> — prepositionen sist. <span lang="sv"><strong>Han kom sent, vilket irriterade alla.</strong></span> — <span lang="sv">vilket</span> för en hel sats.
</MemoryTip>
