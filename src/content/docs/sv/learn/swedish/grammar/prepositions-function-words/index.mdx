Den här hyllan samlar prepositionsval och kompakta uppslag om funktionsord och
länkar regler för ordföljd till deras kanoniska satssidor.

## Välj efter behov

| Om du behöver … | Börja med … |
| --- | --- |
| välja en preposition för plats, riktning eller tid | [Prepositioner](./prepositions/) |
| lära ett verb tillsammans med dess fasta preposition | [Prepositioner](./prepositions/#verb-med-fast-preposition) |
| skilja <span lang="sv">därför</span> från <span lang="sv">därför att</span> | [*där-* och *här*-adverb](./dar-har-adverbs/) |
| välja <span lang="sv">här</span>/<span lang="sv">hit</span> eller <span lang="sv">där</span>/<span lang="sv">dit</span> | [*där-* och *här*-adverb](./dar-har-adverbs/#här-eller-hit-där-eller-dit) |
| välja ett bindeord för orsak, följd, kontrast, villkor eller exempel | [Konnektorer](./connectors/) |
| kontrollera ordföljden efter en konnektor | [V2](../sentence-structure/v2/) eller [Bisatser](../sentence-structure/subordinate-clauses/) |

## Lär i denna ordning

1. [Prepositioner](./prepositions/) ger uppslag för vardagliga uttryck om
   plats, riktning, tid och fasta fraser.
2. [*där-* och *här*-adverb](./dar-har-adverbs/) lägger till kompakta former
   och den praktiska kontrasten <span lang="sv">därför</span>/<span lang="sv">därför att</span>.
3. [Konnektorer](./connectors/) hjälper dig välja bindeord för tillägg,
   kontrast, alternativ, orsak, följd, villkor och exempel.

## Se upp med

- En preposition hör till ett substantiv eller ett fast verbuttryck; en partikel
  hör till verbet och kan ha betoning.
- [*där-* och *här*-adverb](./dar-har-adverbs/) behandlar sammansatta adverb;
  [demonstrativa](../pronouns-roles/demonstratives-har-dar/) behandlar
  utpekande fraser som <span lang="sv">den här boken</span>.
- [Konnektorer](./connectors/) behandlar bindeordet; sidorna om satsstruktur
  behandlar regeln för ordföljd.
