<KeyTakeaway>
- Välj konnektor efter relationen: tillägg, kontrast, alternativ, orsak, följd, villkor eller exempel.
- Konnektorer kan binda ihop huvudsatser, inleda bisatser eller vara adverb som syftar tillbaka.
- När konnektorn påverkar ordföljden följer du den kanoniska satsregeln: V2 i huvudsats och bisatsordföljd i bisats.
</KeyTakeaway>

Svenska konnektorer för en tanke vidare till nästa. Sidan är en valkarta: den
visar vilken ordfamilj du behöver och var du hittar regeln när konnektorn ändrar satsens form.

## Använd detta nu

| Betydelse | Vardagliga val | Använd för |
| --- | --- | --- |
| tillägg | <span lang="sv">och</span>, <span lang="sv">också</span>, <span lang="sv">dessutom</span> | mer information |
| kontrast | <span lang="sv">men</span>, <span lang="sv">fast</span>, <span lang="sv">däremot</span> | svag eller stark kontrast |
| alternativ | <span lang="sv">eller</span>, <span lang="sv">annars</span> | val och varningar |
| orsak | <span lang="sv">för att</span>, <span lang="sv">eftersom</span>, <span lang="sv">därför att</span> | varför något händer |
| följd | <span lang="sv">så</span>, <span lang="sv">därför</span> | vad som följer |
| villkor | <span lang="sv">om</span>, <span lang="sv">ifall</span>, <span lang="sv">annars</span> | om-ramar och följder |
| exempel | <span lang="sv">till exempel</span>, <span lang="sv">som</span> | exempel och precisering |

## Tillägg, kontrast och alternativ

De minsta konnektorerna binder ihop ord, fraser eller satser:

- <span lang="sv">Jag dricker kaffe och te.</span>
- <span lang="sv">Jag vill gå, men jag hinner inte.</span>
- <span lang="sv">Vill du ha kaffe eller te?</span>

För en starkare skriftlig länk används ofta adverbiella konnektorer som
<span lang="sv">dessutom</span> eller <span lang="sv">däremot</span>. Står de först i nästa huvudsats följer du [V2](../../sentence-structure/v2/).

## Orsaker och följder

En orsaksbindeord förklarar varför något hände:

- <span lang="sv">Jag stannade hemma eftersom jag var sjuk.</span>
- <span lang="sv">Jag stannade hemma därför att jag var sjuk.</span>

En följdkonnektor säger vad som hände sedan:

- <span lang="sv">Jag var sjuk. Därför stannade jag hemma.</span>
- <span lang="sv">Det regnade, så vi stannade inne.</span>

<span lang="sv">Därför</span> och <span lang="sv">därför att</span> är lätta att blanda ihop. Den exakta
kontrasten finns på [*där-* och *här*-adverb](../dar-har-adverbs/).

## Villkor och följder

<span lang="sv">Om</span> och <span lang="sv">ifall</span> inleder ett villkor:

- <span lang="sv">Om det regnar stannar vi hemma.</span>
- <span lang="sv">Vi stannar hemma om det regnar.</span>

<span lang="sv">Annars</span> anger följden om villkoret inte uppfylls:

- <span lang="sv">Ta med jacka. Annars blir du kall.</span>

För varningar, erbjudanden och följder använder du [villkor och konsekvenser](../../../sentence-patterns/conditions-and-consequences/). Den grammatiska sidan är [villkorssatser](../../mood-politeness-reports/conditionals/).

## Exempel

Det säkraste vardagsuttrycket är <span lang="sv">till exempel</span>:

- <span lang="sv">Jag gillar svensk mat, till exempel köttbullar.</span>

I korta definitioner kan <span lang="sv">som</span> inleda ett exempel:

- <span lang="sv">Städer som Malmö och Uppsala växer.</span>

För färdiga förklaringsfraser, se [skäl och exempel](../../../sentence-patterns/reasons-and-examples/).

## Direkt jämförelse

<LanguageComparison title="Orsak">
	<p slot="de">Ich blieb zu Hause, weil ich krank war.</p>
	<p slot="en">I stayed home because I was ill.</p>
	<p slot="sv">Jag stannade hemma eftersom jag var sjuk.</p>
</LanguageComparison>

<LanguageComparison title="Följd">
	<p slot="de">Ich war krank. Deshalb blieb ich zu Hause.</p>
	<p slot="en">I was ill. Therefore I stayed home.</p>
	<p slot="sv">Jag var sjuk. Därför stannade jag hemma.</p>
</LanguageComparison>

<MistakeBox title="Vanliga misstag">
	- Använd inte en svensk konnektor för varje tyskt <span lang="de">weil / deshalb / damit</span> eller engelskt <span lang="en">because / so / therefore</span>.
	- <span lang="sv">därför</span> betyder alltså, <span lang="sv">därför att</span> betyder eftersom.
	- Gissa inte ordföljden när konnektorn ändrar satstypen. Använd [V2](../../sentence-structure/v2/) eller [bisatser](../../sentence-structure/subordinate-clauses/).
</MistakeBox>

<MemoryTip>
Välj först relationen: lägg till med <span lang="sv">och</span>, kontrastera med <span lang="sv">men</span>,
förklara med <span lang="sv">eftersom</span>, visa följd med <span lang="sv">därför</span> och sätt villkor med <span lang="sv">om</span>.
</MemoryTip>
