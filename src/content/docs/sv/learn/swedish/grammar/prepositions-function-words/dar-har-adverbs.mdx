<KeyTakeaway>
- <Sv>där</Sv>, <Sv>här</Sv> och <Sv>var</Sv> tillsammans med en preposition bildar ett ord, precis som tyska <span lang="de">darum</span> eller <span lang="de">hiermit</span>.
- <Sv>Därför</Sv> betyder ungefär alltså och har verbet på andra plats; <Sv>därför att</Sv> betyder ungefär eftersom och inleder en bisats.
- För plats används <Sv>här</Sv> och <Sv>där</Sv>, för riktning <Sv>hit</Sv> och <Sv>dit</Sv>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenskan kombinerar <Sv>där</Sv>, <Sv>här</Sv> och <Sv>var</Sv> med en
preposition till ett ord. Tysktalande känner igen mönstret från
<span lang="de">darum</span>, <span lang="de">damit</span> och <span lang="de">hiermit</span>.

## Mönstret

| Bas | + preposition | Betydelse |
| --- | --- | --- |
| <Sv>där</Sv> | <Sv>därför</Sv> | alltså, av den anledningen |
| | <Sv>därmed</Sv> | därigenom, med detta |
| | <Sv>därefter</Sv> | efter det |
| | <Sv>därav</Sv> | av den anledningen |
| | <Sv>därifrån</Sv> | från den platsen |
| <Sv>här</Sv> | <Sv>härmed</Sv> | härigenom |
| | <Sv>härefter</Sv> | hädanefter |
| | <Sv>härav</Sv> | av detta |
| <Sv>var</Sv> | <Sv>varför</Sv> | av vilken anledning |
| | <Sv>varav</Sv> | av vilket |
| | <Sv>varifrån</Sv> | från vilken plats |

<Sv>Där-</Sv>-orden syftar tillbaka på något nämnt, <Sv>här-</Sv>-orden på
något närvarande och <Sv>var-</Sv>-orden frågar eller relaterar.

Registret spelar roll. <Sv>Därför</Sv>, <Sv>därefter</Sv>, <Sv>därifrån</Sv> och
<Sv>varför</Sv> är vardagliga. <Sv>Härmed</Sv>, <Sv>härav</Sv>, <Sv>därav</Sv>
och <Sv>varav</Sv> hör till formell skrift: känn igen dem, men säg hellre
<Sv>Jag är intresserad av det</Sv> än <Sv>Jag är intresserad därav</Sv>.

## därför och därför att är inte samma ord

Det här är skillnaden som orsakar flest fel. <Sv>Därför</Sv> ensamt betyder
alltså och inleder en huvudsats. <Sv>Därför att</Sv> betyder eftersom och
inleder en bisats.

- <Sv>Jag var sjuk. Därför stannade jag hemma.</Sv> — huvudsats, verbet på andra plats.
- <Sv>Jag stannade hemma därför att jag var sjuk.</Sv> — bisats efter därför att.

<RuleBox title="Regel">
	<Sv>Därför</Sv> inleder en huvudsats. När det står först utlöser det V2:
	<Sv>Därför **stannade** jag hemma.</Sv> <Sv>Därför att</Sv> inleder en bisats;
	satsen efteråt har bisatsordföljd.
</RuleBox>

<Sv>Eftersom</Sv> är ett annat sätt att uttrycka orsak:

- <Sv>Eftersom jag var sjuk stannade jag hemma.</Sv>
- <Sv>Jag stannade hemma eftersom jag var sjuk.</Sv>

Se [V2](../../sentence-structure/v2/) och [bisatser](../../sentence-structure/subordinate-clauses/).

## här eller hit, där eller dit

De enkla adverben skiljer plats från riktning:

| Plats | Riktning | Därifrån |
| --- | --- | --- |
| <Sv>här</Sv> | <Sv>hit</Sv> | <Sv>härifrån</Sv> |
| <Sv>där</Sv> | <Sv>dit</Sv> | <Sv>därifrån</Sv> |

- <Sv>Jag bor här.</Sv>
- <Sv>Kom hit!</Sv>
- <Sv>Hon arbetar där.</Sv>
- <Sv>Vi åker dit i morgon.</Sv>

Frågeorden följer samma skillnad: <Sv>var</Sv> frågar om plats, <Sv>vart</Sv>
om riktning. Se [frågeord](../../questions-negation/question-words/).

## varför frågar, därför svarar

- <Sv>Varför stannade du hemma?</Sv>
- <Sv>Därför att jag var sjuk.</Sv>

Som kort svar på <Sv>varför</Sv> används både <Sv>därför att jag var sjuk</Sv>
och bara <Sv>därför!</Sv>. Se [frågeord](../../questions-negation/question-words/).

## Direkt jämförelse

<LanguageComparison title="Therefore, en huvudsats">
	<p slot="de">Ich war krank. Darum blieb ich zu Hause.</p>
	<p slot="en">I was ill. That is why I stayed home.</p>
	<p slot="sv">Jag var sjuk. Därför stannade jag hemma.</p>
</LanguageComparison>

<LanguageComparison title="Because, en bisats">
	<p slot="de">Ich blieb zu Hause, weil ich krank war.</p>
	<p slot="en">I stayed home because I was ill.</p>
	<p slot="sv">Jag stannade hemma därför att jag var sjuk.</p>
</LanguageComparison>

<MistakeBox title="Vanliga misstag">
	- ❌ <Sv>Jag stannade hemma därför jag var sjuk.</Sv> ✅ <Sv>Jag stannade hemma därför att jag var sjuk.</Sv>
	- ❌ <Sv>Därför jag stannade hemma.</Sv> ✅ <Sv>Därför stannade jag hemma.</Sv> — verbet står tvåa.
	- Använd inte formella <Sv>därav</Sv> eller <Sv>härmed</Sv> i vardagligt tal. Välj preposition + <Sv>det</Sv>.
</MistakeBox>

<MemoryTip>
Håll fast vid ett par: <Sv><strong>Därför stannade jag hemma</strong></Sv> —
huvudsats, verbet tvåa. <Sv><strong>… därför att jag var sjuk</strong></Sv> —
bisats. Det extra <Sv>att</Sv> ändrar konnektorn.
</MemoryTip>
