<KeyTakeaway>
- <span lang="sv">där</span>, <span lang="sv">här</span> och <span lang="sv">var</span> tillsammans med en preposition bildar ett ord, precis som tyska <span lang="de">darum</span> eller <span lang="de">hiermit</span>.
- <span lang="sv">Därför</span> betyder ungefär alltså och har verbet på andra plats; <span lang="sv">därför att</span> betyder ungefär eftersom och inleder en bisats.
- För plats används <span lang="sv">här</span> och <span lang="sv">där</span>, för riktning <span lang="sv">hit</span> och <span lang="sv">dit</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenskan kombinerar <span lang="sv">där</span>, <span lang="sv">här</span> och <span lang="sv">var</span> med en
preposition till ett ord. Tysktalande känner igen mönstret från
<span lang="de">darum</span>, <span lang="de">damit</span> och <span lang="de">hiermit</span>.

## Mönstret

| Bas | + preposition | Betydelse |
| --- | --- | --- |
| <span lang="sv">där</span> | <span lang="sv">därför</span> | alltså, av den anledningen |
| | <span lang="sv">därmed</span> | därigenom, med detta |
| | <span lang="sv">därefter</span> | efter det |
| | <span lang="sv">därav</span> | av det |
| | <span lang="sv">därifrån</span> | från den platsen |
| <span lang="sv">här</span> | <span lang="sv">härmed</span> | härigenom |
| | <span lang="sv">härefter</span> | hädanefter |
| | <span lang="sv">härav</span> | av detta |
| <span lang="sv">var</span> | <span lang="sv">varför</span> | av vilken anledning |
| | <span lang="sv">varav</span> | av vilket |
| | <span lang="sv">varifrån</span> | från vilken plats |

Förleden avslöjar funktionen: <span lang="sv">där-</span>-orden syftar tillbaka på något
nämnt, <span lang="sv">här-</span>-orden på något närvarande och <span lang="sv">var-</span>-orden frågar
eller relaterar.

Registret spelar roll. <span lang="sv">Därför</span>, <span lang="sv">därefter</span>, <span lang="sv">därifrån</span> och
<span lang="sv">varför</span> är vardagliga. <span lang="sv">Härmed</span>, <span lang="sv">härav</span>, <span lang="sv">därav</span>
och <span lang="sv">varav</span> hör till formell skrift: känn igen dem, men en preposition
plus <span lang="sv">det</span> är det normala talspråksvalet:
<span lang="sv">Jag är intresserad av det</span> snarare än <span lang="sv">Jag är intresserad därav</span>.

## därför och därför att är inte samma ord

Det här är skillnaden som orsakar flest fel. <span lang="sv">Därför</span> ensamt betyder
alltså och inleder en huvudsats. <span lang="sv">Därför att</span> betyder eftersom och
inleder en bisats.

- <span lang="sv">Jag var sjuk. Därför stannade jag hemma.</span> — huvudsats, verbet på andra plats.
- <span lang="sv">Jag stannade hemma därför att jag var sjuk.</span> — bisats efter därför att.

<RuleBox title="Regel">
	<span lang="sv">Därför</span> inleder en huvudsats. När det står först utlöser det V2:
	<span lang="sv">Därför **stannade** jag hemma.</span> <span lang="sv">Därför att</span> inleder en bisats;
	satsen efteråt har bisatsordföljd.
</RuleBox>

Ett annat sätt att uttrycka orsak är <span lang="sv">eftersom</span>:

- <span lang="sv">Eftersom jag var sjuk stannade jag hemma.</span>
- <span lang="sv">Jag stannade hemma eftersom jag var sjuk.</span>

Se [V2](../../sentence-structure/v2/) och [bisatser](../../sentence-structure/subordinate-clauses/).

## här eller hit, där eller dit

De enkla adverben skiljer plats från riktning:

| Plats | Riktning | Därifrån |
| --- | --- | --- |
| <span lang="sv">här</span> | <span lang="sv">hit</span> | <span lang="sv">härifrån</span> |
| <span lang="sv">där</span> | <span lang="sv">dit</span> | <span lang="sv">därifrån</span> |

- <span lang="sv">Jag bor här.</span>
- <span lang="sv">Kom hit!</span>
- <span lang="sv">Hon arbetar där.</span>
- <span lang="sv">Vi åker dit i morgon.</span>

Frågeorden följer samma skillnad: <span lang="sv">var</span> frågar om plats, <span lang="sv">vart</span>
om riktning. Se [frågeord](../../questions-negation/question-words/).

## varför frågar, därför svarar

- <span lang="sv">Varför stannade du hemma?</span>
- <span lang="sv">Därför att jag var sjuk.</span>

Som kort svar på <span lang="sv">varför</span> används både <span lang="sv">därför att jag var sjuk</span>
och bara <span lang="sv">därför!</span>. Se [frågeord](../../questions-negation/question-words/).

## Direkt jämförelse

<LanguageComparison title="Därför, en huvudsats">
	<p slot="de">Ich war krank. Darum blieb ich zu Hause.</p>
	<p slot="en">I was ill. That is why I stayed home.</p>
	<p slot="sv">Jag var sjuk. Därför stannade jag hemma.</p>
</LanguageComparison>

<LanguageComparison title="Därför att, en bisats">
	<p slot="de">Ich blieb zu Hause, weil ich krank war.</p>
	<p slot="en">I stayed home because I was ill.</p>
	<p slot="sv">Jag stannade hemma därför att jag var sjuk.</p>
</LanguageComparison>

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">Jag stannade hemma därför jag var sjuk.</span> ✅ <span lang="sv">Jag stannade hemma därför att jag var sjuk.</span>
	- ❌ <span lang="sv">Därför jag stannade hemma.</span> ✅ <span lang="sv">Därför stannade jag hemma.</span> — verbet står tvåa.
	- Använd inte formella <span lang="sv">därav</span> eller <span lang="sv">härmed</span> i vardagligt tal. Välj preposition + <span lang="sv">det</span>.
</MistakeBox>

<MemoryTip>
Håll fast vid ett par: <span lang="sv"><strong>Därför stannade jag hemma</strong></span> —
huvudsats, verbet tvåa. <span lang="sv"><strong>… därför att jag var sjuk</strong></span> —
bisats. Det extra <span lang="sv">att</span> ändrar konnektorn.
</MemoryTip>
