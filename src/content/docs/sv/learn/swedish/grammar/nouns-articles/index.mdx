- Lär dig ett substantiv med artikel och plural: formerna öppnar hela nominalfrasen.
- Använd översikten med fyra former för numerus och bestämdhet; använd sidan om ägande när en nominalfras anger ägaren till en annan.

Det här avsnittet skiljer mellan fyra nära sammanhängande val: substantivets genus, form, pluralmönster och ägande med substantiv.

## Välj efter behov

| Om du behöver … | Börja med … |
| --- | --- |
| välja <span lang="sv">en</span> eller <span lang="sv">ett</span> | [<span lang="sv">en</span> / <span lang="sv">ett</span>](./en-ett/) |
| göra ett substantiv obestämt eller bestämt, i singular eller plural | [Substantivformer](./noun-forms/) |
| hitta en trolig pluraländelse eller känna igen en oregelbunden plural | [Pluralöversikt](./plural-overview/) |
| säga ”Annas bok” eller ”hundens namn” | [Ägande](./possession/) |
| välja <em>min, din, hans, hennes, vår</em> eller <em>deras</em> | [Possessiva pronomen](../pronouns-roles/possessive-pronouns/) |

## Lär dig i den här ordningen

1. [<span lang="sv">en</span> / <span lang="sv">ett</span>](./en-ett/) ger substantivets genus och den säkraste studievana.
2. [Substantivformer](./noun-forms/) bygger de fyra centrala formerna.
3. [Pluralöversikt](./plural-overview/) lägger till de viktigaste pluralmönstren och vanliga oregelbundna former.
4. [Ägande](./possession/) visar hur en nominalfras som anger ägaren bestämmer ett annat substantiv.

## Se upp med

- **Substantivformer eller pluralöversikt:** Den första sidan visar hela systemet med singular/plural och obestämd/bestämd form; den andra fokuserar på hur pluralen bildas.
- **Ägande eller possessiva pronomen:** [Ägande](./possession/) behandlar substantiviska ägare som *Annas*; [possessiva pronomen](../pronouns-roles/possessive-pronouns/) behandlar former som *min*, *mitt* och *mina*.
