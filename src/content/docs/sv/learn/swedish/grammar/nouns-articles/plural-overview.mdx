<KeyTakeaway>
- Obestämd plural följer ett av fem mönster: <span lang="sv">-or</span>, <span lang="sv">-ar</span>, <span lang="sv">-er</span>, <span lang="sv">-n</span> eller ingen ändelse alls.
- Genus och ordslut begränsar bara gissningen; pluralen måste läras med substantivet.
- Avsaknad av ändelse betyder inte singular: <span lang="sv">tre hus</span> är plural.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenska substantiv bildar obestämd plural på flera sätt. Genus och ordslut ger användbara ledtrådar, men förutsäger inte varje ord. För säker användning behöver du lära ett substantiv med genus och plural.

## De viktigaste pluralmönstren

Traditionella beskrivningar grupperar svenska substantiv efter deras pluraländelser:

| Mönster | Typiskt exempel | Obestämd plural | Bestämd plural |
| --- | --- | --- | --- |
| <span lang="sv">-or</span> | <span lang="sv">en flicka</span> | <span lang="sv">flickor</span> | <span lang="sv">flickorna</span> |
| <span lang="sv">-ar</span> | <span lang="sv">en bil</span> | <span lang="sv">bilar</span> | <span lang="sv">bilarna</span> |
| <span lang="sv">-er</span> | <span lang="sv">en telefon</span> | <span lang="sv">telefoner</span> | <span lang="sv">telefonerna</span> |
| <span lang="sv">-n</span> | <span lang="sv">ett äpple</span> | <span lang="sv">äpplen</span> | <span lang="sv">äpplena</span> |
| ingen ändelse | <span lang="sv">ett hus</span> | <span lang="sv">hus</span> | <span lang="sv">husen</span> |

Det här är studiemönster, inte regler som tar bort behovet av att lära enskilda substantivformer.

## Användbara ledtrådar

- Många en-ord som slutar på obetonat <span lang="sv">-a</span> får <span lang="sv">-or</span>: <span lang="sv">en vecka → veckor</span>.
- Många vanliga en-ord får <span lang="sv">-ar</span>: <span lang="sv">en stol → stolar</span>.
- Många internationella ord får <span lang="sv">-er</span>: <span lang="sv">en station → stationer</span>.
- Många ett-ord som slutar på vokal får <span lang="sv">-n</span>: <span lang="sv">ett äpple → äpplen</span>.
- Många ett-ord som slutar på konsonant saknar obestämd pluraländelse: <span lang="sv">ett barn → barn</span>.

## Stamändringar och oregelbundna former

Vissa vanliga substantiv ändras inuti ordet eller har oregelbunden plural:

- <span lang="sv">en bok → böcker → böckerna</span>
- <span lang="sv">en man → män → männen</span>
- <span lang="sv">en hand → händer → händerna</span>
- <span lang="sv">ett öga → ögon → ögonen</span>

Lär de här formerna som hela substantivparadigm i stället för att pressa in dem i ett regelbundet ändelsemönster.

## Latinska och grekiska lånord

En grupp ett-ord som slutar på <span lang="sv">-um</span> byter ut ändelsen i plural. Flera är vardagsord, så mönstret är värt att känna igen:

| Singular | Plural | Bestämd plural |
| --- | --- | --- |
| <span lang="sv">ett museum</span> | <span lang="sv">museer</span> | <span lang="sv">museerna</span> |
| <span lang="sv">ett gymnasium</span> | <span lang="sv">gymnasier</span> | <span lang="sv">gymnasierna</span> |
| <span lang="sv">ett laboratorium</span> | <span lang="sv">laboratorier</span> | <span lang="sv">laboratorierna</span> |
| <span lang="sv">ett akvarium</span> | <span lang="sv">akvarier</span> | <span lang="sv">akvarierna</span> |

Två vanliga ord fungerar annorlunda:

- <span lang="sv">ett faktum → fakta</span> — pluralen är <span lang="sv">fakta</span>, som också ofta behandlas som ett massord.
- <span lang="sv">ett datum → datum</span> — oförändrat i plural.

Utvidga inte detta till varje ord på <span lang="sv">-um</span>: vardagliga <span lang="sv">ett centrum</span> är vanligen <span lang="sv">centrum</span> i plural, medan latinska <span lang="sv">centra</span> är begränsat till formell skrift.

## Numerus efter räkneord

Använd obestämd plural efter tal större än ett:

- <span lang="sv">en bil</span>
- <span lang="sv">två bilar</span>
- <span lang="sv">tre hus</span>

Att <span lang="sv">tre hus</span> saknar synlig ändelse gör inte substantivet till singular; talet och sammanhanget visar plural.

## Direkt jämförelse

<LanguageComparison title="Obestämd singular">
	<p slot="de">ein Haus</p>
	<p slot="en">a house</p>
	<p slot="sv">ett hus</p>
</LanguageComparison>

<LanguageComparison title="Obestämd plural">
	<p slot="de">Häuser</p>
	<p slot="en">houses</p>
	<p slot="sv">hus</p>
</LanguageComparison>

Liksom tyskan har svenskan flera pluralmönster och stamändringar. Engelskt <span lang="en">-s</span> är därför ingen säker modell för svenska.

<MistakeBox>
Anta inte att alla en-ord får en ändelse och alla ett-ord en annan:

<span lang="sv">en bil → bilar</span>, men <span lang="sv">en telefon → telefoner</span>;  
<span lang="sv">ett äpple → äpplen</span>, men <span lang="sv">ett hus → hus</span>.
</MistakeBox>

<MemoryTip>
Lär de fyra formerna, inte ett gissat gruppnummer: <span lang="sv"><strong>ett äpple — äpplet — äpplen — äpplena</strong></span>. Mönstret blir bekant genom upprepade exempel.
</MemoryTip>
