<KeyTakeaway>
- Lägg till <span lang="sv">-s</span> till ett substantiv eller namn för att göra det till ägare: <span lang="sv">Annas bok</span>, <span lang="sv">hundens namn</span>.
- Det ägda substantivet står vanligen utan artikel eller bestämd ändelse efter en ägare: <span lang="sv">Annas nya bil</span>, inte <span lang="sv">den Annas bilen</span>.
- Använd ett possessivt pronomen när ägaren uttrycks med *min, din, hans, hennes, vår* eller *deras*.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenskt nominalt ägande sätter ägaren först och markerar den med <span lang="sv">-s</span>. Den här sidan behandlar ägande med substantiv och namn; pronomen som ägare har en egen översikt.

## Använd detta nu

| Vad anger ägaren? | Använd | Exempel |
| --- | --- | --- |
| ett namn | namn + <span lang="sv">-s</span> | <span lang="sv">Annas bok</span> |
| en nominalfras | nominalfras + <span lang="sv">-s</span> | <span lang="sv">min väns bil</span> |
| *min, din, hans, hennes, vår, deras* | ett possessivt pronomen | <span lang="sv">min bok</span> |
| tredje personens egen sak | <span lang="sv">sin / sitt / sina</span> | <span lang="sv">Anna tar sin bok.</span> |

## Grundregel

Ägaren kommer före det ägda substantivet:

| Ägare | Ägarfras |
| --- | --- |
| <span lang="sv">Anna</span> | <span lang="sv">Annas cykel</span> |
| <span lang="sv">hunden</span> | <span lang="sv">hundens namn</span> |
| <span lang="sv">mina vänner</span> | <span lang="sv">mina vänners hus</span> |

<span lang="sv">-s</span> hör till hela ägaruttrycket. Svenskan skriver det utan apostrof: <span lang="sv">Eriks rum</span>, inte <span lang="sv">Erik's rum</span>.

Namn som redan slutar på <span lang="sv">-s</span>, <span lang="sv">-x</span> eller <span lang="sv">-z</span> får vanligen inte ett till skrivet <span lang="sv">s</span>: <span lang="sv">Lars bok</span>, <span lang="sv">Max cykel</span>.

## Det ägda substantivet har obestämd form

Efter en ägare står substantivet vanligen utan artikel och utan enkel bestämd ändelse:

- <span lang="sv">Annas bil</span>
- <span lang="sv">Annas nya bil</span>
- <span lang="sv">hundens namn</span>

Ett adjektiv får sin bestämt liknande form på <span lang="sv">-a</span>, men svenskan lägger ändå inte till <span lang="sv">den</span> eller gör det ägda substantivet bestämt: <span lang="sv">Annas nya bil</span>.

## Andra naturliga sätt att uttrycka ägande

s-genitiven bildar en nominalfras. När poängen är att säga vem som äger något är en hel sats ofta tydligare:

- <span lang="sv">Boken tillhör Anna.</span>
- <span lang="sv">Det är Annas bok.</span>
- <span lang="sv">Anna har en bok.</span>

## Direkt jämförelse

<LanguageComparison title="Annas nya bil">
	<p slot="de">Annas neues Auto</p>
	<p slot="en">Anna's new car</p>
	<p slot="sv">Annas nya bil</p>
</LanguageComparison>

Engelskan använder apostrof i den här konstruktionen, men svenskan och tyskan gör det inte. Svenskan låter också det ägda substantivet stå utan egen artikel.

<MistakeBox title="Vanliga misstag">
- <span lang="sv">❌ Anna's bok</span> → <span lang="sv">✅ Annas bok</span>
- <span lang="sv">❌ Annas bilen</span> → <span lang="sv">✅ Annas bil</span>
- <span lang="sv">❌ Annas ny bil</span> → <span lang="sv">✅ Annas nya bil</span>
</MistakeBox>

<MemoryTip>
Sätt ägaren först, lägg till <span lang="sv">-s</span> och låt det ägda substantivet stå utan artikel: <span lang="sv"><strong>Anna + s + bok → Annas bok</strong></span>.
</MemoryTip>
