<KeyTakeaway>
- Varje substantiv är ett en-ord eller ett ett-ord. Lär dig det som
  <span lang="sv">en bil</span> eller <span lang="sv">ett hus</span>, aldrig
  ensamt.
- Måste du gissa, gissa <span lang="sv">en</span>: de flesta substantiv är
  en-ord, och många ordändelser visar genus.
- Ett sammansatt ord får genus från sin **sista** del:
  <span lang="sv">ett sommarhus</span>, eftersom <span lang="sv">ett hus</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Varje svenskt substantiv hör till en av två grupper, som kallas genus
([genus](../../../glossary/#genus)). Ett **en-ord** har artikeln
<span lang="sv">en</span> (<span lang="sv">en bil</span>), ett **ett-ord** har
artikeln <span lang="sv">ett</span> (<span lang="sv">ett hus</span>). Tyskan
har tre sådana grupper — <span lang="de">der</span>,
<span lang="de">die</span>, <span lang="de">das</span> — engelskan har inga. Du
behöver genus för varje substantiv du använder, eftersom artikeln, den
bestämda formen (<span lang="sv">bilen</span>, <span lang="sv">huset</span>)
och adjektivet beror på det.

## Snabb hjälp

När du möter ett nytt substantiv, gå igenom listan uppifrån:

| Situation | Gör så här | Exempel |
| --- | --- | --- |
| Du lär dig ett nytt substantiv | Lär dig det tillsammans med artikeln, inte ensamt. | <span lang="sv">en bil</span>, <span lang="sv">ett hus</span> |
| Du har ingen aning | Gissa <span lang="sv">en</span> och kontrollera senare. | <span lang="sv">en dag</span>, <span lang="sv">en fråga</span> |
| Substantivet har en typisk ändelse | Låt ändelsen hjälpa dig, men lär dig ändå substantivet med artikeln. | <span lang="sv">en tidning</span>, <span lang="sv">ett bibliotek</span> |
| Substantivet är ett sammansatt ord | Ta genus från den sista delen. Kontrollera ord du inte känner till. | <span lang="sv">ett sommarhus</span> av <span lang="sv">ett hus</span> |
| Du lägger till ett adjektiv | Böj adjektivet efter substantivets genus och efter om det är ett eller flera. | <span lang="sv">en stor bil</span>, <span lang="sv">ett stort hus</span> |

Den mest användbara vanan är enkel: säg varje nytt substantiv högt med sin
artikel. Den vanan ger dig artikeln, den bestämda formen och senare också rätt
ändelse på adjektivet.

## Kärnregel

| Genus | Obestämd form, singular |
| --- | --- |
| en-ord | <span lang="sv">en bil</span> |
| ett-ord | <span lang="sv">ett hus</span> |

Ingen regel säger vilket genus varje svenskt substantiv har. Lär dig artikeln
tillsammans med substantivet: inte bara <span lang="sv">bil</span>, utan
<span lang="sv">en bil</span>. Vissa ändelser är så pålitliga att de hjälper
dig gissa, och sammansatta ord följer sin sista del.

<RuleBox>
	Lär dig ett svenskt substantiv tillsammans med artikeln. Artikeln visar
	genus, och genus avgör de andra formerna: den bestämda formen och
	adjektivet.
</RuleBox>

## Ändelser som visar genus

De flesta svenska substantiv är en-ord, så <span lang="sv">en</span> är den
bästa gissningen när du inte har något annat att gå på. Många ändelser gör
gissningen säkrare.

De här ändelserna hör vanligtvis till en-ord:

| Ändelse | Exempel |
| --- | --- |
| <span lang="sv">-a</span> | <span lang="sv">en flicka</span>, <span lang="sv">en gata</span>, <span lang="sv">en vecka</span> |
| <span lang="sv">-are</span> | <span lang="sv">en lärare</span>, <span lang="sv">en bagare</span> |
| <span lang="sv">-else</span> | <span lang="sv">en händelse</span>, <span lang="sv">en rörelse</span> |
| <span lang="sv">-het</span> | <span lang="sv">en möjlighet</span>, <span lang="sv">en nyhet</span> |
| <span lang="sv">-ning</span>, <span lang="sv">-ing</span> | <span lang="sv">en tidning</span>, <span lang="sv">en övning</span> |
| <span lang="sv">-dom</span> | <span lang="sv">en sjukdom</span>, <span lang="sv">en visdom</span> |
| <span lang="sv">-lek</span> | <span lang="sv">en kärlek</span>, <span lang="sv">en storlek</span> |
| <span lang="sv">-nad</span> | <span lang="sv">en byggnad</span>, <span lang="sv">en skillnad</span> |
| <span lang="sv">-tion</span>, <span lang="sv">-sion</span> | <span lang="sv">en station</span>, <span lang="sv">en diskussion</span> |
| <span lang="sv">-ist</span>, <span lang="sv">-ent</span>, <span lang="sv">-ör</span> | <span lang="sv">en turist</span>, <span lang="sv">en student</span>, <span lang="sv">en frisör</span> |

De här ändelserna hör vanligtvis till ett-ord:

| Ändelse | Exempel |
| --- | --- |
| <span lang="sv">-ande</span>, <span lang="sv">-ende</span> | <span lang="sv">ett meddelande</span>, <span lang="sv">ett leende</span> |
| <span lang="sv">-eri</span> | <span lang="sv">ett bageri</span>, <span lang="sv">ett tryckeri</span> |
| <span lang="sv">-um</span> | <span lang="sv">ett museum</span>, <span lang="sv">ett centrum</span>, <span lang="sv">ett faktum</span> |
| <span lang="sv">-ment</span> | <span lang="sv">ett dokument</span>, <span lang="sv">ett argument</span> |
| <span lang="sv">-tek</span> | <span lang="sv">ett bibliotek</span>, <span lang="sv">ett apotek</span> |
| <span lang="sv">-gram</span> | <span lang="sv">ett program</span>, <span lang="sv">ett diagram</span> |

Tre fall kräver försiktighet:

- <span lang="sv">-a</span> har en liten grupp ett-ord:
  <span lang="sv">ett öga</span>, <span lang="sv">ett öra</span>,
  <span lang="sv">ett hjärta</span>.
- <span lang="sv">-ande</span> och <span lang="sv">-ende</span> är ett-ord när
  de betyder en handling, men en-ord när de betyder en person:
  <span lang="sv">ett meddelande</span> mot
  <span lang="sv">en studerande</span>.
- <span lang="sv">-skap</span> är delat. Ord för saker eller grupper är oftast
  ett-ord (<span lang="sv">ett landskap</span>,
  <span lang="sv">ett sällskap</span>), medan ord för relationer och
  egenskaper oftast är en-ord (<span lang="sv">en vänskap</span>,
  <span lang="sv">en kunskap</span>). Kontrollera ord med den här ändelsen i
  stället för att gissa.

En ändelse som <span lang="sv">-e</span> ger ingen ledtråd alls: jämför
<span lang="sv">en pojke</span> med <span lang="sv">ett äpple</span>.

Substantiv för personer och djur är oftast en-ord —
<span lang="sv">en man</span>, <span lang="sv">en kvinna</span>,
<span lang="sv">en hund</span> — men inte alltid:
<span lang="sv">ett barn</span>, <span lang="sv">ett djur</span>,
<span lang="sv">ett lejon</span>.

## Sammansatta ord följer sin sista del

Svenskan sätter ihop ord hela tiden: <span lang="sv">sommar</span> +
<span lang="sv">hus</span> blir <span lang="sv">sommarhus</span>. Därför är det
här den mest användbara genusregeln: den sista delen i det sammansatta ordet
([efterled](../../../glossary/#efterled)) avgör genus. Delarna före den spelar
ingen roll:

| Delar | Sammansatt ord |
| --- | --- |
| <span lang="sv">en cykel</span> + <span lang="sv">ett hjul</span> | <span lang="sv">ett cykelhjul</span> |
| <span lang="sv">ett tåg</span> + <span lang="sv">en station</span> | <span lang="sv">en tågstation</span> |
| <span lang="sv">en sommar</span> + <span lang="sv">ett hus</span> | <span lang="sv">ett sommarhus</span> |
| <span lang="sv">en post</span> + <span lang="sv">ett kontor</span> | <span lang="sv">ett postkontor</span> |

Den bestämda formen och pluralen följer oftast också den sista delen:
<span lang="sv">ett cykelhjul → cykelhjulet</span>,
<span lang="sv">en tågstation → tågstationen</span>.

<RuleBox title="Tumregel">
	I ett sammansatt ord tittar du på den sista delen. Dess genus, dess
	bestämda form och dess plural gäller oftast för hela ordet.
</RuleBox>

## Obestämd och bestämd form

Obestämd form har artikeln framför ordet: <span lang="sv">en bil</span>.
Bestämd form får en ändelse på substantivet i stället:

| Genus | Obestämd form | Bestämd form |
| --- | --- | --- |
| en-ord | <span lang="sv">en bil</span> | <span lang="sv">bilen</span> |
| ett-ord | <span lang="sv">ett hus</span> | <span lang="sv">huset</span> |

## Adjektivets ändelse

Ett adjektiv ändrar ändelse så att det passar substantivet: ett en-ord eller
ett ett-ord, ett eller flera. Artikeln visar vilket du har:

- <span lang="sv">en <strong>stor</strong> bil</span>
- <span lang="sv">ett <strong>stort</strong> hus</span>
- <span lang="sv"><strong>stora</strong> bilar</span>
- <span lang="sv"><strong>stora</strong> hus</span>

Grundmönstret: **grundformen** med ett en-ord, oftast **-t** med ett ett-ord
och oftast **-a** i plural. Några adjektiv har oregelbundna former. Hela
förklaringen finns på sidan om
[hur adjektiv böjs efter substantivet](../../adjectives-adverbs/agreement/).

## Den stora bilen: två markeringar för bestämd form

När ett adjektiv står före ett substantiv i bestämd form markerar svenskan
bestämd form två gånger: med ett eget ord framför
(<span lang="sv">den</span>) och med ändelsen på substantivet
(<span lang="sv">-en</span>):

<p lang="sv">den stora bilen</p>

Det kallas [dubbel bestämdhet](../../../glossary/#dubbel-bestämdhet). Hela
mönstret och undantaget efter ord som <span lang="sv">min</span> finns på sidan
om
[hur adjektiv böjs efter substantivet](../../adjectives-adverbs/agreement/#bestämda-nominalfraser-och-dubbel-bestämdhet).

## Plural

Artikeln <span lang="sv">en</span> eller <span lang="sv">ett</span> visar inte
vilken pluralform ordet får:

- <span lang="sv">en bil → bilar</span>
- <span lang="sv">ett hus → hus</span>
- <span lang="sv">ett äpple → äpplen</span>

Lär dig de viktiga pluralformerna tillsammans med substantivet. Se
[Pluralöversikt](../plural-overview/).

<MistakeBox title="Vanliga fel">
Vad något betyder avgör inte om det heter <span lang="sv">en</span> eller
<span lang="sv">ett</span>, och <span lang="sv">en</span> passar inte för alla
ord. Ta inte heller genus till ett sammansatt ord från dess första del:
<span lang="sv">❌ en cykelhjul</span>, <span lang="sv">✅ ett cykelhjul</span>.

<span lang="sv">❌ en hus</span>  
<span lang="sv">✅ ett hus</span>

Låt också adjektivet passa substantivet:

<span lang="sv">❌ ett stor hus</span>  
<span lang="sv">✅ ett stort hus</span>
</MistakeBox>

<MemoryTip>
	Se artikeln som en del av ordet: lär dig
	<span lang="sv"><strong>en bil</strong></span> och
	<span lang="sv"><strong>ett hus</strong></span>. Lägg till de fyra formerna av
	substantivet när du kan dem: <span lang="sv">en bil, bilen, bilar, bilarna</span>.
</MemoryTip>
