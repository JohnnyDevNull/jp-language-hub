<KeyTakeaway>
- Varje substantiv har ett genus, så lär det som <span lang="sv">en bil</span> eller <span lang="sv">ett hus</span>, aldrig som ett ensamt substantiv.
- <span lang="sv">en</span> är den bättre gissningen: en-ord är klart flest och flera avledningsändelser gör gissningen säkrare.
- Produktiva sammansättningar får normalt genus från sitt **sista** led.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

De flesta svenska substantiv tillhör ett av två grammatiska genus. Ett **en-ord** använder <span lang="sv">en</span>; ett **ett-ord** använder <span lang="sv">ett</span>. Substantivets genus påverkar artiklar, bestämda former och adjektivändelser.

## Använd detta nu

När du behöver använda ett nytt substantiv väljer du den säkraste vägen i den här ordningen:

| Situation | Gör så här | Exempel |
| --- | --- | --- |
| Du lär dig ett nytt substantiv | Lagra det med artikeln, inte ensamt. | <span lang="sv">en bil</span>, <span lang="sv">ett hus</span> |
| Du har ingen aning | Gissa <span lang="sv">en</span> och kontrollera senare. | <span lang="sv">en dag</span>, <span lang="sv">en fråga</span> |
| Substantivet har en tydlig ändelsesignal | Låt ändelsen vägleda dig, men lär ändå hela nominalfrasen. | <span lang="sv">en tidning</span>, <span lang="sv">ett bibliotek</span> |
| Substantivet ser ut som en vanlig produktiv sammansättning | Börja med slutledets genus och kontrollera okända ord. | <span lang="sv">ett sommarhus</span> från <span lang="sv">ett hus</span> |
| Du lägger till ett adjektiv | Anpassa adjektivet efter substantivets genus och numerus. | <span lang="sv">en stor bil</span>, <span lang="sv">ett stort hus</span> |

I vardagligt tal är den mest användbara vanan enkel: säg substantivet högt med artikeln varje gång du lär dig det. Den vanan ger dig artikel, bestämd form och det adjektivmönster som en mening senare behöver.

## Grundregel

| Genus | Obestämd singular |
| --- | --- |
| en-ord | <span lang="sv">en bil</span> |
| ett-ord | <span lang="sv">ett hus</span> |

Det finns ingen helt tillförlitlig regel som förutsäger genus för varje svenskt substantiv. Lär artikeln tillsammans med substantivet: inte bara <span lang="sv">bil</span>, utan <span lang="sv">en bil</span>. Vissa ordändelser begränsar gissningen tillräckligt regelbundet, och produktiva sammansättningar följer vanligen slutledet.

<RuleBox>
	Lär ett svenskt substantiv tillsammans med artikeln. Artikeln är en del av ordets grammatiska information: den visar genus och hjälper dig att välja passande former på andra håll i nominalfrasen.
</RuleBox>

## Ändelser som pekar mot ett genus

En-ord är klart flest i svenskan, så <span lang="sv">en</span> är den bättre gissningen när du saknar andra ledtrådar. Många avledningsändelser begränsar gissningen ytterligare.

De här ändelserna är normalt en-ord:

| Ändelse | Exempel |
| --- | --- |
| <span lang="sv">-a</span> | <span lang="sv">en flicka</span>, <span lang="sv">en gata</span>, <span lang="sv">en vecka</span> |
| <span lang="sv">-are</span> | <span lang="sv">en lärare</span>, <span lang="sv">en bagare</span> |
| <span lang="sv">-else</span> | <span lang="sv">en händelse</span>, <span lang="sv">en rörelse</span> |
| <span lang="sv">-het</span> | <span lang="sv">en möjlighet</span>, <span lang="sv">en nyhet</span> |
| <span lang="sv">-ning</span>, <span lang="sv">-ing</span> | <span lang="sv">en tidning</span>, <span lang="sv">en övning</span> |
| <span lang="sv">-dom</span> | <span lang="sv">en sjukdom</span>, <span lang="sv">en visdom</span> |
| <span lang="sv">-lek</span> | <span lang="sv">en kärlek</span>, <span lang="sv">en storlek</span> |
| <span lang="sv">-nad</span> | <span lang="sv">en byggnad</span>, <span lang="sv">en skillnad</span> |
| <span lang="sv">-tion</span>, <span lang="sv">-sion</span> | <span lang="sv">en station</span>, <span lang="sv">en diskussion</span> |
| <span lang="sv">-ist</span>, <span lang="sv">-ent</span>, <span lang="sv">-ör</span> | <span lang="sv">en turist</span>, <span lang="sv">en student</span>, <span lang="sv">en frisör</span> |

De här ändelserna är normalt ett-ord:

| Ändelse | Exempel |
| --- | --- |
| <span lang="sv">-ande</span>, <span lang="sv">-ende</span> | <span lang="sv">ett meddelande</span>, <span lang="sv">ett leende</span> |
| <span lang="sv">-eri</span> | <span lang="sv">ett bageri</span>, <span lang="sv">ett tryckeri</span> |
| <span lang="sv">-um</span> | <span lang="sv">ett museum</span>, <span lang="sv">ett centrum</span>, <span lang="sv">ett faktum</span> |
| <span lang="sv">-ment</span> | <span lang="sv">ett dokument</span>, <span lang="sv">ett argument</span> |
| <span lang="sv">-tek</span> | <span lang="sv">ett bibliotek</span>, <span lang="sv">ett apotek</span> |
| <span lang="sv">-gram</span> | <span lang="sv">ett program</span>, <span lang="sv">ett diagram</span> |

Tre fall kräver omsorg:

- <span lang="sv">-a</span> har en liten grupp ett-ord: <span lang="sv">ett öga</span>, <span lang="sv">ett öra</span>, <span lang="sv">ett hjärta</span>.
- <span lang="sv">-ande</span> och <span lang="sv">-ende</span> är ett-ord när de betecknar en handling, men en-ord när de betecknar en person: <span lang="sv">ett meddelande</span> jämfört med <span lang="sv">en studerande</span>.
- <span lang="sv">-skap</span> är verkligen delat. Konkreta och kollektiva substantiv tenderar att vara ett-ord (<span lang="sv">ett landskap</span>, <span lang="sv">ett sällskap</span>), medan relationer och egenskaper tenderar att vara en-ord (<span lang="sv">en vänskap</span>, <span lang="sv">en kunskap</span>). Kontrollera denna ändelse i stället för att gissa.

En ändelse som <span lang="sv">-e</span> ger ingen användbar signal alls: jämför <span lang="sv">en pojke</span> med <span lang="sv">ett äpple</span>.

Substantiv för människor och djur är oftast en-ord — <span lang="sv">en man</span>, <span lang="sv">en kvinna</span>, <span lang="sv">en hund</span> — men inte alltid: <span lang="sv">ett barn</span>, <span lang="sv">ett djur</span>, <span lang="sv">ett lejon</span>.

## Produktiva sammansättningar följer normalt sitt sista led

Det här är den mest användbara genusregeln eftersom svenskan bildar sammansättningar hela tiden. I produktiva sammansättningar är slutledet huvudledet och ger normalt hela ordets genus; de tidigare leden spelar ingen roll:

| Delar | Sammansättning |
| --- | --- |
| <span lang="sv">en cykel</span> + <span lang="sv">ett hjul</span> | <span lang="sv">ett cykelhjul</span> |
| <span lang="sv">ett tåg</span> + <span lang="sv">en station</span> | <span lang="sv">en tågstation</span> |
| <span lang="sv">en sommar</span> + <span lang="sv">ett hus</span> | <span lang="sv">ett sommarhus</span> |
| <span lang="sv">en post</span> + <span lang="sv">ett kontor</span> | <span lang="sv">ett postkontor</span> |

För vanliga produktiva sammansättningar följer bestämd och plural form normalt också slutledet: <span lang="sv">ett cykelhjul → cykelhjulet</span>, <span lang="sv">en tågstation → tågstationen</span>.

<RuleBox title="Pålitlig genväg">
	Börja med slutledet i en vanlig produktiv sammansättning. Dess genus, bestämda ändelse och pluralmönster förs normalt över till hela ordet.
</RuleBox>

## Obestämd och bestämd form

Svenskan använder vanligen en separat artikel i obestämd singular men lägger en ändelse till substantivet i enkel bestämd form:

| Genus | Obestämd | Bestämd |
| --- | --- | --- |
| en-ord | <span lang="sv">en bil</span> | <span lang="sv">bilen</span> |
| ett-ord | <span lang="sv">ett hus</span> | <span lang="sv">huset</span> |

<NounForms indefiniteSingular="en bil" definiteSingular="bilen" indefinitePlural="bilar" definitePlural="bilarna" caption="Grundformer av bil" />

Jämför:

## Adjektivkongruens

Nominalfrasens genus och numerus bestämmer adjektivets grundform. Artikeln gör den grammatiska informationen synlig:

- <span lang="sv">en <strong>stor</strong> bil</span>
- <span lang="sv">ett <strong>stort</strong> hus</span>
- <span lang="sv"><strong>stora</strong> bilar</span>
- <span lang="sv"><strong>stora</strong> hus</span>

Grundmönstret är **grundform** med en-ord, ofta **-t** med ett-ord och ofta **-a** i plural. Adjektiv har också oregelbundna och stavningsberoende former; den kanoniska förklaringen finns under [adjektivkongruens](../../adjectives-adverbs/agreement/).

## Bestämda adjektivkonstruktioner

När ett adjektiv bestämmer ett bestämt substantiv markerar standardsvenskan normalt bestämdhet både med en separat artikel och substantivets bestämda ändelse:

<p lang="sv">den stora bilen</p>

Detta kallas **dubbel bestämdhet**. Se [adjektivkongruens](../../adjectives-adverbs/agreement/#bestämda-nominalfraser-och-dubbel-bestämdhet) för hela mönstret, genus- och numerusformerna samt undantaget med possessiv.

## Plural

Pluraländelsen kan inte härledas från en eller ett enbart:

- <span lang="sv">en bil → bilar</span>
- <span lang="sv">ett hus → hus</span>
- <span lang="sv">ett äpple → äpplen</span>

Lär de viktiga pluralformerna med substantivet. Se [pluralöversikt](../plural-overview/).

<MistakeBox title="Vanliga misstag">
Anta inte att ett föremåls naturliga egenskaper avgör en eller ett, och använd inte <span lang="sv">en</span> som universell artikel. Ta inte heller genus i en sammansättning från första ledet: <span lang="sv">❌ en cykelhjul</span>, <span lang="sv">✅ ett cykelhjul</span>.

<span lang="sv">❌ en hus</span>  
<span lang="sv">✅ ett hus</span>

Håll också adjektivet konsekvent:

<span lang="sv">❌ ett stor hus</span>  
<span lang="sv">✅ ett stort hus</span>
</MistakeBox>

<MemoryTip>
	Behandla artikeln som en del av ordet: lär <span lang="sv"><strong>en bil</strong></span> och <span lang="sv"><strong>ett hus</strong></span>. Lägg till de fyra substantivformerna när du kan: <span lang="sv">en bil, bilen, bilar, bilarna</span>.
</MemoryTip>
