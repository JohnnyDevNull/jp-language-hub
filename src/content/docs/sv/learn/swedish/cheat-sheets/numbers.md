## Grundtal

| Intervall | Svenska |
| --- | --- |
| 1–10 | <span lang="sv">en/ett, två, tre, fyra, fem, sex, sju, åtta, nio, tio</span> |
| 11–20 | <span lang="sv">elva, tolv, tretton, fjorton, femton, sexton, sjutton, arton, nitton, tjugo</span> |
| Tiotal | <span lang="sv">trettio, fyrtio, femtio, sextio, sjuttio, åttio, nittio</span> |
| Större | <span lang="sv">hundra, tusen, en miljon, en miljard</span> |

## Bilda tal

| Regel | Exempel |
| --- | --- |
| Tiotalet först, inget <span lang="sv">och</span>, ett ord | 21 → <span lang="sv">tjugoett</span>, 156 → <span lang="sv">hundrafemtiosex</span> |
| Fristående 1 böjs efter substantivet | <span lang="sv">en bil</span>, <span lang="sv">ett hus</span> |
| Sista siffran 1 efter tiotal är normalt <span lang="sv">-en</span> | <span lang="sv">tjugoen kronor</span>, <span lang="sv">trettioen fartyg</span> |
| Sista <span lang="sv">-ett</span> kvarstår i etablerade uttryck | <span lang="sv">tjugoett år</span>, <span lang="sv">nummer tjugoett</span>, <span lang="sv">tjugoett öre</span> |
| Alla andra tal böjs inte | <span lang="sv">två bilar</span>, <span lang="sv">två hus</span> |

## Ordningstal

| Intervall | Svenska |
| --- | --- |
| 1:a–10:e | <span lang="sv">första, andra, tredje, fjärde, femte, sjätte, sjunde, åttonde, nionde, tionde</span> |
| 11:e–12:e | <span lang="sv">elfte, tolfte</span> |
| 13:e–19:e | vanligen grundtal + <span lang="sv">-de</span>: <span lang="sv">trettonde, fjortonde, nittonde</span> |
| Hela tiotal | tiotalsform: <span lang="sv">tjugo → tjugonde</span>, <span lang="sv">trettio → trettionde</span> |
| Sammansatt | endast sista ledet: <span lang="sv">tjugoförsta, fyrtioandra</span> |
| Som siffror | <span lang="sv">1:a, 2:a</span> — men <span lang="sv">3:e, 4:e, 24:e</span> |

Ordningstal följer normalt <span lang="sv">den</span>:
<span lang="sv">den första maj</span>.

## Stora tal och decimaltal

| Värde | Svenska | Plural |
| --- | --- | --- |
| 10⁶ | <span lang="sv">en miljon</span> | <span lang="sv">miljoner</span> |
| 10⁹ | <span lang="sv">en miljard</span> | <span lang="sv">miljarder</span> |
| 10¹² | <span lang="sv">en biljon</span> | <span lang="sv">biljoner</span> |

Engelskans *billion* motsvarar <span lang="sv">en miljard</span>. Svenskan
räknar som tyskan. Decimaltecknet är ett kommatecken:
<span lang="sv">3,5</span> = <span lang="sv">tre komma fem</span>.

:::tip[Minnestips]
<span lang="sv">tjugoett</span>, inte <span lang="sv">ettochtjugo</span> —
tiotalet kommer först, precis som på engelska.
:::

## Undvik dessa misstag

- ❌ <span lang="sv">tjugo och ett</span> → ✅ <span lang="sv">tjugoett</span>
- ❌ <span lang="sv">tjugoett kronor</span> → ✅ <span lang="sv">tjugoen kronor</span>
- ❌ <span lang="sv">trettioett fartyg</span> → ✅ <span lang="sv">trettioen fartyg</span>
- ❌ <span lang="sv">fyrtiondeandra</span> → ✅ <span lang="sv">fyrtioandra</span>
- ❌ <span lang="sv">den 3:a maj</span> → ✅ <span lang="sv">den 3:e maj</span>
