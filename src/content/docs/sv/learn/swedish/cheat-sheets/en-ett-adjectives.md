## Tumregler för genus

| Ledtråd | Genus | Exempel |
| --- | --- | --- |
| Sammansatt substantiv | det **sista** ledet avgör | <span lang="sv">en cykel</span> + <span lang="sv">ett hjul</span> → <span lang="sv">ett cykelhjul</span> |
| <span lang="sv">-a, -are, -else, -het, -ning, -tion</span> | <span lang="sv">en</span> | <span lang="sv">en tidning</span>, <span lang="sv">en möjlighet</span> |
| <span lang="sv">-ande, -eri, -um, -ment, -tek, -gram</span> | <span lang="sv">ett</span> | <span lang="sv">ett meddelande</span>, <span lang="sv">ett museum</span> |
| Ingen ledtråd alls | gissa <span lang="sv">en</span> — majoriteten | |

Produktiva sammansättningar får normalt genus av det sista ledet. Ändelserna
är starka tendenser, inte fasta regler: se upp med
<span lang="sv">ett öga</span>, <span lang="sv">en studerande</span> och den
delade <span lang="sv">-skap</span>.

## Obestämda former

| Substantivform | Adjektivmönster | Exempel |
| --- | --- | --- |
| Singular <span lang="sv">en</span> | grundform | <span lang="sv">en stor bil</span> |
| Singular <span lang="sv">ett</span> | vanligen <span lang="sv">-t</span> | <span lang="sv">ett stort hus</span> |
| Plural | vanligen <span lang="sv">-a</span> | <span lang="sv">stora bilar</span> |

## Bestämda former

| Substantivform | Mönster | Exempel |
| --- | --- | --- |
| Singular <span lang="sv">en</span> | <span lang="sv">den</span> + <span lang="sv">-a</span>-adjektiv + bestämt substantiv | <span lang="sv">den stora bilen</span> |
| Singular <span lang="sv">ett</span> | <span lang="sv">det</span> + <span lang="sv">-a</span>-adjektiv + bestämt substantiv | <span lang="sv">det stora huset</span> |
| Plural | <span lang="sv">de</span> + <span lang="sv">-a</span>-adjektiv + bestämt substantiv | <span lang="sv">de stora bilarna</span> |

## Adjektivens stavning

| Stam | ett-form | plural/bestämd form |
| --- | --- | --- |
| betonad vokal: <span lang="sv">ny, blå</span> | <span lang="sv">nytt, blått</span> | <span lang="sv">nya, blåa</span> |
| vokal + <span lang="sv">d/t</span>: <span lang="sv">röd, vit</span> | <span lang="sv">rött, vitt</span> | <span lang="sv">röda, vita</span> |
| <span lang="sv">-en</span>: <span lang="sv">öppen, mogen</span> | <span lang="sv">öppet, moget</span> | <span lang="sv">öppna, mogna</span> |
| <span lang="sv">-er, -el</span>: <span lang="sv">vacker, enkel</span> | <span lang="sv">vackert, enkelt</span> | <span lang="sv">vackra, enkla</span> |

Oregelbundna: <span lang="sv">gammal → gammalt → gamla</span>,
<span lang="sv">liten → litet → små</span> (bestämd singular
<span lang="sv">lilla</span>).

Böjs aldrig: <span lang="sv">bra, kul, äkta, rosa, lila, beige</span> —
<span lang="sv">ett bra hus</span>.

:::tip[Minnestips]
<span lang="sv">en stor — ett stort — flera stora</span>
:::

## Undvik dessa misstag

- ❌ <span lang="sv">ett stor hus</span> → ✅ <span lang="sv">ett stort hus</span>
- ❌ <span lang="sv">den stor bilen</span> → ✅ <span lang="sv">den stora bilen</span>
- ❌ <span lang="sv">en cykelhjul</span> → ✅ <span lang="sv">ett cykelhjul</span>
- ❌ <span lang="sv">öppena fönster</span> → ✅ <span lang="sv">öppna fönster</span>
- Lär dig varje substantiv med sin artikel; genus går inte alltid att förutsäga med säkerhet.
- Det här är vanliga grundmönster, inte regler utan undantag.
