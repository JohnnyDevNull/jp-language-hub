## Tre uppgifter, två ord

| Uppgift | Ord | Exempel |
| --- | --- | --- |
| infinitivmärke — en ren verbform följer | att | Vi planerar att flytta. |
| bisatsinledare — en tanke eller ett påstående följer | att | Jag tycker att huset är dyrt. |
| relativpronomen — det beskriver substantivet framför sig | som | en kompis som bor i Malmö |

## Beslutet i en fråga

Vad gör bisatsen?

- Beskriver ordet framför sig → som
- Anger vad någon tycker, säger eller vet → att
- Ger en verbform utan nytt subjekt → att + infinitiv

Testfråga: går ordet att byta mot vilken, vilket eller vilka? Då är det som.

## Inuti bisatsen

| Bisats | bisatsinledare | subjekt | finit verb |
| --- | --- | --- | --- |
| Innehåll | att | han | kommer |
| Relativ, subjekt | som | — | bor |
| Relativ, objekt | som | jag | läste |

Som är själv subjektet i rad två, så det fältet står tomt. Att fyller
aldrig en roll, så ett subjekt följer alltid efter.

## Inget att efter ett modalt verb

| Ren infinitiv | Med att |
| --- | --- |
| Jag kan simma. | Jag lär mig att simma. |
| Vi ska åka. | Vi kommer att åka. |
| Du måste läsa. | Du glömde att läsa. |

## När det kan försvinna

| Ord | Kan det utelämnas? |
| --- | --- |
| att + bisats | Ofta i talspråk: Jag tror (att) han kommer. |
| att + infinitiv | Nej, förutom efter några få verb: Hon började (att) läsa. |
| som | Bara objekt, aldrig subjekt |

:::tip[Minnestips]
Något som min man vill göra. — det beskriver
något.
Jag tycker att det blir bra. — det är vad jag tycker.
:::

## Undvik dessa misstag

- ❌ en vän att bor här → ✅ en vän som bor här
- ❌ Jag kan att simma. → ✅ Jag kan simma.
- ❌ Han kom sent, som irriterade alla. → ✅ …, vilket irriterade alla.
- ❌ Boken som jag läste inte → ✅ Boken som jag inte läste
