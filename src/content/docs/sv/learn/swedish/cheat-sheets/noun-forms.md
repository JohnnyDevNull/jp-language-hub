Lär dig ett svenskt substantiv som en kedja av fyra former.

| Betydelse | Obestämd singular | Bestämd singular | Obestämd plural | Bestämd plural |
| --- | --- | --- | --- | --- |
| fordon med fyra hjul | <span lang="sv">en bil</span> | <span lang="sv">bilen</span> | <span lang="sv">bilar</span> | <span lang="sv">bilarna</span> |
| byggnad man bor i | <span lang="sv">ett hus</span> | <span lang="sv">huset</span> | <span lang="sv">hus</span> | <span lang="sv">husen</span> |
| rund frukt, ofta röd eller grön | <span lang="sv">ett äpple</span> | <span lang="sv">äpplet</span> | <span lang="sv">äpplen</span> | <span lang="sv">äpplena</span> |
| ungt kvinnligt barn | <span lang="sv">en flicka</span> | <span lang="sv">flickan</span> | <span lang="sv">flickor</span> | <span lang="sv">flickorna</span> |

## Grundmönster

- Obestämd singular använder <span lang="sv">en</span> eller
  <span lang="sv">ett</span>: <span lang="sv">en bil</span>,
  <span lang="sv">ett hus</span>.
- Bestämd artikel är vanligen en ändelse: <span lang="sv">bilen</span>,
  <span lang="sv">huset</span>.
- Pluraländelserna varierar. Lär dig pluralformen tillsammans med substantivet.
- Bestämd plural lägger en bestämd ändelse till pluralformen:
  <span lang="sv">bilarna</span>, <span lang="sv">husen</span>.

## Med ett bestämt adjektiv

Svenska använder vanligen både en egen artikel och den bestämda
substantivändelsen:

- <span lang="sv">den stora bilen</span>
- <span lang="sv">det stora huset</span>
- <span lang="sv">de stora bilarna</span>

Det här mönstret kallas ofta dubbel bestämdhet.

:::tip[Minnestips]
Notera substantiv som <span lang="sv">en bil — bilen — bilar — bilarna</span>, inte
som ett isolerat översättningspar.
:::
