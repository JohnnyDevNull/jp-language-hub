## Ordföljd

| Regel | Exempel |
| --- | --- |
| Partikeln står före objektet | <span lang="sv">Han slog på radion.</span> |
| Även före ett pronomenobjekt | <span lang="sv">Han slog på den.</span> |
| <span lang="sv">inte</span> står mellan verb och partikel | <span lang="sv">Jag tycker inte om henne.</span> |
| Partikeln följer efter supinum | <span lang="sv">Jag har tagit med boken.</span> |

Partikeln flyttar aldrig till satsens slut, som ett tyskt avskiljbart prefix
gör: <span lang="de">Ich rufe ihn an</span> →
<span lang="sv">Jag ringer upp honom.</span>

## Partikel eller preposition?

| Test | Partikel | Preposition |
| --- | --- | --- |
| Betoning | på partikeln: <span lang="sv">tycka **om**</span> | på verbet: <span lang="sv">**tit**ta på</span> |
| Med <span lang="sv">inte</span> | <span lang="sv">tycker inte om</span> | <span lang="sv">tittar inte på</span> |

## Vanliga partikelverb

| Svenska | Betydelse |
| --- | --- |
| <span lang="sv">tycka om</span> | gilla |
| <span lang="sv">komma ihåg</span> | minnas |
| <span lang="sv">komma på</span> | få en idé, inse |
| <span lang="sv">se ut</span> | verka, framstå som |
| <span lang="sv">känna igen</span> | identifiera |
| <span lang="sv">ta med</span> | föra med sig |
| <span lang="sv">ta på sig</span> / <span lang="sv">ta av sig</span> | klä på sig / klä av sig |
| <span lang="sv">ta reda på</span> | skaffa information om |
| <span lang="sv">slå på</span> / <span lang="sv">stänga av</span> | aktivera / inaktivera |
| <span lang="sv">tala om</span> | berätta |
| <span lang="sv">hålla på</span> | vara mitt uppe i något |
| <span lang="sv">passa på</span> | ta chansen |

## Särskrivet eller sammanskrivet

| Särskrivet | Prefigerat |
| --- | --- |
| <span lang="sv">gå av</span> — kliva av | <span lang="sv">avgå</span> — lämna sin post, ge sig av |
| <span lang="sv">gå ut</span> — lämna hemmet | <span lang="sv">utgå</span> — falla bort |

Som adjektiv eller substantiv skrivs delarna ihop:
<span lang="sv">radion är påslagen</span>,
<span lang="sv">tågets avgång</span>.

:::tip[Minnestips]
<span lang="sv">Jag tycker inte om det.</span> — <span lang="sv">inte</span>
först, sedan partikeln, sedan objektet.
:::

## Undvik dessa misstag

- ❌ <span lang="sv">Han slog den på.</span> → ✅ <span lang="sv">Han slog på den.</span>
- ❌ <span lang="sv">Jag tycker om inte henne.</span> → ✅ <span lang="sv">Jag tycker inte om henne.</span>
- Använd inte <span lang="sv">passa på</span> för att uttrycka att vara
  uppmärksam eller att akta sig; använd i stället ett lämpligt uttryck som
  <span lang="sv">var uppmärksam</span> eller <span lang="sv">akta dig</span>.
- Lär dig konstruktionen som följer efter <span lang="sv">hålla på</span>,
  eftersom den hjälper dig skilja dess vanliga betydelser åt.
