## Formkedja

| Infinitiv | Imperativ | Presens | Preteritum | Supinum | Perfekt |
| --- | --- | --- | --- | --- | --- |
| <span lang="sv">(att) tala</span> | <span lang="sv">tala!</span> | <span lang="sv">talar</span> | <span lang="sv">talade</span> | <span lang="sv">talat</span> | <span lang="sv">har talat</span> |
| <span lang="sv">(att) köpa</span> | <span lang="sv">köp!</span> | <span lang="sv">köper</span> | <span lang="sv">köpte</span> | <span lang="sv">köpt</span> | <span lang="sv">har köpt</span> |
| <span lang="sv">(att) bo</span> | <span lang="sv">bo!</span> | <span lang="sv">bor</span> | <span lang="sv">bodde</span> | <span lang="sv">bott</span> | <span lang="sv">har bott</span> |
| <span lang="sv">(att) skriva</span> | <span lang="sv">skriv!</span> | <span lang="sv">skriver</span> | <span lang="sv">skrev</span> | <span lang="sv">skrivit</span> | <span lang="sv">har skrivit</span> |

Formen är densamma för alla personer:

<span lang="sv">jag köper · du köper · hon köper · vi köper · de köper</span>

## Val av tidsform

| Betydelse | Mönster | Exempel |
| --- | --- | --- |
| Presens, vana, kontextuell framtid | presens | <span lang="sv">Jag köper en bok.</span> |
| Avslutad förfluten ram | preteritum | <span lang="sv">Jag köpte boken i går.</span> |
| Dåtid med koppling till nutid | <span lang="sv">har</span> + supinum | <span lang="sv">Jag har köpt boken.</span> |
| Tidigare än en annan förfluten händelse | <span lang="sv">hade</span> + supinum | <span lang="sv">Jag hade köpt boken.</span> |

## Grundmönster för verbgrupper

| Grupp | Presens | Preteritum | Supinum | Modell |
| --- | --- | --- | --- | --- |
| 1 | <span lang="sv">-ar</span> | <span lang="sv">-ade</span> | <span lang="sv">-at</span> | <span lang="sv">talar — talade — talat</span> |
| 2 | <span lang="sv">-er</span> | <span lang="sv">-de/-te</span> | <span lang="sv">-t</span> | <span lang="sv">köper — köpte — köpt</span> |
| 3 | <span lang="sv">-r</span> | <span lang="sv">-dde</span> | <span lang="sv">-tt</span> | <span lang="sv">bor — bodde — bott</span> |
| 4 / oregelbunden | varierar | varierar | varierar | <span lang="sv">skriver — skrev — skrivit</span> |

## Passiv

| Passiv | Mönster | Exempel |
| --- | --- | --- |
| s-passiv, presens | presensändelse → <span lang="sv">-s</span> | <span lang="sv">Rummet städas varje dag.</span> |
| s-passiv, preteritum | preteritum + <span lang="sv">-s</span> | <span lang="sv">Cykeln stals i går.</span> |
| s-passiv, supinum | supinum + <span lang="sv">-s</span> | <span lang="sv">Dörren har öppnats.</span> |
| bli-passiv | <span lang="sv">bli</span> + kongruerande particip | <span lang="sv">Huset blev sålt.</span> |

Rutin eller en allmän regel leder ofta till s-passiv.
<span lang="sv">bli</span> + particip lyfter fram en händelse eller
förändring, men s-passiv kan också beskriva en specifik händelse. Den
handlande parten läggs till med <span lang="sv">av</span>:
<span lang="sv">skrevs av Astrid Lindgren</span>.

<span lang="sv">finns, hoppas, trivs, minns, lyckas, andas</span> slutar på
<span lang="sv">-s</span> men är inga passivformer.

:::tip[Snabb minneshjälp]
Lär dig presens — preteritum — supinum som en talad kedja:
<span lang="sv">köper — köpte — köpt</span>.
:::

## Undvik dessa misstag

- Efter <span lang="sv">har</span> används supinum:
  ✅ <span lang="sv">har köpt</span>, inte ❌ <span lang="sv">har köpa</span>.
- Bilda inte oregelbundna preteritumformer med en regelbunden ändelse:
  ✅ <span lang="sv">skrev</span>, inte ❌ <span lang="sv">skrivade</span>.
