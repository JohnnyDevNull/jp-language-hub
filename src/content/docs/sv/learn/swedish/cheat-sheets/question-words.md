## Orden

| Svenska | Frågar om … | Svenska | Frågar om … |
| --- | --- | --- | --- |
| <span lang="sv">vem</span> | en person | <span lang="sv">var</span> | plats |
| <span lang="sv">vems</span> | en ägare | <span lang="sv">vart</span> | riktning |
| <span lang="sv">vad</span> | sak, händelse eller identitet | <span lang="sv">när</span> | tid |
| <span lang="sv">vilken/vilket/vilka</span> | ett val ur en mängd | <span lang="sv">hur</span> | sätt eller tillstånd |
| <span lang="sv">hur mycket / många</span> | mängd eller antal | <span lang="sv">varför</span> | orsak |

<span lang="sv">Vem</span> har ingen egen objektform. Av dessa kärnformer är
det <span lang="sv">vilken</span>-serien som böjs efter genus och numerus:
<span lang="sv">vilken bok</span>, <span lang="sv">vilket hus</span>,
<span lang="sv">vilka böcker</span>.

## var eller vart

Tabellen visar standardspråkets distinktion: <span lang="sv">var</span> för
plats och <span lang="sv">vart</span> för riktning. I vardagligt tal används
ibland <span lang="sv">var</span> även för riktning.

| Fråga | Betydelse |
| --- | --- |
| <span lang="sv">Var bor du?</span> | plats — <span lang="de">wo</span> |
| <span lang="sv">Vart går du?</span> | riktning — <span lang="de">wohin</span> |
| <span lang="sv">Var kommer du ifrån?</span> | ursprung — prepositionen sist |

## Ordföljd

| Typ | Mönster | Exempel |
| --- | --- | --- |
| Med frågeord | frågeord + verb | <span lang="sv">Var bor du?</span> |
| Ja/nej-fråga | verb först, inget <span lang="sv">do</span> | <span lang="sv">Bor du här?</span> |
| Indirekt | ingen inversion | <span lang="sv">Jag vet inte var hon bor.</span> |
| Indirekt ja/nej | <span lang="sv">om</span> | <span lang="sv">Jag vet inte om hon kommer.</span> |

## som markerar subjektet

Bara i indirekta frågor:

| Roll | Exempel |
| --- | --- |
| Frågeordet är subjekt | <span lang="sv">Jag vet inte vem **som** ringde.</span> |
| Frågeordet är objekt | <span lang="sv">Jag vet inte vem hon ringde.</span> |

Direkta frågor behöver inget <span lang="sv">som</span>:
<span lang="sv">Vem ringde?</span>, <span lang="sv">Vad hände?</span>

:::tip[Minnestips]
<span lang="sv">vem som ringde</span> — den som ringde.
<span lang="sv">vem hon ringde</span> — personen hon ringde. Det extra
<span lang="sv">som</span> markerar subjektet.
:::

## Undvik dessa misstag

- ❌ <span lang="sv">Jag vet inte var bor hon.</span> → ✅ <span lang="sv">…var hon bor.</span>
- ❌ <span lang="sv">Jag vet inte vem ringde.</span> → ✅ <span lang="sv">…vem som ringde.</span>
- ❌ <span lang="sv">Vart bor du?</span> → ✅ <span lang="sv">Var bor du?</span>
- ❌ <span lang="sv">Vilken hus är ditt?</span> → ✅ <span lang="sv">Vilket hus är ditt?</span>
