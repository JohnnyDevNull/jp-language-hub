## som täcker nästan allt

| Funktion | Exempel |
| --- | --- |
| Subjekt — måste stå kvar | <span lang="sv">Mannen som bor här heter Erik.</span> |
| Objekt — kan utelämnas | <span lang="sv">Boken (som) jag läste var bra.</span> |
| Står inte direkt efter en enkel preposition i vardagligt tal | <span lang="sv">huset som jag bor i</span> |

<span lang="sv">Som</span> är oböjligt: inget genus, inget numerus, inget
kasus, ingen genitiv.

## Var prepositionen står

| Svenska | Tyska |
| --- | --- |
| <span lang="sv">bussen som vi väntar på</span> | <span lang="de">der Bus, auf den wir warten</span> |
| <span lang="sv">personen som jag talade med</span> | <span lang="de">die Person, mit der ich gesprochen habe</span> |

I det vardagliga mönstret står prepositionen kvar i **slutet** av
relativsatsen. Formellt skriftspråk kan välja en tyngre konstruktion med
preposition + <span lang="sv">vilken</span>/<span lang="sv">vilket</span>.

## De andra relativorden

| Betydelse | Ord | Exempel |
| --- | --- | --- |
| Syftar på en hel sats | <span lang="sv">vilket</span> | <span lang="sv">Han kom sent, vilket irriterade alla.</span> |
| ägande | <span lang="sv">vars</span> | <span lang="sv">en författare vars böcker jag älskar</span> |
| plats | <span lang="sv">där</span> | <span lang="sv">staden där jag bor</span> |
| riktning | <span lang="sv">dit</span> | <span lang="sv">staden dit jag flyttade</span> |

<span lang="sv">Vars</span> och preposition + <span lang="sv">vilken</span>/
<span lang="sv">vilket</span> hör till skriftspråket. I tal bygger man i
stället om meningen.

## Ordföljd inne i relativsatsen

En relativsats är en bisats, så <span lang="sv">inte</span> står före verbet:
<span lang="sv">Mannen som **inte** bor här</span>.

:::tip[Minnestips]
<span lang="sv">Bussen som vi väntar på är sen.</span> — prepositionen sist.
<span lang="sv">Han kom sent, vilket irriterade alla.</span> —
<span lang="sv">vilket</span> för en hel sats.
:::

## Undvik dessa misstag

- ❌ <span lang="sv">huset i som jag bor</span> → ✅ <span lang="sv">huset som jag bor i</span>
- ❌ <span lang="sv">Mannen vilken bor här</span> → ✅ <span lang="sv">Mannen som bor här</span>
- ❌ <span lang="sv">Han kom sent, som irriterade alla.</span> → ✅ <span lang="sv">…, vilket irriterade alla.</span>
- ❌ <span lang="sv">Mannen som bor inte här</span> → ✅ <span lang="sv">Mannen som inte bor här</span>
