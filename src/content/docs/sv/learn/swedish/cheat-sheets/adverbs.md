## Bildning

Många sättsadverb använder adjektivets ett-form:

| Adjektiv | Adverb | Exempel |
| --- | --- | --- |
| <span lang="sv">snabb</span> | <span lang="sv">snabbt</span> | <span lang="sv">Han springer snabbt.</span> |
| <span lang="sv">tydlig</span> | <span lang="sv">tydligt</span> | <span lang="sv">Hon talar tydligt.</span> |
| <span lang="sv">vacker</span> | <span lang="sv">vackert</span> | <span lang="sv">Hon sjunger vackert.</span> |

## Oregelbundna adverb

| Adverb | Komparativ | Superlativ |
| --- | --- | --- |
| <span lang="sv">bra / väl</span> | <span lang="sv">bättre</span> | <span lang="sv">bäst</span> |
| <span lang="sv">gärna</span> | <span lang="sv">hellre</span> | <span lang="sv">helst</span> |
| <span lang="sv">illa</span> | <span lang="sv">värre</span> | <span lang="sv">värst</span> |

Regelbundna adverb kompareras som adjektiv:
<span lang="sv">snabbt → snabbare → snabbast</span>.

## Riktning eller position

| Riktning | Position |
| --- | --- |
| <span lang="sv">hem</span> — <span lang="sv">Jag går hem.</span> | <span lang="sv">hemma</span> — <span lang="sv">Jag är hemma.</span> |
| <span lang="sv">ut</span> | <span lang="sv">ute</span> |
| <span lang="sv">in</span> | <span lang="sv">inne</span> |
| <span lang="sv">upp</span> | <span lang="sv">uppe</span> |
| <span lang="sv">ner</span> | <span lang="sv">nere</span> |
| <span lang="sv">bort</span> | <span lang="sv">borta</span> |
| <span lang="sv">dit</span> | <span lang="sv">där</span> |

Samma uppdelning som frågeorden <span lang="sv">vart</span> och
<span lang="sv">var</span>.

## Satsadverb

Många satsadverb, till exempel <span lang="sv">alltid</span>,
<span lang="sv">aldrig</span> och <span lang="sv">ofta</span>, delar
placeringsmönstret med <span lang="sv">inte</span>:

| Sats | Exempel |
| --- | --- |
| Huvudsats | <span lang="sv">Hon kommer **alltid** sent.</span> |
| Bisats | <span lang="sv">…eftersom hon **alltid** kommer sent.</span> |

## Attitydord

<span lang="sv">ju</span> (som du redan vet), <span lang="sv">nog</span>
(förmodligen), <span lang="sv">väl</span> (eller hur?),
<span lang="sv">visst</span> — som tyskans
<span lang="de">ja</span>, <span lang="de">wohl</span>,
<span lang="de">doch</span>. Lär dig dem bäst av sammanhanget.

:::tip[Snabb minneshjälp]
<span lang="sv">ett snabbt tåg</span> → <span lang="sv">han springer snabbt</span>.
Sedan de två serier som inte går att härleda:
<span lang="sv">gärna — hellre — helst</span> och <span lang="sv">hem / hemma</span>.
:::

## Undvik dessa misstag

- ❌ <span lang="sv">Han springer snabb.</span> → ✅ <span lang="sv">…snabbt.</span>
- ❌ <span lang="sv">Jag är hem.</span> → ✅ <span lang="sv">Jag är hemma.</span>
- ❌ <span lang="sv">Jag går hemma.</span> → ✅ <span lang="sv">Jag går hem.</span>
- ❌ <span lang="sv">Jag vill mer gärna stanna.</span> → ✅ <span lang="sv">…hellre stanna.</span>
- ❌ <span lang="sv">…eftersom hon kommer alltid sent.</span> → ✅ <span lang="sv">…hon alltid kommer sent.</span>
