<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenska räkneord är praktiskt ordförråd för priser, datum, klockslag,
adresser och mängder. När de första tjugo sitter följer de flesta
vardagliga formerna ett förutsägbart mönster.

## Använd detta nu

| Om du vill... | Använd |
| --- | --- |
| räkna från 0 till 20 | lär dig grundlistan utantill |
| bilda 21, 42 eller 156 | tiotal före ental, inget <span lang="sv">och</span>: <span lang="sv">tjugoett</span>, <span lang="sv">fyrtiotvå</span>, <span lang="sv">hundrafemtiosex</span> |
| räkna ett substantiv för sig | välj <span lang="sv">en</span> eller <span lang="sv">ett</span> efter substantivets genus |
| bilda 21, 31, 41 framför ett substantiv | använd normalt sista <span lang="sv">-en</span>: <span lang="sv">trettioen fartyg</span> |
| använda etablerade uttryck med t-formen | använd <span lang="sv">-ett</span>: <span lang="sv">tjugoett år</span>, <span lang="sv">nummer tjugoett</span>, <span lang="sv">tjugoett öre</span> |
| skriva datum | använd ordningstalet efter <span lang="sv">den</span>: <span lang="sv">den tredje maj</span> |
| skriva decimaltal | använd kommatecken: <span lang="sv">3,5</span> |

## Grundtal

| Tal | Svenska | Tal | Svenska |
| --- | --- | --- | --- |
| 0 | <span lang="sv">noll</span> | 11 | <span lang="sv">elva</span> |
| 1 | <span lang="sv">en / ett</span> | 12 | <span lang="sv">tolv</span> |
| 2 | <span lang="sv">två</span> | 13 | <span lang="sv">tretton</span> |
| 3 | <span lang="sv">tre</span> | 14 | <span lang="sv">fjorton</span> |
| 4 | <span lang="sv">fyra</span> | 15 | <span lang="sv">femton</span> |
| 5 | <span lang="sv">fem</span> | 16 | <span lang="sv">sexton</span> |
| 6 | <span lang="sv">sex</span> | 17 | <span lang="sv">sjutton</span> |
| 7 | <span lang="sv">sju</span> | 18 | <span lang="sv">arton</span> |
| 8 | <span lang="sv">åtta</span> | 19 | <span lang="sv">nitton</span> |
| 9 | <span lang="sv">nio</span> | 20 | <span lang="sv">tjugo</span> |
| 10 | <span lang="sv">tio</span> | | |

Tiotalen bildas med <span lang="sv">-tio</span>:

| Tal | Svenska | Tal | Svenska |
| --- | --- | --- | --- |
| 30 | <span lang="sv">trettio</span> | 70 | <span lang="sv">sjuttio</span> |
| 40 | <span lang="sv">fyrtio</span> | 80 | <span lang="sv">åttio</span> |
| 50 | <span lang="sv">femtio</span> | 90 | <span lang="sv">nittio</span> |
| 60 | <span lang="sv">sextio</span> | 100 | <span lang="sv">hundra</span> |

Lägg märke till stavningen <span lang="sv">fyrtio</span> för 40, som inte följer
<span lang="sv">fyra</span>. Flera räkneord innehåller också sj- och tj-ljuden:
<span lang="sv">sju</span>, <span lang="sv">sjutton</span>,
<span lang="sv">sjuttio</span>, <span lang="sv">tjugo</span>. Se
[uttalsgrunder](../../pronunciation-basics/).

## Bilda större tal

Vardagliga sammansatta tal byggs upp från den största delen och nedåt.
Två- och tredelade sammansättningar skrivs normalt som ett ord:

- 21 — <span lang="sv">tjugoett</span>
- 42 — <span lang="sv">fyrtiotvå</span>
- 156 — <span lang="sv">hundrafemtiosex</span>
- 3 000 — <span lang="sv">tretusen</span>

<RuleBox title="Svenska vänder inte på siffrorna">
	Tyska säger <span lang="de">einundzwanzig</span>, med entalet
	först. Svenska säger, liksom engelskan, tiotalet först:
	<span lang="sv">tjugoett</span>. Det finns inget <span lang="sv">och</span> mellan delarna.
</RuleBox>

<span lang="sv">Hundra</span> och <span lang="sv">tusen</span> kan stå ensamma
eller ta <span lang="sv">ett</span> för betoning eller tydlighet:
<span lang="sv">hundra kronor</span> eller
<span lang="sv">etthundra kronor</span>.

## en eller ett för talet 1

Räknat för sig böjs talet 1 efter det räknade substantivets genus,
precis som den obestämda artikeln:

- <span lang="sv">en bil</span> — ett fordon
- <span lang="sv">ett hus</span> — en byggnad

Efter ett tiotal är sista siffran 1 dock normalt <span lang="sv">-en</span>, även
framför många ett-ord:

- <span lang="sv">tjugoen kronor</span> — 21 SEK
- <span lang="sv">trettioen fartyg</span> — 31 skepp, trots att <span lang="sv">ett fartyg</span> är
  ett ett-ord

Använd <span lang="sv">-ett</span> i etablerade uttryck med t-formen, särskilt
<span lang="sv">år</span>, <span lang="sv">nummer</span>, <span lang="sv">öre</span>, och vid klockslag:

- <span lang="sv">tjugoett år</span>
- <span lang="sv">nummer tjugoett</span>
- <span lang="sv">tjugoett öre</span>
- <span lang="sv">klockan tjugoett</span>

Alla andra tal böjs inte. Se
[en / ett](../../grammar/nouns-articles/en-ett/) för substantivgenus.

## Ordningstal

| Tal | Svenska | Tal | Svenska |
| --- | --- | --- | --- |
| 1:a | <span lang="sv">första</span> | 11:e | <span lang="sv">elfte</span> |
| 2:a | <span lang="sv">andra</span> | 12:e | <span lang="sv">tolfte</span> |
| 3:e | <span lang="sv">tredje</span> | 13:e | <span lang="sv">trettonde</span> |
| 4:e | <span lang="sv">fjärde</span> | 14:e | <span lang="sv">fjortonde</span> |
| 5:e | <span lang="sv">femte</span> | 15:e | <span lang="sv">femtonde</span> |
| 6:e | <span lang="sv">sjätte</span> | 16:e | <span lang="sv">sextonde</span> |
| 7:e | <span lang="sv">sjunde</span> | 17:e | <span lang="sv">sjuttonde</span> |
| 8:e | <span lang="sv">åttonde</span> | 18:e | <span lang="sv">artonde</span> |
| 9:e | <span lang="sv">nionde</span> | 19:e | <span lang="sv">nittonde</span> |
| 10:e | <span lang="sv">tionde</span> | 20:e | <span lang="sv">tjugonde</span> |

De första tolv är värda att lära sig utantill. Från 13 till 19 lägger
svenskan normalt till <span lang="sv">-de</span> på grundtalet:
<span lang="sv">trettonde</span>, <span lang="sv">fjortonde</span>,
<span lang="sv">nittonde</span>. Hela tiotal har egna former, som
<span lang="sv">tjugo → tjugonde</span> och
<span lang="sv">trettio → trettionde</span>.

I ett sammansatt ordningstal blir **bara sista ledet** ett ordningstal.
Är sista ledet 1 eller 2, används <span lang="sv">första</span> eller
<span lang="sv">andra</span>:

- 21:a — <span lang="sv">tjugoförsta</span>
- 42:a — <span lang="sv">fyrtioandra</span>
- 100:e — <span lang="sv">hundrade</span>

## Ordningstal i datum och skrift

Ordningstal följer normalt efter <span lang="sv">den</span>:

- <span lang="sv">Vi ses den första maj.</span> — vi träffas den 1 maj
- <span lang="sv">Det är hennes tredje bok.</span> — det är hennes bok nummer tre

Skrivet med siffror markerar svenskan ordningstalet med kolon plus
ändelse: <span lang="sv">1:a</span> och <span lang="sv">2:a</span> för
formerna på <span lang="sv">-a</span>, och <span lang="sv">3:e</span>,
<span lang="sv">4:e</span>, <span lang="sv">24:e</span> för de övriga.

## Miljoner, miljarder och decimaltal

<span lang="sv">Miljon</span> och <span lang="sv">miljard</span> är substantiv: de
tar artikel och plural.

| Värde | Svenska | Plural |
| --- | --- | --- |
| 10⁶ | <span lang="sv">en miljon</span> | <span lang="sv">två miljoner</span> |
| 10⁹ | <span lang="sv">en miljard</span> | <span lang="sv">två miljarder</span> |
| 10¹² | <span lang="sv">en biljon</span> | <span lang="sv">två biljoner</span> |

<MistakeBox title="En farlig falsk vän">
Svenska <span lang="sv">en biljon</span> är 10¹², inte en miljard. Engelskans
*billion* motsvarar <span lang="sv">en miljard</span>. Svenskan räknar som tyskan:
<span lang="de">Milliarde</span> → <span lang="sv">miljard</span>,
<span lang="de">Billion</span> → <span lang="sv">biljon</span>.
</MistakeBox>

Liksom tyskan använder svenskan **kommatecken** som decimaltecken och
mellanslag för att gruppera tusental: <span lang="sv">3,5</span> läses
<span lang="sv">tre komma fem</span>, och 10 000 skrivs med mellanslag.

<MistakeBox title="Vanliga misstag">
	- ❌ <span lang="sv">ettochtjugo</span> — tysk siffernordning
	  ✅ <span lang="sv">tjugoett</span>
	- ❌ <span lang="sv">tjugo och ett</span>
	  ✅ <span lang="sv">tjugoett</span>
	- ❌ <span lang="sv">tjugoett kronor</span>
	  ✅ <span lang="sv">tjugoen kronor</span>
	- ❌ <span lang="sv">trettioett fartyg</span>
	  ✅ <span lang="sv">trettioen fartyg</span>
	- ❌ <span lang="sv">den 3:a maj</span>
	  ✅ <span lang="sv">den 3:e maj</span>
	- Gör inte båda delarna av ett sammansatt ordningstal till
	  ordningstal:
	  <span lang="sv">❌ fyrtiondeandra</span>,
	  <span lang="sv">✅ fyrtioandra</span>.
</MistakeBox>

<MemoryTip>
Öva först på de tal du verkligen behöver: priser, husnummer, årtal och
ditt eget telefonnummer. Säg dem högt i svensk rytm —
<span lang="sv">tjugoett, tjugotvå, tjugotre</span> — så att ordningen
tiotal-före-ental blir automatisk i stället för översatt.
</MemoryTip>
