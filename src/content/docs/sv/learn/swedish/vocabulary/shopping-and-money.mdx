- Priser uttrycks med <span lang="sv">kostar</span>: <span lang="sv">Vad kostar den?</span>
- Peka med <span lang="sv">den här</span> eller <span lang="sv">det här</span> när du inte kan ordet.

  <span lang="sv">kontant</span>.

Använd den här sidan när du ska köpa en enda sak, fråga om priset eller
förstå de vanligaste orden i kassan.

## Grundord

| Område | Svenska | Förklaring |
| --- | --- | --- |
| plats | <span lang="sv">en affär, affärer</span> | ställe där man handlar |
| plats | <span lang="sv">en butik, butiker</span> | mindre försäljningsställe |
| sak | <span lang="sv">en vara, varor</span> | det man köper eller säljer |
| sak | <span lang="sv">ett kvitto, kvitton</span> | bevis på ett köp |
| pengar | <span lang="sv">ett pris, priser</span> | vad något kostar |
| pengar | <span lang="sv">en krona, kronor</span> | svensk valutaenhet |
| betalning | <span lang="sv">ett kort, kort</span> | plastbricka för att betala |
| betalning | <span lang="sv">kontanter</span> | sedlar och mynt |

## Butiksmönster

| Behov | Svenskt mönster |
| --- | --- |
| fråga om priset | <span lang="sv">Vad kostar den?</span> |
| fråga om en ett-sak | <span lang="sv">Vad kostar det här?</span> |
| säga att du tar den här | <span lang="sv">Jag tar den här.</span> |
| be om hjälp | <span lang="sv">Kan du hjälpa mig?</span> |
| betala med kort | <span lang="sv">Jag betalar med kort.</span> |
| be om ett kvitto | <span lang="sv">Kan jag få kvitto?</span> |

## Prisord

| Svenska | Förklaring |
| --- | --- |
| <span lang="sv">billig</span> | kostar lite |
| <span lang="sv">dyr</span> | kostar mycket |
| <span lang="sv">rea</span> | tillfälligt sänkt pris |
| <span lang="sv">rabatt</span> | sänkning av priset |
| <span lang="sv">öppet</span> | går att handla i just nu |
| <span lang="sv">stängt</span> | går inte att handla i just nu |

Vid priser säger man på svenska oftast talet plus <span lang="sv">kronor</span>:
<span lang="sv">Det kostar femtio kronor.</span>
