<KeyTakeaway>
- Priser uttrycks med <Sv>kostar</Sv>: <Sv>Vad kostar den?</Sv>
- Peka med <Sv>den här</Sv> eller <Sv>det här</Sv> när du inte kan ordet.
- Betalningsuttryck är korta: <Sv>med kort</Sv>, <Sv>med Swish</Sv>,
  <Sv>kontant</Sv>.

förstå de vanligaste orden i kassan.

## Grundord

| Område | Svenska | Förklaring |
| --- | --- | --- |
| plats | <Sv>en affär, affärer</Sv> | ställe där man handlar |
| plats | <Sv>en butik, butiker</Sv> | mindre försäljningsställe |
| sak | <Sv>en vara, varor</Sv> | det man köper eller säljer |
| sak | <Sv>ett kvitto, kvitton</Sv> | bevis på ett köp |
| pengar | <Sv>ett pris, priser</Sv> | vad något kostar |
| pengar | <Sv>en krona, kronor</Sv> | svensk valutaenhet |
| betalning | <Sv>ett kort, kort</Sv> | plastbricka för att betala |
| betalning | <Sv>kontanter</Sv> | sedlar och mynt |

## Butiksmönster

| Behov | Svenskt mönster |
| --- | --- |
| fråga om priset | <Sv>Vad kostar den?</Sv> |
| fråga om en ett-sak | <Sv>Vad kostar det här?</Sv> |
| säga att du tar den här | <Sv>Jag tar den här.</Sv> |
| be om hjälp | <Sv>Kan du hjälpa mig?</Sv> |
| betala med kort | <Sv>Jag betalar med kort.</Sv> |
| be om ett kvitto | <Sv>Kan jag få kvitto?</Sv> |

## Prisord

| Svenska | Förklaring |
| --- | --- |
| <Sv>billig</Sv> | kostar lite |
| <Sv>dyr</Sv> | kostar mycket |
| <Sv>rea</Sv> | tillfälligt sänkt pris |
| <Sv>rabatt</Sv> | sänkning av priset |
| <Sv>öppet</Sv> | går att handla i just nu |
| <Sv>stängt</Sv> | går inte att handla i just nu |

Vid priser säger man på svenska oftast talet plus <Sv>kronor</Sv>:
<Sv>Det kostar femtio kronor.</Sv>
