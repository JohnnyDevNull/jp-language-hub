<KeyTakeaway>
- Svenskan namnger vägen genom släkten: <span lang="sv">mormor</span> är mammas mamma,
  <span lang="sv">farmor</span> är pappas mamma.
- Läs en släktsammansättning från höger. Sista leden är personen, leden före är
  vägen dit.
- <span lang="sv">mamma</span> och <span lang="sv">pappa</span> är vardagsorden.
  <span lang="sv">mor</span> och <span lang="sv">far</span> låter formella utanför sammansättningar.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Svenskan saknar ett enda ord för det som tyskan och engelskan täcker med
<span lang="de">Oma</span>, <span lang="de">Tante</span> och <span lang="en">nephew</span>. Varje
sådant ord byggs av släktingarna däremellan, så ordet säger redan vilken sida av
släkten du menar.

## Använd direkt

| Du menar | Svenska |
| --- | --- |
| pappas mamma | <span lang="sv">min farmor</span> |
| mammas mamma | <span lang="sv">min mormor</span> |
| mammas syster | <span lang="sv">min moster</span> |
| pappas bror | <span lang="sv">min farbror</span> |
| systerns son | <span lang="sv">min systerson</span> |
| ditt barns barn | <span lang="sv">mitt barnbarn</span> |
| morbrors eller fasters barn | <span lang="sv">min kusin</span> |

## Huvudregel

> En släktsammansättning namnger vägen, inte relationen. Sista leden är
> personen; allt före den är kedjan dit, räknad utåt från dig själv.

<span lang="sv">mor</span> plus <span lang="sv">mor</span> ger <span lang="sv">mormor</span>,
<span lang="sv">far</span> plus <span lang="sv">bror</span> ger <span lang="sv">farbror</span>. Inget
skjuts in mellan leden. <span lang="sv">moster</span> och <span lang="sv">faster</span> följer samma
regel, bara nednötta: de började som <span lang="sv">morsyster</span> och
<span lang="sv">farsyster</span>.

## Föräldrar, barn och syskon

| Svenska | Plural | Förklaring |
| --- | --- | --- |
| <span lang="sv">en mamma, en mor</span> | <span lang="sv">mammor, mödrar</span> | kvinnlig förälder |
| <span lang="sv">en pappa, en far</span> | <span lang="sv">pappor, fäder</span> | manlig förälder |
| <span lang="sv">en förälder</span> | <span lang="sv">föräldrar</span> | den som har ett barn |
| <span lang="sv">ett barn</span> | <span lang="sv">barn</span> | någons dotter eller son |
| <span lang="sv">en dotter</span> | <span lang="sv">döttrar</span> | kvinnligt barn |
| <span lang="sv">en son</span> | <span lang="sv">söner</span> | manligt barn |
| <span lang="sv">ett syskon</span> | <span lang="sv">syskon</span> | någon med samma föräldrar |
| <span lang="sv">en syster</span> | <span lang="sv">systrar</span> | kvinnligt syskon |
| <span lang="sv">en bror</span> | <span lang="sv">bröder</span> | manligt syskon |

## Mor- och farföräldrar

| Svenska | Plural | Förklaring |
| --- | --- | --- |
| <span lang="sv">en mormor</span> | <span lang="sv">mormödrar</span> | mammas mamma |
| <span lang="sv">en morfar</span> | <span lang="sv">morfäder</span> | mammas pappa |
| <span lang="sv">en farmor</span> | <span lang="sv">farmödrar</span> | pappas mamma |
| <span lang="sv">en farfar</span> | <span lang="sv">farfäder</span> | pappas pappa |

Tillsammans heter de <span lang="sv">mor- och farföräldrar</span>, eller en sida i taget:
<span lang="sv">morföräldrar</span> och <span lang="sv">farföräldrar</span>. Ett släktled längre
bak sätts prefixet <span lang="sv">gammel-</span> framför: <span lang="sv">gammelmormor</span>,
<span lang="sv">gammelfarfar</span>.

## Mostrar, farbröder och kusiner

| Svenska | Plural | Förklaring |
| --- | --- | --- |
| <span lang="sv">en moster</span> | <span lang="sv">mostrar</span> | mammas syster |
| <span lang="sv">en faster</span> | <span lang="sv">fastrar</span> | pappas syster |
| <span lang="sv">en morbror</span> | <span lang="sv">morbröder</span> | mammas bror |
| <span lang="sv">en farbror</span> | <span lang="sv">farbröder</span> | pappas bror |
| <span lang="sv">en kusin</span> | <span lang="sv">kusiner</span> | barn till en förälders syskon |
| <span lang="sv">en syssling</span> | <span lang="sv">sysslingar</span> | barn till en förälders kusin |

Den som gift sig in i den rollen har inget eget ord. Namnge blodssläktingen
i stället: <span lang="sv">min mosters man</span>.

| Svenska | Plural | Förklaring |
| --- | --- | --- |
| <span lang="sv">ett syskonbarn</span> | <span lang="sv">syskonbarn</span> | barn till ditt syskon |
| <span lang="sv">en brorsdotter</span> | <span lang="sv">brorsdöttrar</span> | broderns dotter |
| <span lang="sv">en brorson</span> | <span lang="sv">brorsöner</span> | broderns son |
| <span lang="sv">en systerdotter</span> | <span lang="sv">systerdöttrar</span> | systerns dotter |
| <span lang="sv">en systerson</span> | <span lang="sv">systersöner</span> | systerns son |
| <span lang="sv">ett barnbarn</span> | <span lang="sv">barnbarn</span> | barn till ditt barn |
| <span lang="sv">ett barnbarnsbarn</span> | <span lang="sv">barnbarnsbarn</span> | ett släktled till nedåt |

Samma väglogik namnger ett enskilt barnbarn: <span lang="sv">sonson</span>,
<span lang="sv">sondotter</span>, <span lang="sv">dotterson</span>, <span lang="sv">dotterdotter</span>.

| Svenska | Plural | Förklaring |

| <span lang="sv">en flickvän</span> | <span lang="sv">flickvänner</span> | kvinnlig partner i ett förhållande |
| <span lang="sv">en svärmor</span> | <span lang="sv">svärmödrar</span> | partnerns mamma |
| <span lang="sv">en svärfar</span> | <span lang="sv">svärfäder</span> | partnerns pappa |

<span lang="sv">svär-</span> markerar de släktingar som tillkommer genom giftermål, så
båda tillsammans blir <span lang="sv">svärföräldrar</span>.

## Bonusfamilj

<span lang="sv">styv-</span> är det formella prefixet: <span lang="sv">styvmor</span>,
<span lang="sv">styvfar</span>, <span lang="sv">styvbarn</span>, <span lang="sv">styvsyskon</span>. I vardagen
föredrar svenskan <span lang="sv">bonus-</span>, som inte bär något kyligt:
<span lang="sv">bonusmamma</span>, <span lang="sv">bonuspappa</span>, <span lang="sv">bonusbarn</span>, och
hela hushållet heter <span lang="sv">en bonusfamilj</span>. Ett syskon med bara en
gemensam förälder är <span lang="sv">ett halvsyskon</span>.

## Direkt jämförelse

<LanguageComparison title="Ett ord på tyska, två på svenska">
	<p slot="de">Das ist meine Oma.</p>
	<p slot="en">This is my grandmother.</p>
	<p slot="sv">Det här är min farmor. / Det här är min mormor.</p>
</LanguageComparison>

<LanguageComparison title="Samma sak med tant och moster">
	<p slot="de">Meine Tante wohnt in Malmö.</p>
	<p slot="en">My aunt lives in Malmö.</p>
	<p slot="sv">Min moster bor i Malmö. / Min faster bor i Malmö.</p>
</LanguageComparison>

Valet går inte att undvika med ett neutralt ord, för något sådant finns inte.
Vet du inte vilken sida det gäller, fråga.

<MistakeBox incorrect="Det här är min mor." correct="Det här är min mamma." lang="sv">
	Tyskans <span lang="de">Mutter</span> är det neutrala ordet, så inlärare tar
	<span lang="sv">mor</span>. På svenska är det tvärtom:
	<span lang="sv">mamma</span> är neutralt både i tal och i skrift, medan
	<span lang="sv">mor</span> och <span lang="sv">far</span> låter formella eller ålderdomliga
	utanför sammansättningar och fasta uttryck.
</MistakeBox>

<SpecialRule language="Swedish" title="Där svenskan delar och slår ihop">
	Svenskan delar där tyskan och engelskan slår ihop, och slår ihop där de delar.
	<span lang="sv">mormor</span>, <span lang="sv">moster</span>, <span lang="sv">farbror</span>,
	<span lang="sv">systerdotter</span> och <span lang="sv">barnbarn</span> tvingar alla fram ett val
	av sida. Men <span lang="sv">kusin</span> täcker både <span lang="de">Cousin</span> och
	<span lang="de">Cousine</span>, och <span lang="sv">ett syskon</span> ger svenskan ett
	singularord som <span lang="de">Geschwister</span> saknar.
</SpecialRule>

<MemoryTip>
	Läs sammansättningen baklänges: <span lang="sv">farmor</span> är den
	<span lang="sv">mor</span> du når via din <span lang="sv">far</span>. Tricket fungerar nedåt
	också — <span lang="sv">dotterdotter</span> är din dotters dotter.
</MemoryTip>
