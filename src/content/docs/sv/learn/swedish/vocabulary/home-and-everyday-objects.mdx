<KeyTakeaway>
- Hemvokabulär är bra för att öva <span lang="sv">en</span>, <span lang="sv">ett</span> och pluralformer.
- Använd <span lang="sv">i</span> för rum och slutna platser: <span lang="sv">i köket</span>.
- Använd <span lang="sv">på</span> för många ytor och aktiviteter hemma: <span lang="sv">på bordet</span>,
  <span lang="sv">på jobbet</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Använd den här sidan för att namnge rum och vanliga föremål, och sätt sedan
ihop dem till korta meningar om var något finns.

## Rum

| Svenska | Förklaring |
| --- | --- |
| <span lang="sv">ett rum, rum</span> | utrymme i en bostad |
| <span lang="sv">ett kök, kök</span> | rum för matlagning |
| <span lang="sv">ett badrum, badrum</span> | rum med dusch |
| <span lang="sv">ett sovrum, sovrum</span> | rum där man sover |
| <span lang="sv">ett vardagsrum, vardagsrum</span> | rum där familjen samlas |
| <span lang="sv">en hall, hallar</span> | utrymme innanför ytterdörren |

## Vardagsföremål

| Svenska | Förklaring |
| --- | --- |
| <span lang="sv">ett bord, bord</span> | möbel man äter vid |
| <span lang="sv">en stol, stolar</span> | möbel att sitta på |
| <span lang="sv">en säng, sängar</span> | möbel att sova i |
| <span lang="sv">en dörr, dörrar</span> | öppning man går igenom |
| <span lang="sv">ett fönster, fönster</span> | öppning i väggen med glas |
| <span lang="sv">en lampa, lampor</span> | ger ljus i ett rum |
| <span lang="sv">en nyckel, nycklar</span> | öppnar en dörr |
| <span lang="sv">en väska, väskor</span> | för att bära saker |

## Platsuttryck

| Behov | Svenskt mönster |
| --- | --- |
| säga var något finns | <span lang="sv">Väskan ligger i hallen.</span> |
| säga att något ligger på en yta | <span lang="sv">Nyckeln ligger på bordet.</span> |
| fråga var något finns | <span lang="sv">Var är nyckeln?</span> |
| säga att det finns något i ett rum | <span lang="sv">Det finns ett bord i köket.</span> |
| säga att du är hemma | <span lang="sv">Jag är hemma.</span> |

Den bestämda formen dyker ofta upp naturligt när föremålet är känt:
<span lang="sv">nyckeln</span>, <span lang="sv">väskan</span>, <span lang="sv">bordet</span>.
