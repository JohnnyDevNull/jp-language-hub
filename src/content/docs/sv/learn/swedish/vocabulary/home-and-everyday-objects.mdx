<KeyTakeaway>
- Hemvokabulär är bra för att öva <Sv>en</Sv>, <Sv>ett</Sv> och pluralformer.
- Använd <Sv>i</Sv> för rum och slutna platser: <Sv>i köket</Sv>.
- Använd <Sv>på</Sv> för många ytor och aktiviteter hemma: <Sv>på bordet</Sv>,
  <Sv>på jobbet</Sv>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Använd den här sidan för att namnge rum och vanliga föremål, och sätt sedan
ihop dem till korta meningar om var något finns.

## Rum

| Svenska | Förklaring |
| --- | --- |
| <Sv>ett rum, rum</Sv> | utrymme i en bostad |
| <Sv>ett kök, kök</Sv> | rum för matlagning |
| <Sv>ett badrum, badrum</Sv> | rum med dusch |
| <Sv>ett sovrum, sovrum</Sv> | rum där man sover |
| <Sv>ett vardagsrum, vardagsrum</Sv> | rum där familjen samlas |
| <Sv>en hall, hallar</Sv> | utrymme innanför ytterdörren |

## Vardagsföremål

| Svenska | Förklaring |
| --- | --- |
| <Sv>ett bord, bord</Sv> | möbel man äter vid |
| <Sv>en stol, stolar</Sv> | möbel att sitta på |
| <Sv>en säng, sängar</Sv> | möbel att sova i |
| <Sv>en dörr, dörrar</Sv> | öppning man går igenom |
| <Sv>ett fönster, fönster</Sv> | öppning i väggen med glas |
| <Sv>en lampa, lampor</Sv> | ger ljus i ett rum |
| <Sv>en nyckel, nycklar</Sv> | öppnar en dörr |
| <Sv>en väska, väskor</Sv> | för att bära saker |

## Platsuttryck

| Behov | Svenskt mönster |
| --- | --- |
| säga var något finns | <Sv>Väskan ligger i hallen.</Sv> |
| säga att något ligger på en yta | <Sv>Nyckeln ligger på bordet.</Sv> |
| fråga var något finns | <Sv>Var är nyckeln?</Sv> |
| säga att det finns något i ett rum | <Sv>Det finns ett bord i köket.</Sv> |
| säga att du är hemma | <Sv>Jag är hemma.</Sv> |

Den bestämda formen dyker ofta upp naturligt när föremålet är känt:
<Sv>nyckeln</Sv>, <Sv>väskan</Sv>, <Sv>bordet</Sv>.
