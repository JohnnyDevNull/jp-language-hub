export const requireEntry = async (id) => {
	const entry = await getEntry('vocabulary', id);
	if (!entry) {
		throw new Error(`Missing required vocabulary entry: ${id}`);
	}
	return entry.data;
};

export const car = await requireEntry('sv-bil');
export const apple = await requireEntry('sv-apple');

export const starterIds = [
	'sv-dag',
	'sv-tid',
	'sv-klocka',
	'sv-van',
	'sv-stad',
	'sv-hund',
	'sv-hus',
	'sv-barn',
	'sv-bord',
];

export const allNouns = await getCollection('vocabulary');
export const starters = starterIds.map((id) => {
	const entry = allNouns.find((candidate) => candidate.id === id);
	if (!entry) {
		throw new Error(`Missing required vocabulary entry: ${id}`);
	}
	return entry.data;
});

<KeyTakeaway>
- Anteckna alltid ett svenskt substantiv med dess artikel, aldrig bara som ett
  ordpar: <Sv>en bil</Sv>, inte bara <Sv>bil</Sv> tillsammans med en enda
  översättning.
- Artikeln ensam räcker inte. Lär dig de fyra formerna tillsammans — obestämd
  och bestämd singular, obestämd och bestämd plural.
- Lemmats form ger ofta en ledtråd till pluralen, men det räcker inte. Att
  lära sig pluralen en gång per ord är billigare än att gissa den varje gång
  du talar.
</KeyTakeaway>

Det mesta av arbetet med svenskt ordförråd handlar inte om ett ords betydelse,
utan om dess genus och dess plural. Båda är oförutsägbara utifrån tyskan,
därför hör de hemma i anteckningen från början. Ämnessidor grupperar ord efter
situation, så att du kan lära dig substantiven och frasmönstren du behöver
tillsammans.

## Grundregel

> Ett användbart substantivuppslag innehåller fem saker: lemmat, genuset
> (<Sv>en</Sv> eller <Sv>ett</Sv>), den bestämda singularen, den obestämda
> pluralen och den bestämda pluralen.

<Sv>Ett hus</Sv> är neutrum på svenska och neutrum på tyska, men
<Sv>ett bord</Sv> är ett <Sv>ett</Sv>-ord medan tyskans
<span lang="de">der Tisch</span> är maskulinum. Att bara kopiera det tyska
genuset slår fel tillräckligt ofta för att det inte ska duga som strategi.

De två korten visar systemets två halvor: ett <Sv>en</Sv>-ord som tar
<Sv>-ar</Sv> i pluralis, och ett <Sv>ett</Sv>-ord som tar <Sv>-n</Sv>.

## Grundläggande ord

En liten samling vardagliga substantiv, med formerna snarare än bara
översättningen. Vart och ett kommer från samma uppslag som korten ovan.

				<td lang="de">{noun.translations?.de}</td>
				<td lang="en">{noun.translations?.en}</td>
				<td lang="sv">{noun.morphology.definiteSingular}</td>
				<td lang="sv">{noun.morphology.indefinitePlural}</td>
				<td lang="sv">{noun.morphology.definitePlural}</td>
			</tr>
		))}
	</tbody>
</table>

Läser man pluralkolumnen nedåt börjar användbara mönster synas: <Sv>-ar</Sv>
och <Sv>-or</Sv> och <Sv>-er</Sv> för <Sv>en</Sv>-ord, och ingen ändelse alls
för många enstaviga <Sv>ett</Sv>-ord som <Sv>hus</Sv>, <Sv>barn</Sv> och
<Sv>bord</Sv>.

## Områden

Ordförrådet är organiserat efter den situation ett ord används i, inte efter
bokstaven det börjar på. Varje områdessida hålls tillräckligt liten för att
fungera som en arbetslista snarare än en ordbok.
