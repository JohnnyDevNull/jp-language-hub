<KeyTakeaway>
- Lär dig matsubstantiv med artikel och plural: <Sv>en bulle, bullar</Sv>.
- Använd <Sv>jag skulle vilja ha</Sv> som den artiga standardfrasen vid
  beställning.
- Små modifierare gör stor skillnad: <Sv>med</Sv>, <Sv>utan</Sv>,
  <Sv>lite</Sv>, <Sv>en till</Sv>.
</KeyTakeaway>

Den här sidan ger dig tillräckligt med matordförråd för att beställa något
enkelt, läsa en grundläggande meny och anpassa vad du beställer.

## Grundord

| Användning | Svenska | Förklaring |
| --- | --- | --- |
| dryck | <Sv>en kaffe, kaffe</Sv> | dryck bryggd på rostade bönor |
| dryck | <Sv>ett te, teer</Sv> | vatten draget på torkade blad |
| dryck | <Sv>ett vatten, vatten</Sv> | den vanligaste och enklaste drycken |
| dryck | <Sv>en mjölk</Sv> | vit dryck från kor |
| mat | <Sv>en bulle, bullar</Sv> | runt bakverk med kanel |
| mat | <Sv>en smörgås, smörgåsar</Sv> | skiva bröd med pålägg |
| mat | <Sv>en sallad, sallader</Sv> | maträtt av rå grönsaker |
| mat | <Sv>en soppa, soppor</Sv> | varm maträtt i skål |
| sött | <Sv>en kaka, kakor</Sv> | bakverk till kaffet |
| sött | <Sv>en glass, glassar</Sv> | fryst, söt dessert |

Massubstantiv som <Sv>kaffe</Sv>, <Sv>te</Sv> och <Sv>vatten</Sv> klarar sig
ofta utan plural vid vardaglig beställning. Använd artikeln när du menar en
portion: <Sv>en kaffe</Sv>, <Sv>ett vatten</Sv>.

## Beställningsmönster

| Behov | Svenskt mönster |
| --- | --- |
| beställa artigt | <Sv>Jag skulle vilja ha en kaffe.</Sv> |
| fråga direkt | <Sv>Kan jag få en smörgås?</Sv> |
| lägga till något | <Sv>med mjölk</Sv>, <Sv>med ost</Sv> |
| ta bort något | <Sv>utan socker</Sv>, <Sv>utan lök</Sv> |
| be om en till | <Sv>en till, tack</Sv> |
| fråga vad som finns | <Sv>Finns det något vegetariskt?</Sv> |
