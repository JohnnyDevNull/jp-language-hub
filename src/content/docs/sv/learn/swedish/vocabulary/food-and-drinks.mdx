<KeyTakeaway>
- Lär dig matsubstantiv med artikel och plural: <span lang="sv">en bulle, bullar</span>.
- Använd <span lang="sv">jag skulle vilja ha</span> som den artiga standardfrasen vid
  beställning.
- Små modifierare gör stor skillnad: <span lang="sv">med</span>, <span lang="sv">utan</span>,
  <span lang="sv">lite</span>, <span lang="sv">en till</span>.
</KeyTakeaway>

Den här sidan ger dig tillräckligt med matordförråd för att beställa något
enkelt, läsa en grundläggande meny och anpassa vad du beställer.

## Grundord

| Användning | Svenska | Förklaring |
| --- | --- | --- |
| dryck | <span lang="sv">en kaffe, kaffe</span> | dryck bryggd på rostade bönor |
| dryck | <span lang="sv">ett te, teer</span> | vatten draget på torkade blad |
| dryck | <span lang="sv">ett vatten, vatten</span> | den vanligaste och enklaste drycken |
| dryck | <span lang="sv">en mjölk</span> | vit dryck från kor |
| mat | <span lang="sv">en bulle, bullar</span> | runt bakverk med kanel |
| mat | <span lang="sv">en smörgås, smörgåsar</span> | skiva bröd med pålägg |
| mat | <span lang="sv">en sallad, sallader</span> | maträtt av rå grönsaker |
| mat | <span lang="sv">en soppa, soppor</span> | varm maträtt i skål |
| sött | <span lang="sv">en kaka, kakor</span> | bakverk till kaffet |
| sött | <span lang="sv">en glass, glassar</span> | fryst, söt dessert |

Massubstantiv som <span lang="sv">kaffe</span>, <span lang="sv">te</span> och <span lang="sv">vatten</span> klarar sig
ofta utan plural vid vardaglig beställning. Använd artikeln när du menar en
portion: <span lang="sv">en kaffe</span>, <span lang="sv">ett vatten</span>.

## Beställningsmönster

| Behov | Svenskt mönster |
| --- | --- |
| beställa artigt | <span lang="sv">Jag skulle vilja ha en kaffe.</span> |
| fråga direkt | <span lang="sv">Kan jag få en smörgås?</span> |
| lägga till något | <span lang="sv">med mjölk</span>, <span lang="sv">med ost</span> |
| ta bort något | <span lang="sv">utan socker</span>, <span lang="sv">utan lök</span> |
| be om en till | <span lang="sv">en till, tack</span> |
| fråga vad som finns | <span lang="sv">Finns det något vegetariskt?</span> |

## Kort dialog

<p lang="sv">A: Hej! Vad vill du ha?</p>
<p lang="sv">B: Jag skulle vilja ha en kaffe och en bulle.</p>
<p lang="sv">A: Vill du ha mjölk?</p>
<p lang="sv">B: Ja tack, lite mjölk.</p>
