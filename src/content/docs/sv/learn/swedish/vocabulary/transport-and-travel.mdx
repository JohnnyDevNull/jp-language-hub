- Använd <Sv>till</Sv> för resmålet och <Sv>mot</Sv> för rutten eller skylten.

  <Sv>på tåget</Sv>.

Den här sidan ger dig orden för att hitta en rutt, köpa eller nämna en
biljett och fråga när något avgår.

## Transportord

| Område | Svenska | Förklaring |
| --- | --- | --- |
| fordon | <Sv>en buss, bussar</Sv> | fordon som kör en linje på gator |
| fordon | <Sv>ett tåg, tåg</Sv> | fordon som går på räls |
| system | <Sv>tunnelbanan</Sv> | spårtrafik under marken |
| fordon | <Sv>en spårvagn, spårvagnar</Sv> | spårfordon som kör på gator |
| plats | <Sv>en hållplats, hållplatser</Sv> | ställe där bussen stannar |
| plats | <Sv>en station, stationer</Sv> | större hållplats, ofta för tåg |
| biljett | <Sv>en biljett, biljetter</Sv> | bevis på att man betalat för resan |
| tid | <Sv>en avgång, avgångar</Sv> | tidpunkt då ett fordon lämnar |

## Resmönster

| Behov | Svenskt mönster |
| --- | --- |
| fråga vart en buss går | <Sv>Går den här bussen till centrum?</Sv> |
| fråga när den avgår | <Sv>När går tåget?</Sv> |
| säga sitt resmål | <Sv>Jag ska till Malmö.</Sv> |
| fråga efter hållplatsen | <Sv>Var är hållplatsen?</Sv> |
| läsa skylten | <Sv>bussen mot centrum</Sv> |
| köpa en biljett | <Sv>En biljett till Lund, tack.</Sv> |

## Riktningsord

| Svenska | Förklaring |
| --- | --- |
| <Sv>till</Sv> | mot ett mål |
| <Sv>från</Sv> | ursprunget för en resa |
| <Sv>mot</Sv> | riktningen på en skylt eller linje |
| <Sv>nästa</Sv> | den som kommer efter denna |
| <Sv>sista</Sv> | den allra sista i en rad |
| <Sv>här</Sv> | på den här platsen |
| <Sv>där</Sv> | på den platsen, inte här |
