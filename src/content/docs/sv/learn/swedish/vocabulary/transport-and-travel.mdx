- Använd <span lang="sv">till</span> för resmålet och <span lang="sv">mot</span> för rutten eller skylten.
- Kollektivtrafik använder ofta <span lang="sv">på</span>: <span lang="sv">på bussen</span>,
  <span lang="sv">på tåget</span>.
- Lär dig biljettord tillsammans med resetypen: <span lang="sv">en enkelbiljett</span>,
  <span lang="sv">en tur och retur</span>.
</KeyTakeaway>

Den här sidan ger dig orden för att hitta en rutt, köpa eller nämna en
biljett och fråga när något avgår.

## Transportord

| Område | Svenska | Förklaring |
| --- | --- | --- |
| fordon | <span lang="sv">en buss, bussar</span> | fordon som kör en linje på gator |
| fordon | <span lang="sv">ett tåg, tåg</span> | fordon som går på räls |
| system | <span lang="sv">tunnelbanan</span> | spårtrafik under marken |
| fordon | <span lang="sv">en spårvagn, spårvagnar</span> | spårfordon som kör på gator |
| plats | <span lang="sv">en hållplats, hållplatser</span> | ställe där bussen stannar |
| plats | <span lang="sv">en station, stationer</span> | större hållplats, ofta för tåg |
| biljett | <span lang="sv">en biljett, biljetter</span> | bevis på att man betalat för resan |
| tid | <span lang="sv">en avgång, avgångar</span> | tidpunkt då ett fordon lämnar |

## Resmönster

| Behov | Svenskt mönster |
| --- | --- |
| fråga vart en buss går | <span lang="sv">Går den här bussen till centrum?</span> |
| fråga när den avgår | <span lang="sv">När går tåget?</span> |
| säga sitt resmål | <span lang="sv">Jag ska till Malmö.</span> |
| fråga efter hållplatsen | <span lang="sv">Var är hållplatsen?</span> |
| läsa skylten | <span lang="sv">bussen mot centrum</span> |
| köpa en biljett | <span lang="sv">En biljett till Lund, tack.</span> |

## Riktningsord

| Svenska | Förklaring |
| --- | --- |
| <span lang="sv">till</span> | mot ett mål |
| <span lang="sv">från</span> | ursprunget för en resa |
| <span lang="sv">mot</span> | riktningen på en skylt eller linje |
| <span lang="sv">nästa</span> | den som kommer efter denna |
| <span lang="sv">sista</span> | den allra sista i en rad |
| <span lang="sv">här</span> | på den här platsen |
| <span lang="sv">där</span> | på den platsen, inte här |

## Kort rutt

<p lang="sv">A: Ursäkta, går den här bussen till stationen?</p>
<p lang="sv">B: Nej, ta buss 5 mot centrum.</p>
<p lang="sv">A: Tack! Var är hållplatsen?</p>
<p lang="sv">B: Där borta, vid apoteket.</p>
