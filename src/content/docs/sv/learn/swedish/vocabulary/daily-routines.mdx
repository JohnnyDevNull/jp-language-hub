<KeyTakeaway>
- Presens böjs inte efter person: <Sv>jag jobbar</Sv>, <Sv>vi jobbar</Sv>.
- Tidsinledda rutinmeningar följer V2-mönstret:
  <Sv>På morgonen dricker jag kaffe.</Sv>
- Lär dig rutiner som hela fraser: <Sv>gå upp</Sv>,
  <Sv>gå och lägga sig</Sv>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Använd den här sidan för att prata om vad som brukar hända under en dag.
Orden är enkla, men de övar presens och vanliga tidsuttryck. För ordföljden
bakom tidsinledda meningar, se [V2-regeln](../../grammar/sentence-structure/v2/).

## Rutinverb

| Svenska | Förklaring |
| --- | --- |
| <Sv>gå upp</Sv> | vakna och stiga ur sängen |
| <Sv>äta frukost</Sv> | inta sin första måltid för dagen |
| <Sv>dricka kaffe</Sv> | avnjuta en kopp koffeinhaltig dryck |
| <Sv>gå till jobbet</Sv> | bege sig till sin arbetsplats |
| <Sv>jobba</Sv> | utföra sitt dagliga arbete |
| <Sv>plugga</Sv> | ägna tid åt att studera |
| <Sv>laga mat</Sv> | tillaga en måltid |
| <Sv>titta på tv</Sv> | se på ett tv-program |
| <Sv>läsa</Sv> | ta del av en text |
| <Sv>gå och lägga sig</Sv> | bege sig till sängs för natten |

## Tidsuttryck

| Svenska | Förklaring |
| --- | --- |
| <Sv>på morgonen</Sv> | tiden strax efter att man vaknat |
| <Sv>på förmiddagen</Sv> | tiden mellan morgonen och lunch |
| <Sv>på eftermiddagen</Sv> | tiden mellan lunch och kvällen |
| <Sv>på kvällen</Sv> | den senare delen av dagen, före natten |
| <Sv>på natten</Sv> | den mörka delen av dygnet, när de flesta sover |
| <Sv>varje dag</Sv> | dagligen, utan undantag |
| <Sv>ofta</Sv> | vid upprepade tillfällen |
| <Sv>ibland</Sv> | då och då |

## Vardagsmönster

| Behov | Svenskt mönster |
| --- | --- |
| säga vad du gör | <Sv>Jag dricker kaffe på morgonen.</Sv> |
| sätta tiden först | <Sv>På morgonen dricker jag kaffe.</Sv> |
| säga när du börjar | <Sv>Jag börjar klockan åtta.</Sv> |
| säga hur ofta | <Sv>Jag tränar ofta.</Sv> |
| fråga om en vana | <Sv>Vad gör du på kvällen?</Sv> |

## Kort rutin

<p lang="sv">På morgonen går jag upp klockan sju.</p>
<p lang="sv">Jag äter frukost och dricker kaffe.</p>
<p lang="sv">Sedan går jag till jobbet.</p>
<p lang="sv">På kvällen lagar jag mat och läser.</p>
