<KeyTakeaway>
- Presens böjs inte efter person: <span lang="sv">jag jobbar</span>, <span lang="sv">vi jobbar</span>.
- Tidsinledda rutinmeningar följer V2-mönstret:
  <span lang="sv">På morgonen dricker jag kaffe.</span>
- Lär dig rutiner som hela fraser: <span lang="sv">gå upp</span>,
  <span lang="sv">gå och lägga sig</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Använd den här sidan för att prata om vad som brukar hända under en dag.
Orden är enkla, men de övar presens och vanliga tidsuttryck. För ordföljden
bakom tidsinledda meningar, se [V2-regeln](../../grammar/sentence-structure/v2/).

## Rutinverb

| Svenska | Förklaring |
| --- | --- |
| <span lang="sv">gå upp</span> | vakna och stiga ur sängen |
| <span lang="sv">äta frukost</span> | inta sin första måltid för dagen |
| <span lang="sv">dricka kaffe</span> | avnjuta en kopp koffeinhaltig dryck |
| <span lang="sv">gå till jobbet</span> | bege sig till sin arbetsplats |
| <span lang="sv">jobba</span> | utföra sitt dagliga arbete |
| <span lang="sv">plugga</span> | ägna tid åt att studera |
| <span lang="sv">laga mat</span> | tillaga en måltid |
| <span lang="sv">titta på tv</span> | se på ett tv-program |
| <span lang="sv">läsa</span> | ta del av en text |
| <span lang="sv">gå och lägga sig</span> | bege sig till sängs för natten |

## Tidsuttryck

| Svenska | Förklaring |
| --- | --- |
| <span lang="sv">på morgonen</span> | tiden strax efter att man vaknat |
| <span lang="sv">på förmiddagen</span> | tiden mellan morgonen och lunch |
| <span lang="sv">på eftermiddagen</span> | tiden mellan lunch och kvällen |
| <span lang="sv">på kvällen</span> | den senare delen av dagen, före natten |
| <span lang="sv">på natten</span> | den mörka delen av dygnet, när de flesta sover |
| <span lang="sv">varje dag</span> | dagligen, utan undantag |
| <span lang="sv">ofta</span> | vid upprepade tillfällen |
| <span lang="sv">ibland</span> | då och då |

## Vardagsmönster

| Behov | Svenskt mönster |
| --- | --- |
| säga vad du gör | <span lang="sv">Jag dricker kaffe på morgonen.</span> |
| sätta tiden först | <span lang="sv">På morgonen dricker jag kaffe.</span> |
| säga när du börjar | <span lang="sv">Jag börjar klockan åtta.</span> |
| säga hur ofta | <span lang="sv">Jag tränar ofta.</span> |
| fråga om en vana | <span lang="sv">Vad gör du på kvällen?</span> |

## Kort rutin

<p lang="sv">På morgonen går jag upp klockan sju.</p>
<p lang="sv">Jag äter frukost och dricker kaffe.</p>
<p lang="sv">Sedan går jag till jobbet.</p>
<p lang="sv">På kvällen lagar jag mat och läser.</p>
