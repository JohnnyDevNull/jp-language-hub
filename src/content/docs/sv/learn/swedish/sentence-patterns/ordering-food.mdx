<KeyTakeaway>
- Använd <span lang="sv">Jag skulle vilja ha ...</span> som den säkra, artiga
  beställningsramen.
- Använd <span lang="sv">Kan jag få ...?</span> när du frågar efter en sak, en meny, vatten
  eller notan.
- Justera beställningen med <span lang="sv">med</span>, <span lang="sv">utan</span>, <span lang="sv">extra</span> och
  <span lang="sv">vid sidan av</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Den här sidan ger dig ett användbart restaurang- eller kaféskript: fråga vad
som finns, beställa, justera, svara på en fråga och betala.

## Beställa

| Mönster | Använd det för | Exempel |
| --- | --- | --- |
| <span lang="sv">Jag skulle vilja ha ...</span> | artig standardbeställning | <span lang="sv">Jag skulle vilja ha en kaffe.</span> |
| <span lang="sv">Kan jag få ...?</span> | fråga efter en sak | <span lang="sv">Kan jag få menyn?</span> |
| <span lang="sv">Jag tar ...</span> | snabbt val | <span lang="sv">Jag tar dagens lunch.</span> |
| <span lang="sv">Har ni ...?</span> | kontrollera vad som finns | <span lang="sv">Har ni något vegetariskt?</span> |
| <span lang="sv">Vad rekommenderar du?</span> | be om ett råd | <span lang="sv">Vad rekommenderar du?</span> |
| <span lang="sv">Vad ingår?</span> | vad beställningen innehåller | <span lang="sv">Vad ingår i dagens lunch?</span> |

## Justera beställningen

| Mönster | Använd det för | Exempel |
| --- | --- | --- |
| <span lang="sv">med ...</span> | med något | <span lang="sv">med mjölk</span> |
| <span lang="sv">utan ...</span> | utan något | <span lang="sv">utan lök</span> |
| <span lang="sv">extra ...</span> | extra | <span lang="sv">extra sås</span> |
| <span lang="sv">vid sidan av</span> | separat | <span lang="sv">Kan jag få såsen vid sidan av?</span> |
| <span lang="sv">att dricka</span> | avsett att drickas på plats | <span lang="sv">En kaffe att dricka här.</span> |
| <span lang="sv">att ta med</span> | avsett att tas med | <span lang="sv">En kaffe att ta med, tack.</span> |

## Betala och avsluta

| Mönster | Använd det för | Exempel |
| --- | --- | --- |
| <span lang="sv">Kan jag få notan?</span> | fråga efter notan | <span lang="sv">Kan jag få notan?</span> |
| <span lang="sv">Kan jag betala med kort?</span> | kortbetalning | <span lang="sv">Kan jag betala med kort?</span> |
| <span lang="sv">Det var allt, tack.</span> | inget mer behövs | <span lang="sv">Det var allt, tack.</span> |
| <span lang="sv">Tack, det var jättegott.</span> | tacka efter maten | <span lang="sv">Tack, det var jättegott.</span> |

## Kort dialog

| Talare | Svenska |
| --- | --- |
| A | <span lang="sv">Hej! Vad vill du ha?</span> |
| B | <span lang="sv">Jag skulle vilja ha en kaffe och en bulle.</span> |
| A | <span lang="sv">Vill du ha mjölk i kaffet?</span> |
| B | <span lang="sv">Ja tack, lite mjölk. Och kan jag få ett glas vatten?</span> |
| A | <span lang="sv">Självklart.</span> |
| B | <span lang="sv">Tack. Det var allt.</span> |

## Direkt jämförelse

<LanguageComparison title="Artig beställning">
	<p slot="de">Ich hätte gern einen Kaffee.</p>
	<p slot="en">I would like a coffee.</p>
	<p slot="sv">Jag skulle vilja ha en kaffe.</p>
</LanguageComparison>

Det här är den säkraste fullständiga ramen eftersom den innehåller
konditionalisen <span lang="sv">skulle</span>, önskeverbet <span lang="sv">vilja</span> och mottagarverbet
<span lang="sv">ha</span>.

<LanguageComparison title="Att ta med">
	<p slot="de">Einen Kaffee zum Mitnehmen, bitte.</p>
	<p slot="en">A coffee to go, please.</p>
	<p slot="sv">En kaffe att ta med, tack.</p>
</LanguageComparison>

Svenska använder en infinitivfras: bokstavligen ”en kaffe att ta med”. Lär dig
<span lang="sv">att ta med</span> som en fast kaféfras.
