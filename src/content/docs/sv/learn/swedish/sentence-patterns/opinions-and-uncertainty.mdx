<KeyTakeaway>
- <span lang="sv">tycker</span> uttrycker ett personligt omdöme, <span lang="sv">tror</span> en
  föreställning om fakta, <span lang="sv">vet</span> säker kunskap. Tyskans
  <span lang="de">glauben</span> och <span lang="de">finden</span> går inte
  att översätta rakt av.
- De flesta åsiktsramar tar en <span lang="sv">att</span>-sats, och <span lang="sv">att</span> utelämnas
  mycket mer sällan än engelskans *that*.
- Nekar du ramen, inte innehållet: <span lang="sv">Jag tror inte att han kommer.</span>
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

De här ramarna bär meningen medan du tänker ut resten av den. Lär dig dem
som hela enheter, inklusive <span lang="sv">att</span> som följer efter. För grammatiken
bakom <span lang="sv">borde</span> och andra modala val, använd
[Modala verb](../../grammar/verb-patterns-voice/modal-verbs/). För att
återge vad någon annan har sagt i stället för din egen ståndpunkt, använd
[Indirekt tal](../../grammar/mood-politeness-reports/reported-speech/).

## Uttrycka en åsikt

| Mönster | Vad det gör | Register |
| --- | --- | --- |
| <span lang="sv">Jag tycker att …</span> | personligt omdöme, smak, värdering | neutral |
| <span lang="sv">Jag tror att …</span> | en föreställning eller gissning om ett faktum | neutral |
| <span lang="sv">Jag anser att …</span> | genomtänkt, argumenterad ståndpunkt | formell |
| <span lang="sv">Enligt min mening …</span> | markerar att det som följer är din synvinkel | formell, skriftlig |
| <span lang="sv">Jag skulle säga att …</span> | mjukar upp påståendet | neutral |
| <span lang="sv">För mig är det …</span> | ramar in det som personligt, inte allmängiltigt | talspråk |

## Markera osäkerhet

| Mönster | Vad det gör | Register |
| --- | --- | --- |
| <span lang="sv">Jag är inte säker på om …</span> | uttrycker tvivel om ett sakförhållande | neutral |
| <span lang="sv">Jag vet inte riktigt.</span> | signalerar att du saknar ett tydligt svar | talspråk |
| <span lang="sv">Det beror på …</span> | pekar på vad som avgör svaret | neutral |
| <span lang="sv">Så vitt jag vet …</span> | reserverar uttalandet till din egen kännedom | neutral |
| <span lang="sv">Jag har ingen aning.</span> | markerar total avsaknad av svar | talspråk, rättframt |

## Göra ett antagande

| Mönster | Vad det gör | Register |
| --- | --- | --- |
| <span lang="sv">Jag antar att …</span> | uttrycker en rimlig gissning | neutral |
| <span lang="sv">Det verkar som om …</span> | bygger på ett intryck, inte säker vetskap | neutral |
| <span lang="sv">Det låter som …</span> | drar slutsatsen av vad du just hört | talspråk |
| <span lang="sv">Förmodligen …</span> / <span lang="sv">Troligen …</span> | anger hög sannolikhet | neutral till formell |
| <span lang="sv">Det borde vara …</span> | en slutsats dragen från tillgängliga tecken | neutral |

<span lang="sv">Förmodligen</span>, <span lang="sv">troligen</span> och <span lang="sv">så vitt jag vet</span> är
adverbial. Sätt dem först, och det finita verbet följer ändå direkt efter —
V2 bryr sig inte om att frasen är tre ord lång.

## Direkt jämförelse

<LanguageComparison title="Omdöme: tycker">
	<p slot="de">Ich finde, dass der Film gut ist.</p>
	<p slot="en">I think the film is good.</p>
	<p slot="sv">Jag tycker att filmen är bra.</p>
</LanguageComparison>

<LanguageComparison title="Föreställning om ett faktum: tror">
	<p slot="de">Ich glaube, dass er kommt.</p>
	<p slot="en">I think he is coming.</p>
	<p slot="sv">Jag tror att han kommer.</p>
</LanguageComparison>

Engelskans *I think* täcker båda raderna; svenskan tvingar fram valet.
Tyskans <span lang="de">finden</span> motsvarar <span lang="sv">tycker</span> och
<span lang="de">glauben</span> motsvarar <span lang="sv">tror</span>, vilket gör tyskan
till den säkrare bron här.

<LanguageComparison title="Mildra ett påstående">
	<p slot="de">Ich bin mir nicht sicher, ob das stimmt.</p>
	<p slot="en">I'm not sure if that's right.</p>
	<p slot="sv">Jag är inte säker på om det stämmer.</p>
</LanguageComparison>

Prepositionen hör till mönstret: <span lang="sv">säker på</span>, aldrig <span lang="sv">säker om</span>.
