<KeyTakeaway>
- Börja med <span lang="sv">Ursäkta, var ligger …?</span> för platser och
  <span lang="sv">Hur kommer jag till …?</span> för vägar.
- Använd <span lang="sv">till</span> för målet, <span lang="sv">mot</span> för riktningen och
  <span lang="sv">förbi</span> för att passera något.
- Riktningssvar är ofta imperativ:
  <span lang="sv">Gå rakt fram</span>, <span lang="sv">sväng vänster</span>, <span lang="sv">ta höger</span>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Den här sidan är till för gatuögonblicket: du behöver stoppa någon, fråga
enkelt och känna igen orden som säger vart du ska ta vägen härnäst.

För själva imperativformen, se
[Imperativ](../../grammar/verb-patterns-voice/imperative/). Den här sidan
håller sig till vägbeskrivningsskriptet.

## Ställa frågan

| Mönster | Använd det när … | Register |
| --- | --- | --- |
| <span lang="sv">Ursäkta, var ligger …?</span> | fråga var en plats ligger | neutral |
| <span lang="sv">Vet du var … ligger?</span> | mjukare: fråga om någon vet var det ligger | neutral |
| <span lang="sv">Hur kommer jag till …?</span> | fråga hur man tar sig dit | neutral |
| <span lang="sv">Är det långt härifrån?</span> | fråga om det är långt härifrån | neutral |
| <span lang="sv">Är det åt rätt håll?</span> | kontrollera om det är åt rätt håll | neutral |
| <span lang="sv">Kan du visa på kartan?</span> | be någon visa på kartan | neutral |

En vanlig svensk platsfråga är <span lang="sv">Var ligger stationen?</span> För hela
frågeordsmönstret, se
[Frågeord](../../grammar/questions-negation/question-words/). För en resväg,
använd <span lang="sv">till</span>: <span lang="sv">Hur kommer jag till stationen?</span>

## Förstå svaret

| Mönster | Betydelse |
| --- | --- |
| <span lang="sv">Gå rakt fram.</span> | fortsätt utan att svänga |
| <span lang="sv">Sväng vänster.</span> / <span lang="sv">Ta vänster.</span> | vänd åt vänster |
| <span lang="sv">Sväng höger.</span> / <span lang="sv">Ta höger.</span> | vänd åt höger |
| <span lang="sv">Gå förbi kyrkan.</span> | passera kyrkan till fots |
| <span lang="sv">Det ligger bredvid apoteket.</span> | det finns alldeles intill apoteket |
| <span lang="sv">Det ligger mittemot stationen.</span> | det finns snett emot stationen, på andra sidan |
| <span lang="sv">Det är på vänster sida.</span> | det befinner sig till vänster |

## Minisamtal på gatan

<p lang="sv">
	A: Ursäkta, var ligger biblioteket?
	<br />
	B: Gå rakt fram och sväng höger vid torget.
	<br />
	A: Är det långt härifrån?
	<br />
	B: Nej, det tar fem minuter.
</p>

## Direkt jämförelse

<LanguageComparison title="Var ligger det?">
	<p slot="de">Wo ist der Bahnhof?</p>
	<p slot="en">Where is the station?</p>
	<p slot="sv">Var ligger stationen?</p>
</LanguageComparison>

Svenskan använder ofta <span lang="sv">ligger</span> för var byggnader och platser
befinner sig. Frågan handlar inte om att något ligger ner; det är helt
enkelt det vanliga verbet för plats.

<LanguageComparison title="Hur tar jag mig dit?">
	<p slot="de">Wie komme ich zum Bahnhof?</p>
	<p slot="en">How do I get to the station?</p>
	<p slot="sv">Hur kommer jag till stationen?</p>
</LanguageComparison>
