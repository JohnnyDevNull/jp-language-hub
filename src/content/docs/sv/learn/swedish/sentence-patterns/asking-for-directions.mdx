<KeyTakeaway>
- Börja med <Sv>Ursäkta, var ligger …?</Sv> för platser och
  <Sv>Hur kommer jag till …?</Sv> för vägar.
- Använd <Sv>till</Sv> för målet, <Sv>mot</Sv> för riktningen och
  <Sv>förbi</Sv> för att passera något.
- Riktningssvar är ofta imperativ:
  <Sv>Gå rakt fram</Sv>, <Sv>sväng vänster</Sv>, <Sv>ta höger</Sv>.
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Den här sidan är till för gatuögonblicket: du behöver stoppa någon, fråga
enkelt och känna igen orden som säger vart du ska ta vägen härnäst.

För själva imperativformen, se
[Imperativ](../../grammar/verb-patterns-voice/imperative/). Den här sidan
håller sig till vägbeskrivningsskriptet.

## Ställa frågan

| Mönster | Använd det när … | Register |
| --- | --- | --- |
| <Sv>Ursäkta, var ligger …?</Sv> | fråga var en plats ligger | neutral |
| <Sv>Vet du var … ligger?</Sv> | mjukare: fråga om någon vet var det ligger | neutral |
| <Sv>Hur kommer jag till …?</Sv> | fråga hur man tar sig dit | neutral |
| <Sv>Är det långt härifrån?</Sv> | fråga om det är långt härifrån | neutral |
| <Sv>Är det åt rätt håll?</Sv> | kontrollera om det är åt rätt håll | neutral |
| <Sv>Kan du visa på kartan?</Sv> | be någon visa på kartan | neutral |

En vanlig svensk platsfråga är <Sv>Var ligger stationen?</Sv> För hela
frågeordsmönstret, se
[Frågeord](../../grammar/questions-negation/question-words/). För en resväg,
använd <Sv>till</Sv>: <Sv>Hur kommer jag till stationen?</Sv>

## Förstå svaret

| Mönster | Betydelse |
| --- | --- |
| <Sv>Gå rakt fram.</Sv> | fortsätt utan att svänga |
| <Sv>Sväng vänster.</Sv> / <Sv>Ta vänster.</Sv> | vänd åt vänster |
| <Sv>Sväng höger.</Sv> / <Sv>Ta höger.</Sv> | vänd åt höger |
| <Sv>Gå förbi kyrkan.</Sv> | passera kyrkan till fots |
| <Sv>Det ligger bredvid apoteket.</Sv> | det finns alldeles intill apoteket |
| <Sv>Det ligger mittemot stationen.</Sv> | det finns snett emot stationen, på andra sidan |
| <Sv>Det är på vänster sida.</Sv> | det befinner sig till vänster |

## Minisamtal på gatan

<p lang="sv">
	A: Ursäkta, var ligger biblioteket?
	<br />
	B: Gå rakt fram och sväng höger vid torget.
	<br />
	A: Är det långt härifrån?
	<br />
	B: Nej, det tar fem minuter.
</p>

## Direkt jämförelse

<LanguageComparison title="Var ligger det?">
	<p slot="de">Wo ist der Bahnhof?</p>
	<p slot="en">Where is the station?</p>
	<p slot="sv">Var ligger stationen?</p>
</LanguageComparison>

Svenskan använder ofta <Sv>ligger</Sv> för var byggnader och platser
befinner sig. Frågan handlar inte om att något ligger ner; det är helt
enkelt det vanliga verbet för plats.

<LanguageComparison title="Hur tar jag mig dit?">
	<p slot="de">Wie komme ich zum Bahnhof?</p>
	<p slot="en">How do I get to the station?</p>
	<p slot="sv">Hur kommer jag till stationen?</p>
</LanguageComparison>
