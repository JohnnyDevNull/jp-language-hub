<KeyTakeaway>
- Svenska håller igång ett samtal med mycket korta frågor:
  <span lang="sv">Hur så?</span>, <span lang="sv">Och sen då?</span>, <span lang="sv">Hur menar du?</span>
- <span lang="sv">Förresten</span> och <span lang="sv">apropå</span> är de två vanliga sätten att öppna
  ett ämnesbyte; <span lang="sv">apropå</span> knyter an till det som just sagts,
  <span lang="sv">förresten</span> behöver inte göra det.
- Ett avbrott aviseras, det bara startas inte:
  <span lang="sv">Förlåt att jag avbryter, men …</span>
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Det här är fraserna som får ett samtal att kännas dubbelriktat. Ingen av dem
bär på innehåll, och just därför kan de läras in som fasta enheter.

## Ställa en följdfråga

| Mönster | Vad det gör | Register |
| --- | --- | --- |
| <span lang="sv">Hur menar du?</span> | vad menar du med det | neutral |
| <span lang="sv">Hur så?</span> | varför det, hur kommer det sig | talspråk |
| <span lang="sv">Och sen då?</span> | och vad hände sedan | talspråk |
| <span lang="sv">Vad hände sen?</span> | vad hände efter det | talspråk |
| <span lang="sv">Berätta mer!</span> | be någon utveckla | talspråk |
| <span lang="sv">Menar du att …?</span> | kontrollera att du förstått rätt | neutral |
| <span lang="sv">Kan du utveckla det?</span> | be om ett mer utförligt svar | neutral till formell |

## Fortsätta och byta ämne

| Mönster | Vad det gör | Register |
| --- | --- | --- |
| <span lang="sv">Just det, och …</span> | hålla med och sedan lägga till något | talspråk |
| <span lang="sv">Som sagt …</span> | återknyta till en poäng som redan nämnts | neutral |
| <span lang="sv">Apropå det …</span> | på tal om det | neutral |
| <span lang="sv">Förresten …</span> | inleda en sidoreplik | talspråk |
| <span lang="sv">En annan sak …</span> | föra in ett nytt ämne | talspråk |
| <span lang="sv">För att byta ämne …</span> | markera ett medvetet ämnesbyte | neutral |

## Avbryta artigt

| Mönster | Vad det gör | Register |
| --- | --- | --- |
| <span lang="sv">Förlåt att jag avbryter, men …</span> | be om ursäkt innan ett avbrott | neutral |
| <span lang="sv">Ursäkta, men …</span> | be om uppmärksamhet innan invändningen | neutral |
| <span lang="sv">Får jag säga en sak?</span> | be om utrymme att komma till tals | neutral |

## Sammanfatta

| Mönster | Vad det gör | Register |
| --- | --- | --- |
| <span lang="sv">Kort sagt …</span> | sammanfatta i få ord | neutral |
| <span lang="sv">Sammanfattningsvis …</span> | inleda en formell sammanfattning | formell, skriftlig |
| <span lang="sv">Så det du säger är att …</span> | kontrollera din tolkning av den andra | neutral |
| <span lang="sv">Om jag förstår dig rätt …</span> | be om bekräftelse på din tolkning | neutral |
| <span lang="sv">Med andra ord …</span> | omformulera det som sagts | neutral |

## Direkt jämförelse

<LanguageComparison title="Förresten">
	<p slot="de">Übrigens, ich habe Anna getroffen.</p>
	<p slot="en">By the way, I met Anna.</p>
	<p slot="sv">Förresten, jag träffade Anna.</p>
</LanguageComparison>

<LanguageComparison title="Avisera ett avbrott">
	<p slot="de">Entschuldige, dass ich unterbreche, aber …</p>
	<p slot="en">Sorry to interrupt, but …</p>
	<p slot="sv">Förlåt att jag avbryter, men …</p>
</LanguageComparison>

<span lang="sv">Förlåt</span> ber om ursäkt för något du själv gör; <span lang="sv">ursäkta</span> ber om
uppmärksamhet. Båda fungerar här, och <span lang="sv">att</span>-satsen är obligatorisk i
det första mönstret.

<LanguageComparison title="Spela tillbaka en poäng">
	<p slot="de">Du sagst also, dass es zu teuer ist.</p>
	<p slot="en">So what you're saying is that it's too expensive.</p>
	<p slot="sv">Så det du säger är att det är för dyrt.</p>
</LanguageComparison>
