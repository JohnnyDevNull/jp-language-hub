<KeyTakeaway>
- Använd <span lang="sv">Jag heter ...</span> som den normala första meningen; den betyder
  "jag kallas", inte bokstavligen "jag namnger".
- Använd <span lang="sv">kommer från</span> för ursprung och <span lang="sv">bor i</span> för var du bor nu.
- Fråga tillbaka med samma ram: <span lang="sv">Vad heter du?</span>,
  <span lang="sv">Var kommer du ifrån?</span>, <span lang="sv">Vad gör du?</span>
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Det här är den minsta användbara självpresentationen: namn, ursprung, plats, ett
skäl till att du är här och en fråga tillbaka.

## Grundmönster för att presentera dig

| Mönster | Använd det för | Exempel |
| --- | --- | --- |
| <span lang="sv">Hej, jag heter ...</span> | öppna med ditt namn | <span lang="sv">Hej, jag heter Philipp.</span> |
| <span lang="sv">Jag kommer från ...</span> | land, stad, bakgrund | <span lang="sv">Jag kommer från Tyskland.</span> |
| <span lang="sv">Jag bor i ...</span> | var du bor nu | <span lang="sv">Jag bor i Stockholm.</span> |
| <span lang="sv">Jag jobbar som ...</span> | yrkesroll | <span lang="sv">Jag jobbar som utvecklare.</span> |
| <span lang="sv">Jag pluggar ...</span> | ämne du studerar | <span lang="sv">Jag pluggar svenska.</span> |
| <span lang="sv">Jag lär mig svenska.</span> | varför du talar långsamt | <span lang="sv">Jag lär mig svenska.</span> |
| <span lang="sv">Trevligt att träffas.</span> | hälsningsfras vid en första träff | <span lang="sv">Trevligt att träffas!</span> |

## Fråga tillbaka

| Fråga | Vad den frågar om | Naturligt svar |
| --- | --- | --- |
| <span lang="sv">Vad heter du?</span> | namn | <span lang="sv">Jag heter Anna.</span> |
| <span lang="sv">Var kommer du ifrån?</span> | ursprung | <span lang="sv">Jag kommer från Malmö.</span> |
| <span lang="sv">Var bor du?</span> | var du bor nu | <span lang="sv">Jag bor i Uppsala.</span> |
| <span lang="sv">Vad gör du?</span> | arbete eller studier, i kontext | <span lang="sv">Jag pluggar.</span> |
| <span lang="sv">Hur länge har du bott här?</span> | hur länge du har bott här | <span lang="sv">I två år.</span> |

Med städer och länder är <span lang="sv">i</span> det säkra tidiga mönstret:
<span lang="sv">i Sverige</span>, <span lang="sv">i Stockholm</span>, <span lang="sv">i Tyskland</span>. Gatunamn och
vissa institutioner använder ofta <span lang="sv">på</span>, men spara det till
prepositionssidan.

## Minisekvens

| Talare | Svenska |
| --- | --- |
| A | <span lang="sv">Hej, jag heter Anna. Vad heter du?</span> |
| B | <span lang="sv">Jag heter Philipp. Trevligt att träffas.</span> |
| A | <span lang="sv">Trevligt! Var kommer du ifrån?</span> |
| B | <span lang="sv">Jag kommer från Tyskland, men jag bor i Stockholm.</span> |
| A | <span lang="sv">Vad gör du?</span> |
| B | <span lang="sv">Jag jobbar som utvecklare och jag lär mig svenska.</span> |

## Direkt jämförelse

<LanguageComparison title="Namn">
	<p slot="de">Ich heiße Philipp.</p>
	<p slot="en">My name is Philipp.</p>
	<p slot="sv">Jag heter Philipp.</p>
</LanguageComparison>

Tyska är den bättre bron här: <span lang="de">heißen</span> och <span lang="sv">heta</span>
beter sig båda som "kallas". Engelska lockar dig mot en nominalfras, men den
vardagliga svenska meningen är verbmönstret.

<LanguageComparison title="Ursprung och nuvarande hem">
	<p slot="de">Ich komme aus Deutschland, aber ich wohne in Stockholm.</p>
	<p slot="en">I am from Germany, but I live in Stockholm.</p>
	<p slot="sv">Jag kommer från Tyskland, men jag bor i Stockholm.</p>
</LanguageComparison>
