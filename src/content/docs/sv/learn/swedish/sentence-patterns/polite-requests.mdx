<KeyTakeaway>
- <span lang="sv">Kan jag få ...?</span> är standardmönstret när du ber om att få en sak.
- <span lang="sv">Kan du ...?</span> ber någon göra något; <span lang="sv">Skulle du kunna ...?</span> gör
  samma begäran mjukare.
- Sätt <span lang="sv">tack</span> sist i korta servicebegäranden:
  <span lang="sv">En kaffe, tack.</span>
</KeyTakeaway>

<TagList levels={frontmatter.levels} tags={frontmatter.tags} />

Artig svenska är oftast direkt men mjukas upp av rätt ram, ton och
<span lang="sv">tack</span>. Du behöver ingen lång ursäkt innan varje begäran.

## Be om en sak

| Mönster | Använd det för | Exempel |
| --- | --- | --- |
| <span lang="sv">Kan jag få ...?</span> | att få eller begära en sak | <span lang="sv">Kan jag få ett kvitto?</span> |
| <span lang="sv">Jag skulle vilja ha ...</span> | jag skulle vilja ha; artig standardform | <span lang="sv">Jag skulle vilja ha en kaffe.</span> |
| <span lang="sv">En ..., tack.</span> | kort beställning i disken | <span lang="sv">En bulle, tack.</span> |
| <span lang="sv">Har ni ...?</span> | fråga om de har något | <span lang="sv">Har ni havremjölk?</span> |
| <span lang="sv">Finns det ...?</span> | fråga om något finns | <span lang="sv">Finns det en toalett här?</span> |

## Be någon göra något

| Mönster | Använd det för | Exempel |
| --- | --- | --- |
| <span lang="sv">Kan du ...?</span> | enkel begäran | <span lang="sv">Kan du hjälpa mig?</span> |
| <span lang="sv">Skulle du kunna ...?</span> | mjukare begäran | <span lang="sv">Skulle du kunna skriva ner det?</span> |
| <span lang="sv">Kan du säga det igen?</span> | be om upprepning | <span lang="sv">Kan du säga det igen?</span> |
| <span lang="sv">Kan du prata lite långsammare?</span> | be om långsammare tal | <span lang="sv">Kan du prata lite långsammare?</span> |
| <span lang="sv">Ursäkta, var ligger ...?</span> | fråga efter en plats | <span lang="sv">Ursäkta, var ligger stationen?</span> |

## Mjuka upp och avsluta

| Mönster | Använd det för | Exempel |
| --- | --- | --- |
| <span lang="sv">Ursäkta ...</span> | få uppmärksamhet | <span lang="sv">Ursäkta, kan du hjälpa mig?</span> |
| <span lang="sv">lite</span> | mjuka upp en mängd eller grad | <span lang="sv">Kan du prata lite långsammare?</span> |
| <span lang="sv">om det går</span> | om det är möjligt | <span lang="sv">Jag skulle vilja byta tid, om det går.</span> |
| <span lang="sv">Tack så mycket.</span> | tacka mycket | <span lang="sv">Tack så mycket!</span> |
| <span lang="sv">Ingen fara.</span> | inget problem | <span lang="sv">Ingen fara.</span> |

## Minisekvens

| Talare | Svenska |
| --- | --- |
| A | <span lang="sv">Ursäkta, kan du hjälpa mig?</span> |
| B | <span lang="sv">Ja, absolut.</span> |
| A | <span lang="sv">Kan du säga det igen, lite långsammare?</span> |
| B | <span lang="sv">Självklart.</span> |
| A | <span lang="sv">Tack så mycket.</span> |

## Direkt jämförelse

<LanguageComparison title="Kan jag få?">
	<p slot="de">Kann ich bitte eine Quittung bekommen?</p>
	<p slot="en">Can I have a receipt, please?</p>
	<p slot="sv">Kan jag få ett kvitto?</p>
</LanguageComparison>

<span lang="sv">få</span> är det användbara serviceverbet här: du ber om att få något. Ett
avslutande <span lang="sv">tack</span> kan läggas till, men ramen är redan artig i en vanlig
servicesituation.

<LanguageComparison title="Kan du?">
	<p slot="de">Könntest du das bitte aufschreiben?</p>
	<p slot="en">Could you write that down, please?</p>
	<p slot="sv">Skulle du kunna skriva ner det?</p>
</LanguageComparison>

Svenskan använder <span lang="sv">skulle</span> + <span lang="sv">kunna</span> för att mjuka upp begäran,
ungefär som tyskan och engelskan använder ett konditionalt modalverb.
