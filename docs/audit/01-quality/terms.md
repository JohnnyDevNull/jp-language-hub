# Term Register

Grammar terms that need a gloss (see `rubric.md`). Source for the glossary
pages. Tree: `sv`, `en`, `de` = the learning-language glossary the term
belongs in; a term used in several trees is listed once per tree.

| Term | Tree | Plain gloss (draft) | Seen in |
| --- | --- | --- | --- |
| supine (`supinum`) | sv | verb form used after `har`/`hade` | P0 perfect, verb-forms |
| finite verb (`finit verb`) | sv, de | the verb that shows tense | P0 perfect, biff, from-german |
| non-finite verb (`infinit verb`) | sv | verb form without tense | P0 biff |
| auxiliary | sv, en | helper verb, e.g. `har`, `have` | P0 perfect, present-perfect |
| past participle | en | form after `have`: `seen`, `worked` | P0 present-perfect |
| participle | sv | verb form used like an adjective | P0 verb-forms |
| preterite (`preteritum`) | sv | simple past form: `köpte` | P0 perfect, verb-forms |
| imperative | sv | command form: `köp!` | P0 verb-forms |
| infinitive | sv | basic form: `(att) köpa` | P0 verb-forms |
| subordinate clause (`bisats`) | sv | part-sentence that cannot stand alone | P0 biff, perfect |
| sentence adverb (`satsadverbial`) | sv | word like `inte`, `aldrig`, `kanske` | P0 biff |
| `fundament` | sv | first position before the verb | P0 biff |
| V2 | sv | verb always in second position | P0 perfect |
| BIFF | sv | memory rule for `inte` in subordinate clauses | P0 perfect |
| predicative adjective | sv | adjective after `är`: `Huset är stort` | P0 from-german |
| inflect | sv | change a word's ending | P0 from-german |
| s-passive | sv | passive with `-s`: `städas` | P0 verb-forms |
| agent | sv | who does the action in a passive | P0 verb-forms |
| compound | sv | word built from two words | P0 family-and-relatives |
| case | de | form that shows a word's role | P0 dative |
| dative | de | case for receivers and many prepositions | P0 dative |
| two-way preposition (`Wechselpräposition`) | de | preposition taking dative or accusative | P0 dative |
